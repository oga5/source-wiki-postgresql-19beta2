3Tests for SASLprep
4==================
5
6This repository contains a test suite for stressing the SASLprep
7implementation internal to PostgreSQL.
8
9It provides a set of functions able to check the validity of a SASLprep
10operation for a single byte as well as a range of these, acting as
11wrappers around pg_saslprep().
12
13Running the tests
14=================
15
16NOTE: A portion of the tests requires --enable-tap-tests, with
17PG_TEST_EXTRA=saslprep set to run the TAP test suite.
18
19Run
20    make check PG_TEST_EXTRA=saslprep
21or
22    make installcheck PG_TEST_EXTRA=saslprep
23
24The SQL test suite can run with or without PG_TEST_EXTRA=saslprep
25set.
