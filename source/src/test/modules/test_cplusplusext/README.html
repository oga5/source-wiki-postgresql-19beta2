1test_cplusplusext - Test C++ Extension Compatibility
2====================================================
3
4This test module verifies that PostgreSQL headers and macros work
5correctly when compiled with a C++ compiler.
6
7While PostgreSQL already tests that headers are syntactically valid
8C++ using headerscheck, the macros defined in those headers might
9still expand to invalid C++ code.  This module catches such issues by
10actually compiling and running an extension that's written in C++.
