227 <reference id="reference-client">
228  <title>PostgreSQL Client Applications</title>
229
230  <partintro>
231   <para>
232    This part contains reference information for
233    <productname>PostgreSQL</productname> client applications and
234    utilities.  Not all of these commands are of general utility; some
235    might require special privileges.  The common feature of these
236    applications is that they can be run on any host, independent of
237    where the database server resides.
238   </para>
239
240   <para>
241    When specified on the command line, user and database names have
242    their case preserved &mdash; the presence of spaces or special
243    characters might require quoting.  Table names and other identifiers
244    do not have their case preserved, except where documented, and
245    might require quoting.
246   </para>
247  </partintro>
