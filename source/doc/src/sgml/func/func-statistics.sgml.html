14  <sect2 id="functions-statistics-mcv">
15   <title>Inspecting MCV Lists</title>
16
17   <indexterm>
18    <primary>pg_mcv_list_items</primary>
19   </indexterm>
20
21<synopsis>
22<function>pg_mcv_list_items</function> ( <type>pg_mcv_list</type> ) <returnvalue>setof record</returnvalue>
23</synopsis>
24
25   <para>
26    <function>pg_mcv_list_items</function> returns a set of records describing
27    all items stored in a multi-column <acronym>MCV</acronym> list.  It
28    returns the following columns:
29
30    <informaltable>
31     <tgroup cols="3">
32      <thead>
33       <row>
34        <entry>Name</entry>
35        <entry>Type</entry>
36        <entry>Description</entry>
37       </row>
38      </thead>
39
40      <tbody>
41       <row>
42        <entry><literal>index</literal></entry>
43        <entry><type>integer</type></entry>
44        <entry>index of the item in the <acronym>MCV</acronym> list</entry>
45       </row>
46       <row>
47        <entry><literal>values</literal></entry>
48        <entry><type>text[]</type></entry>
49        <entry>values stored in the MCV item</entry>
50       </row>
51       <row>
52        <entry><literal>nulls</literal></entry>
53        <entry><type>boolean[]</type></entry>
54        <entry>flags identifying <literal>NULL</literal> values</entry>
55       </row>
56       <row>
57        <entry><literal>frequency</literal></entry>
58        <entry><type>double precision</type></entry>
59        <entry>frequency of this <acronym>MCV</acronym> item</entry>
60       </row>
61       <row>
62        <entry><literal>base_frequency</literal></entry>
63        <entry><type>double precision</type></entry>
64        <entry>base frequency of this <acronym>MCV</acronym> item</entry>
65       </row>
66      </tbody>
67     </tgroup>
68    </informaltable>
69   </para>
70
71   <para>
72    The <function>pg_mcv_list_items</function> function can be used like this:
73
74<programlisting>
75SELECT m.* FROM pg_statistic_ext join pg_statistic_ext_data on (oid = stxoid),
76                pg_mcv_list_items(stxdmcv) m WHERE stxname = 'stts';
77</programlisting>
78
79    Values of the <type>pg_mcv_list</type> type can be obtained only from the
80    <structname>pg_statistic_ext_data</structname>.<structfield>stxdmcv</structfield>
81    column.
82   </para>
