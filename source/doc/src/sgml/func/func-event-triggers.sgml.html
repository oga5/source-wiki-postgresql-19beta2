14  <sect2 id="pg-event-trigger-ddl-command-end-functions">
15   <title>Capturing Changes at Command End</title>
16
17   <indexterm>
18    <primary>pg_event_trigger_ddl_commands</primary>
19   </indexterm>
20
21<synopsis>
22<function>pg_event_trigger_ddl_commands</function> () <returnvalue>setof record</returnvalue>
23</synopsis>
24
25   <para>
26    <function>pg_event_trigger_ddl_commands</function> returns a list of
27    <acronym>DDL</acronym> commands executed by each user action,
28    when invoked in a function attached to a
29    <literal>ddl_command_end</literal> event trigger.  If called in any other
30    context, an error is raised.
31    <function>pg_event_trigger_ddl_commands</function> returns one row for each
32    base command executed; some commands that are a single SQL sentence
33    may return more than one row.  This function returns the following
34    columns:
35
36    <informaltable>
37     <tgroup cols="3">
38      <thead>
39       <row>
40        <entry>Name</entry>
41        <entry>Type</entry>
42        <entry>Description</entry>
43       </row>
44      </thead>
45
46      <tbody>
47       <row>
48        <entry><literal>classid</literal></entry>
49        <entry><type>oid</type></entry>
50        <entry>OID of catalog the object belongs in</entry>
51       </row>
52       <row>
53        <entry><literal>objid</literal></entry>
54        <entry><type>oid</type></entry>
55        <entry>OID of the object itself</entry>
56       </row>
57       <row>
58        <entry><literal>objsubid</literal></entry>
59        <entry><type>integer</type></entry>
60        <entry>Sub-object ID (e.g., attribute number for a column)</entry>
61       </row>
62       <row>
63        <entry><literal>command_tag</literal></entry>
64        <entry><type>text</type></entry>
65        <entry>Command tag</entry>
66       </row>
67       <row>
68        <entry><literal>object_type</literal></entry>
69        <entry><type>text</type></entry>
70        <entry>Type of the object</entry>
71       </row>
72       <row>
73        <entry><literal>schema_name</literal></entry>
74        <entry><type>text</type></entry>
75        <entry>
76         Name of the schema the object belongs in, if any; otherwise <literal>NULL</literal>.
77         No quoting is applied.
78        </entry>
79       </row>
80       <row>
81        <entry><literal>object_identity</literal></entry>
82        <entry><type>text</type></entry>
83        <entry>
84         Text rendering of the object identity, schema-qualified. Each
85         identifier included in the identity is quoted if necessary.
86        </entry>
87       </row>
88       <row>
89        <entry><literal>in_extension</literal></entry>
90        <entry><type>boolean</type></entry>
91        <entry>True if the command is part of an extension script</entry>
92       </row>
93       <row>
94        <entry><literal>command</literal></entry>
95        <entry><type>pg_ddl_command</type></entry>
96        <entry>
97         A complete representation of the command, in internal format.
98         This cannot be output directly, but it can be passed to other
99         functions to obtain different pieces of information about the
100         command.
101        </entry>
102       </row>
103      </tbody>
104     </tgroup>
105    </informaltable>
106   </para>

109  <sect2 id="pg-event-trigger-sql-drop-functions">
110   <title>Processing Objects Dropped by a DDL Command</title>
111
112   <indexterm>
113     <primary>pg_event_trigger_dropped_objects</primary>
114   </indexterm>
115
116<synopsis>
117<function>pg_event_trigger_dropped_objects</function> () <returnvalue>setof record</returnvalue>
118</synopsis>
119
120   <para>
121    <function>pg_event_trigger_dropped_objects</function> returns a list of all objects
122    dropped by the command in whose <literal>sql_drop</literal> event it is called.
123    If called in any other context, an error is raised.
124    This function returns the following columns:
125
126    <informaltable>
127     <tgroup cols="3">
128      <thead>
129       <row>
130        <entry>Name</entry>
131        <entry>Type</entry>
132        <entry>Description</entry>
133       </row>
134      </thead>
135
136      <tbody>
137       <row>
138        <entry><literal>classid</literal></entry>
139        <entry><type>oid</type></entry>
140        <entry>OID of catalog the object belonged in</entry>
141       </row>
142       <row>
143        <entry><literal>objid</literal></entry>
144        <entry><type>oid</type></entry>
145        <entry>OID of the object itself</entry>
146       </row>
147       <row>
148        <entry><literal>objsubid</literal></entry>
149        <entry><type>integer</type></entry>
150        <entry>Sub-object ID (e.g., attribute number for a column)</entry>
151       </row>
152       <row>
153        <entry><literal>original</literal></entry>
154        <entry><type>boolean</type></entry>
155        <entry>True if this was one of the root object(s) of the deletion</entry>
156       </row>
157       <row>
158        <entry><literal>normal</literal></entry>
159        <entry><type>boolean</type></entry>
160        <entry>
161         True if there was a normal dependency relationship
162         in the dependency graph leading to this object
163        </entry>
164       </row>
165       <row>
166        <entry><literal>is_temporary</literal></entry>
167        <entry><type>boolean</type></entry>
168        <entry>
169         True if this was a temporary object
170        </entry>
171       </row>
172       <row>
173        <entry><literal>object_type</literal></entry>
174        <entry><type>text</type></entry>
175        <entry>Type of the object</entry>
176       </row>
177       <row>
178        <entry><literal>schema_name</literal></entry>
179        <entry><type>text</type></entry>
180        <entry>
181         Name of the schema the object belonged in, if any; otherwise <literal>NULL</literal>.
182         No quoting is applied.
183        </entry>
184       </row>
185       <row>
186        <entry><literal>object_name</literal></entry>
187        <entry><type>text</type></entry>
188        <entry>
189         Name of the object, if the combination of schema and name can be
190         used as a unique identifier for the object; otherwise <literal>NULL</literal>.
191         No quoting is applied, and name is never schema-qualified.
192        </entry>
193       </row>
194       <row>
195        <entry><literal>object_identity</literal></entry>
196        <entry><type>text</type></entry>
197        <entry>
198         Text rendering of the object identity, schema-qualified. Each
199         identifier included in the identity is quoted if necessary.
200        </entry>
201       </row>
202       <row>
203        <entry><literal>address_names</literal></entry>
204        <entry><type>text[]</type></entry>
205        <entry>
206         An array that, together with <literal>object_type</literal> and
207         <literal>address_args</literal>, can be used by
208         the <function>pg_get_object_address</function> function to
209         recreate the object address in a remote server containing an
210         identically named object of the same kind.
211        </entry>
212       </row>
213       <row>
214        <entry><literal>address_args</literal></entry>
215        <entry><type>text[]</type></entry>
216        <entry>
217         Complement for <literal>address_names</literal>
218        </entry>
219       </row>
220      </tbody>
221     </tgroup>
222    </informaltable>
223   </para>
224
225   <para>
226    The <function>pg_event_trigger_dropped_objects</function> function can be used
227    in an event trigger like this:
228<programlisting>
229CREATE FUNCTION test_event_trigger_for_drops()
230        RETURNS event_trigger LANGUAGE plpgsql AS $$
231DECLARE
232    obj record;
233BEGIN
234    FOR obj IN SELECT * FROM pg_event_trigger_dropped_objects()
235    LOOP
236        RAISE NOTICE '% dropped object: % %.% %',
237                     tg_tag,
238                     obj.object_type,
239                     obj.schema_name,
240                     obj.object_name,
241                     obj.object_identity;
242    END LOOP;
243END;
244$$;
245CREATE EVENT TRIGGER test_event_trigger_for_drops
246   ON sql_drop
247   EXECUTE FUNCTION test_event_trigger_for_drops();
248</programlisting>
249    </para>

252  <sect2 id="pg-event-trigger-table-rewrite-functions">
253   <title>Handling a Table Rewrite Event</title>
254
255   <para>
256    The functions shown in
257    <xref linkend="functions-event-trigger-table-rewrite"/>
258    provide information about a table for which a
259    <literal>table_rewrite</literal> event has just been called.
260    If called in any other context, an error is raised.
261   </para>
262
263   <table id="functions-event-trigger-table-rewrite">
264    <title>Table Rewrite Information Functions</title>
265    <tgroup cols="1">
266     <thead>
267      <row>
268       <entry role="func_table_entry"><para role="func_signature">
269        Function
270       </para>
271       <para>
272        Description
273       </para></entry>
274      </row>
275     </thead>
276
277     <tbody>
278      <row>
279       <entry role="func_table_entry"><para role="func_signature">
280        <indexterm>
281         <primary>pg_event_trigger_table_rewrite_oid</primary>
282        </indexterm>
283        <function>pg_event_trigger_table_rewrite_oid</function> ()
284        <returnvalue>oid</returnvalue>
285       </para>
286       <para>
287        Returns the OID of the table about to be rewritten.
288       </para></entry>
289      </row>
290
291      <row>
292       <entry role="func_table_entry"><para role="func_signature">
293        <indexterm>
294         <primary>pg_event_trigger_table_rewrite_reason</primary>
295        </indexterm>
296        <function>pg_event_trigger_table_rewrite_reason</function> ()
297        <returnvalue>integer</returnvalue>
298       </para>
299       <para>
300        Returns a code explaining the reason(s) for rewriting. The value is
301        a bitmap built from the following values: <literal>1</literal>
302        (the table has changed its persistence), <literal>2</literal>
303        (default value of a column has changed), <literal>4</literal>
304        (a column has a new data type) and <literal>8</literal>
305        (the table access method has changed).
306       </para></entry>
307      </row>
308     </tbody>
309    </tgroup>
310   </table>
311
312   <para>
313    These functions can be used in an event trigger like this:
314<programlisting>
315CREATE FUNCTION test_event_trigger_table_rewrite_oid()
316 RETURNS event_trigger
317 LANGUAGE plpgsql AS
318$$
319BEGIN
320  RAISE NOTICE 'rewriting table % for reason %',
321                pg_event_trigger_table_rewrite_oid()::regclass,
322                pg_event_trigger_table_rewrite_reason();
323END;
324$$;
325
326CREATE EVENT TRIGGER test_table_rewrite_oid
327                  ON table_rewrite
328   EXECUTE FUNCTION test_event_trigger_table_rewrite_oid();
329</programlisting>
330    </para>
