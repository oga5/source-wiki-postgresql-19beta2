2  <title>Enum Support Functions</title>
3
4  <para>
5   For enum types (described in <xref linkend="datatype-enum"/>),
6   there are several functions that allow cleaner programming without
7   hard-coding particular values of an enum type.
8   These are listed in <xref linkend="functions-enum-table"/>. The examples
9   assume an enum type created as:
10
11<programlisting>
12CREATE TYPE rainbow AS ENUM ('red', 'orange', 'yellow', 'green', 'blue', 'purple');
13</programlisting>
14
15  </para>

77       </para>

79        <literal>enum_range(null::rainbow)</literal>
80        <returnvalue>{red,orange,yellow,&zwsp;green,blue,purple}</returnvalue>
81       </para></entry>
82      </row>
83      <row>
84       <entry role="func_table_entry"><para role="func_signature">
85        <function>enum_range</function> ( <type>anyenum</type>, <type>anyenum</type> )
86        <returnvalue>anyarray</returnvalue>
87       </para>
88       <para>
89        Returns the range between the two given enum values, as an ordered
90        array. The values must be from the same enum type. If the first
91        parameter is null, the result will start with the first value of
92        the enum type.
93        If the second parameter is null, the result will end with the last
94        value of the enum type.
95       </para>
96       <para>
97        <literal>enum_range('orange'::rainbow, 'green'::rainbow)</literal>
98        <returnvalue>{orange,yellow,green}</returnvalue>
99       </para>
100       <para>
101        <literal>enum_range(NULL, 'green'::rainbow)</literal>
102        <returnvalue>{red,orange,&zwsp;yellow,green}</returnvalue>
103       </para>
104       <para>
105        <literal>enum_range('orange'::rainbow, NULL)</literal>
106        <returnvalue>{orange,yellow,green,&zwsp;blue,purple}</returnvalue>
107       </para></entry>
108      </row>

111   </table>
112
113   <para>
114    Notice that except for the two-argument form of <function>enum_range</function>,
115    these functions disregard the specific value passed to them; they care
116    only about its declared data type.  Either null or a specific value of
117    the type can be passed, with the same result.  It is more common to
118    apply these functions to a table column or function argument than to
119    a hardwired type name as used in the examples.
120   </para>
