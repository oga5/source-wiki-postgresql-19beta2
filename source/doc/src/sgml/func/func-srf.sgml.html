9  <para>
10   This section describes functions that possibly return more than one row.
11   The most widely used functions in this class are series generating
12   functions, as detailed in <xref linkend="functions-srf-series"/> and
13   <xref linkend="functions-srf-subscripts"/>.  Other, more specialized
14   set-returning functions are described elsewhere in this manual.
15   See <xref linkend="queries-tablefunctions"/> for ways to combine multiple
16   set-returning functions.
17  </para>

81  <para>
82   When <parameter>step</parameter> is positive, zero rows are returned if
83   <parameter>start</parameter> is greater than <parameter>stop</parameter>.
84   Conversely, when <parameter>step</parameter> is negative, zero rows are
85   returned if <parameter>start</parameter> is less than <parameter>stop</parameter>.
86   Zero rows are also returned if any input is <literal>NULL</literal>.
87   It is an error
88   for <parameter>step</parameter> to be zero. Some examples follow:
89<programlisting>
90SELECT * FROM generate_series(2,4);
91 generate_series
92-----------------
93               2
94               3
95               4
96(3 rows)
97
98SELECT * FROM generate_series(5,1,-2);
99 generate_series
100-----------------
101               5
102               3
103               1
104(3 rows)
105
106SELECT * FROM generate_series(4,3);
107 generate_series
108-----------------
109(0 rows)
110
111SELECT generate_series(1.1, 4, 1.3);
112 generate_series
113-----------------
114             1.1
115             2.4
116             3.7
117(3 rows)
118

120SELECT current_date + s.a AS dates FROM generate_series(0,14,7) AS s(a);

123 2004-02-05
124 2004-02-12
125 2004-02-19

209  <para>
210   <function>generate_subscripts</function> is a convenience function that generates
211   the set of valid subscripts for the specified dimension of the given
212   array.
213   Zero rows are returned for arrays that do not have the requested dimension,
214   or if any input is <literal>NULL</literal>.
215   Some examples follow:
216<programlisting>
217-- basic usage:
218SELECT generate_subscripts('{NULL,1,NULL,2}'::int[], 1) AS s;
219 s
220---
221 1
222 2
223 3
224 4
225(4 rows)
226
227-- presenting an array, the subscript and the subscripted
228-- value requires a subquery:
229SELECT * FROM arrays;
230         a
231--------------------
232 {-1,-2}
233 {100,200,300}
234(2 rows)
235
236SELECT a AS array, s AS subscript, a[s] AS value
237FROM (SELECT generate_subscripts(a, 1) AS s, a FROM arrays) foo;
238     array     | subscript | value
239---------------+-----------+-------
240 {-1,-2}       |         1 |    -1
241 {-1,-2}       |         2 |    -2
242 {100,200,300} |         1 |   100
243 {100,200,300} |         2 |   200
244 {100,200,300} |         3 |   300
245(5 rows)
246
247-- unnest a 2D array:
248CREATE OR REPLACE FUNCTION unnest2(anyarray)
249RETURNS SETOF anyelement AS $$
250SELECT $1[i][j]
251   FROM generate_subscripts($1,1) g1(i),
252        generate_subscripts($1,2) g2(j);
253$$ LANGUAGE sql IMMUTABLE;
254CREATE FUNCTION
255SELECT * FROM unnest2(ARRAY[[1,2],[3,4]]);
256 unnest2
257---------
258       1
259       2
260       3
261       4
262(4 rows)
263</programlisting>
264  </para>

270  <para>
271   When a function in the <literal>FROM</literal> clause is suffixed
272   by <literal>WITH ORDINALITY</literal>, a <type>bigint</type> column is
273   appended to the function's output column(s), which starts from 1 and
274   increments by 1 for each row of the function's output.
275   This is most useful in the case of set returning
276   functions such as <function>unnest()</function>.
277
278<programlisting>
279-- set returning function WITH ORDINALITY:
280SELECT * FROM pg_ls_dir('.') WITH ORDINALITY AS t(ls,n);
