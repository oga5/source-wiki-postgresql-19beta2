56 <refsect1>
57  <title>Description</title>
58
59  <para>
60   <command>ALTER PROPERTY GRAPH</command> changes the definition of an
61   existing property graph.  There are several subforms:
62
63   <variablelist>
64    <varlistentry>
65     <term><literal>ADD {VERTEX|NODE|EDGE|RELATIONSHIP} TABLES</literal></term>
66     <listitem>
67      <para>
68       This form adds new vertex or edge tables to the property graph, using the
69       same syntax as <link linkend="sql-create-property-graph"><command>CREATE
70       PROPERTY GRAPH</command></link>.
71      </para>
72     </listitem>
73    </varlistentry>
74
75    <varlistentry>
76     <term><literal>DROP {VERTEX|NODE|EDGE|RELATIONSHIP} TABLES</literal></term>
77     <listitem>
78      <para>
79       This form removes vertex or edge tables from the property graph.  (Only
80       the association of the tables with the graph is removed.  The tables
81       themselves are not dropped.)
82      </para>
83     </listitem>
84    </varlistentry>
85
86    <varlistentry>
87     <term><literal>ALTER {VERTEX|NODE|EDGE|RELATIONSHIP} TABLE ... ADD LABEL</literal></term>
88     <listitem>
89      <para>
90       This form adds a new label to an existing vertex or edge table, using
91       the same syntax as <link
92       linkend="sql-create-property-graph"><command>CREATE PROPERTY
93       GRAPH</command></link>.
94      </para>
95     </listitem>
96    </varlistentry>
97
98    <varlistentry>
99     <term><literal>ALTER {VERTEX|NODE|EDGE|RELATIONSHIP} TABLE ... DROP LABEL</literal></term>
100     <listitem>
101      <para>
102       This form removes a label from an existing vertex or edge table.  The
103       last label on an element table cannot be dropped; every vertex or edge
104       table must have at least one label.
105      </para>
106     </listitem>
107    </varlistentry>
108
109    <varlistentry>
110     <term><literal>ALTER {VERTEX|NODE|EDGE|RELATIONSHIP} TABLE ... ALTER LABEL ... ADD PROPERTIES</literal></term>
111     <listitem>
112      <para>
113       This form adds new properties to an existing label on an existing
114       vertex or edge table.
115      </para>
116     </listitem>
117    </varlistentry>
118
119    <varlistentry>
120     <term><literal>ALTER {VERTEX|NODE|EDGE|RELATIONSHIP} TABLE ... ALTER LABEL ... DROP PROPERTIES</literal></term>
121     <listitem>
122      <para>
123       This form removes properties from an existing label on an existing
124       vertex or edge table.
125      </para>
126     </listitem>
127    </varlistentry>
128
129    <varlistentry>
130     <term><literal>OWNER</literal></term>
131     <listitem>
132      <para>
133       This form changes the owner of the property graph to the specified user.
134      </para>
135     </listitem>
136    </varlistentry>
137
138    <varlistentry>
139     <term><literal>RENAME</literal></term>
140     <listitem>
141      <para>
142       This form changes the name of a property graph.
143      </para>
144     </listitem>
145    </varlistentry>
146
147    <varlistentry>
148     <term><literal>SET SCHEMA</literal></term>
149     <listitem>
150      <para>
151       This form moves the property graph into another schema.
152      </para>
153     </listitem>
154    </varlistentry>
155   </variablelist>
156  </para>
157
158  <para>
159   You must own the property graph to use <command>ALTER PROPERTY
160   GRAPH</command>.  To change a property graph's schema, you must also have
161   <literal>CREATE</literal> privilege on the new schema.  To alter the owner,
162   you must be able to <literal>SET ROLE</literal> to the new owning role, and
163   that role must have <literal>CREATE</literal> privilege on the property
164   graph's schema.  (These restrictions enforce that altering the owner
165   doesn't do anything you couldn't do by dropping and recreating the property
166   graph.  However, a superuser can alter ownership of any property graph
167   anyway.)
168  </para>
169 </refsect1>
170
171 <refsect1>
172  <title>Parameters</title>
173
174  <variablelist>
175   <varlistentry>
176    <term><replaceable class="parameter">name</replaceable></term>
177    <listitem>
178     <para>
179      The name (optionally schema-qualified) of a property graph to be altered.
180     </para>
181    </listitem>
182   </varlistentry>
183
184   <varlistentry>
185    <term><literal>IF EXISTS</literal></term>
186    <listitem>
187     <para>
188      Do not throw an error if the property graph does not exist.  A notice is
189      issued in this case.
190     </para>
191    </listitem>
192   </varlistentry>
193
194   <varlistentry>
195    <term><replaceable class="parameter">vertex_table_definition</replaceable></term>
196    <term><replaceable class="parameter">edge_table_definition</replaceable></term>
197    <listitem>
198     <para>
199      See <link linkend="sql-create-property-graph"><command>CREATE PROPERTY
200      GRAPH</command></link>.
201     </para>
202    </listitem>
203   </varlistentry>
204
205   <varlistentry>
206    <term><replaceable class="parameter">vertex_table_alias</replaceable></term>
207    <term><replaceable class="parameter">edge_table_alias</replaceable></term>
208    <listitem>
209     <para>
210      The alias of an existing vertex or edge table to operate on.  (Note that
211      the alias is potentially different from the name of the underlying
212      table, if the vertex or edge table was created with <literal>AS
213      <replaceable class="parameter">alias</replaceable></literal>.)
214     </para>
215    </listitem>
216   </varlistentry>
217
218   <varlistentry>
219    <term><replaceable class="parameter">label_name</replaceable></term>
220    <term><replaceable class="parameter">property_name</replaceable></term>
221    <term><replaceable class="parameter">expression</replaceable></term>
222    <listitem>
223     <para>
224      See <link linkend="sql-create-property-graph"><command>CREATE PROPERTY
225      GRAPH</command></link>.
226     </para>
227    </listitem>
228   </varlistentry>
229
230   <varlistentry>
231    <term><replaceable class="parameter">new_owner</replaceable></term>
232    <listitem>
233     <para>
234      The user name of the new owner of the property graph.
235     </para>
236    </listitem>
237   </varlistentry>
238
239   <varlistentry>
240    <term><replaceable class="parameter">new_name</replaceable></term>
241    <listitem>
242     <para>
243      The new name for the property graph.
244     </para>
245    </listitem>
246   </varlistentry>
247
248   <varlistentry>
249    <term><replaceable class="parameter">new_schema</replaceable></term>
250    <listitem>
251     <para>
252      The new schema for the property graph.
253     </para>
254    </listitem>
255   </varlistentry>
256  </variablelist>

259 <refsect1>
260  <title>Notes</title>
261
262  <para>
263   The consistency checks on a property graph described at <xref
264   linkend="sql-create-property-graph-notes"/> must be maintained by
265   <command>ALTER PROPERTY GRAPH</command> operations.  In some cases, it
266   might be necessary to make multiple alterations in a single command to
267   satisfy the checks.
268  </para>
269 </refsect1>

272  <title>Examples</title>
273
274  <para>
275<programlisting>
276ALTER PROPERTY GRAPH g1 ADD VERTEX TABLES (v2);
277
278ALTER PROPERTY GRAPH g1 ALTER VERTEX TABLE v1 DROP LABEL foo;
279
280ALTER PROPERTY GRAPH g1 RENAME TO g2;
281</programlisting></para>
