macOS がシステム起動時に PostgreSQL サーバーを自動的に起動するようにするには、 以下の手順を実行します。

1. postgres-wrapper.sh スクリプトを編集し、Postgres を /usr/local/pgsql 以外に インストールしている場合は、そのインストール場所を反映するように先頭の ファイルパス変数を調整します。

2. 修正した postgres-wrapper.sh スクリプトを適切なインストールディレクトリに コピーします。Postgres の実行ファイルを格納している場所であっても構いませんが、 そこである必要はありません。

3. org.postgresql.postgres.plist ファイルを編集し、手順 2 で行った内容に 合わせて postgres-wrapper.sh のパスを調整します。また、"postgres" 以外の ユーザー名で Postgres サーバーを実行する予定がある場合は、 その UserName パラメータの値を調整します。

4. 修正した org.postgresql.postgres.plist ファイルを /Library/LaunchDaemons/ に コピーします。この操作は root で実行する必要があります。 sudo cp org.postgresql.postgres.plist /Library/LaunchDaemons root 所有になっていないファイルは無視されるためです。

この時点で再起動を行えばサーバーが起動するはずです。しかし、再起動せずに テストしたい場合は、以下を実行できます。 sudo launchctl load /Library/LaunchDaemons/org.postgresql.postgres.plist
