PostgreSQL contrib ツリー ---------------------------

このサブツリーには、移植ツール、分析ユーティリティ、およびプラグイン機能が含まれています。これらは主に、対象とするユーザー層が限られていることや、メインのソースツリーに入れるには実験的すぎるという理由から、PostgreSQLコアシステムのパーツにはなっていません。だからといって、これらが有用でないわけではありません。

各モジュールのユーザー向けドキュメントは、メインのSGMLドキュメントに含まれています。

ソース配布物からビルドする場合、"world"ターゲットをビルドしない限り、これらのモジュールは自動的にはビルドされません。また、このディレクトリで "make all" および "make install" を実行することで、これらすべてをビルドおよびインストールすることもできます。または、選択した1つのモジュールだけをビルドおよびインストールするには、そのモジュールのサブディレクトリで同様の操作を行います。

ディレクトリによっては、新しいユーザー定義関数、演算子、または型を提供しているものもあります。これらのモジュールのいずれかを利用するには、コードをインストールした後、CREATE EXTENSION コマンドを実行して、データベースシステムに新しいSQLオブジェクトを登録する必要があります。新しいデータベースでは、単に次のように実行できます。

CREATE EXTENSION module_name;

この手順の詳細については、PostgreSQLのドキュメントを参照してください。
