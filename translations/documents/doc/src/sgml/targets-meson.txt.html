# Copyright (c) 2023-2026, PostgreSQL Global Development Group

# 'help'ターゲットおよびinstallation.sgml（generate-targets-meson.pl経由）で使用される、
# 重要なmesonターゲットの説明。現時点では、パーサーは非常に単純です。
# 両方のパーサーはコメントを無視します。helpターゲットはそれ以外をすべて出力します。
# xmlの場合、先頭に改行がないものはすべてグループであり、
# 残りの行は、空白で説明と区切られたターゲットです。

コードターゲット:
  all                           ドキュメント以外のすべてをビルドする
  backend                       バックエンドおよび関連モジュールをビルドする
  bin                           フロントエンドのバイナリをビルドする
  contrib                       contribモジュールをビルドする
  pl                            手続き言語をビルドする

開発者向けターゲット:
  reformat-dat-files            カタログデータファイルを標準フォーマットに書き換える
  expand-dat-files              すべてのデータファイルを展開してデフォルト値を含める
  update-unicode                Unicodeデータを新しいバージョンに更新する
  headerscheck                  すべてのヘッダーが単独でコンパイルできるかチェックする
  cpluspluscheck                すべてのヘッダーがC++としてコンパイルできるかチェックする

ドキュメントターゲット:
  html                          マルチページHTML形式でドキュメントをビルドする
  man                           manページ形式でドキュメントをビルドする
  docs                          マルチページHTMLおよびmanページ形式でドキュメントをビルドする
  doc/src/sgml/postgres-A4.pdf  PDF形式（A4サイズ）でドキュメントをビルドする
  doc/src/sgml/postgres-US.pdf  PDF形式（USレターサイズ）でドキュメントをビルドする
  doc/src/sgml/postgres.html    シングルページHTML形式でドキュメントをビルドする
  alldocs                       サポートされているすべての形式でドキュメントをビルドする

インストールターゲット:
  install                       ドキュメントを除くpostgresをインストールする
  install-docs                  マルチページHTMLおよびmanページ形式のドキュメントをインストールする
  install-html                  マルチページHTML形式のドキュメントをインストールする
  install-man                   manページ形式のドキュメントをインストールする
  install-quiet                 "install"と同様だが、インストールされたファイルを表示しない
  install-world                 マルチページHTMLおよびmanページ形式のドキュメントを含むpostgresをインストールする
  uninstall                     インストールされたファイルを削除する

その他のターゲット:
  clean                         すべてのビルド生成物を削除する
  test                          有効になっているすべてのテスト（contribを含む）を実行する
  world                         ドキュメントを含むすべてをビルドする
  help                          重要なターゲットを一覧表示する
