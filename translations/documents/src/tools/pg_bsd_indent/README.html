src/tools/pg_bsd_indent/README

これは、FreeBSD プロジェクトによってメンテナンスされている "indent" プログラムを軽微に修正したものです。修正の大部分は BSD 系以外のプラットフォームへ移植しやすくするためのものですが、アップストリーム側に取り込んでもらえなかったフォーマット用のスイッチが 1 つだけ含まれています。

ビルドするには、周囲の Postgres ソースツリーを configure してから、このディレクトリで "make" を実行します。 オプションとして、簡単なテストを実行するために "make test" を実行することもできます。

使用する前に、PATH の通った場所に pg_bsd_indent をインストールする必要があります。開発者であれば、おそらく周辺の Postgres のビルドがインストールされるのと同じ場所に配置したくはないでしょう。したがって、この手順は以下のように実行します。

make install prefix=/usr/local

ビルドに Meson を使用している場合、標準のビルドターゲットで pg_bsd_indent のビルドとテストが行われますが、現在のところ任意の場所へインストールする仕組みはありません。ビルドされた実行ファイルを build/src/tools/pg_bsd_indent/pg_bsd_indent から配置したい場所へ手動でコピーしてください。

もし indent のソースコードをハッキングする機会があるなら、既存のインデントスタイルに最も近い設定は以下のようになります。

./pg_bsd_indent -i4 -l79 -di12 -nfc1 -nlp -sac somefile.c

もっとも、これが厳密に守られているわけではありません。 （靴職人の子供についての格言はどんなものだったでしょうか？） Postgres スタイルに再インデントする予定はありません。なぜなら、そうすると FreeBSD のソースとの比較が難しくなるためです。

これは C 言語のインデントツールであり、元々は PDP-11 Unix 用のいくつかの配布テープを介してイリノイ大学から提供されたものです。その後、CMU のジェームズ・ゴスリング（James Gosling）によって手を加えられました。あまり洗練されておらず、実際には完全に作り直す必要がありますが、おそらく現存する中で最も優れた C 言語のプリフィッター（整形プログラム）です。

「カーネル正規形式（Kernel Normal Form）」を提供するためのさらなる追加は、サン・マイクロシステムズ（Sun Microsystems）の人々によって貢献されました。

したがって、問題は comp.sources.unix を通じて「どれを」配布するかという点に帰着します。皆さんの許可が得られるのであれば（一部に著作権があることを考慮して）、最も最新のバージョンと思われる indent の 4.3 バージョンを配布することを提案します。 私は、作者から unix テープへの最初の提出物、その後の G-Emacs バージョン、あらゆる 4.n バージョン、サン版、Unipress 版を含む、知られている限りのほぼすべてのバージョンの indent を偶然にも持っています。 それでもなお、私たちが「過去に逆戻り」して、あなた方が行ったすべての作業をやり直す必要はないと考えています。

これについてどう思われるか、お返事をお待ちしております。もちろん 4.3 バージョンをモデレーターに直接送っていただいても構いませんし、許可をお知らせいただければ私がソースを送ることもできます。あるいは 4.3 バージョンがNGであると知らせていただければ、その場合はおそらく古いバージョンに戻さざるを得なくなるでしょう。いずれにせよ、何らかのバージョンの indent を comp.sources.unix に届けたいと思っています。
