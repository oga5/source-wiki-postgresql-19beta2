src/tools/ifaddrs/README

test_ifaddrs

このプログラムは、ローカルマシンのすべてのIPv4およびIPv6インターフェースの アドレスとネットマスクを出力します。この機能がさまざまなプラットフォームで 動作することをテストするのに便利です。pg_hba.conf内の"samehost"や"samenet"が 正しく動作していないように思われる場合は、このプログラムを実行して何が 起きているかを確認してください。

使用方法: test_ifaddrs
