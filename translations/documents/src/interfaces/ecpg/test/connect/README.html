src/interfaces/ecpg/test/connect/README

このディレクトリ内のプログラムは、あらゆる種類の接続をテストします。

その他のすべてのプログラムは、1つの標準的な接続方法のみを使用します。

回帰データベースの詳細（ポート、Unixソケットファイル、ユーザー名、パスワードなど）が変更された場合、これらのプログラムにはハードコードされた値が含まれているため、同様に変更する必要があります。
