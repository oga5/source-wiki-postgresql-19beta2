src/test/recovery/README

リカバリとレプリケーションの回帰テスト

このディレクトリには、リカバリとレプリケーションのテストスイートが含まれています。

テストの実行

注意: configureに--enable-tap-tests引数を与えている必要があります。 また、"make installcheck"を使用するには、コアコードに加えて contrib/pg_prewarm、contrib/pg_stat_statements、およびcontrib/test_decoding をビルドしてインストールしておく必要があります。

以下を実行します。 make check または make installcheck 事前に"make install"を行っている場合は、"make installcheck"を使用できます。 その場合、インストールツリー内のコードがテストされます。"make check"を使用すると、 現在のソースから一時的なインストールツリーが構築され、それがテストされます。

どちらの方法でも、このテストは複数のテスト用Postgresクラスターを初期化、起動、および停止します。

WALの一貫性チェックをテストしたい場合は、"make"コマンドに PG_TEST_EXTRA=wal_consistency_checking を追加してください。これはリソースを大量に消費するため、デフォルトでは行われません。

これらのテストの実行に関する詳細については、src/test/perl/READMEを参照してください。
