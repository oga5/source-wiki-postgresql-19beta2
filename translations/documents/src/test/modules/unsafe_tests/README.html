このディレクトリは、実際には拡張モジュールをまったく含んでいません。

その代わりに、本番環境へのインストールにおいて望ましくないと思われる副作用を及ぼす可能性があるため、"make installcheck"の実行中には実行したくない回帰テストの格納場所となっています。

例えば、rolenames.sqlはALTER USER ALLをテストするため、既存のロールに影響を与える可能性があります。
