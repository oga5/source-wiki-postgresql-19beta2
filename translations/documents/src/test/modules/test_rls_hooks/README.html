test_rls_hooks は、RLS 用に提供されているフックを使用して追加のポリシーを定義する方法を示す例です。

Functions ========= test_rls_hooks_permissive(CmdType cmdtype, Relation relation) RETURNS List*

リレーション上の既存のポリシーに追加され、OR で結合されるべきポリシーのリストを返します。

test_rls_hooks_restrictive(CmdType cmdtype, Relation relation) RETURNS List*

リレーション上の既存のポリシーに追加され、AND で結合されるべきポリシーのリストを返します。
