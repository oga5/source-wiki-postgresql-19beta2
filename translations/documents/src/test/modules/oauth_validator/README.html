OAuth用のテストプログラムとライブラリ -------------------------------------

このフォルダーには、クライアント側およびサーバー側のOAuth実装のテストが含まれています。ほとんどのテストは、両方を同時にテストするためにエンドツーエンドで実行されます。t/001_server内のテストは、t/OAuth/Server.pmとt/oauth_server.pyによって共同で実装されたモックOAuth認可サーバーを使用して、libpqのデバイス認可フローを実行します。t/002_client内のテストはカスタムOAuthフローをテストするものであり、認可サーバーを必要としません。

TCP/IPソケットでlocalhostをリスンするHTTPSサーバーが起動されるため、このフォルダー内のテストを実行するにはPG_TEST_EXTRAに'oauth'が含まれている必要があります。モック認可サーバーを実行するには、Pythonのインストールが必要です。
