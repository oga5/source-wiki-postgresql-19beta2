Dummy Index AM ==============

Dummy index AMは、インデックスアクセスメソッドで使用可能な任意の機能をテストするためのモジュールであり、そのコードは可能な限りシンプルに保たれています。

これには、すべてのリレーションオプションタイプのテストが含まれます。

  • ブール値および三値
  • 列挙型
  • 整数
  • 実数
  • 文字列（デフォルトとしてのNULLの有無に関わらず）
