spgist_name_opsは、"name"型の列のインデックスを作成するSP-GiST演算子クラスを実装しますが、 そのストレージはSP-GiSTのtext_opsで使用されるものと同一です。

これ自体はそれほど有用ではないかもしれませんが、インデックス対象のデータ型がリーフ データ型と異なっているにもかかわらず、元のインデックス値を再構成できるというケースを テストすることができます。 この状況は、組み込みのSP-GiST演算子クラスではテストされていません。
