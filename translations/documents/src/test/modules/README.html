テスト用拡張機能とライブラリ

src/test/modules には、主に、または完全に PostgreSQL のテストを目的とした、あるいはサンプルコードとして機能することを目的とした PostgreSQL 拡張機能が含まれています。ここにある拡張機能は、本番サーバーへのインストールを想定しておらず、「実際の業務」には適していません。

さらに、このディレクトリまたはそのサブディレクトリで "make install" や "make installcheck" を実行することは可能ですが、価値のあるデータが含まれているサーバーに対して実行することは推奨されません（NOT ADVISABLE）。これらのテストの一部は、テスト対象のサーバー内のロールやその他のグローバルオブジェクトに対して、望ましくない副作用を及ぼす可能性があります。トップレベルでの "make installcheck-world" は、このディレクトリを再帰的に処理しません。

ほとんどの拡張機能には、独自の pg_regress テストまたは isolationtester 仕様があります。一部は、ツリー内の他の場所にあるテストでも使用されています。

新しいフックや、CレベルのAPIとして公開されるその他の機能を追加する場合は、ここにそのテストを追加します。
