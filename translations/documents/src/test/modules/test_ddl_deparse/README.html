test_ddl_deparseは、pg_ddl_commandデータ型の使用方法の例です。 それ自体で何か有用なことを行うようには意図されていません。むしろ、このデータ型の使用方法のデモンストレーションであり、そのためのユニットテストを提供するためのものです。
