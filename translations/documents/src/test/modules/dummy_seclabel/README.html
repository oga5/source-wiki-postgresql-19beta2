dummy_seclabel モジュールは、SECURITY LABEL 文のリグレッションテストをサポートするためだけに存在します。本番環境で使用することを意図したものではありません。

Rationale

SECURITY LABEL 文を使用すると、ユーザーはデータベースオブジェクトにセキュリティラベルを割り当てることができます。ただし、セキュリティラベルはロード可能なモジュールによって明示的に許可されている場合にのみ割り当てることができるため、適切なリグレッションテストを行えるようにこのモジュールが提供されています。

本番環境で使用することを意図したセキュリティラベルプロバイダーは、通常、SELinux などのプラットフォーム固有の機能に依存します。このモジュールはプラットフォームに依存しないため、リグレッションテストにより適しています。

Usage

使用方法の簡単な例を以下に示します。

postgresql.conf

shared_preload_libraries = 'dummy_seclabel'

postgres=# CREATE TABLE t (a int, b text); CREATE TABLE postgres=# SECURITY LABEL ON TABLE t IS 'classified'; SECURITY LABEL

dummy_seclabel モジュールは、unclassified、classified、secret、top secret の4つのハードコードされたラベルのみを提供します。他の文字列をセキュリティラベルとして許可しません。

これらのラベルはアクセス制御の強制には使用されません。SECURITY LABEL 文が期待どおりに動作するかどうかを確認するためだけに使用されます。
