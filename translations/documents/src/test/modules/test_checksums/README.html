src/test/modules/test_checksums/README

Regression tests for data checksums =================================== このディレクトリには、オフラインおよび実行中のクラスターの両方でデータチェック サムを有効化および無効化するためのテストスイートが含まれています。

Running the tests with autoconf ===============================

make check

or

make installcheck

Running the tests with meson ============================ ビルドディレクトリから、以下のコマンドを実行します。

meson test -q --print-errorlogs --suite setup --suite test_checksums

NOTE: これにより、テストのために、マスターまたはスタンバイである複数のノードを 持つ一時的なインストール（"make check"または"--suite setup"の場合）が作成され ます。

NOTE: このテストスイートを実行するにはTAPテストが有効である必要があります。 また、テストの一部は動作するためにインジェクションポイントを必要とします。 拡張テストを実行するには、PG_TEST_EXTRA環境変数に"checksum_extended"を設定 する必要があります。
