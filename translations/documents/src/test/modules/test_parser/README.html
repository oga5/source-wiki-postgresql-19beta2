test_parserは、全文検索用のカスタムパーサーの例です。特に実用的なことは行いませんが、独自のパーサーを開発するための出発点として役立ちます。

test_parserは空白で区切られた単語を認識し、2つのトークンタイプのみを返します。

mydb=# SELECT * FROM ts_token_type('testparser'); tokid | alias | description -------+-------+--------------- 3 | word | Word 12 | blank | Space symbols (2 rows)

これらのトークン番号は、デフォルトパーサーの番号付けと互換性があるように選択されています。これにより、そのheadline()関数を使用することができ、例をシンプルに保つことができます。

使用方法 ========

test_parser拡張機能をインストールすると、テキスト検索パーサーtestparserが作成されます。ユーザーが設定可能なパラメータはありません。

例えば、以下のようにパーサーをテストできます。

mydb=# SELECT * FROM ts_parse('testparser', 'That''s my first own parser'); tokid | token -------+-------- 3 | That's 12 | 3 | my 12 | 3 | first 12 | 3 | own 12 | 3 | parser

実用的な使用には、このパーサーを使用するテキスト検索設定をセットアップする必要があります。例えば、

mydb=# CREATE TEXT SEARCH CONFIGURATION testcfg ( PARSER = testparser ); CREATE TEXT SEARCH CONFIGURATION

mydb=# ALTER TEXT SEARCH CONFIGURATION testcfg mydb-# ADD MAPPING FOR word WITH english_stem; ALTER TEXT SEARCH CONFIGURATION

mydb=# SELECT to_tsvector('testcfg', 'That''s my first own parser'); to_tsvector ------------------------------- 'that':1 'first':3 'parser':5 (1 row)

mydb=# SELECT ts_headline('testcfg', 'Supernovae stars are the brightest phenomena in galaxies', mydb(# to_tsquery('testcfg', 'star')); ts_headline ----------------------------------------------------------------- Supernovae <b>stars</b> are the brightest phenomena in galaxies (1 row)
