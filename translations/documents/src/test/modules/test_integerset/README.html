test_integersetは、src/backend/lib/integerset.cにおける整数セットの実装を テストするためのユニットテストを含んでいます。

これらのテストは実装の正確性を検証するものですが、マイクロベンチマークとしても 使用できます。test_integerset.cで'intset_test_stats'フラグを設定すると、 テストは実行時間とメモリ使用量に関する追加情報を出力します。
