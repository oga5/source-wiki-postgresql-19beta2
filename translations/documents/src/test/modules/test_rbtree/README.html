test_rbtree は、赤黒木操作の正確性を検証するためのテストモジュールです。

これらのテストは、整数を格納する赤黒木に対して実行されます。 rbtree のロジックは比較関数をブラックボックスとして扱うため、キーの型が正確に何であるかは重要ではありません。

走査の正確性の検証は、赤黒木が二分探索木であるという事実に基づいているため、要素は昇順（左-現-右の場合）または降順（右-現-左の場合）で訪問される必要があります。

また、このモジュールでは、検索、削除、および最左端（leftmost）操作の正確性に関するいくつかの検証も行います。
