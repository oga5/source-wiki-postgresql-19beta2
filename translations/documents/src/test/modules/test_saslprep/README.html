src/test/modules/test_saslprep

SASLprepのテスト

このリポジトリには、PostgreSQL内部のSASLprep実装に負荷をかけるためのテストスイートが含まれています。

これは、pg_saslprep()のラッパーとして機能し、単一のバイトおよびそれらの範囲に対するSASLprep操作の妥当性を検証できる一連の関数を提供します。

テストの実行

注意: テストの一部は--enable-tap-testsを必要とし、TAPテストスイートを実行するにはPG_TEST_EXTRA=saslprepを設定する必要があります。

以下を実行します。 make check PG_TEST_EXTRA=saslprep または make installcheck PG_TEST_EXTRA=saslprep

SQLテストスイートは、PG_TEST_EXTRA=saslprepの設定有無にかかわらず実行できます。
