モジュール test_json_parser

このモジュールには、jsonパーサーをテストするための2つのプログラムが含まれています。

  • test_json_parser_incremental は、インクリメンタルパーサーをテストするためのものです。ファイルを読み込み、非常に小さなチャンク（デフォルトは一度に60バイト）でインクリメンタルパーサーに渡します。これは速度テストを目的としたものではなく、インクリメンタルパーサーの正確性をテストするためのものです。オプション "-c nn" は代替のチャンクサイズを指定し、"-r nn" は同じ入力に対して1バイトまでの範囲のチャンクサイズを実行し（出力はヌルバイトで区切られます）、"-s" はセマンティックルーチンの使用を指定します。セマンティックルーチンは、あまりきれいな形式ではありませんが、jsonを再出力します。必須の非オプション引数は、入力ファイル名です。
  • test_json_parser_perf は、標準的な再帰下降パーサーと非再帰インクリメンタルパーサーの両方の速度テストを行うためのものです。-i フラグが指定された場合は非再帰パーサーを使用し、そうでない場合は標準パーサーを使用します。残りのフラグは、パースの反復回数と入力を含むファイルです。非再帰パーサーを使用する場合でも、入力は単一のチャンクでパーサーに渡されます。したがって、結果は標準パーサーのものと比較可能です。

サンプル入力ファイルは、数年前に取得された delicious ブックマークのリストから抽出され、サニタイズされた小さな抜粋であり、すべて単一の json 配列にラップされています。
