PostgreSQLのテスト ================

このディレクトリには、さまざまなテストインフラストラクチャと、PostgreSQLのテストの一部が含まれています。すべてのテストがここにあるわけではありません。特に、個々の contrib/ モジュールや src/bin にもテストがあります。

これらのテストすべてが "make check" によって実行されるわけではありません。どのテストが自動的に実行されるかについては、src/test/Makefile を確認してください。

authentication/ 認証用のテスト（ただし以下も参照）

examples/ "make check" を介した回帰テストを兼ねた libpq のデモンストレーションプログラム

isolation/ SQLレベルでの並行動作のテスト

kerberos/ Kerberos/GSSAPI認証および暗号化のテスト

ldap/ LDAPベースの認証のテスト

locale/ ロケールデータ、エンコーディングなどのサニティチェック

mb/ マルチバイトエンコーディング（UTF-8）サポートのテスト

modules/ テスト目的のみ、または主にテスト目的で使用される拡張機能。一般に本番データベースへのインストールには適していません。

perl/ PerlベースのTAPテスト用インフラストラクチャ

recovery/ リカバリおよびレプリケーションのテストスイート

regress/ PostgreSQLのメインの回帰テストスイート、pg_regress

ssl/ SSL証明書の処理を実行および検証するためのテスト

subscription/ ロジカルレプリケーションのテスト
