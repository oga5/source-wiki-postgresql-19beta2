src/test/icu/README

ICU機能の回帰テスト

このディレクトリには、ICU機能のテストスイートが含まれています。

テストの実行

注意：configureに--enable-tap-tests引数を指定しておく必要があります。

以下を実行します。 make check または make installcheck 事前に"make install"を行っている場合は、"make installcheck"を使用できます。 その場合、インストールツリー内のコードがテストされます。 "make check"では、現在のソースから一時的なインストールツリーが構築され、 テストされます。

どちらの方法でも、このテストはいくつかのテスト用Postgresクラスターを 初期化、起動、および停止します。

これらのテストの実行に関する詳細については、src/test/perl/READMEを参照してください。
