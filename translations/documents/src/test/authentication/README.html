src/test/authentication/README

認証の回帰テスト

このディレクトリには、認証用のテストスイートが含まれています。SSL証明書 認証のテストは、より複雑であり、マルチユーザーシステムで実行するのが 安全ではないため、src/test/ssl/ に分けて置かれています。

テストの実行

注意: configure に --enable-tap-tests 引数を指定しておく必要があります。

以下を実行します。 make check または make installcheck 以前に "make install" を実行している場合は、"make installcheck" を使用できます。 その場合、インストールツリー内のコードがテストされます。"make check" では、 現在のソースから一時的なインストールツリーが構築され、テストされます。

どちらの方法でも、このテストはテスト用の Postgres クラスターを初期化、 起動、および停止します。

これらのテストの実行に関する詳細については、src/test/perl/README を参照してください。
