src/test/subscription/README

サブスクリプション/ロジカルレプリケーションの回帰テスト

このディレクトリには、サブスクリプション/ロジカルレプリケーションのテストスイートが含まれています。

テストの実行

注意: configureに--enable-tap-tests引数を指定している必要があります。 また、"make installcheck"を使用するには、コアコードに加えて contrib/hstoreをビルドしてインストールしておく必要があります。

以下を実行します。 make check または make installcheck 以前に"make install"を実行している場合は、"make installcheck"を使用できます。 その場合、インストールツリー内のコードがテストされます。"make check"では、 現在のソースから一時的なインストールツリーがビルドされ、テストされます。

どちらの方法でも、このテストは複数のテスト用Postgresクラスターを初期化、起動、 および停止します。

これらのテストの実行に関する詳細については、src/test/perl/READMEを参照してください。
