src/test/postmaster/README

postmasterの回帰テスト

このディレクトリには、postmasterの接続、接続制限、および起動/停止シーケンスの 処理に関するテストスイートが含まれています。

テストの実行

注意: configureに--enable-tap-tests引数を指定しておく必要があります。

実行するには、 make check または make installcheck 事前に"make install"を実行している場合は、"make installcheck"を使用できます。 その場合、インストールツリー内のコードがテストされます。 "make check"を使用すると、現在のソースから一時的なインストールツリーが構築され、 それがテストされます。

どちらの方法でも、このテストはテスト用のPostgresクラスターを初期化、起動、および停止します。

これらのテストの実行に関する詳細については、src/test/perl/READMEを参照してください。
