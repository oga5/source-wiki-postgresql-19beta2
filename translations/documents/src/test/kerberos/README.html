src/test/kerberos/README

Kerberos/GSSAPI機能のテスト =======================================

このディレクトリには、Kerberos/GSSAPI機能のテストスイートが含まれています。これには、サーバーおよびクライアントツールを含む完全なMIT Kerberosのインストールが必要であるため、別個に管理され、デフォルトでは実行されません。

注意: このテストによって実行されるテストサーバーは、localhost上のTCP接続を監視するように構成されています。テストの実行中、同じホスト上の任意のユーザーがテストサーバーにログインできます。すべてのローカルユーザーを信頼できないマルチユーザーシステムでは、このスイートを実行しないでください！また、このテストスイートは、実質的なアクセス制御なしでlocalhost上のTCP/IP接続を監視するKDCサーバーを作成します。

テストの実行 =================

注意: configureに--enable-tap-tests引数を指定している必要があります。また、"make installcheck"を使用するには、コアコードに加えてcontrib/dblinkおよびcontrib/postgres_fdwをビルドしてインストールしておく必要があります。

以下を実行します。 make check PG_TEST_EXTRA=kerberos または make installcheck PG_TEST_EXTRA=kerberos 事前に"make install"を実行している場合は、"make installcheck"を使用できます。その場合、インストールツリー内のコードがテストされます。"make check"を使用すると、現在のソースから一時的なインストールツリーが構築され、テストされます。

どちらの方法でも、このテストはテスト用のPostgresクラスターとテスト用のKDCサーバーを初期化、起動、および停止します。

これらのテストの実行に関する詳細については、src/test/perl/READMEを参照してください。

要件 ============

MIT Kerberosのサーバーおよびクライアントツールが必要です。Heimdalはサポートされていません。

Debian/Ubuntuパッケージ: krb5-admin-server krb5-kdc krb5-user

RHEL/CentOS/Fedoraパッケージ: krb5-server krb5-workstation

FreeBSDポート: krb5 (ベースシステムにはHeimdalが含まれています)
