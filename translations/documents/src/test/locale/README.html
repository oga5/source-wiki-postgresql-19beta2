ロケール =======

このディレクトリには、ロケール用のテストセットが含まれています。libcにおけるCTYPEのサポートとインストールされているロケールデータをテストするために、1つのCプログラム test-ctype.c を提供しました。また、照合順序をテストする test-sort.pl と test-sort.py もあります。

特定のロケールのテストを実行するには、以下を実行します。 make check-$locale 例えば、以下のようにします。 make check-koi8-r

現在、利用可能なテストは少数のロケールのみです。スクリプト 'runall' は、libcとロケールデータをテストするために test-ctype を呼び出し、test-sort.pl を呼び出し（Pythonインタプリタがインストールされている場合は、test-sort.py のコメントを解除してください）、提供されているSQLスクリプトファイルを使用してPostgreSQLのテストを行います。

ロケールテストを追加するには、ディレクトリ $locale を作成し、koi8-r/* に類似した Makefile（およびその他のファイル）を作成する必要があります。実際、最も簡単な方法（と私は思います）は、単に koi8-r ディレクトリをコピーして、ファイルを編集/置換することです。
