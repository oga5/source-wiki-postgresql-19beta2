src/bin/pgevent/README

pgevent

MSG00001.binは、Microsoft MCコンパイラによって生成されるバイナリファイルです。MCコンパイラはMS Core SDKに付属しており無料でダウンロードできますが、MSYSツールには含まれておらず、MCファイルをコンパイルする他の方法を見つけることはできませんでした。

要約すると、"MC pgmsgevent.mc"というコマンドによってpgmsgevent.h、pgmsgevent.rc、およびMSG00001.binファイルが生成されます。MCファイル内では、%sフォーマットの文字列を宣言しているため、将来この文字列の定義を変更することなく、任意のテキストを書き込むことができます。

最後に、DllUnregisterServerとDllRegisterServerはシステムで定義されたエントリポイントであるため、これら2つの関数を「装飾」なしの名前でエクスポートする必要があります。そのため、手動での修正なしに自動生成された.defファイルを使用することはできません。
