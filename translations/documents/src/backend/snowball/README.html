Snowballに基づくステミング =======================

このモジュールは、Snowballプロジェクト（http://snowballstem.org 、旧 http://snowball.tartarus.org ）によって開発された単語ステミングコードを使用しています。このコードはBSDスタイルのライセンスの下でリリースされています。

Snowballプロジェクトは頻繁に正式リリースを行わないため、彼らのgitリポジトリからプルするのが最善です。

git clone https://github.com/snowballstem/snowball.git

その後、派生ファイルをビルドするのは以下のように簡単です。

cd snowball make

少なくともLinux上では、プラットフォーム固有の調整は必要ありません。

src/backend/snowball/libstemmer/ および src/include/snowball/libstemmer/ 配下にあるPostgresのファイルは、Snowballのファイルから直接取得したものであり、ファイルのインクルードに関してわずかな調整のみを行っています。これらのファイルのほとんどは、実際にはオリジナルのソースではなく派生ファイルであることに注意してください。オリジナルのソースはSnowball言語で書かれており、Snowballプロジェクトの一部でもあるSnowball-to-Cコンパイラを使用してビルドされます。ほとんどのインストール環境ではSnowballコンパイラが利用できないため、PostgreSQLの配布物には派生ファイルを含めることにしています。

現在は、2025-12-15のSnowballのgitコミット 2d2e312df56f2ede014a4ffb3e91e6dea43c24be と同期しています。

新しいSnowballバージョンからPostgreSQLのソースを更新するには：

0. まだ行っていない場合は、"make -C snowball"を実行します。

1. snowball/src_c/ 内の *.c ファイルを src/backend/snowball/libstemmer にコピーします。その際、例えば以下のようにして、"../runtime/snowball_runtime.h" を "snowball_runtime.h" に置換します。

for f in .../snowball/src_c/*.c do sed 's|\.\./runtime/snowball_runtime\.h|snowball_runtime.h|' $f >libstemmer/basename $f done

彼らの libstemmer/modules.txt で非標準としてリストされているステマー（"lovins" など）はコピーしないでください。

2. snowball/runtime/ 内の *.c ファイルを src/backend/snowball/libstemmer にコピーし、それらを編集して <stdio.h> などのシステムヘッダの直接インクルードを削除します。これらは "snowball_runtime.h" のみをインクルードする必要があります。（この削除により、<stdio.h> がラージファイルコンパイルオプションに影響されやすい一部のプラットフォームでの移植性の問題を回避できます。）

3. snowball/src_c/ および snowball/runtime/ 内の *.h ファイルを src/include/snowball/libstemmer にコピーします。本稿執筆時点では、ヘッダファイルに変更を加える必要はありません。ここでも、非標準ステマー用の *.h ファイルは除外してください。

4. ステマーモジュールが追加または削除されたかどうかを確認します。追加または削除された場合は、Makefile の OBJS リスト、meson.build の dict_snowball_sources リスト、dict_snowball.c の #include リストと stemmer_modules[] テーブル、textsearch.sgml のドキュメント内にある有効な言語パラメータのリスト、および textsearch.sgml のドキュメント内にあるサンプルの \dFd 出力を編集します。また、snowball_create.pl の @languages 配列や initdb.c の tsearch_config_languages[] テーブルを変更する必要がある場合もあります。通常、後者の2つは、完全に新しい言語のステマーが追加された場合に拡張する必要がありますが、既存の言語に対する代替ステマーはそれらには表現されません。

5. stopwords/ 内の様々なストップワードファイルは、snowballstem.org のウェブサイトのページから個別にダウンロードする必要があります。これらのファイルはUTF-8エンコーディングで保存する必要があることに注意してください。追加または削除された場合は、Makefile の stop_files リストを更新します（ただし、mesonツールはこのための調整を必要としません）。
