PostgreSQL データベース管理システム

このディレクトリには、PostgreSQL データベース管理システムのソースコード ディストリビューションが含まれています。

PostgreSQL は、トランザクション、外部キー、サブクエリ、トリガー、 ユーザー定義型および関数など、SQL 標準の拡張サブセットをサポートする 高度なオブジェクトリレーショナルデータベース管理システムです。 このディストリビューションには、C 言語のバインディングも含まれています。

著作権およびライセンスの情報は、COPYRIGHT ファイルに記載されています。

このバージョンの PostgreSQL に関する一般的なドキュメントは、 <https://www.postgresql.org/docs/19/> にあります。 特に、ソースコードから PostgreSQL をビルドする方法については、 <https://www.postgresql.org/docs/19/installation.html> を参照してください。

このソフトウェアの最新バージョンおよび関連ソフトウェアは、 <https://www.postgresql.org/download/> から入手できます。 詳細については、<https://www.postgresql.org/> にある当社のWebサイトをご覧ください。
