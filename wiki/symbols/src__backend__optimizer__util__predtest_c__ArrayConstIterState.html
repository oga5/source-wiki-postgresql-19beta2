ソース抜粋

~~~c typedef struct { OpExpr opexpr; Const const_expr; int next_elem; int num_elems; Datum *elem_values; bool *elem_nulls; } ArrayConstIterState; ~~~

目的

定数配列を伴う ScalarArrayOpExpr を要素単位の OpExpr に展開しながら走査するための作業状態を保持する構造体である。

フィールドと表現

  • opexpr: 展開および評価のベースとなる OpExpr 構造体。
  • const_expr: 各要素の評価時に利用される Const 構造体。
  • next_elem: 次に走査すべき配列要素のインデックスを示す整数値。
  • num_elems: 配列に含まれる総要素数を示す整数値。
  • elem_values: 配列の各要素の Datum 値を格納した配列へのポインタ。
  • elem_nulls: 配列の各要素の NULL フラグを格納した真偽値配列へのポインタ。
