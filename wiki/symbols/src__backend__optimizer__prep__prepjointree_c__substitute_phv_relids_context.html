ソース抜粋

~~~c typedef struct { int varno; int sublevels_up; Relids subrelids; } substitute_phv_relids_context; ~~~

目的

クエリツリー内のPlaceHolderVarが参照するrelidを、サブクエリ引き上げやRESULT RTE削除に伴い別のrelidに置換するためのコンテキスト情報を提供する構造体である。

フィールドと表現

  • varno (int): 置換対象となる変数の範囲テーブルインデックス（varno）を保持する。
  • sublevels_up (int): クエリのネストの深さを追跡するためのサブレベル数を保持する。
  • subrelids (Relids): 関連するサブクエリやリレーションのID集合を保持する。
