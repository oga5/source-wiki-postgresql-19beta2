目的

指定された RelOptInfo 構造体に対して、拡張機能固有の状態ポインタ（opaque）を格納するための拡張状態配列を設定または更新する。

シグネチャまたは形状

  • シグネチャ: void SetRelOptInfoExtensionState(RelOptInfo *rel, int extension_id, void *opaque)

入力と出力

  • 引数:
  • RelOptInfo *rel: 状態を格納する対象の RelOptInfo 構造体ポインタ
  • int extension_id: 拡張機能を識別する非負の整数 ID
  • void *opaque: 格納する拡張機能固有の状態ポインタ
  • 戻り値: なし (void)

前提条件と不変条件

  • extension_id は 0 以上でなければならない（アサーションにより検証される）。

アルゴリズムまたは振る舞い

1. Assert により extension_id >= 0 であることを検証する。 2. 対象の RelOptInfo における拡張状態配列 (rel->extension_state) がまだ割り当てられていない場合:

  • GetMemoryChunkContext(rel) を用いて対象メモリチャンクのコンテキストを取得する。
  • Max(4, pg_nextpower2_32(extension_id + 1)) により初期割り当てサイズを決定する。
  • MemoryContextAllocZero を呼び出してゼロクリアされた配列領域を確保し、rel->extension_state に設定する。

    • 3. 既存の配列の割り当てサイズが extension_id 未満（すなわち配列が一杯）である場合:

  • pg_nextpower2_32(extension_id + 1) により新しいサイズを計算する。
  • repalloc0_array を用いて配列を拡張し、ゼロ初期化された追加領域を確保する。
  • 割り当てサイズ変数を更新する。

    • 4. 指定されたインデックス extension_id の位置に opaque ポインタを格納する。

失敗モードと境界条件

  • extension_id に負の値を渡した場合、アサーション違反によりプロセスが停止する。
