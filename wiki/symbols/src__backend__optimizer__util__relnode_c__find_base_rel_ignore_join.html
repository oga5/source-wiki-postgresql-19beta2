目的

指定されたレンジテーブルインデックス（relid）に対応するベースリレーション（RelOptInfo）を検索して返すが、対象の relid が内部結合ではない外部結合を参照している特殊なケースではエラーとせず NULL を返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーの全体情報を保持する構造体ポインタ。
  • int relid: 検索対象のレンジテーブルインデックス。
  • 戻り値:
  • RelOptInfo *: 対応するリレーション情報。条件を満たす外部結合のエントリであるか、あるいは配列範囲外などの不正な場合は NULL（または elog(ERROR) による異常終了）。

前提条件と不変条件

  • 負の配列要素へのアクセスを防止するため、relid は符号なし比較（uint32 キャスト）によって root->simple_rel_array_size と比較される。

アルゴリズムまたは振る舞い

1. **配列範囲のチェック**: (uint32) relid < (uint32) root->simple_rel_array_size であるかどうかを判定する。 2. **既存ベースリレーションの確認**: 範囲内の場合、root->simple_rel_array[relid] から RelOptInfo を取得する。該当エントリが存在すればそのまま返す。 3. **外部結合の判定**: RelOptInfo が存在しない場合、デバッグ目的にて root->simple_rte_array[relid] から対応する RangeTblEntry（rte）を取得する。もし rte が存在し、その種類が RTE_JOIN かつ結合タイプが非内結合（JOIN_INNER 以外）であれば、エラーとせずに NULL を返す。 4. **エラー処理**: 上記のいずれにも該当しない場合、または配列範囲外の場合は elog(ERROR) を呼び出して処理をアボートする。

失敗モードと境界条件

  • relid が simple_rel_array_size の範囲外であるか、有効なベースリレーションおよび非内結合のレンジテーブルエントリのいずれにも該当しない場合、elog(ERROR, "no relation entry for relid %d", relid) が発生する。
