目的

クエリの最適化において、更新・削除・マージ対象のリレーション（UPDATE/DELETE/MERGE）に必要な行識別子（row-id）変数を管理・登録する。

シグネチャまたは形状

  • シグネチャ: void add_row_identity_var(PlannerInfo *root, Var *orig_var, Index rtindex, const char *rowid_name)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報を保持する構造体
  • Var *orig_var: 対象となる元の変数ノード (Var)
  • Index rtindex: 対象リレーションのレンジテーブルインデックス
  • const char *rowid_name: 行識別子の名前（例: "ctid", "wholerow", "tableoid"）
  • 戻り値: なし (void)

前提条件と不変条件

  • orig_var 引数は Var ノードであり、その varno は指定された rtindex と一致し、レベル参照 varlevelsup は 0、ヌリング関係 varnullingrels は NULL でなければならない。
  • 非継承の UPDATE/DELETE/MERGE の場合を除き、rtindex は root->leaf_result_relids に含まれる葉ターゲットリレーションであり、root->append_rel_array[rtindex] が初期化されている必要がある。

アルゴリズムまたは振る舞い

1. 入力検証: 引数 orig_var が Var ノードであることや、varno、varlevelsup、varnullingrels に関するアサート条件を検証する。 2. 非継承クエリの分岐: rtindex が root->parse->resultRelation（非継承の更新対象）と等しい場合、orig_var からターゲットエントリ (TargetEntry) を構築して root->processed_tlist の末尾に追加し、処理を終了する。 3. 継承リレーションの検証: 継承テーブル等の場合は、rtindex が root->leaf_result_relids のメンバーであり、root->append_rel_array[rtindex] が存在することを確認する。 4. 識別子の照合と登録:

  • orig_var のコピーを作成し、その varno を ROWID_VAR に書き換えた rowid_var を用意する。
  • root->row_identity_vars リストを走査し、同じ rowid_name を持つ既存の RowIdentityVarInfo を探す。
  • 一致するものが見つかった場合、それが equal(rowid_var, ridinfo->rowidvar) を満たせば、ridinfo->rowidrels に rtindex を追加して終了する。満たさない場合はエラー (ERROR) を送出する。

    • 5. 新規 RowIdentityVarInfo の追加:

  • 一致する既存情報がない場合、新しい RowIdentityVarInfo ノードを生成する。
  • 型情報から平均幅を推定し、rowidname、および rtindex を含むビットマップセット (rowidrels) を設定した上で、root->row_identity_vars の末尾に追加する。
  • rowid_var->varattno を新しい row_identity_vars リストの長さに更新し、その rowid_var を含むターゲットエントリを root->processed_tlist に追加する。

呼び出し元と呼び出し先

  • 呼び出し元: add_row_identity_columns, expand_single_inheritance_child, postgresAddForeignUpdateTargets
  • 呼び出し先: Assert, bms_add_member, bms_is_member, bms_make_singleton, elog, equal, exprType, exprTypmod, get_typavgwidth, lappend, makeTargetEntry

失敗モードと境界条件

  • 既存の行識別子名と名前が同じであるにもかかわらず、式の内容 (equal(rowid_var, ridinfo->rowidvar)) が一致しない場合、elog(ERROR, ...) により「conflicting uses of row-identity name」エラーが発生する。
