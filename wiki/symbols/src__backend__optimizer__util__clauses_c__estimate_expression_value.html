ソース抜粋

~~~c Node * estimate_expression_value(PlannerInfo *root, Node *node) { eval_const_expressions_context context;

context.boundParams = root->glob->boundParams; /* bound Params */ /* we do not need to mark the plan as depending on inlined functions */ context.root = NULL; context.active_fns = NIL; /* nothing being recursively simplified */ context.case_val = NULL; /* no CASE being examined */ context.estimate = true; /* unsafe transformations OK */ return eval_const_expressions_mutator(node, &context); } ~~~

目的

estimate_expression_value は、プランナの評価コンテキストを利用して式を見積もり・単純化するための関数である。

入力と出力

  • 引数: PlannerInfo *root（プランナ情報）, Node *node（評価・単純化対象の式ツリー）
  • 戻り値: Node *（変換・評価された結果の式ノード）

前提条件と不変条件

  • eval_const_expressions_context 構造体を初期化し、バインドされたパラメータとして root->glob->boundParams を設定する。
  • 計画がインライン化された関数に依存しているというマーク付けは不要であるため、context.root は NULL に設定される。
  • 再帰的に単純化中の関数は無く、検討中の CASE 式も存在しない状態で初期化される。
  • context.estimate を true に設定し、安全でない変換を許可するモードで動作させる。

アルゴリズムまたは振る舞い

  • ローカル変数として宣言した eval_const_expressions_context の各フィールドを設定した後、eval_const_expressions_mutator を呼び出して入力された式ツリーの変形と評価を実行し、その結果を返す。

失敗モードと境界条件

  • 無効なパラメータ参照や評価不可能な構造が含まれる場合の挙動は、内部で呼び出される eval_const_expressions_mutator の規則に従う。
