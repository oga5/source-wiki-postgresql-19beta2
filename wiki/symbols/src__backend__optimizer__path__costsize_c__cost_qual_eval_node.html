ソース抜粋

~~~c void cost_qual_eval_node(QualCost *cost, Node *qual, PlannerInfo *root) { cost_qual_eval_context context;

context.root = root; context.total.startup = 0; context.total.per_tuple = 0;

cost_qual_eval_walker(qual, &context);

*cost = context.total; } ~~~

目的

指定された式や修飾条件（Node *qual）全体の評価コストを計算し、起動時コストと1タプル毎の実行コストを QualCost 構造体に格納する。

アルゴリズムまたは振る舞い

  • cost_qual_eval_context 構造体を初期化し、プランナー情報（root）を保持した上で、累積コストの起動時コスト（startup）と1タプル毎のコスト（per_tuple）を 0 に設定する。
  • cost_qual_eval_walker を呼び出して条件式ツリーを再帰的に走査し、評価コストを算出してコンテキストに蓄積する。
  • 最終的に算出された累積コストを、出力引数である cost にコピーする。
