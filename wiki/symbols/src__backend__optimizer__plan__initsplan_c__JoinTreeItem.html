目的

JoinTreeItem は、クエリの結合ツリー（jointree）を再帰的に走査および分解する処理において、構文木ノードやスコープ、およびアウタージョイン情報を保持するための内部構造体です。

フィールドと表現

  • Node *jtnode: 検査対象となる結合ツリーのノードです。
  • JoinDomain *jdomain: ON/WHERE 句のための結合ドメインです。
  • struct JoinTreeItem *jti_parent: このノードの親に対応する JoinTreeItem、最上位の場合は NULL です。
  • Relids qualscope: この結合ツリーノードに構文上含まれるベースリレーションおよびアウタージョインの識別子集合（Relids）です。
  • Relids inner_join_rels: この結合ツリーノードの階層またはその下位に出現する内部結合に構文上含まれるベースリレーションおよびアウタージョインの識別子集合です。
  • Relids left_rels: 結合ノードである場合、左側のリレーション識別子集合です。
  • Relids right_rels: 結合ノードである場合、右側のリレーション識別子集合です。
  • Relids nonnullable_rels: アウタジョインである場合、非ヌル側（non-nullable side）のリレーション識別子集合です。
  • SpecialJoinInfo *sjinfo: アウタージョインである場合、対応する SpecialJoinInfo です。
  • List *oj_joinclauses: まだ分散されていないアウタージョインの条件（quals）のリストです。
  • List *lateral_clauses: ラテラル参照によって子ノードから後回しにされた条件のリストです。
