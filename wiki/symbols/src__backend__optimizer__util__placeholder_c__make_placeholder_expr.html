目的

与えられた式と構文上の位置情報（リレーション集合）を基に、新しい PlaceHolderVar ノードを生成し、一意なプレースホルダIDを割り振る。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報を保持する構造体ポインタ
  • Expr *expr: プレースホルダ内に包む式
  • Relids phrels: プレースホルダが評価される構文上のリレーション集合
  • 戻り値: PlaceHolderVar *（新しく割り当てられ初期化されたプレースホルダ変数ノード）

前提条件と不変条件

  • root->glob が有効であり、lastPHId がインクリメント可能であること
  • 生成直後の PlaceHolderVar の phnullingrels は NULL に、phlevelsup は 0 に初期化される

アルゴリズムまたは振る舞い

  • makeNode(PlaceHolderVar) を用いて新しい PlaceHolderVar ノード領域を確保する。
  • 引数として渡された expr を ph_expr フィールドに、phrels を ph_rels フィールドにそれぞれ設定する。
  • phnullingrels を NULL に、phlevelsup を 0 に設定する（これらは後続の処理や呼び出し元によって変更される場合がある）。
  • root->glob->lastPHId をインクリメントした値を新しいプレースホルダID (phid) として割り当てる。
  • 初期化された PlaceHolderVar ポインタを返す。

失敗モードと境界条件

  • メモリ不足時に makeNode が失敗またはエラー送出する可能性がある。
