目的

ネストループ結合パスの妥当性を検証し、条件を満たす場合にのみコスト見積もりと事前チェックを経て結合関係へパスを登録する。

入力と出力

  • 引数: PlannerInfo *root, RelOptInfo *joinrel, Path *outer_path, Path *inner_path, List *pathkeys, JoinType jointype, uint64 nestloop_subtype, JoinPathExtraData *extra
  • 戻り値: void

前提条件と不変条件

  • 外部結合の形成時、入力パス自体がその外部結合リレーションをパラメータ化の依存先として使用している場合は無効とみなされ処理が中断される。
  • インナーパスがパラメータ化されている場合、外側リレーションの親関係に対して再パラメータ化可能である必要がある。

アルゴリズムまたは振る舞い

1. **パラメータ化と外部結合の制約チェック**: 入力パスのパラメータ化関係（inner_paramrels, outer_paramrels）と、形成する外側の結合リレーション（extra->sjinfo->ojrelid）との間で不正な依存関係がないか確認し、該当する場合は早期リターンする。また、リレーションの最上位親リレーション（top_parent_relids）または自身の relids を解決する。 2. **結合の必須外部パラメータ算出**: calc_nestloop_required_outer を用いて必要な外部パラメータ（required_outer）を計算し、星型スキーマ結合の許容例外に該当せず、かつ extra->param_source_rels と重複しない場合は、割り当てた required_outer を解放して破棄する。 3. **安全性および再パラメータ化の確認**: 安全でない外部結合参照がないことをアサートし、インナーパスが外側リレーションの親によってパラメータ化されている場合に、子リレーションによる再パラメータ化が可能であることを確認する。 4. **コスト事前チェックとパス追加**: initial_cost_nestloop で作業領域に初期コストを下限として計算し、add_path_precheck によって既存パスに劣後しないと判定された場合のみ、create_nestloop_path でネストループパスを生成して add_path で joinrel に登録する。判定不合格の場合は required_outer を解放してメモリをリークさせないようにする。

失敗モードと境界条件

  • extra->sjinfo->ojrelid が inner_paramrels または outer_paramrels に含まれる場合、パス構築を行わずに早期リターンする。
  • 算出された required_outer が extra->param_source_rels と重複せず、かつ allow_star_schema_join も許容しない場合は、メモリを解放して処理を中断する。
  • インナーパスが外側リレーションの親でパラメータ化されており、かつ再パラメータ化が不可能な場合は、メモリを解放して中断する。
  • add_path_precheck の結果により既存パスに支配されると見なされた場合、生成処理を行わず required_outer を解放する。
