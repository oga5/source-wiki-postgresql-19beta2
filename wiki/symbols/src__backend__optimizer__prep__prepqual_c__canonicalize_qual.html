~~~c Expr * canonicalize_qual(Expr *qual, bool is_check) { Expr *newqual;

/* Quick exit for empty qual */ if (qual == NULL) return NULL;

/* This should not be invoked on quals in implicit-AND format */ Assert(!IsA(qual, List));

/*

  • Pull up redundant subclauses in OR-of-AND trees. We do this only
  • within the top-level AND/OR structure; there's no point in looking
  • deeper. Also remove any NULL constants in the top-level structure.

    • */ newqual = find_duplicate_ors(qual, is_check);

return newqual; } ~~~

目的

修飾式全体の最適化や前処理を行い、トップレベルの AND/OR 構造から冗長な共通項の引き上げや定数の縮退処理を実行するエントリーポイントとして機能する。

入力と出力

  • 引数:
  • Expr *qual: 最適化対象の修飾式
  • bool is_check: CHECK 制約かどうかを示すフラグ
  • 戻り値:
  • Expr *: 最適化および前処理が適用された新しい修飾式、または空の場合は NULL

前提条件と不変条件

  • qual が暗黙的 AND 形式（リスト形式）である場合はアサーション違反となる。
  • 入力される修飾式はあらかじめフラットネスの前提を満たしていることが想定される。

アルゴリズムまたは振る舞い

  • 引数 qual が NULL の場合は早期リターンとして NULL を返す。
  • トップレベルの AND/OR 構造内においてのみ冗長なサブ句の引き上げ（逆 OR 分配律の適用）や、定数（NULL など）の削除処理を行うため、内部の find_duplicate_ors 関数を呼び出す。
  • より深い構造の走査は行わない。

失敗モードと境界条件

  • qual が NULL のときは安全に NULL を返して終了する。
  • qual にリストノードが渡された場合、アサーションにより処理が停止する。
