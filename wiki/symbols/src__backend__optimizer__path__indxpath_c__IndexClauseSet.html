ソース抜粋

~~~c typedef struct { bool nonempty; /* True if lists are not all empty */ /* Lists of IndexClause nodes, one list per index column */ List *indexclauses[INDEX_MAX_KEYS]; } IndexClauseSet; ~~~

目的

IndexClauseSet は、インデックスの各キー列に対応する IndexClause ノードのリストを保持し、インデックス列ごとのマッチした条件を管理する構造体です。

フィールドと表現

  • bool nonempty: リスト群がすべて空ではない場合に真となるフラグです。
  • List *indexclauses[INDEX_MAX_KEYS]: インデックスのキー列ごとの IndexClause ノードのリスト配列です（1インデックス列につき1つのリスト）。

ライフサイクルと所有権

  • プランニング中に構築される IndexClause や各 List セルは、通常クルーザーのメモリコンテキスト（PlannerInfo->planner_cxt）上で割り当てられ、クエリ計画完了後に一括解放されます。
