typedef enum { COSTS_EQUAL, /* path costs are fuzzily equal */ COSTS_BETTER1, /* first path is cheaper than second */ COSTS_BETTER2, /* second path is cheaper than first */ COSTS_DIFFERENT, /* neither path dominates the other on cost */ } PathCostComparison; ~~~

目的

2つのパスコスト比較において、第1のパスのコストが第2のパスよりも安い（優れている）ことを示す列挙子です。

アルゴリズムまたは振る舞い

PathCostComparison 列挙型の一部として定義されており、ファジィコスト比較やパスの選抜時にコスト優劣の判定結果を表すために使用されます。
