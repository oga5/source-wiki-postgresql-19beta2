目的

提案された2つのリレーション間（または結合関係）の結合が、特殊結合（外結合や半結合など）の順序制約、LATERAL 参照、および関連するパラメータ化の制約に照らして合法であるか判定し、対応する SpecialJoinInfo と逆順フラグを決定する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • RelOptInfo *rel1: 結合の左側（または片側）のリレーション
  • RelOptInfo *rel2: 結合の右側（またはもう片側）のリレーション
  • Relids joinrelids: 2つのリレーションの結合によって形成される全リレーションID集合
  • SpecialJoinInfo **sjinfo_p: マッチした特殊結合情報を格納する出力ポインタ（不適合時は NULL が設定される）
  • bool *reversed_p: 結合の左右が逆転しているかを格納する出力ポインタ
  • 戻り値: bool: 結合が合法な場合は true、不適格な場合は false を返す

前提条件と不変条件

  • 失敗して戻る場合でも、予期せぬ未初期化変数の警告を避けるため出力パラメータ *sjinfo_p は NULL に、*reversed_p は false に必ず初期化される。

アルゴリズムまたは振る舞い

1. **初期化**: 出力パラメータ *sjinfo_p と *reversed_p を初期化し、ローカル状態変数群をクリアする。 2. **特殊結合情報の走査**: root->join_info_list 内の各 SpecialJoinInfo（sjinfo）を順に評価する。

  • sjinfo の右側（min_righthand）が提案された joinrelids とオーバーラップしない場合、または提案された結合が右側内部に完全に含まれる場合は、この特殊結合に対して関連外としてスキップする。
  • rel1 または rel2 のいずれかの入力内に既にこの特殊結合の全体が含まれている場合もスキップする。
  • 半結合（JOIN_SEMI）の場合、右側が既に各入力内に含まれていて一致しないときはスキップする。
  • 一方が min_lefthand を持ち、もう一方が min_righthand を持つ場合は、一致する match_sjinfo を設定し、順序の反転有無を記録する（複数の sjinfo にマッチした場合は無効な結合パスとして false を返す）。
  • 半結合において、右側（syn_righthand）が rel2 と一致し create_unique_paths が成功する場合、あるいは rel1 と一致し成功する場合は、一意化された半結合として match_sjinfo と reversed、unique_ified を設定する。
  • それ以外のケースで、両方の入力が sjinfo->min_righthand とオーバーラップする場合は過去の違反とみなして続行し、そうでない場合は結合がこの sjinfo の右側に結びつくための要件（sjinfo->jointype == JOIN_LEFT かつ joinrelids が左側とオーバーラップしないこと）を満たすかを判定し、満たさない場合は不適合として false を返す。

    • 3. **左側結合要件の最終判定**: 結合が左側結合の要件（must_be_leftjoin）を満たしつつマッチした sjinfo が存在しない、あるいは JOIN_LEFT ではないか、左側が厳格（lhs_strict）でない場合は false を返す。 4. **LATERAL 参照制約の検証**: クエリが hasLateralRTEs を持つ場合、以下のチェックを行う。

  • rel1 と rel2 の双方がお互いにラテラル参照を持っている場合は false を返す。
  • 片方向のみラテラル参照がある場合、対応するネストループとして実装可能か、および直接参照（direct_lateral_relids）が存在するか検証し、違反すれば false を返す。
  • 結合の最小パラメータ化（min_join_parameterization）と外部結合の RHS 伝播を追跡し、構築不可能な外部結合の依存関係がある場合は false を返す。

    • 5. **成功時の返却**: すべてのチェックを通過した場合、*sjinfo_p に match_sjinfo を、*reversed_p に reversed を代入して true を返す。

呼び出し元と呼び出し先

  • 呼び出し元: make_join_rel, has_legal_joinclause
  • 呼び出し先: bms_overlap, bms_is_subset, bms_equal, create_unique_paths, min_join_parameterization, bms_copy, bms_add_members

失敗モードと境界条件

  • 複数の SpecialJoinInfo に対して同時にマッチした場合は、無効な結合パスと判定され直ちに false を返す。
  • 半結合において一意化（create_unique_paths）に失敗した場合や、必要な JOIN_LEFT 条件・厳格性（lhs_strict）を満たさない場合は false を返す。
  • LATERAL 参照が双方向に存在する場合、または直接参照ではなく間接参照のみである場合は不成立として false を返す。
  • 結合の最小パラメータ化が外部結合の RHS リレーションと競合して構築不能となる場合は false を返す。

保守担当者向けメモ

  • 出力引数 *sjinfo_p と *reversed_p は、関数のどのリターンパス（成功時・失敗時）においても必ず書き込まれるよう保証されている。
