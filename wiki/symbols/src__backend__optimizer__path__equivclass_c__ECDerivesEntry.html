ソース抜粋

~~~c typedef struct { uint32 status; ECDerivesKey key; RestrictInfo *rinfo; } ECDerivesEntry; ~~~

目的

ECDerivesEntry は、派生条件（derived clauses）の検索を高速化するために simplehash ベースのハッシュテーブル（ec_derives_hash）内で使用されるエントリ構造体である。

フィールドと表現

  • uint32 status: ハッシュテーブルのエントリ状態を管理するためのステータスフィールド。
  • ECDerivesKey key: 派生条件を識別するための正規化されたキー構造体。2つの等価メンバ（EM）と親等価クラス（EC）の組み合わせを保持する。
  • RestrictInfo *rinfo: キーに対応して動的に生成または取得される制限・結合条件（RestrictInfo）へのポインタ。
