目的

クエリの基本結合および単一リレーションに対するパス（アクセスパス）の生成を統括し、結合木に基づく最適な結合リレーション（RelOptInfo）を構築する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーの全体状態や構文木を保持する構造体ポインタ
  • query_pathkeys_callback qp_callback: パスキー（出力順序）を計算するためのコールバック関数
  • void *qp_extra: コールバックに渡される追加の拡張データへのポインタ
  • 戻り値:
  • RelOptInfo *: 構築された最終的な結合リレーション構造体のポインタ

前提条件と不変条件

  • 呼び出し前に subquery_planner によって append_rel_list が設定されていること
  • ジョインツリーの fromlist が空ではないこと

アルゴリズムまたは振る舞い

1. **状態初期化**: PlannerInfo の各種結合リストやハッシュテーブル、プレースホルダー関連フィールドを空（NIL または NULL）に初期化し、setup_simple_rel_arrays を呼び出してベースリレーション用配列をセットアップする。 2. **高速パス（RTE_RESULT の場合）**: ジョインツリーの fromlist が単一の RangeTblRef であり、かつ対応する RangeTblEntry の種類が RTE_RESULT である場合、結合処理をバイパスして以下の処理を行う。

  • build_simple_rel により直接 final_rel を作成する。
  • 必要に応じて並列実行安全性を検証し、create_group_result_path を用いて Result パスを追加する。
  • set_cheapest を呼び出し、等価クラスのマージ完了を設定した上で qp_callback を実行して final_rel を返す。

    • 3. **メタデータ構築と等価クラス処理**:

  • add_base_rels_to_query によりジョインツリーからベースリレーションを追加する。
  • remove_useless_groupby_columns で冗長な GROUP BY カラムを削除する。
  • build_base_rel_tlists、find_placeholders_in_jointree、find_lateral_references、deconstruct_jointree を呼び出し、ターゲットリスト、プレースホルダー、ラテラル参照、結合リストを構築する。
  • reconsider_outer_join_clauses と generate_base_implied_equalities を用いて、外部結合句の再検討や等価クラスに基づく制限条項の生成を行う。
  • パスキーを計算するため qp_callback を実行する。

    • 4. **結合の最適化とクエリ構造の拡張**:

  • fix_placeholder_input_needed_levels を呼び出し、プレースホルダーの必要入力レベルを修正する。
  • remove_useless_joins、reduce_unique_semijoins、remove_useless_self_joins により、不要な結合、セミジョイン、セルフ結合を削減する。
  • add_placeholders_to_base_rels、create_lateral_join_info、match_foreign_keys_to_quals、extract_restriction_or_clauses、setup_eager_aggregation を順次実行する。
  • add_other_rels_to_query でパーティション等の子リレーションを展開し、distribute_row_identity_vars で行識別変数を対象リレーションに配布する。

    • 5. **最終プラン生成**:

  • make_one_rel を呼び出して最終的な結合リレーションとアクセスパスを構築する。

失敗モードと境界条件

  • final_rel、final_rel->cheapest_total_path が取得できなかった場合、あるいは最安パスの param_info が NULL でない場合は、elog(ERROR) により「failed to construct the join relation」エラーを送出する。
