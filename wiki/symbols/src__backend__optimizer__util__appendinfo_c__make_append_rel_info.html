~~~c AppendRelInfo * make_append_rel_info(Relation parentrel, Relation childrel, Index parentRTindex, Index childRTindex) { AppendRelInfo *appinfo = makeNode(AppendRelInfo);

appinfo->parent_relid = parentRTindex; appinfo->child_relid = childRTindex; appinfo->parent_reltype = parentrel->rd_rel->reltype; appinfo->child_reltype = childrel->rd_rel->reltype; make_inh_translation_list(parentrel, childrel, childRTindex, appinfo); appinfo->parent_reloid = RelationGetRelid(parentrel);

目的

親リレーションと子リレーションのペアから AppendRelInfo ノードを生成し、範囲テーブルインデックス、リレーション型、オブジェクト識別子、および列の翻訳リストを設定する。

入力と出力

  • 引数:
  • Relation parentrel: 親リレーションのオープンされたリレーション記述子
  • Relation childrel: 子リレーションのオープンされたリレーション記述子
  • Index parentRTindex: 親リレーションのレンジテーブルインデックス
  • Index childRTindex: 子リレーションのレンジテーブルインデックス
  • 戻り値:
  • 生成・初期化された AppendRelInfo * 構造体へのポインタ

前提条件と不変条件

  • parentrel および childrel は有効な Relation 構造体を指していること。

アルゴリズムまたは振る舞い

  • makeNode(AppendRelInfo) を用いて新しい AppendRelInfo ノードを割り当てる。
  • 引数で渡された親および子のレンジテーブルインデックスをそれぞれ parent_relid および child_relid に代入する。
  • parentrel および childrel の rd_rel->reltype からリレーション型を取得し、それぞれ parent_reltype および child_reltype に設定する。
  • make_inh_translation_list を呼び出して、親リレーションから子リレーションへの列の翻訳リストやマッピングを初期化する。
  • RelationGetRelid(parentrel) を用いて親リレーションの OID を取得し、parent_reloid に設定する。
