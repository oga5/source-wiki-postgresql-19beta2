~~~c typedef struct { List *rollups; List *hash_sets_idx; double dNumHashGroups; bool any_hashable; Bitmapset *unsortable_refs; Bitmapset *unhashable_refs; List *unsortable_sets; int *tleref_to_colnum_map; } grouping_sets_data; ~~~

目的

grouping_sets_dataは、グループ化セット（Grouping Sets）のロールアップ情報、ハッシュセットのインデックス、ハッシュグループの推定数、ハッシュ化の可否、ソートまたはハッシュ化が不可能な参照やセット、およびターゲットリスト参照から列番号へのマッピング情報を保持する構造体です。

フィールドと表現

  • rollups: ロールアップ構造を保持するリスト（List *）。
  • hash_sets_idx: ハッシュセットのインデックスを保持するリスト（List *）。
  • dNumHashGroups: 推定されるハッシュグループ数（double）。
  • any_hashable: ハッシュ化可能な要素が含まれているかを示すフラグ（bool）。
  • unsortable_refs: ソート不可能な参照を表すビットマップセット（Bitmapset *）。
  • unhashable_refs: ハッシュ化不可能な参照を表すビットマップセット（Bitmapset *）。
  • unsortable_sets: ソート不可能なセットを保持するリスト（List *）。
  • tleref_to_colnum_map: ターゲットリスト参照から列番号へのマッピング配列（int *）。
