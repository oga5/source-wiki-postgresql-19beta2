  • Deal with cases where val and/or base is NaN, following the rule that
  • NaN sorts after non-NaN (cf cmp_numerics). The offset cannot affect
  • the conclusion.

    • */ if (NUMERIC_IS_NAN(val)) { if (NUMERIC_IS_NAN(base)) result = true; /* NAN = NAN */ else result = !less; /* NAN > non-NAN */ } else if (NUMERIC_IS_NAN(base)) { result = less; /* non-NAN < NAN */ }

  • (see in_range_float8_float8() for reasoning).

    • */ result = true; } else if (sub) { /* base - offset must be -inf */ if (less) result = NUMERIC_IS_NINF(val); /* only -inf is <= sum */ else result = true; /* any val is >= sum */ } ~~~
