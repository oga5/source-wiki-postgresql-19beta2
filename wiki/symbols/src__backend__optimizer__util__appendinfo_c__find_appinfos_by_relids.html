~~~c AppendRelInfo ** find_appinfos_by_relids(PlannerInfo *root, Relids relids, int *nappinfos) { AppendRelInfo **appinfos; int cnt = 0; int i;

/* Allocate an array that's certainly big enough */ appinfos = palloc_array(AppendRelInfo *, bms_num_members(relids));

i = -1; while ((i = bms_next_member(relids, i)) >= 0) { AppendRelInfo *appinfo = root->append_rel_array[i];

if (!appinfo) { /* Probably i is an OJ index, but let's check */ if (find_base_rel_ignore_join(root, i) == NULL) continue; /* It's a base rel, but we lack an append_rel_array entry */ elog(ERROR, "child rel %d not found in append_rel_array", i); }

appinfos[cnt++] = appinfo; } *nappinfos = cnt; return appinfos; } ~~~

目的

指定された Relids（Bitmapset）に含まれる各リレーション識別子に対応する AppendRelInfo ポインタを root->append_rel_array から収集し、動的に割り当てられた配列として返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を保持する構造体ポインタ
  • Relids relids: 対象のリレーション識別子集合
  • int *nappinfos: 収集された AppendRelInfo の実際の数を書き戻すための出力ポインタ
  • 戻り値:
  • AppendRelInfo **: 見つかった AppendRelInfo へのポインタを格納した配列

前提条件と不変条件

  • 引数 relids に含まれる各メンバーインデックス i について、それが外部結合インデックス（OJインデックス）等ではなくベースリレーションである場合、root->append_rel_array[i] に有効な AppendRelInfo エントリが存在していなければならない。

アルゴリズムまたは振る舞い

1. **配列の領域確保**: bms_num_members(relids) を用いて、十分に大きいサイズの AppendRelInfo * 配列を palloc_array で割り当てる。 2. **ビットマップセットの走査**: bms_next_member を使用して relids 内のすべてのメンバーインデックス i を順に走査する。 3. **エントリの取得と検証**:

  • 各インデックス i に対し、root->append_rel_array[i] から AppendRelInfo *appinfo を取得する。
  • appinfo が NULL の場合、find_base_rel_ignore_join(root, i) を呼び出してベースリレーションが存在するか確認する。
  • find_base_rel_ignore_join が NULL を返す場合は外部結合インデックスであるとみなして無視（continue）する。
  • そうでない場合はベースリレーションであるにもかかわらずエントリが欠損しているため、elog(ERROR, ...) によりエラーを送出する。

    • 4. **結果の格納**: 有効な appinfo を結果配列の cnt 番目に格納し、カウンタ cnt をインクリメントする。 5. **返却**: 収集した総数を *nappinfos に設定し、構築した配列へのポインタを返す。

失敗モードと境界条件

  • **子リレーションのエントリ欠損**: ベースリレーションに対応する append_rel_array エントリが存在しない場合、elog(ERROR, "child rel %d not found in append_rel_array", i) が発生する。
