目的

遺伝的クエリ最適化（GEQO）の探索過程において、ある染色体（Chromosome）の遺伝子配列および評価値を別の染色体へ複製します。

入力と出力

  • 入力:
  • PlannerInfo *root: クエリの最適化に関する情報（本関数内では直接参照されません）。
  • Chromosome *chromo1: コピー先の染色体へのポインタ。
  • Chromosome *chromo2: コピー元の染色体へのポインタ。
  • int string_length: 複製する遺伝子配列長（要素数）。
  • 出力: なし（戻り値 void）。chromo1 が指す構造体のメンバが書き換えられます。

前提条件と不変条件

  • コピー先およびコピー元の Chromosome ポインタは有効であり、string_length で指定された要素数を保持するのに十分なメモリ領域が確保されている必要があります。

アルゴリズムまたは振る舞い

  • 0 から string_length - 1 までのループを回し、chromo2->string の各要素を chromo1->string の対応する位置へ順次代入します。
  • ループ終了後、chromo2->worth の値を chromo1->worth に代入して評価値を引き継ぎます。

失敗モードと境界条件

  • string_length が実際の配列の割り当てサイズを超えている場合、バッファオーバーランを引き起こす可能性があります。
