~~~c static bool desirable_join(PlannerInfo *root, RelOptInfo *outer_rel, RelOptInfo *inner_rel) { /*

  • Join if there is an applicable join clause, or if there is a join order
  • restriction forcing these rels to be joined.

    • */ if (have_relevant_joinclause(root, outer_rel, inner_rel) || have_join_order_restriction(root, outer_rel, inner_rel)) return true;

/* Otherwise postpone the join till later. */ return false; } ~~~

目的

2つのリレーション間に適用可能な結合条件または結合順序制約が存在するかどうかを判定し、直積を避けて優先的に結合すべきかを決定する。

アルゴリズムまたは振る舞い

  • have_relevant_joinclause(root, outer_rel, inner_rel) が真を返すか、または have_join_order_restriction(root, outer_rel, inner_rel) が真を返す場合に true を返す。
  • どちらの条件も満たさない場合は結合を後回しにするため false を返す。
