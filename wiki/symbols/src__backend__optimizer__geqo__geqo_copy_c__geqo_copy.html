目的

GEQO（遺伝的クエリ最適化）モジュールにおいて、ある個体（染色体）の遺伝子配列と評価値を別の個体にインプレースで複製します。

シグネチャまたは形状

  • シグネチャ: void geqo_copy(PlannerInfo *root, Chromosome *chromo1, Chromosome *chromo2, int string_length)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー情報（本関数内では未使用）
  • Chromosome *chromo1: 複製先の染色体構造体へのポインタ
  • Chromosome *chromo2: 複製元の染色体構造体へのポインタ
  • int string_length: 複製する遺伝子配列長
  • 戻り値: なし（void）

前提条件と不変条件

  • 複製先の chromo1->string 配列には、string_length で指定された要素数を格納するために十分なメモリ領域が事前に割り当てられている必要があります。

アルゴリズムまたは振る舞い

  • ループ処理により、0 から string_length - 1 までのインデックスについて、chromo2->string[i] の値を chromo1->string[i] に順次代入します。
  • 遺伝子配列のコピー完了後、chromo2->worth の値を chromo1->worth にコピーします。

失敗モードと境界条件

  • string_length が実際の string 配列の割り当てサイズを超過している場合、バッファオーバーランが発生する可能性があります。
