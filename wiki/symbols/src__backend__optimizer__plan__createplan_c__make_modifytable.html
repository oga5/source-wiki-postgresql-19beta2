目的

ModifyTable プランノードを新しく割り当てて初期化し、各種修飾句、コンフリクト処理設定、外国テーブル（FDW）用のプライベート情報や直接更新プランを構築・結合します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Plan *subplan: 子プランノード
  • CmdType operation: 操作の種類（CMD_UPDATE, CMD_MERGE など）
  • bool canSetTag: コマンドタグを設定可能かどうか
  • Index nominalRelation: 公称リレーションのインデックス
  • Index rootRelation: ルートリレーションのインデックス
  • List *resultRelations: 結果リレーションの範囲テーブルインデックス（RTI）リスト
  • List *updateColnosLists: 更新対象列番号のリスト
  • List *withCheckOptionLists: WITH CHECK OPTION のリスト
  • List *returningLists: RETURNING 句のリスト
  • List *rowMarks: 行マークのリスト
  • OnConflictExpr *onconflict: ON CONFLICT 式
  • List *mergeActionLists: MERGE アクションのリスト
  • List *mergeJoinConditions: MERGE 結合条件のリスト
  • ForPortionOfExpr *forPortionOf: 期間指定（FOR PORTION OF）式
  • int epqParam: 実行時 EvalPlanQual パラメータ
  • 戻り値:
  • ModifyTable *: 初期化された ModifyTable プランノードへのポインタ

前提条件と不変条件

  • operation が CMD_MERGE であるか、あるいは operation が CMD_UPDATE の場合は resultRelations と updateColnosLists の長さが等しく、それ以外の場合は updateColnosLists が NIL でなければならない。
  • withCheckOptionLists が NIL でない場合、その長さは resultRelations の長さと等しくなければならない。
  • returningLists が NIL でない場合、その長さは resultRelations の長さと等しくなければならない。

アルゴリズムまたは振る舞い

1. 基本ノードの割り当てと初期化:

  • makeNode(ModifyTable) でノードを割り当て、子プラン（subplan）、右ツリー、修飾句（qual）、ターゲットリスト（targetlist）を初期化する（ターゲットリストは setrefs.c が必要に応じて埋めるため空にする）。
  • operation, canSetTag, nominalRelation, rootRelation, resultRelations をノードに設定する。

    • 2. ON CONFLICT 条件の処理:

  • onconflict が存在しない場合は各種競合処理フィールドをデフォルト（無効値や NIL）に設定する。
  • 存在するばあい、アクション、ロック強度、更新セット式をコピーし、extract_update_targetlist_colnos で更新対象列番号を抽出し、infer_arbiter_indexes で一意インデックスの推論を行い、排他関係の RTI およびターゲットリストを設定する。

    • 3. その他のプロパティ設定:

  • updateColnosLists, forPortionOf, withCheckOptionLists, returningLists, rowMarks, mergeActionLists, mergeJoinConditions, epqParam およびパーサからの returningOldAlias と returningNewAlias を設定する。

    • 4. 結果リレーションと FDW（外国テーブル）の走査:

  • resultRelations をループし、各リレーションの FdwRoutine を取得する（PlannerInfo の simple_rel_array または planner_rt_fetch を経由する）。
  • 外国テーブルへの非システムテーブルアクセス制限を満たしているか検証し、違反している場合はエラーを報告する。
  • operation が CMD_MERGE で対象が外国テーブルである場合は非サポートエラーを報告する。
  • FDW が直接修正（Direct Modify）をサポートしており、行トリガー、保存生成列、親ビューからの WITH CHECK OPTION、RETURNING での OLD/OLD/NEW 変数、および遷移テーブルの条件がない場合に PlanDirectModify を試みる。
  • 直接修正が成功した場合は direct_modify_plans ビットマップセットにインデックスを追加し、失敗した場合で PlanForeignModify が存在する場合は fdw_private 情報を構築して fdw_private_list に追加する。

    • 5. 完了:

  • 収集した fdwPrivLists と fdwDirectModifyPlans をノードに格納して返す。

失敗モードと境界条件

  • operation が CMD_UPDATE の際、resultRelations と updateColnosLists の要素数が一致しない場合は Assert によりアボートする。
  • withCheckOptionLists または returningLists が空でない場合、それぞれのリスト長が resultRelations の長さに一致しないと Assert によりアボートする。
  • 非システム外国テーブルへのアクセスが制限されている状態でアクセスしようとした場合、ERRCODE_OBJECT_NOT_IN_PREREQUISITE_STATE のエラーが送出される。
  • パーティション等に含まれる外国テーブルに対して CMD_MERGE を実行しようとした場合、ERRCODE_FEATURE_NOT_SUPPORTED のエラーが送出される。
