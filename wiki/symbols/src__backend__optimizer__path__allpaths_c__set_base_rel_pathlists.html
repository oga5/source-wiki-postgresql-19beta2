~~~c static void set_base_rel_pathlists(PlannerInfo *root) { Index rti;

for (rti = 1; rti < root->simple_rel_array_size; rti++) { RelOptInfo *rel = root->simple_rel_array[rti];

/* there may be empty slots corresponding to non-baserel RTEs */ if (rel == NULL) continue;

Assert(rel->relid == rti); /* sanity check on array */

/* ignore RTEs that are "other rels" */ if (rel->reloptkind != RELOPT_BASEREL) continue;

定義

  • PlannerInfo *root が保持するシンプルリレーション配列を走査し、各ベースリレーションに対してパスリスト（アクセスパス群）を構築する関数である。定義箇所は src/backend/optimizer/path/allpaths.c:383 である。

目的

クエリ内のすべての有効なベースリレーション（RELOPT_BASEREL）を対象として、それぞれに適合するスキャン方法やアクセスパスを網羅したパスリストを生成することである。

シグネチャまたは形状

static void set_base_rel_pathlists(PlannerInfo *root)

入力と出力

  • 入力:
  • root: プランナ全体の情報を保持する PlannerInfo 構造体へのポインタ。
  • 出力: なし（void）

前提条件と不変条件

  • root->simple_rel_array 内の各スロットについて、割り当てられているリレーションが存在する場合、そのリレーションID rel->relid は配列のインデックス rti と一致していなければならない（Assert(rel->relid == rti)）。

アルゴリズムまたは振る舞い

1. rti = 1 から root->simple_rel_array_size - 1 までループを回し、root->simple_rel_array 内の各リレーション（RelOptInfo *rel）を順番に取得する。 2. リレーションが NULL である場合は、非ベースリレーションのRTEに対応する空スロットであるためスキップする。 3. rel->relid == rti であることを Assert で検証する。 4. rel->reloptkind が RELOPT_BASEREL 以外の「その他のリレーション（other rels）」である場合はスキップする。 5. 条件を満たしたベースリレーションに対し、set_rel_pathlist(root, rel, rti, root->simple_rte_array[rti]) を呼び出して当該リレーションのパスリストを設定する。

呼び出し元と呼び出し先

  • 呼び出し元: make_one_rel
  • 呼び出し先: set_rel_pathlist

失敗モードと境界条件

  • root->simple_rel_array のスロットが NULL である場合や、reloptkind が RELOPT_BASEREL 以外の場合は処理をスキップするため、安全に除外される。
