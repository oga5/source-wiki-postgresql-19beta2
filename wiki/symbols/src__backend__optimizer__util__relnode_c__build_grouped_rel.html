目的

既存のリレーション情報構造体（RelOptInfo）を複製し、グループ化された新しいリレーション表現用ノードを構築して返します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報へのポインタ。
  • RelOptInfo *rel: 元となるリレーション情報構造体へのポインタ。
  • 戻り値:
  • RelOptInfo *: 新たに割り当てられ初期化されたグループ化リレーションの RelOptInfo ポインタ。

前提条件と不変条件

  • 入力された rel の全領域が memcpy によって新しい RelOptInfo ノードへバイト単位でコピーされます。
  • コピー直後、パス情報（pathlist, ppilist, partial_pathlist, 最安パス等）、パーティション情報（スキーム、境界、クオリティ等）、およびサイズ見積もり（rows）は安全にクリア（リセット）されます。

アルゴリズムまたは振る舞い

1. makeNode(RelOptInfo) を用いて新しい RelOptInfo ノードのメモリ領域を割り当てます。 2. memcpy により、引数 rel の中身を新しく割り当てた grouped_rel にコピーします。 3. パス情報フィールド群（pathlist, ppilist, partial_pathlist, cheapest_startup_path, cheapest_total_path, cheapest_parameterized_paths）を初期状態（NIL または NULL）にクリアします。 4. パーティション情報フィールド群（part_scheme, boundinfo, partition_qual, part_rels, live_parts, all_partrels, partexprs, nullable_partexprs を初期化し、nparts を -1 に、partbounds_merged と consider_partitionwise_join を false に設定します。 5. サイズ見積もりフィールドである rows を 0 にリセットします。 6. 構築された grouped_rel を返します。

失敗モードと境界条件

  • メモリ不足時には palloc 経由の makeNode によりエラー（OOM）が発生する可能性があります。
