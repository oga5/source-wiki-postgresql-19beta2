目的

NestPath から実行エンジンの処理単位である NestLoop プランノードを構築し、内部側と外部側のプランや結合条件、ネストループパラメータを組み立てて返します。

シグネチャまたは形状

static NestLoop * create_nestloop_plan(PlannerInfo *root, NestPath *best_path)

入力と出力

  • 入力:
  • PlannerInfo *root: プラン作成の全体コンテキスト情報
  • NestPath *best_path: 最適化フェーズで選択されたネストループ結合パス
  • 出力:
  • NestLoop *: 構築されたネストループプランノード

前提条件と不変条件

  • reparameterize_path_by_child 実行後の内側結合パスは NULL であってはならず、これをアサートで検証します。

アルゴリズムまたは振る舞い

1. 内側パスの再パラメータ化: 内側結合パスが外部リレーションの最上位親でパラメータ化されている場合、対応する修正を適用します。 2. 外部プランおよび内部プランの再帰的生成: create_plan_recurse を用いて外部プランを生成し、一時的に root->curOuterRels に外部リレーションの relids を追加した上で内側プランを生成します。その後、curOuterRels を復元します。 3. 結合条件の整理と抽出: 結合の制限句を order_qual_clauses で最適順序に並べ替えた後、アウタージョインであるかどうかに応じて extract_actual_join_clauses または extract_actual_clauses を呼び出して条件句（joinclauses と otherclauses）を取得します。 4. パラメータの置換: パスにパラメータ情報が存在する場合、結合条件内の外部関係変数をネストループパラメータに置換します。 5. ネストループパラメータの特定とプレースホルダ変数（PHV）の補完: identify_current_nestloop_params で必要なパラメータを特定し、パラメータが PlaceHolderVar であり外部プランのターゲットリストに存在しない場合は、outer_tlist に当該式を追加して並列安全性も追跡します。 6. プランノードの作成: make_nestloop を呼び出して NestLoop ノードを生成し、copy_generic_path_info でパスの共通情報をコピーした後に返却します。
