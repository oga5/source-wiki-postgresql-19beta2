ソース抜粋

~~~c static bool is_safe_restriction_clause_for(RestrictInfo *rinfo, RelOptInfo *rel) { /*

  • We want clauses that mention the rel, and only the rel. So in
  • particular pseudoconstant clauses can be rejected quickly. Then check
  • the clause's Var membership.

    • */ if (rinfo->pseudoconstant) return false; if (!bms_equal(rinfo->clause_relids, rel->relids)) return false;

/* We don't want extra evaluations of any volatile functions */ if (contain_volatile_functions((Node *) rinfo->clause)) return false;

return true; } ~~~

目的

指定された RestrictInfo が、対象のリレーションにとって安全な制限条件（単一のリレーションのみを参照し、擬似定数や volatile 関数を含まない条件）であるかどうかを判定します。

シグネチャまたは形状

  • シグネチャ: static bool is_safe_restriction_clause_for(RestrictInfo *rinfo, RelOptInfo *rel)

入力と出力

  • 引数:
  • RestrictInfo *rinfo: 判定対象の制限情報オブジェクト
  • RelOptInfo *rel: 基準となるターゲットリレーション情報
  • 戻り値:
  • bool: 条件が安全な制限条件として使用できる場合は true、そうでない場合は false

前提条件と不変条件

  • 渡される rinfo は擬似定数（pseudoconstant）であってはならず、その参照するリレーションの集合（clause_relids）が rel のリレーション識別子（relids）と完全に一致している必要があります。
  • 条件式内に volatile 関数が含まれていてはなりません。

アルゴリズムまたは振る舞い

  • rinfo->pseudoconstant が真である場合、擬似定数条件であるため直ちに false を返します。
  • rinfo->clause_relids と rel->relids が bms_equal により一致するか比較し、一致しない場合は直ちに false を返します。
  • rinfo->clause に対して contain_volatile_functions を呼び出し、volatile 関数が含まれている場合は直ちに false を返します。
  • 上記のすべての検査を通過した場合は true を返します。

呼び出し元と呼び出し先

  • 呼び出し元: extract_or_clause
  • 呼び出し先: bms_equal, contain_volatile_functions

失敗モードと境界条件

  • 該当条件が単一のリレーション以外（複数リレーションや結合条件）を参照している場合、または全く参照していない場合は不適格とみなされ false が返されます。
  • 予期せぬ多重評価を防ぐため、volatile 関数を含む式はすべて除外されます。
