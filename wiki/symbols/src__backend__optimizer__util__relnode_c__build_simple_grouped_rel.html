~~~c RelOptInfo * build_simple_grouped_rel(PlannerInfo *root, RelOptInfo *rel) { RelOptInfo *grouped_rel; RelAggInfo *agg_info;

/*

  • We should have available aggregate expressions and grouping
  • expressions, otherwise we cannot reach here.

    • */ Assert(root->agg_clause_list != NIL); Assert(root->group_expr_list != NIL);

/* nothing to do for dummy rel */ if (IS_DUMMY_REL(rel)) return NULL;

/*

  • Prepare the information needed to create grouped paths for this simple
  • relation.

    • */ agg_info = create_rel_agg_info(root, rel, true); if (agg_info == NULL) return NULL;

/*

  • If grouped paths for the given simple relation are not considered
  • useful, skip building the grouped relation.

    • */ if (!agg_info->agg_useful) return NULL;

/* Track the set of relids at which partial aggregation is applied */ agg_info->apply_agg_at = bms_copy(rel->relids);

/* build the grouped relation */ grouped_rel = build_grouped_rel(root, rel); grouped_rel->reltarget = agg_info->target; grouped_rel->rows = agg_info->grouped_rows; grouped_rel->agg_info = agg_info;

rel->grouped_rel = grouped_rel;

return grouped_rel; } ~~~

目的

単一リレーションに対する早期集約（Eager Aggregation）用のグループ化リレーション（RelOptInfo）を構築し、集約情報の設定やリレーションへの紐付けを行う。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナーのグローバル情報ツリー
  • RelOptInfo *rel: グループ化の対象となる単一リレーション
  • 戻り値: RelOptInfo * （構築されたグループ化リレーション、または条件不成立やダミーリレーション等の場合に返される NULL）

前提条件と不変条件

  • root->agg_clause_list および root->group_expr_list が空（NIL）ではないこと。

アルゴリズムまたは振る舞い

1. **前提条件の検証**: root->agg_clause_list と root->group_expr_list が NIL でないことをアサートで確認する。 2. **ダミーリレーションのチェック**: 対象リレーション rel が IS_DUMMY_REL である場合は何も行わず NULL を返す。 3. **集約情報の作成**: create_rel_agg_info(root, rel, true) を呼び出して集約用情報を準備する。結果が NULL の場合は NULL を返す。 4. **集約の有用性判定**: 取得した agg_info->agg_useful が偽である場合は、グループ化リレーションの構築をスキップして NULL を返す。 5. **部分集約適用の追跡**: agg_info->apply_agg_at に rel->relids のコピーを設定する。 6. **グループ化リレーションの構築と設定**:

  • build_grouped_rel(root, rel) を呼び出して grouped_rel を生成する。
  • grouped_rel->reltarget に agg_info->target を設定する。
  • grouped_rel->rows に agg_info->grouped_rows を設定する。
  • grouped_rel->agg_info に agg_info を設定する。
  • 対象リレーションの rel->grouped_rel に生成した grouped_rel を格納し、これを返す。

失敗モードと境界条件

  • 対象リレーションがダミーリレーション（IS_DUMMY_REL(rel) が真）の場合、早期に NULL を返す。
  • create_rel_agg_info の戻り値が NULL である場合、処理を中断して NULL を返す。
  • グループ化パスが有用ではないと判定された場合（agg_info->agg_useful が偽）、処理を中断して NULL を返す。
