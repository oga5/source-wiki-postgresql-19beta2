目的

EquivalenceMemberIterator が指す状態を進行させながら、等価クラス（EquivalenceClass）に含まれる次の EquivalenceMember を順次返却する。

シグネチャまたは形状

  • シグネチャ: EquivalenceMember * eclass_member_iterator_next(EquivalenceMemberIterator *it)

入力と出力

  • 引数:
  • it: 走査状態を保持する EquivalenceMemberIterator * 型のイテレータ構造体
  • 戻り値:
  • 次の EquivalenceMember *（存在しない場合は NULL）

前提条件と不変条件

  • 引数 it および内部の it->ec は有効なオブジェクトを指していること

アルゴリズムまたは振る舞い

1. 現在リストの走査: it->current_list が非 NULL かつ it->current_cell が非 NULL の間、it->current_cell から EquivalenceMember を取得し、細胞ポインタを次のセルに進めてからそのメンバを返す。 2. 次のリストの探索: 現在のリストを使い切った場合、child_relids ビットマップから次のリレーションID（it->current_relid）を順次取り出すループを実行する。 3. 境界チェック: 取得した current_relid が it->ec->ec_childmembers_size 以上の場合は、安全性確保のため NULL を返して終了する。 4. リストの切り替え: リレーションIDに対応する子メンバリスト（ec_childmembers）を取得し、それが空（NIL）でなければ、current_cell をその先頭に設定してステップ1に戻る。 5. 終了: 走査すべきリストやリレーションが残っていない場合は NULL を返す。

失敗モードと境界条件

  • 与えられたリレーションIDが ec_childmembers_size を超えている場合、保護のため即座に NULL を返す。
  • 走査対象のメンバが存在しない、あるいは走査が完了した場合は NULL を返す。
