~~~c void SetPlannerInfoExtensionState(PlannerInfo *root, int extension_id, void *opaque) { Assert(extension_id >= 0);

/* If there is no array yet, create one. */ if (root->extension_state == NULL) { Size sz;

root->extension_state_allocated = Max(4, pg_nextpower2_32(extension_id + 1)); sz = root->extension_state_allocated * sizeof(void *); root->extension_state = MemoryContextAllocZero(root->planner_cxt, sz); }

/* If there's an array but it's currently full, expand it. */ if (extension_id >= root->extension_state_allocated) { int i;

i = pg_nextpower2_32(extension_id + 1); root->extension_state = repalloc0_array(root->extension_state, void *, root->extension_state_allocated, i); root->extension_state_allocated = i; }

root->extension_state[extension_id] = opaque; } ~~~

目的

PlannerInfo 構造体に対して拡張機能固有の状態ポインタ (opaque) を格納または更新する。

入力と出力

  • 入力:
  • PlannerInfo *root: 状態を格納する対象のプランナー情報構造体
  • int extension_id: 拡張機能を識別する非負の整数 ID
  • void *opaque: 格納する拡張機能固有の状態ポインタ
  • 戻り値: なし (void)

前提条件と不変条件

  • extension_id >= 0 であること。

アルゴリズムまたは振る舞い

1. 前提条件の検証:

  • extension_id が 0 以上であることをアサートで検証する。

    • 2. 初期状態の割り当てチェック:

  • root->extension_state が NULL の場合、Max(4, pg_nextpower2_32(extension_id + 1)) により割り当てサイズを計算し、root->planner_cxt メモリコンテキストから MemoryContextAllocZero を用いて 0 クリアされた配列領域を確保する。

    • 3. 配列容量の拡張チェック:

  • extension_id が現在の割り当てサイズ (root->extension_state_allocated) 以上である場合、pg_nextpower2_32(extension_id + 1) で新しいサイズを計算し、repalloc0_array を用いて既存の配列領域を拡張・ゼロクリアし、割り当てサイズを更新する。

    • 4. 状態の格納:

  • 確保・拡張された配列の extension_id インデックスの位置に opaque ポインタを格納する。

失敗モードと境界条件

  • extension_id が負の値である場合はアサートにより失敗する。
