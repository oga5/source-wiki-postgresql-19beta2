目的

テーブル、インデックス、または外部テーブルの物理ページ数、タプル数、および全可視ページ割合（allvisfrac）を見積もる。

入力と出力

  • 引数:
  • Relation rel: 対象リレーションの構造体
  • int32 *attr_widths: 属性ごとの幅の配列
  • 出力（ポインタ経由で設定される引数）:
  • BlockNumber *pages: 見積もられたページ数
  • double *tuples: 見積もられたタプル数
  • double *allvisfrac: 全可視ページの割合
  • 戻り値: なし（void）

前提条件と不変条件

  • rel リレーションの種類（relkind）に応じて、適切な見積もりパス（テーブルAM、インデックス、またはその他のリレーション種別）へ分岐する。

アルゴリズムまたは振る舞い

1. **テーブルAMの判定**: RELKIND_HAS_TABLE_AM(rel->rd_rel->relkind) が真の場合、table_relation_estimate_size を呼び出して見積もりを委譲する。 2. **インデックスの処理**: rel->rd_rel->relkind == RELKIND_INDEX の場合、以下の手順を実行する：

  • RelationGetNumberOfBlocks(rel) を呼び出して現在のストレージブロック数 curpages を取得し、*pages に設定する。
  • curpages == 0 の場合は、*tuples = 0 および *allvisfrac = 0 として直ちに終了する。
  • pg_class の値から relpages、reltuples、relallvisible を取得し、メタページが存在する場合は curpages と relpages の双方をデクリメントする。
  • 過去のタプル密度（reltuples / relpages）が利用可能な場合はそれを使用し、そうでない（バキューム未実施などでデータがない）場合は、属性データ型や get_rel_data_width(rel, attr_widths) を用いてタプル幅とページあたり密度を計算する。
  • 密度と curpages から丸め処理を経て *tuples を算出する。
  • relallvisible の値と curpages を比較し、0以下の場合は *allvisfrac = 0、relallvisible がページ数以上の場合は 1、それ以外の場合は比率を計算して *allvisfrac に設定する。

    • 3. **その他のリレーション（外部テーブル、シーケンスなど）の処理**: 上記以外の場合、pg_class に保持されている relpages と reltuples をそのまま *pages と *tuples に設定し、*allvisfrac = 0 とする。

失敗モードと境界条件

  • インデックスのページ数が 0 の場合は、タプル数と可視率を 0 として早期リターンする。
  • 外部テーブルなどのリレーションでは、reltuples が -1 となる場合があるため、FDW側で適切に対処する必要がある。
