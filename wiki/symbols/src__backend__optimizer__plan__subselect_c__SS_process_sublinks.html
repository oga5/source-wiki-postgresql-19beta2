目的

式ツリー内の SubLink を再帰的にスキャンして処理するためのラッパー関数です。

シグネチャまたは形状

  • Node * SS_process_sublinks(PlannerInfo *root, Node *expr, bool isQual)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • Node *expr: 処理対象の式ツリー
  • bool isQual: 処理対象が上位の修飾子（qual）かどうかを示すフラグ
  • 戻り値:
  • Node *: 変換済みの式ツリー

アルゴリズムまたは振る舞い

  • process_sublinks_context 構造体を初期化し、root および isTopQual フィールドにそれぞれ引数の root と isQual を設定します。
  • 設定したコンテキストを渡して process_sublinks_mutator を呼び出し、式ツリーを再帰的に走査および変形してその結果を返します。
