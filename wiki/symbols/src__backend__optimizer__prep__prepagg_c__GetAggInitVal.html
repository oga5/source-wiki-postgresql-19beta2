~~~c static Datum GetAggInitVal(Datum textInitVal, Oid transtype) { Oid typinput, typioparam; char *strInitVal; Datum initVal;

getTypeInputInfo(transtype, &typinput, &typioparam); strInitVal = TextDatumGetCString(textInitVal); initVal = OidInputFunctionCall(typinput, strInitVal, typioparam, -1); pfree(strInitVal); return initVal; } ~~~

目的

テキスト形式で表現された集約の初期値を、指定された遷移型（transtype）の Datum に変換する。

アルゴリズムまたは振る舞い

1. getTypeInputInfo を使用して、指定された transtype の入力関数（typinput）およびそのパラメータ（typioparam）を取得する。 2. TextDatumGetCString を呼び出して textInitVal から C 文字列（strInitVal）を取り出す。 3. OidInputFunctionCall を実行し、入力関数を用いて C 文字列を該当型の Datum（initVal）に変換する。 4. 一時的に割り当てた C 文字列バッファを pfree で解放し、変換済みの initVal を返す。
