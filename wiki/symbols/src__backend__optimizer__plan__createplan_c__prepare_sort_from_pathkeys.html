目的

指定されたパスキー（pathkeys）を元に、実行用プランノードに対してソート用の列番号、ソート演算子、照合順序（collation）、およびヌル値の順序（nulls first）の配列を準備・構築し、必要に応じてターゲットリストへのエントリ追加や射影プランの挿入を行う。

入力と出力

  • 引数:
  • Plan *lefttree: 入力元となるプランツリー。
  • List *pathkeys: ソートの基準となるパスキーのリスト。
  • Relids relids: 対象のリレーション識別子。
  • const AttrNumber *reqColIdx: 一致させるべきソート列番号の配列（省略時は NULL）。
  • bool adjust_tlist_in_place: ターゲットリストをその場で直接調整してよいかを示すフラグ。
  • int *p_numsortkeys: 決定されたソートキーの数を出力するポインタ。
  • AttrNumber **p_sortColIdx: ソート列番号の配列を出力するポインタ。
  • Oid **p_sortOperators: ソート演算子 Oid の配列を出力するポインタ。
  • Oid **p_collations: 照合順序 Oid の配列を出力するポインタ。
  • bool **p_nullsFirst: ヌル値を先頭にするかの配列を出力するポインタ。
  • 戻り値: Plan * - 必要に応じて射影プラン（Result ノード等）が挿入された、更新済みのプランツリー。

前提条件と不変条件

  • パスキーの同値クラス（EquivalenceClass）が volatile である場合、ec_sortref が 0 であってはならず、メンバ数が 1 でなければならない。

アルゴリズムまたは振る舞い

1. pathkeys の要素数に基づいて、ソートキー関連の配列（sortColIdx、sortOperators、collations、nullsFirst）を palloc で割り当てる。 2. pathkeys の各パスキーを順に走査し、対応するターゲットエントリ（TargetEntry）およびデータ型を決定する。

  • パスキーの同値クラスが volatile な場合は get_sortgroupref_tle を用いて対応するターゲットリストエントリを取得する。
  • reqColIdx が指定されている場合は指定位置のターゲットエントリを参照し、式が同値クラスに一致するか検証する。
  • それ以外の場合は、ターゲットリスト内から同値クラスにマッチする最初の式を探索する。

    • 3. マッチするターゲットエントリが見つからない場合、計算可能な同値クラスメンバを find_computable_ec_member で探索する。

  • 見つからない場合はエラー（ERROR）を発生させる。
  • 既存のプランが射影を実行できない場合かつ adjust_tlist_in_place が偽である場合は、ターゲットリストをコピーして inject_projection_plan により新しい射影プランを挿入する。
  • 新しい resjunk ターゲットエントリを makeTargetEntry で作成し、入力プランのターゲットリストに追加する。

    • 4. パスキーの演算子ファミリーとデータ型から、get_opfamily_member_for_cmptype を用いて適切なソート演算子を取得する。

  • 演算子が無効な場合はエラーを発生させる。

    • 5. 決定したソート列番号、ソート演算子、照合順序、ヌル配置フラグを各配列の対応位置に格納する。 6. 最終的なソートキー数および各配列へのポインタを出力引数経由で設定し、更新されたプランツリーを返す。

失敗モードと境界条件

  • volatile な同値クラスの ec_sortref が 0 の場合、エラーログ（ERROR）が出力される。
  • マッチするターゲットエントリが存在せず、かつ計算可能な同値クラスメンバも見つからない場合、エラーログ（ERROR）が出力される。
  • 取得したソート演算子の Oid が無効（OidIsValid が偽）である場合、エラーログ（ERROR）が出力される。
