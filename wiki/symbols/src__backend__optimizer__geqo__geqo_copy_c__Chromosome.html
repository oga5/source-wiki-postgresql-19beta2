chromo1->worth = chromo2->worth; } ~~~

目的

ある遺伝的クエリ最適化（GEQO）の染色体情報（Chromosome）から別の染色体へ、遺伝子配列と評価値をコピーする。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナー情報へのポインタ。
  • Chromosome *chromo1: コピー先となる染色体構造体へのポインタ。
  • Chromosome *chromo2: コピー元となる染色体構造体へのポインタ。
  • int string_length: コピーする遺伝子配列長。
  • 出力: なし（void）

前提条件と不変条件

  • chromo1 および chromo2 は有効な Chromosome 構造体を指していること。
  • コピー先の chromo1->string は、少なくとも string_length 要素分のメモリ領域が事前に確保されていること。

アルゴリズムまたは振る舞い

  • 0から string_length - 1 までのインデックス i でループを回し、chromo2->string[i] の値を chromo1->string[i] に順次代入する。
  • ループ終了後、chromo2->worth の評価値を chromo1->worth にコピーする。

失敗モードと境界条件

  • メモリの動的確保や境界チェックは関数内で行われないため、string_length がコピー先バッファの容量を超えている場合はバッファオーバーランを引き起こすおそれがある。
