目的

指定された Query の groupClause 内から、渡された Var の属性番号（varattno）に対応する等価演算子（equality operator: Oid）を探索して返す。

入力と出力

  • 入力:
  • Query *parse: 探索対象のパースツリー
  • Var *var: 属性番号を持つ対象の変数式
  • 戻り値:
  • Oid: 一致するグループ化条項の等価演算子 Oid

前提条件と不変条件

  • 引数 var の varlevelsup は 0 でなければならない（アサートにより検証される）。

アルゴリズムまたは振る舞い

1. counter 変数を 0 に初期化する。 2. var->varlevelsup == 0 であることをアサートで検証する。 3. parse->groupClause に含まれる各 SortGroupClause（sgc）を順に走査する。 4. 各 sgc に対応するターゲットリストエントリが parse->targetList 内に存在しない場合はスキップする。 5. 有効なグループ化列としてカウンタをインクリメントし、それが var->varattno と一致するか比較する。一致した場合は、その sgc->eqop を返す。 6. ループが終了しても対応するグループ化句が見つからない場合は、エラーを発生させる。

失敗モードと境界条件

  • var->varlevelsup != 0 の場合、アサート違反により異常終了する。
  • parse->groupClause を最後まで走査しても var->varattno と一致する有効なグループ化列が見つからない場合、ERROR レベルのログを出力して処理を中断する。
