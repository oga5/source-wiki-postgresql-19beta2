~~~c List * remove_useless_joins(PlannerInfo *root, List *joinlist) { ListCell *lc;

/*

  • We are only interested in relations that are left-joined to, so we can
  • scan the join_info_list to find them easily.

    • */ restart: foreach(lc, root->join_info_list) { SpecialJoinInfo *sjinfo = (SpecialJoinInfo *) lfirst(lc); int innerrelid; int nremoved;

/* Skip if not removable */ if (!join_is_removable(root, sjinfo)) continue;

/*

  • Currently, join_is_removable can only succeed when the sjinfo's
  • righthand is a single baserel. Remove that rel from the query and
  • joinlist.

    • */ innerrelid = bms_singleton_member(sjinfo->min_righthand);

remove_leftjoinrel_from_query(root, innerrelid, sjinfo);

/* We verify that exactly one reference gets removed from joinlist */ nremoved = 0; joinlist = remove_rel_from_joinlist(joinlist, innerrelid, &nremoved); if (nremoved != 1) elog(ERROR, "failed to find relation %d in joinlist", innerrelid);

/*

  • We can delete this SpecialJoinInfo from the list too, since it's no
  • longer of interest. (Since we'll restart the foreach loop
  • immediately, we don't bother with foreach_delete_current.)

    • */ root->join_info_list = list_delete_cell(root->join_info_list, lc);

/*

  • Restart the scan. This is necessary to ensure we find all
  • removable joins independently of ordering of the join_info_list
  • (note that removal of attr_needed bits may make a join appear
  • removable that did not before).

    • */ goto restart; }

return joinlist; } ~~~

目的

root->join_info_list をスキャンし、条件を満たす不要な左結合（Left Join）を特定してクエリから安全に削除し、更新された結合リストを返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報を格納する構造体。
  • List *joinlist: 現在の結合ツリー構造を表す RangeTblRef 等のリスト。
  • 戻り値:
  • List *: 不要な結合が削除された新しい結合リスト。

前提条件と不変条件

  • 左結合の削除が成功するためには、対象の SpecialJoinInfo の右辺が単一のベースリレーション（baserel）で構成されている必要がある。

アルゴリズムまたは振る舞い

1. root->join_info_list を先頭から順に走査し、各要素を SpecialJoinInfo として取得する。 2. join_is_removable(root, sjinfo) を呼び出し、該当する結合が削除可能かどうかを判定する。削除不可能な場合はスキップする。 3. 削除可能な場合、bms_singleton_member(sjinfo->min_righthand) を用いて右辺の単一ベースリレーションID（innerrelid）を抽出する。 4. remove_leftjoinrel_from_query(root, innerrelid, sjinfo) を実行し、クエリメタデータや結合情報から該当リレーションを除去する。 5. remove_rel_from_joinlist(joinlist, innerrelid, &nremoved) を呼び出して joinlist から対象リレーションを削除し、正確に1つの参照が削除されたことを検証する。 6. 処理済みの SpecialJoinInfo を root->join_info_list からセル単位で削除する。 7. 削除対象の処理によって attr_needed などのビットが変わり、新たな削除可能ジョインが生じる可能性があるため、スキャンを先頭 (restart) からやり直す。 8. 削除候補がなくなったら最終的な joinlist を返して終了する。

失敗モードと境界条件

  • remove_rel_from_joinlist によって joinlist から削除された参照の数（nremoved）が 1 でない場合、elog(ERROR) により「failed to find relation %d in joinlist」エラーが発生する。
