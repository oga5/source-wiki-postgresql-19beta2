~~~c static List * build_path_tlist(PlannerInfo *root, Path *path) { List *tlist = NIL; Index *sortgrouprefs = path->pathtarget->sortgrouprefs; int resno = 1; ListCell *v;

foreach(v, path->pathtarget->exprs) { Node *node = (Node *) lfirst(v); TargetEntry *tle;

/*

  • If it's a parameterized path, there might be lateral references in
  • the tlist, which need to be replaced with Params. There's no need
  • to remake the TargetEntry nodes, so apply this to each list item
  • separately.

    • */ if (path->param_info) node = replace_nestloop_params(root, node);

tle = makeTargetEntry((Expr *) node, resno, NULL, false); if (sortgrouprefs) tle->ressortgroupref = sortgrouprefs[resno - 1];

tlist = lappend(tlist, tle); resno++; } return tlist; } ~~~

目的

指定された Path のターゲット定義（path->pathtarget）をベースに、実行計画用のターゲットリスト（TargetEntry のリスト）を構築する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報コンテキスト。
  • Path *path: ターゲットリスト構築元となるパスノード。
  • 戻り値:
  • List *: 生成された TargetEntry ノードのリスト。

前提条件と不変条件

  • パラメータ化されたパスである場合、ターゲットリスト内の式に存在するラテラル参照を Param ノードへ置換する必要がある。

アルゴリズムまたは振る舞い

1. tlist を空リスト（NIL）、結果番号 resno を 1 に初期化する。 2. path->pathtarget->exprs 内の各式を順に走査する。 3. パスがパラメータ情報（path->param_info）を持つ場合は、各式に対して replace_nestloop_params を適用してネストループパラメータへ置換する。 4. 処理対象の式から makeTargetEntry を用いて TargetEntry（tle）を生成する。 5. path->pathtarget->sortgrouprefs が存在する場合、対応する resno 位置のソートグループ参照を tle->ressortgroupref に設定する。 6. 生成した TargetEntry を tlist の末尾に lappend で追加し、resno をインクリメントする。 7. すべての式の処理が完了したら、構築した tlist を返す。

失敗モードと境界条件

  • パスがパラメータ化されていない（path->param_info が NULL の）場合、式に対する replace_nestloop_params 呼び出しはスキップされる。
  • ソートグループ参照配列（sortgrouprefs）が NULL の場合、tle->ressortgroupref への設定処理はバイパスされる。
