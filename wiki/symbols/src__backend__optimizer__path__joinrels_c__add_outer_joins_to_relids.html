/*

  • If it's not a left join, we have no rules that would permit executing
  • it in non-syntactic order, so just form the syntactic relid set. (This
  • is just a quick-exit test; we'd come to the same conclusion anyway,
  • since its commute_below_l and commute_above_l sets must be empty.)

    • */ if (sjinfo->jointype != JOIN_LEFT) return bms_add_member(input_relids, sjinfo->ojrelid);

  • a syntactically-lower left join per OJ identity 3. (If it has, then we
  • cannot claim that its outputs represent the final state of its RHS.)
  • There will not be any other OJs that can be added either, so we're
  • done.

  • pair of OJs, it's time to add the relid(s) of the pushed-down join(s).
  • We can skip this if this join was never a candidate to be pushed up.

  • pushed-down join, so we have to examine all the SpecialJoinInfos.
  • Because join_info_list was built in bottom-up order, it's

  • iteration would not have affected decisions of earlier iterations.

目的

指定されたリレーションID集合（input_relids）に対し、特殊結合情報（SpecialJoinInfo）に基づいて外結合の結合関係ID（ojrelid）および条件を満たす押し下げられた結合のIDを追加・拡張する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Relids input_relids: 拡張対象の入力リレーションID集合
  • SpecialJoinInfo *sjinfo: 対象となる特殊結合のメタデータ
  • List **pushed_down_joins: 押し下げられた外結合情報を蓄積するリストのポインタ（NULL許容）
  • 戻り値:
  • Relids: 更新されたリレーションID集合

前提条件と不変条件

  • sjinfo が NULL であるか、または ojrelid == 0 の場合は、何も変更を行わずに input_relids をそのまま返す。
  • 左結合（JOIN_LEFT）以外の非構文順序実行を許可する規則がない結合種別では、構文上の ojrelid を単に追加して返す。
  • sjinfo->commute_below_l が input_relids の部分集合でない場合、外結合の relid は追加されない。

アルゴリズムまたは振る舞い

1. **早期リターン判定**: sjinfo が NULL または sjinfo->ojrelid == 0 の場合、input_relids をそのまま返す。 2. **結合種別チェック**: sjinfo->jointype が JOIN_LEFT 以外である場合、非構文順序での実行規則がないため、即座に input_relids へ sjinfo->ojrelid を加えて返す。 3. **下位可換性の検証**: sjinfo->commute_below_l が input_relids の部分集合であるか検証し、満たさない場合は input_relids をそのまま返す。 4. **自身の ojrelid の追加**: input_relids に sjinfo->ojrelid を追加する。 5. **上位可換性（押し下げ結合）の処理**: sjinfo->commute_above_l が存在する場合、ボトムアップ順に構築された root->join_info_list を走査する。 6. **条件付きリレーション追加**: 各 othersj について以下の条件をすべて満たす場合、othersj->ojrelid を input_relids に追加し、要求されていれば pushed_down_joins に othersj を追加する。

  • othersj が自身ではなく、かつ ojrelid != 0 であり、かつ JOIN_LEFT である。
  • othersj->ojrelid が commute_above_rels に含まれている。
  • othersj->ojrelid が未だ input_relids に含まれていない。
  • othersj の最小左手側・右手側・下位可換セットがすべて input_relids の部分集合である。

    • 7. **可換セットの伝播**: 追加が発生した際、commute_above_rels に othersj->commute_above_l のメンバーを統合する。 8. **終了**: 最終的な input_relids を返す。

失敗モードと境界条件

  • 特殊結合情報が存在しない、または ojrelid が割り当てられていない場合はエラーとならずに入力集合をそのまま返す。
  • 左結合以外の結合や、可換性制約（commute_below_l）を満たさないケースでは、推移的な結合追加を行わず早期に処理を終了する。
