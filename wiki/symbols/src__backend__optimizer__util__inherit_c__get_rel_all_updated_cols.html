~~~c Bitmapset * get_rel_all_updated_cols(PlannerInfo *root, RelOptInfo *rel) { Index relid; RangeTblEntry *rte; RTEPermissionInfo *perminfo; Bitmapset *updatedCols, *extraUpdatedCols;

Assert(root->parse->commandType == CMD_UPDATE); Assert(IS_SIMPLE_REL(rel));

/*

  • We obtain updatedCols for the query's result relation. Then, if
  • necessary, we map it to the column numbers of the relation for which
  • they were requested.

    • */ relid = root->parse->resultRelation; rte = planner_rt_fetch(relid, root); perminfo = getRTEPermissionInfo(root->parse->rteperminfos, rte);

updatedCols = perminfo->updatedCols;

if (rel->relid != relid) { RelOptInfo *top_parent_rel = find_base_rel(root, relid);

Assert(IS_OTHER_REL(rel));

updatedCols = translate_col_privs_multilevel(root, rel, top_parent_rel, updatedCols); }

/*

  • Now we must check to see if there are any generated columns that depend
  • on the updatedCols, and add them to the result.

    • */ extraUpdatedCols = get_dependent_generated_columns(root, rel->relid, updatedCols);

return bms_union(updatedCols, extraUpdatedCols); } ~~~

目的

クエリの更新対象リレーション（resultRelation）について、指定されたシンプルリレーションで更新される全列のビットマップを返す。必要に応じて多段階継承階層間で列番号をマッピングし、依存する生成列（generated columns）も含める。

入力と出力

  • 引数: PlannerInfo *root, RelOptInfo *rel
  • 戻り値: Bitmapset * （更新対象となる列番号および依存生成列のビットマップ）

前提条件と不変条件

  • root->parse->commandType == CMD_UPDATE であること。
  • rel がシンプルリレーション（IS_SIMPLE_REL(rel)）であること。

アルゴリズムまたは振る舞い

1. クエリの更新対象リレーション識別子（resultRelation）を取得し、対応するRangeTblEntryとRTEPermissionInfoから初期の更新列ビットマップ（updatedCols）を取得する。 2. 指定されたリレーションが結果リレーション自体ではない場合（rel->relid != relid）、対象がその他のリレーション（IS_OTHER_REL(rel)）であることをアサートで検証した上で、トップ親リレーションのベースリレーションを取得し、translate_col_privs_multilevel を用いて更新列を対象リレーションの列番号へと多段階変換する。 3. get_dependent_generated_columns を呼び出し、現在の更新列に依存する生成列を特定して追加の更新列セット（extraUpdatedCols）を取得する。 4. 基本の更新列セットと依存生成列のセットの和集合（bms_union）を計算して返す。

失敗モードと境界条件

  • コマンド種別が CMD_UPDATE でない場合、アサートにより失敗する。
  • rel がシンプルリレーションでない場合、アサートにより失敗する。
  • リレーションが親とは異なる（rel->relid != relid）子階層のリレーションである場合、IS_OTHER_REL(rel) のアサートを満たさないと失敗する。
