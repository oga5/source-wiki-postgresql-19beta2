Assert(num_staged_ios <= PGAIO_SUBMIT_BATCH_SIZE);

if (!sqe) elog(ERROR, "io_uring submission queue is unexpectedly full");

pgaio_io_prepare_submit(ioh); pgaio_uring_sq_from_io(ioh, sqe); }

while (true) { int ret;

pgstat_report_wait_start(WAIT_EVENT_AIO_IO_URING_SUBMIT); ret = io_uring_submit(uring_instance); pgstat_report_wait_end();

  • The io_uring_enter() manpage suggests that the appropriate
  • reaction to EAGAIN is:

  • we apply a low limit to the number of outstanding IOs and thus
  • also outstanding completions, making it unlikely that we'd get
