ソース抜粋

~~~c void print_edge_table(FILE *fp, Edge *edge_table, int num_gene) { int i, j;

fprintf(fp, "\nEDGE TABLE\n");

for (i = 1; i <= num_gene; i++) { fprintf(fp, "%d :", i); for (j = 0; j < edge_table[i].unused_edges; j++) fprintf(fp, " %d", edge_table[i].edge_list[j]); fprintf(fp, "\n"); }

fprintf(fp, "\n");

fflush(fp); } ~~~

目的

GEQOのエッジ再結合交叉（ERX）などで使用されるエッジテーブルの状態をファイルストリームにダンプし、デバッグ出力を提供する <!-- source:src/backend/optimizer/geqo/geqo_misc.c:114-133 -->。

入力と出力

  • 引数:
  • FILE *fp: 出力先のファイルストリーム <!-- source:src/backend/optimizer/geqo/geqo_misc.c:114 -->
  • Edge *edge_table: ダンプ対象のエッジテーブル配列 <!-- source:src/backend/optimizer/geqo/geqo_misc.c:114 -->
  • int num_gene: 遺伝子の総数（エッジテーブルの要素数範囲を決定） <!-- source:src/backend/optimizer/geqo/geqo_misc.c:114 -->
  • 戻り値: なし（void） <!-- source:src/backend/optimizer/geqo/geqo_misc.c:114 -->

前提条件と不変条件

  • edge_table は 1 から num_gene までのインデックスが有効にアクセスできる領域を指していること <!-- source:src/backend/optimizer/geqo/geqo_misc.c:120 -->。
  • 各エッジ要素の unused_edges と edge_list が適切に初期化されていること <!-- source:src/backend/optimizer/geqo/geqo_misc.c:124 -->。

アルゴリズムまたは振る舞い

  • ストリーム fp にヘッダー文字列 \nEDGE TABLE\n を書き込む <!-- source:src/backend/optimizer/geqo/geqo_misc.c:120 -->。
  • i = 1 から num_gene までループを回し、各遺伝子インデックス i に対するエッジ情報（edge_table[i]）のヘッダーを出力する <!-- source:src/backend/optimizer/geqo/geqo_misc.c:122-125 -->。
  • 内部のネストしたループで、j = 0 から edge_table[i].unused_edges 未満の間、edge_table[i].edge_list[j] の値をスペース区切りで順次出力する <!-- source:src/backend/optimizer/geqo/geqo_misc.c:124-126 -->。
  • 各行の末尾に改行を出力する <!-- source:src/backend/optimizer/geqo/geqo_misc.c:127 -->。
  • 全エッジ情報の出力完了後、末尾に空行を出力し、fflush(fp) を呼び出してストリームをフラッシュする <!-- source:src/backend/optimizer/geqo/geqo_misc.c:130-132 -->。

失敗モードと境界条件

  • 不正なファイルポインタや範囲外の num_gene が与えられた場合のメモリ安全性の保護や検証は関数内で行われない。
