目的

指定された結合条件（RestrictInfo）を、参加する各ベースリレーションの joininfo リストへ登録します。

シグネチャまたは形状

  • void add_join_clause_to_rels(PlannerInfo *root, RestrictInfo *restrictinfo, Relids join_relids)

入力と出力

  • 引数:
  • root: プランナーのグローバル情報を格納する PlannerInfo へのポインタ。
  • restrictinfo: 登録対象の結合条件を表現する RestrictInfo へのポインタ。
  • join_relids: この結合条件が関与するリレーション群を示す Relids（ビットマップ）。
  • 戻り値: なし（void）

前提条件と不変条件

  • 常に真（always-true）であると判定された制限条件は、リレーションの joininfo に追加されず関数が早期リターンします。
  • 常に偽（always-false）であると証明された制限条件は、定数 FALSE を持つ新しい RestrictInfo に置換されます。この際、直列番号（rinfo_serial および root->last_rinfo_serial）は同一条件として扱えるように維持されます。

アルゴリズムまたは振る舞い

1. 常に真の条件の除外: restriction_is_always_true を呼び出し、条件が常に真であれば何もせず終了します。 2. 常に偽の条件の置換: restriction_is_always_false により条件が常に偽であると判明した場合、現在の rinfo_serial と root->last_rinfo_serial を退避したうえで、makeBuiltConst(false, false) を用いた新しい RestrictInfo を構築し、退避したシリアル番号を復元します。 3. リレーションへの条件追加: bms_next_member を用いて join_relids に含まれる各リレーション ID（cur_relid）を走査します。 4. ベースリレーションの特定と登録: find_base_rel_ignore_join を使って各 cur_relid に対応するベースリレーション（RelOptInfo）を取得します。取得したリレーションが NULL でない場合のみ、lappend を用いて rel->joininfo リストに restrictinfo を追加します。

失敗モードと境界条件

  • find_base_rel_ignore_join がベースリレーションを見つけられず NULL を返した場合、当該リレーションへの joininfo への追加はスキップされます（非ベースリレーションや対象外のIDに対する安全なガード）。
