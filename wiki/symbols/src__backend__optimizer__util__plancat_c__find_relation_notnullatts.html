ソース抜粋

~~~c Bitmapset * find_relation_notnullatts(PlannerInfo *root, Oid relid) { NotnullHashEntry *hentry; bool found;

if (root->glob->rel_notnullatts_hash == NULL) return NULL;

hentry = (NotnullHashEntry *) hash_search(root->glob->rel_notnullatts_hash, &relid, HASH_FIND, &found); if (!found) return NULL;

return hentry->notnullattnums; } ~~~

目的

指定されたリレーション OID に対応する NOT NULL 制約列番号のビットマップを、プランナのグローバルハッシュテーブルから検索して取得します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランニング全体の情報とハッシュテーブルを保持する構造体ポインタ
  • Oid relid: 検索対象のリレーション OID
  • 戻り値:
  • Bitmapset *: 見つかった場合は NOT NULL 列番号を表すビットマップへのポインタ、該当ハッシュテーブルが存在しない場合やエントリが見つからない場合は NULL

前提条件と不変条件

  • root->glob->rel_notnullatts_hash が初期化されていない（NULL の）場合がある。

アルゴリズムまたは振る舞い

  • root->glob->rel_notnullatts_hash が NULL であるかを確認し、NULL ならば直ちに NULL を返します。
  • hash_search を用いて、rel_notnullatts_hash から relid をキーに HASH_FIND モードでハッシュエントリを検索します。
  • エントリが見つからなかった場合は NULL を返します。
  • エントリが見つかった場合は、そのハッシュエントリが保持する notnullattnums フィールド（ビットマップ）を返します。

失敗モードと境界条件

  • ハッシュテーブル自体が未割り当て（NULL）の場合、安全に NULL を返して終了します。
  • 指定された relid がハッシュ内に存在しない場合、hash_search の found が false になり、安全に NULL を返します。
