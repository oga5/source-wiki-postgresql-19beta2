目的

遺伝的アルゴリズム（GA）を用いてクエリの結合順序最適化を行い、最適なクエリプラン構造を導出するエントリポイント関数として機能する。

入力と出力

  • 入力: PlannerInfo *root（プランナのメタ情報）, int number_of_rels（リレーション数）, List *initial_rels（初期リレーションのリスト）
  • 戻り値: 最適なクエリプランを表す RelOptInfo *

前提条件と不変条件

  • Geqo_planner_extension_id が未初期化（負値）の場合、GetPlannerExtensionId("geqo") を呼び出して拡張IDを取得・設定する。
  • コアプランナに対し、将来の再プランニング可能性を示すため root->assumeReplanning = true が設定される。
  • プール内のすべての個体は最良パスを適合度としてソートされた状態を維持し、世代交代ループ内で生成される子個体は最悪個体を置換する形でプールに組み込まれる。

アルゴリズムまたは振る舞い

1. **初期化ステージ**: プライベートデータの設定、乱数シードの初期化（geqo_set_seed）、リレーション数に応じたプールサイズと世代数の算出を行う。 2. **プール構築ステージ**: 遺伝的プールを割り当て（alloc_pool）、ランダム初期化（random_init_pool）した後に、適合度（コスト）順にプールをソート（sort_pool）する。 3. **作業領域割当ステージ**: 交叉アルゴリズムや設定に応じ、親染色体（momma, daddy）や、必要に応じてエッジテーブルまたはシティテーブル、子染色体（kid）のメモリ領域を確保する。 4. **世代交代ループ**: 指定された世代数にわたり以下を繰り返す。

  • 線形バイアス関数に基づき親個体を選択する（geqo_selection）。
  • ビルド時定義に応じた交叉処理（ERX, PMX, CX, PX, OX1, OX2 のいずれか）を実行して子個体を生成し、CXの場合はサイクル差分がゼロの際に突然変異（geqo_mutation）を適用する。
  • 子個体のフィットネスを評価し（geqo_eval）、適合度に応じてプール内へ挿入する（spread_chromo）。

    • 5. **結果抽出とクリーンアップステージ**: プールの先頭にある最良のツアー（best_tour）からツリー構造を構築し（gimme_tree）、確保した染色体、エッジテーブル、シティテーブル、プール等のメモリを解放した上で拡張状態をクリアし、最良の RelOptInfo を返す。

失敗モードと境界条件

  • 最良ツリーの構築結果（best_rel）が NULL である場合、elog(ERROR) により有効なプラン作成失敗のエラーを送出する。
