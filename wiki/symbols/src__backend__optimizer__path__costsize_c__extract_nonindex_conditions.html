目的

提供された制約条件のリストから、疑似定数やインデックス条件と重複する（または同一の同値クラスから導出される）ものを除外し、残りの非インデックス条件を抽出して新しいリストとして返します。

シグネチャまたは形状

  • シグネチャ: static List * extract_nonindex_conditions(List *qual_clauses, List *indexclauses)

入力と出力

  • 引数:
  • List *qual_clauses: 評価対象となる制限条件（RestrictInfo ノードのリスト）。
  • List *indexclauses: インデックス条件のリスト。
  • 戻り値:
  • List *: qual_clauses のうち、疑似定数でもインデックス条件と冗長でもない要素を格納した新しいリスト（初期状態は NIL）。

前提条件と不変条件

  • qual_clauses 内の各要素は RestrictInfo ノードである必要があります。

アルゴリズムまたは振る舞い

1. 結果を格納する空のリスト result (NIL) を初期化します。 2. qual_clauses の各要素（RestrictInfo *rinfo）を順に走査します。 3. rinfo->pseudoconstant が真である場合は、疑似定数として処理対象から除外（スキップ）します。 4. is_redundant_with_indexclauses(rinfo, indexclauses) が真を返す場合（重複しているか、または同一の同値クラスから導出されている場合）は除外します。 5. 上記のいずれにも該当しない RestrictInfo ノードを lappend を用いて result リストに追加します。 6. すべての走査完了後、構築された result リストを返します。

失敗モードと境界条件

  • 特殊なエラーパスはありません。条件に一致しないノードがすべて除外された場合、空のリスト（NIL）が返されます。
