bool have_implic; /* do we know the implication result? */ bool have_refute; /* do we know the refutation result? */ bool same_subexprs_implies; /* X clause_op Y implies X pred_op Y? */ bool same_subexprs_refutes; /* X clause_op Y refutes X pred_op Y? */ Oid implic_test_op; /* OID of the test operator, or 0 if none */ Oid refute_test_op; /* OID of the test operator, or 0 if none */ } OprProofCacheEntry; ~~~

目的

演算子ペアごとの含意・反駁の判定結果やテスト演算子の OID を保持するキャッシュエントリ構造体である。

フィールドと表現

  • key: ハッシュ検索キーであり、ハッシュルックアップキーとして構造体の先頭に配置される。
  • have_implic: 含意結果が既知であるかどうかを示す真偽値。
  • have_refute: 反駁結果が既知であるかどうかを示す真偽値。
  • same_subexprs_implies: $X$ clause_op $Y$ が $X$ pred_op $Y$ を含意するかどうかを示す真偽値。
  • same_subexprs_refutes: $X$ clause_op $Y$ が $X$ pred_op $Y$ に反駁するかどうかを示す真偽値。
  • implic_test_op: テスト演算子の OID、または存在しない場合は 0。
  • refute_test_op: テスト演算子の OID、または存在しない場合は 0。
