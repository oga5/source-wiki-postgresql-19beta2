ソース抜粋

~~~c static RelOptInfo * find_single_rel_for_clauses(PlannerInfo *root, List *clauses) { int lastrelid = 0; ListCell *l;

foreach(l, clauses) { RestrictInfo *rinfo = (RestrictInfo *) lfirst(l); int relid;

/*

  • If we have a list of bare clauses rather than RestrictInfos, we
  • could pull out their relids the hard way with pull_varnos().
  • However, currently the extended-stats machinery won't do anything
  • with non-RestrictInfo clauses anyway, so there's no point in
  • spending extra cycles; just fail if that's what we have.

    • *

  • An exception to that rule is if we have a bare BoolExpr AND clause.
  • We treat this as a special case because the restrictinfo machinery
  • doesn't build RestrictInfos on top of AND clauses.

    • */ if (is_andclause(rinfo)) { RelOptInfo *rel;

rel = find_single_rel_for_clauses(root, ((BoolExpr *) rinfo)->args);

if (rel == NULL) return NULL; if (lastrelid == 0) lastrelid = rel->relid; else if (rel->relid != lastrelid) return NULL;

continue; }

if (!IsA(rinfo, RestrictInfo)) return NULL;

if (bms_is_empty(rinfo->clause_relids)) continue; /* we can ignore variable-free clauses */ if (!bms_get_singleton_member(rinfo->clause_relids, &relid)) return NULL; /* multiple relations in this clause */ if (lastrelid == 0) lastrelid = relid; /* first clause referencing a relation */ else if (relid != lastrelid) return NULL; /* relation not same as last one */ }

if (lastrelid != 0) return find_base_rel(root, lastrelid);

return NULL; /* no clauses */ } ~~~

目的

与えられた条件リスト（clauses）がすべて同一の単一関係（Relation）を参照しているかを検証し、その関係に対応する RelOptInfo を返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • List *clauses: 評価対象の条件リスト（RestrictInfo または裸の式）
  • 戻り値:
  • RelOptInfo *: すべての条件が単一かつ同一のリレーションを参照している場合はその RelOptInfo、条件がない場合や複数の異なるリレーション、あるいは非対応の要素が含まれる場合は NULL

前提条件と不変条件

  • 非 RestrictInfo の裸の式は、is_andclause を満たす BoolExpr の AND 節を除き、処理されずに NULL を返す。
  • 変数を含まない変数なしの条件（clause_relids が空）は無視される。

アルゴリズムまたは振る舞い

1. **条件リストの走査**: clauses 内の各要素を foreach ループで順に走査する。 2. **AND節の再帰処理**: 要素が is_andclause に該当する場合、その引数リスト（((BoolExpr *) rinfo)->args）を対象として find_single_rel_for_clauses を再帰的に呼び出す。返されたリレーションの relid が、これまでに追跡している lastrelid と一致するか検証し、異なる場合は NULL を返す。 3. **RestrictInfoの型確認**: 要素が RestrictInfo でない場合は NULL を返す。 4. **リレーションIDの抽出と照合**:

  • rinfo->clause_relids が空の場合は変数を含まないとみなし、次の条件へスキップする。
  • bms_get_singleton_member を用いて、単一のメンバーリレーションID（relid）を取得する。取得に失敗して複数リレーションにまたがる場合は NULL を返す。
  • 初めてリレーションを参照する条件であれば lastrelid にその relid を設定し、2つ目以降の条件であれば既存の lastrelid と一致するか比較する。一致しない場合は NULL を返す。

    • 5. **ベースリレーションの取得**: ループ完了後、lastrelid が 0 でなければ find_base_rel(root, lastrelid) を呼び出して対応する RelOptInfo を返し、条件が一つも存在しない場合は NULL を返す。

失敗モードと境界条件

  • 異なる複数のリレーションを参照する条件が含まれている場合は NULL を返す。
  • 拡張統計 machinery が扱わない非 RestrictInfo の裸の式（AND節を除く）が渡された場合は NULL を返す。
  • 有効な条件が一切含まれていない場合は NULL を返す。
