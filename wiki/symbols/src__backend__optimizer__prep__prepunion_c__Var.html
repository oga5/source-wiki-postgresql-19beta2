目的

Var は、プラン生成やターゲットリストの構築過程（Appendや集合演算など）において、入力変数を参照するために利用されるコア型・ノード構造体のひとつです。

入力と出力

  • 入力変数を指す識別子や属性番号を保持します。

前提条件と不変条件

  • Appendや集合演算のターゲットリストの一部生成において、入力変数を参照するために varno 0 の Var ノードが使用される場合があります。

アルゴリズムまたは振る舞い

  • 集合演算やAppend処理における列のマッピングや式構築の際、各子クエリの出力を調整・参照するノードとして機能します。

失敗モードと境界条件

  • varno 0 を持つ Var ノードが使用される場合、一部のグループ化関数（estimate_num_groups 等）が直接利用できない制約があります。
