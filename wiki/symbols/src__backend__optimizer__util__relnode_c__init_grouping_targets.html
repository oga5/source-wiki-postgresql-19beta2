目的

早期集約（Eager Aggregation）におけるプッシュダウン処理のパスターゲットやグルーピング句を構築するため、関係のリレーションターゲット式を走査してグルーピングキーや依存式を判定・登録します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報を保持する構造体ポインタ。
  • RelOptInfo *rel: 対象のリレーション情報。
  • PathTarget *target: グループ化されたパスが使用するターゲット。
  • PathTarget *agg_input: 集約の入力パスが使用するターゲット。
  • List **group_clauses: ソートグループ句（SortGroupClause）のリストを格納する出力ポインタ。
  • List **group_exprs: グルーピング式のリストを格納する出力ポインタ。
  • 戻り値: bool - ターゲットの構築および検証に成功した場合は true、等価イメージ不適合や機能的依存関係の検証失敗などにより続行できない場合は false を返します。

前提条件と不変条件

  • ソースターゲット式には Var 以外の複雑な式が含まれていないこと（PlaceHolderVar が早期集約を阻止するため）。

アルゴリズムまたは振る舞い

1. 最大 sortgroupref の特定: クエリの processed_tlist を走査し、既存の ressortgroupref の最大値 (maxSortGroupRef) を取得します。 2. リレーションターゲット式の走査: rel->reltarget->exprs 内の各式について Var であることをアサートで確認し、元のグルーピング式から取得または導出できるか検証します。 3. 既存グルーピングキーの処理: 式にマッチする SortGroupClause が見つかった場合、target と agg_input の両方にカラムを追加し、未登録であれば group_clauses および group_exprs に追加します。 4. 上限結合で必要な式の処理: 式が上位結合で必要とされるもののグルーピング句に含まれない場合、型キャッシュの BTEQUALIMAGE_PROC を参照して等価イメージの処理が可能か判定し、不適合であれば false を返します。条件を満たす場合は新しい SortGroupClause を生成して割り当て、target および agg_input へカラム追加を行い、出力リストに追加します。 5. 集約関数内のみの参照式の処理: 式が集約関数からのみ参照され他に含まれない場合、agg_input のみに新規カラムとして追加します。 6. 関数的依存関係の保留: 上記のいずれにも該当しない式は、依存関係の検証を行うために一時リスト (possibly_dependent) に追加します。 7. 関数的依存関係の検証: possibly_dependent リストを走査し、check_functional_grouping を用いて他のターゲット式に対する機能的依存関係を検証します。依存関係が成立する場合は target と agg_input に新規カラムとして追加し、不成立の場合は false を返します。

失敗モードと境界条件

  • 早期集約の安全性を担保するための等価イメージプロシージャ（BTEQUALIMAGE_PROC）が存在しない、または不適合と判定された場合は false を返します。
  • possibly_dependent に含まれる式について、等価クラス処理等により冗長と証明されたグルーピング式が機能的依存関係を満たせない場合、検証に失敗し false を返します。
