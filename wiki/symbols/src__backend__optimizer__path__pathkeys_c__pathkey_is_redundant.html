~~~c static bool pathkey_is_redundant(PathKey *new_pathkey, List *pathkeys) { EquivalenceClass *new_ec = new_pathkey->pk_eclass; ListCell *lc;

/* Check for EC containing a constant --- unconditionally redundant */ if (EC_MUST_BE_REDUNDANT(new_ec)) return true;

/* If same EC already used in list, then redundant */ foreach(lc, pathkeys) { PathKey *old_pathkey = (PathKey *) lfirst(lc);

if (new_ec == old_pathkey->pk_eclass) return true; }

return false; } ~~~

定義

  • 種別: static function
  • 定義箇所: src/backend/optimizer/path/pathkeys.c:158

目的

指定された PathKey が、既存のパスキーリストに対して冗長であるかどうかを判定します。

シグネチャまたは形状

static bool pathkey_is_redundant(PathKey *new_pathkey, List *pathkeys)

入力と出力

  • **new_pathkey** (PathKey *): 冗長性を検査する対象のパスキー。
  • **pathkeys** (List *): 既存のパスキー（PathKey 構造体のポインタ）を格納するリスト。
  • **戻り値** (bool): new_pathkey が定数を含む等価クラスに属するか、または既存の pathkeys リスト内に同一の等価クラスを持つパスキーが既に存在する場合は true（冗長）、それ以外の場合は false を返します。

前提条件と不変条件

  • new_pathkey は有効な PathKey 構造体を指すポインタであり、その pk_eclass メンバー（等価クラス）にアクセス可能である必要があります。
  • pathkeys リスト内の各要素は、有効な PathKey 構造体へのポインタ（lfirst で取得可能）である必要があります。

アルゴリズムまたは振る舞い

1. **定数等価クラスのチェック**: new_pathkey から対応する等価クラス new_ec を取得し、マクロ EC_MUST_BE_REDUNDANT(new_ec) を用いて定数を含む等価クラスであるかを判定します。定数を含む場合は、無条件に冗長とみなして即座に true を返します。 2. **既存リストの走査**: pathkeys リストの各要素を順に走査します。 3. **等価クラスの比較**: 各要素の PathKey が持つ等価クラス（old_pathkey->pk_eclass）が new_ec とポインタレベルで一致（==）するかどうかを比較します。 4. **早期リターン**: 一致する等価クラスが見つかった場合、即座に true を返して処理を終了します。 5. **非冗長判定**: リストを最後まで走査しても一致する等価クラスが見つからなかった場合は、false を返します。

呼び出し元と呼び出し先

  • **呼び出し先**: EC_MUST_BE_REDUNDANT, foreach, lfirst

失敗モードと境界条件

  • **空のパスキーリスト**: pathkeys 引数が空（NIL）の場合、foreach ループは一度も実行されません。このとき、new_ec が定数を含んでいれば true を返し、そうでなければ false を返します。
  • **定数を含む等価クラスの優先判定**: pathkeys リストが空であっても、new_ec が定数を含む等価クラス（EC_MUST_BE_REDUNDANT が真）であれば、リストの走査を行う前に即座に true（冗長）と判定されます。
  • **ポインタ比較による同一性判定**: 等価クラスの重複判定は、構造体の内容比較ではなく、ポインタの直接比較（new_ec == old_pathkey->pk_eclass）によって行われます。そのため、論理的に同一の等価関係を示すものであっても、異なる EquivalenceClass インスタンスとしてメモリ上に存在している場合は、冗長とは判定されません。
