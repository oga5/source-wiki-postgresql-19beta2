ソース抜粋

~~~c void ox1(PlannerInfo *root, Gene *tour1, Gene *tour2, Gene *offspring, int num_gene, City * city_table) { int left, right, k, p, temp;

/* initialize city table */ for (k = 1; k <= num_gene; k++) city_table[k].used = 0;

/* select portion to copy from tour1 */ left = geqo_randint(root, num_gene - 1, 0); right = geqo_randint(root, num_gene - 1, 0);

if (left > right) { temp = left; left = right; right = temp; }

/* copy portion from tour1 to offspring */ for (k = left; k <= right; k++) { offspring[k] = tour1[k]; city_table[(int) tour1[k]].used = 1; }

k = (right + 1) % num_gene; /* index into offspring */ p = k; /* index into tour2 */

/* copy stuff from tour2 to offspring */ while (k != left) { if (!city_table[(int) tour2[p]].used) { offspring[k] = tour2[p]; k = (k + 1) % num_gene; city_table[(int) tour2[p]].used = 1; } p = (p + 1) % num_gene; /* increment tour2-index */ } } ~~~

目的

GEQO（遺伝的クエリ最適化）モジュールにおいて、Order Crossover (OX1) アルゴリズムを用いて2つの親ツアー（tour1 および tour2）から子孫ツアー（offspring）を生成します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報へのポインタ。
  • Gene *tour1: 1番目の親ツアーの遺伝子配列。
  • Gene *tour2: 2番目の親ツアーの遺伝子配列。
  • Gene *offspring: 生成される子孫ツアーの格納先バッファ。
  • int num_gene: 遺伝子の総数（都市の数）。
  • City *city_table: 都市の使用状況を追跡するための作業用テーブル。
  • 戻り値: なし（void）

前提条件と不変条件

  • city_table の各要素は、処理開始時に全都市について used フラグが 0 にリセットされます。
  • tour1 からコピーされた部分区間に含まれる都市は、city_table 内で used フラグが 1 にマークされます。

アルゴリズムまたは振る舞い

1. **都市テーブルの初期化**: 1から num_gene までの範囲で city_table[k].used を 0 に設定します。 2. **部分区間の選択**: geqo_randint を用いて tour1 からコピーする部分区間の境界 left および right をランダムに決定し、必要に応じて大小関係を整えます。 3. **第1親からの部分コピー**: tour1 の left から right までの遺伝子を offspring の対応位置にコピーし、該当する都市の city_table[...].used を 1 に設定します。 4. **第2親からの順序充填**: right + 1 の位置から開始して tour2 を順方向へスキャンし、city_table で未使用（used が 0）の遺伝子を offspring の空き位置に順次格納し、使用フラグを立てながら left に到達するまでループを継続します。

失敗モードと境界条件

  • left が right より大きい場合、値がスワップされて正しい区間順序に補正されます。
  • 配列インデックスの循環参照にはモジュロ演算子（% num_gene）が適用されます。
