~~~c void add_vars_to_attr_needed(PlannerInfo *root, List *vars, Relids where_needed) { ListCell *temp;

Assert(!bms_is_empty(where_needed));

foreach(temp, vars) { Node *node = (Node *) lfirst(temp);

if (IsA(node, Var)) { Var *var = (Var *) node; RelOptInfo *rel = find_base_rel(root, var->varno); int attno = var->varattno;

phinfo->ph_needed = bms_add_members(phinfo->ph_needed, where_needed); } else elog(ERROR, "unrecognized node type: %d", (int) nodeTag(node)); } } ~~~

目的

指定された変数やプレースホルダー変数のリスト（vars）を走査し、各要素が必要とされる関係やプレースホルダー情報に対して where_needed リレーション識別子を追加・伝播させる。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報とコンテキストを格納する構造体
  • List *vars: 処理対象の Var または PlaceHolderVar ノードを格納したリスト
  • Relids where_needed: 変数やプレースホルダーが必要とされる場所を示すリレーション識別子のビットマップセット
  • 戻り値: なし（void）

前提条件と不変条件

  • where_needed が空のビットマップセットであってはならない（アサーションにより検証される）。

アルゴリズムまたは振る舞い

1. **初期検証**: where_needed が空集合ではないことを Assert(!bms_is_empty(where_needed)) で検証する。 2. **リストの走査**: vars リスト内の各要素を順番に取り出す。 3. **ノード種別ごとの分岐と処理**:

  • **Var ノードの場合**:
  • ノードを Var キャストし、find_base_rel を用いて対応するベース関係（RelOptInfo）を取得する。
  • where_needed がベース関係のリレーションIDのサブセットである場合は、すでにその関係内で充足されているため処理をスキップする。
  • 属性番号が関係の許容範囲内であることをアサーションで確認し、対応する attr_needed 配列エントリに where_needed のメンバーを追加する。
  • **PlaceHolderVar ノードの場合**:
  • ノードを PlaceHolderVar キャストし、find_placeholder_info を用いてプレースホルダー情報を取得する。
  • 取得した PlaceHolderInfo の ph_needed に where_needed のメンバーを追加する。
  • **その他のノードの場合**:
  • 認識されないノード型であるとして、elog(ERROR, ...) を呼び出してエラーを発生させる。

失敗モードと境界条件

  • where_needed が空のビットマップセットである場合、関数冒頭の Assert によりデバッグビルドで停止する。
  • vars 内のノードが Var でも PlaceHolderVar でも無い場合、未認識のノード型としてエラーログが送出される。
