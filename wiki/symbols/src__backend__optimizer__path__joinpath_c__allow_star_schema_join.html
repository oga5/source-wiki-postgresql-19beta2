目的

外側リレーションがインナーリレーションのパラメータ化の一部を提供しつつ全ては提供していない、いわゆるスタースキーマのケースに該当するかどうかを判定する。

シグネチャまたは形状

  • シグネチャ: static inline bool allow_star_schema_join(PlannerInfo *root, Relids outerrelids, Relids inner_paramrels)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • Relids outerrelids: 外側リレーションの識別子集合
  • Relids inner_paramrels: インナーリレーションのパラメータ化識別子集合
  • 戻り値: bool （スタースキーマの条件を満たす場合は真、それ以外は偽）

前提条件と不変条件

  • 外側のリレーション集合がインナーリレーションのパラメータ化に対して一部重複しており、かつすべてを含んではいない（差分が空ではない）関係にあることを前提とする。

アルゴリズムまたは振る舞い

  • bms_overlap(inner_paramrels, outerrelids) により、インナーのパラメータ化リレーションと外側リレーション集合が重複しているかを判定する。
  • bms_nonempty_difference(inner_paramrels, outerrelids) により、インナーのパラメータ化リレーションのうち外側リレーションに含まれない要素（差分）が存在するかを判定する。
  • 両方の条件が同時に満たされる場合に true を返す。

呼び出し元と呼び出し先

  • 呼び出し元: try_nestloop_path
  • 呼び出し先: bms_overlap, bms_nonempty_difference
