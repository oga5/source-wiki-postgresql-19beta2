目的

ターゲットリストやHAVING句から集約（Aggregate）に関する情報を収集し、早期集約（Eager Aggregation）が適用可能であるかを判定してプランナー情報構造体に登録する。

シグネチャまたは形状

  • シグネチャ: static void create_agg_clause_infos(PlannerInfo *root)

入力と出力

  • 引数: PlannerInfo *root: プランナー情報構造体。
  • 戻り値: なし (void)

前提条件と不変条件

  • 実行開始時点で root->agg_clause_list および root->tlist_vars は空（NIL）でなければならない。

アルゴリズムまたは振る舞い

1. root->processed_tlist から集約関数、ウィンドウ関数、プレースホルダーを含む式を抽出する。 2. root->parse->havingQual が存在する場合、同様に式を抽出し、ターゲットリスト側の式リストに結合する。 3. 抽出された式のリストを順に走査し、以下の条件を検証しながら処理する。

  • GroupingFunc が含まれている場合は早期集約を不適用とし、処理を中断する。
  • Var の場合は一意な変数のリスト（tlist_vars）に追加して次の要素へ進む。
  • Aggref の場合、順序付き集約や distinct 引数がないことをアサートで確認する。
  • 揮発性関数（volatile functions）を含む集約関数はプッシュダウンできないため、不適用として中断する。
  • セキュリティ制約 (qual_security_level > 0) があり、かつ非リークプルーフな集約関数が含まれる場合は不適用として中断する。
  • 集約関数が参照するベース関係の識別子（agg_eval_at）を抽出し、累積する。
  • クエリ内の全ベース関係がすべて集約関数によって参照されている場合は、早期集約を不適用として中断する。
  • 条件を通過した場合は AggClauseInfo ノードを生成し、集約句情報のリストに追加する。

    • 4. ループ終了後、早期集約が適用可能な場合は root->agg_clause_list と root->tlist_vars に構築したリストを設定し、不適用な場合は生成したリストをディープ解放する。

失敗モードと境界条件

  • GroupingFunc、揮発性関数、非リークプルーフな集約関数（セキュリティ制約下）、またはクエリ内の全ベース関係が参照されている集約のいずれかに該当する場合、早期集約の適用が取りやめられ、構築中のリストは解放される。
