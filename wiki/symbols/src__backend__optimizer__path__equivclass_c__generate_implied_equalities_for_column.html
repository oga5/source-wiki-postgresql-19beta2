目的

指定されたリレーションの等価クラスインデックスを走査し、コールバック関数に一致するメンバを持つ等価クラスから、他のメンバとの結合条件（RestrictInfo リスト）を生成する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • RelOptInfo *rel: 対象のリレーション情報
  • ec_matches_callback_type callback: メンバの一致を判定するコールバック関数
  • void *callback_arg: コールバックに渡す補助引数
  • Relids prohibited_rels: 結合対象から除外すべきリレーション集合
  • 戻り値:
  • List *: 生成された RestrictInfo のリスト（条件が見つからない場合は NIL）

前提条件と不変条件

  • root->ec_merging_done が真でなければならない。
  • 対象リレーション rel はベースリレーションまたはその他のメンバリレーション（IS_SIMPLE_REL(rel) が真）でなければならない。
  • 子リレーションの場合、親リレーションの集合を取得済みである。

アルゴリズムまたは振る舞い

1. 初期化と検証:

  • root->ec_merging_done および IS_SIMPLE_REL(rel) のアサーションを検証する。
  • rel が子リレーション（RELOPT_OTHER_MEMBER_REL）である場合は find_childrel_parents を用いて親リレーション集合 parent_relids を取得し、それ以外の場合は NULL に設定する。

    • 2. 等価クラスの走査:

  • rel->eclass_indexes に登録されている各等価クラス（EC）のインデックスを順に取得する。
  • 各 EC について、定数を含む場合（ec_has_const）またはメンバ数が1つ以下の場合は結合条件を生成せずにスキップする。

    • 3. ターゲットメンバの探索:

  • setup_eclass_member_iterator と eclass_member_iterator_next を使用して EC 内のメンバを走査し、rel->relids に一致し、かつ callback が真を返す cur_em を探す。
  • 一致する cur_em が見つからなかった場合は次の EC へ進む。

    • 4. 結合条件の生成:

  • 一致した cur_em が見つかった場合、当該 EC の他のすべてのメンバ（other_em）を走査する。
  • other_em が子メンバではないこと、cur_em 自身ではないこと、rel->relids とオーバーラップしないこと、prohibited_rels とオーバーラップしないこと、さらに子リレーションの場合はその親リレーション集合とオーバーラップしないことを確認し、条件を満たさないものはスキップする。
  • select_equality_operator を呼び出して両メンバのデータ型に適した等価演算子（eq_op）を取得する。
  • 演算子が有効な場合、create_join_clause を用いて結合条件（RestrictInfo）を生成し、結果リストに追加する。

    • 5. 終了判定:

  • 結合条件が一つでも生成された場合は、非冗長な条件の重複を避けるために直ちに走査を打ち切って結果を返す。

失敗モードと境界条件

  • eclass_indexes 内の EC が条件を満たさない（定数を含む、またはメンバ数が1つ以下）場合、その EC からは結合条件は生成されない。
  • ターゲット列に一致する cur_em が見つからない場合、あるいは select_equality_operator が有効な演算子を返さない場合は、該当する EC からの条件生成はスキップされる。
  • prohibited_rels や子リレーションの親リレーションとオーバーラップする other_em は除外される。
