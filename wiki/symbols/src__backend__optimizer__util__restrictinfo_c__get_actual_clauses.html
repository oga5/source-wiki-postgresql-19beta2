ソース抜粋

~~~c List * get_actual_clauses(List *restrictinfo_list) { List *result = NIL; ListCell *l;

foreach(l, restrictinfo_list) { RestrictInfo *rinfo = lfirst_node(RestrictInfo, l);

Assert(!rinfo->pseudoconstant); Assert(!rinfo_is_constant_true(rinfo));

result = lappend(result, rinfo->clause); } return result; } ~~~

目的

RestrictInfo ノードのリストから、ラップされている実際の式（Expr）のリストを抽出する。

入力と出力

  • 引数: List *restrictinfo_list （RestrictInfo ノードを要素に持つリスト）
  • 戻り値: List * （抽出された式のリスト）

前提条件と不変条件

  • 入力される RestrictInfo リストの各要素に対して、擬似定数（pseudoconstant）ではないこと、および定数 TRUE ではないことがアサートされる。

アルゴリズムまたは振る舞い

  • result リストを NIL で初期化する。
  • restrictinfo_list の各要素を foreach ループで順に走査する。
  • 各要素を RestrictInfo ノードとして取得し、pseudoconstant フラグおよび rinfo_is_constant_true の評価結果に対するアサート検証を行う。
  • RestrictInfo が持つ実際の式（rinfo->clause）を lappend を用いて result リストの末尾に追加していく。
  • すべての要素の処理が完了した後、構築した result リストを返す。

失敗モードと境界条件

  • 処理対象の RestrictInfo が擬似定数である場合、または定数 TRUE である場合は、アサート違反により実行が停止する。
