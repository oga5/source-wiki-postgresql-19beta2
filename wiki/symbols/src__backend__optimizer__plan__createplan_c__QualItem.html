ソース抜粋

~~~c typedef struct { Node *clause; Cost cost; Index security_level; } QualItem; ~~~

目的

修飾句（qualifier clause）の評価コストやセキュリティレベルを保持し、order_qual_clauses 内で並び替えや管理を行うための内部構造体です。

フィールドと表現

  • Node *clause: 評価対象となる修飾句ノードへのポインタ。
  • Cost cost: 当該修飾句の評価コスト。
  • Index security_level: セキュリティ制限やポリシーに関連するセキュリティレベル。

参照・更新する処理

  • order_qual_clauses 関数などのコンテキスト内で配列として動的に割り当てられ、各修飾句の順序制御や評価順の最適化のために要素の参照および操作が行われます。
