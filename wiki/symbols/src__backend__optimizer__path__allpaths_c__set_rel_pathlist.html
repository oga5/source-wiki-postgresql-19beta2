ソース抜粋

~~~c static void set_rel_pathlist(PlannerInfo *root, RelOptInfo *rel, Index rti, RangeTblEntry *rte) { if (IS_DUMMY_REL(rel)) { /* We already proved the relation empty, so nothing more to do */ } else if (rte->inh) { /* It's an "append relation", process accordingly */ set_append_rel_pathlist(root, rel, rti, rte); } else { switch (rel->rtekind) { case RTE_RELATION: if (rte->relkind == RELKIND_FOREIGN_TABLE) { /* Foreign table */ set_foreign_pathlist(root, rel, rte); } else if (rte->tablesample != NULL) { /* Sampled relation */ set_tablesample_rel_pathlist(root, rel, rte); } else { /* Plain relation */ set_plain_rel_pathlist(root, rel, rte); } break; case RTE_SUBQUERY: /* Subquery --- fully handled during set_rel_size */ break; case RTE_FUNCTION: /* RangeFunction */ set_function_pathlist(root, rel, rte); break; case RTE_TABLEFUNC: /* Table Function */ set_tablefunc_pathlist(root, rel, rte); break; case RTE_VALUES: /* Values list */ set_values_pathlist(root, rel, rte); break; case RTE_CTE: /* CTE reference --- fully handled during set_rel_size */ break; case RTE_NAMEDTUPLESTORE: /* tuplestore reference --- fully handled during set_rel_size */ break; case RTE_RESULT: /* simple Result --- fully handled during set_rel_size */ break; default: elog(ERROR, "unexpected rtekind: %d", (int) rel->rtekind); ~~~

目的

指定されたリレーションの種類や属性に応じて適切なアクセスパス（Path）を生成し、プラグインの介入を経て最適パスを選択し、グループ化パスの構築やデバッグ出力を行うディスパッチ処理です。

シグネチャまたは形状

static void set_rel_pathlist(PlannerInfo *root, RelOptInfo *rel, Index rti, RangeTblEntry *rte)

入力と出力

  • 入力:
  • root: プランナー全体の情報を格納する PlannerInfo へのポインタ
  • rel: パスを構築する対象リレーションの情報を格納する RelOptInfo へのポインタ
  • rti: レンジテーブルインデックス (Index)
  • rte: レンジテーブルエントリを示す RangeTblEntry へのポインタ
  • 出力: なし (void)

前提条件と不変条件

  • リレーションがすでに空であると証明されている場合 (IS_DUMMY_REL(rel)) は、パス生成処理はスキップされます。

アルゴリズムまたは振る舞い

1. ダミーリレーション判定: IS_DUMMY_REL(rel) が真の場合、何もせず処理を終了します。 2. 継承リレーション判定: rte->inh が真の場合、set_append_rel_pathlist を呼び出してアペンドリレーション用のパスを生成します。 3. レンジテーブル種類 (rel->rtekind) による分岐:

  • RTE_RELATION: rte->relkind が RELKIND_FOREIGN_TABLE の場合は set_foreign_pathlist を呼び出し、rte->tablesample が存在する場合は set_tablesample_rel_pathlist を呼び出し、それ以外の場合は set_plain_rel_pathlist を呼び出します。
  • RTE_SUBQUERY、RTE_CTE、RTE_NAMEDTUPLESTORE、RTE_RESULT: set_rel_size 段階で処理済みのため何もしません。
  • RTE_FUNCTION: set_function_pathlist を呼び出します。
  • RTE_TABLEFUNC: set_tablefunc_pathlist を呼び出します。
  • RTE_VALUES: set_values_pathlist を呼び出します。
  • デフォルト: 予期しない rtekind の場合、エラーログ (ERROR) を出力します。

    • 4. プラグインフック呼び出し: set_rel_pathlist_hook が設定されている場合、そのフック関数を呼び出してパスを追加・修正させます。 5. Gatherパス生成: ベースリレーション (reloptkind == RELOPT_BASEREL) かつクエリ全体の結合リレーションではない場合、部分パスに対する Gather パスの生成 (generate_useful_gather_paths) を行います。 6. 最安パス設定: set_cheapest を呼び出してリレーションの最安パスを選択します。 7. グループ化パス設定: set_grouped_rel_pathlist を呼び出してグループ化リレーションの部分集約パスを構築します。 8. デバッグ出力: OPTIMIZER_DEBUG が有効な場合、pprint(rel) を実行します。

呼び出し元と呼び出し先

  • 呼び出し元: set_base_rel_pathlists, set_append_rel_pathlist
  • 呼び出し先: set_append_rel_pathlist, set_foreign_pathlist, set_tablesample_rel_pathlist, set_plain_rel_pathlist, set_function_pathlist, set_tablefunc_pathlist, set_values_pathlist, set_rel_pathlist_hook (間接), generate_useful_gather_paths, set_cheapest, set_grouped_rel_pathlist, pprint

失敗モードと境界条件

  • 想定外の rel->rtekind 値が渡された場合、elog(ERROR, "unexpected rtekind: %d", ...) によりエラーが発生します。
