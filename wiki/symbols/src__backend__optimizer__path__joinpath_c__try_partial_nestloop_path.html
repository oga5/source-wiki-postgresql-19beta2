目的

候補となる外側パス（outer_path）と内側パス（inner_path）を組み合わせて部分的なネストループ結合パス（partial nestloop path）を生成できるかを検証し、条件を満たす場合にコスト見積もりを経て結合関係（joinrel）へ部分パスとして追加する。

シグネチャまたは形状

  • シグネチャ: static void try_partial_nestloop_path(PlannerInfo *root, RelOptInfo *joinrel, Path *outer_path, Path *inner_path, List *pathkeys, JoinType jointype, uint64 nestloop_subtype, JoinPathExtraData *extra)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を格納する構造体ポインタ。
  • RelOptInfo *joinrel: 構築対象の結合関係を表す構造体ポインタ。
  • Path *outer_path: ネストループの外側となるパスのポインタ。
  • Path *inner_path: ネストループの内側となるパスのポインタ。
  • List *pathkeys: 提案するパスのソート順（pathkeys）を表すリスト。
  • JoinType jointype: 結合の種類（内部結合や各種外部結合など）。
  • uint64 nestloop_subtype: ネストループのサブタイプを識別するフラグ。
  • JoinPathExtraData *extra: 結合パス生成時に用いる追加情報（制限リスト等を含む）。
  • 戻り値: なし（void）

前提条件と不変条件

  • 結合関係の lateral_relids が空であること。
  • 提案される外側パスの要求外部パラメータ（PATH_REQ_OUTER(outer_path)）が空であること。

アルゴリズムまたは振る舞い

1. **前提アサーションの検証**:

  • joinrel->lateral_relids が空であること、および外側パスの要求外部パラメータが空であることをアサーションで確認する。

    • 2. **内側パスのパラメータ化の検査**:

  • 内側パスがパラメータ化されている場合、その要求パラメータ（ppi_req_outer）が外側パスの親リレーション（最上位親が存在する場合は top_parent_relids、そうでなければ relids）のサブセットに含まれているかを検証する。含まれていない場合は処理を中断する。

    • 3. **子リレーションによる再パラメータ化可能性の検査**:

  • 内側パスが外側パスの親によってパラメータ化されており、かつ子リレーションによる再パラメータ化が不可能な場合は処理を中断する。

    • 4. **コスト見積もりと事前チェック**:

  • initial_cost_nestloop を呼び出してネストループの初期コストを算出する。
  • add_partial_path_precheck によりコストの事前評価を行い、基準を満たさない場合はパスの生成を行わずに終了する。

    • 5. **部分パスの生成と登録**:

  • 条件を通過した場合、create_nestloop_path を用いてネストループパスオブジェクトを生成し、add_partial_path を使って joinrel の部分パスリストに登録する。

失敗モードと境界条件

  • 内側パスのパラメータ化要件が外側パスのリレーション群によって完全に満たされない場合、早期に中断する。
  • 外側パスの親リレーションによる内側パスの再パラメータ化変換が行えない場合、ネストループパスの作成を避けて早期に中断する。
  • add_partial_path_precheck の事前チェックでコストが不適格と判定された場合、パスは生成されない。
