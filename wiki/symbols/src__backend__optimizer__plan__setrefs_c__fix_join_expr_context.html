目的

fix_join_expr_contextは、結合式やON CONFLICT、MERGEの条件式を修正する際に、外側および内側のインデックス付きターゲットリストや許容リレーションを保持するコンテキスト構造体です。

フィールドと表現

  • PlannerInfo *root: プラン作成全体の情報を保持する PlannerInfo へのポインタ。
  • indexed_tlist *outer_itlist: 外側子プランのターゲットリストをインデックス化した構造体。
  • indexed_tlist *inner_itlist: 内側子プランのターゲットリストをインデックス化した構造体。
  • Index acceptable_rel: 処理中に許容されるリレーションのインデックス。
  • int rtoffset: レンジテーブルのオフセット値。
  • NullingRelsMatch nrm_match: 外部結合等におけるヌリング関係の照合モード。
  • double num_exec: 実行回数の見積もり値。
