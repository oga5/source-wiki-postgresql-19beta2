~~~c void print_pool(FILE *fp, Pool *pool, int start, int stop) { int i, j;

/* be extra careful that start and stop are valid inputs */

if (start < 0) start = 0; if (stop > pool->size) stop = pool->size;

if (start + stop > pool->size) { start = 0; stop = pool->size; }

for (i = start; i < stop; i++) { fprintf(fp, "%d)\t", i); for (j = 0; j < pool->string_length; j++) fprintf(fp, "%d ", pool->data[i].string[j]); fprintf(fp, "%g\n", pool->data[i].worth); }

fflush(fp); } ~~~

目的

GEQO（遺伝的クエリ最適化）の個体群プール内にある指定された範囲の個体（遺伝子配列およびコスト）を、デバッグ目的でファイルストリームへダンプします。

入力と出力

  • 引数:
  • FILE *fp: 出力先のファイルストリーム
  • Pool *pool: ダンプ対象の個体群プール構造体へのポインタ
  • int start: ダンプを開始するプール内のインデックス
  • int stop: ダンプを終了するプール内のインデックス
  • 戻り値: なし (void)

前提条件と不変条件

  • 引数 start および stop がプールの境界外または不正な値である場合、安全のために範囲全体（0 から pool->size まで）の出力に自動修正されます。

アルゴリズムまたは振る舞い

1. **入力値の検証と補正**:

  • start が 0 未満の場合、0 に設定されます。
  • stop が pool->size を超えている場合、pool->size に設定されます。
  • start + stop が pool->size を超える場合、範囲の安全性を確保するため start = 0 かつ stop = pool->size にリセットされます。

    • 2. **プールデータの反復出力**:

  • i を start から stop - 1 までインクリメントしながら各個体を走査します。
  • 各個体のインデックスとタブ（%d)\t）を出力ストリームに書き込みます。
  • 内部の文字列長（pool->string_length）分だけループを回し、個体の遺伝子配列（pool->data[i].string[j]）をスペース区切りで出力します。
  • 最後に個体のコスト（pool->data[i].worth）を改行付きで出力します。

    • 3. **フラッシュ**:

  • 処理の最後に fflush(fp) を呼び出し、出力ストリームをフラッシュします。

失敗モードと境界条件

  • 渡された start および stop の値がプールのサイズに対して不整合を起こしている場合でも、入力補正ロジックによって配列の範囲外アクセスを防ぎます。
