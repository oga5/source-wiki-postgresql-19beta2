目的

GEQO_DEBUG は、遺伝的クエリ最適化（GEQO）モジュールにおいてデバッグおよびログ出力を有効化するためのマクロである。このマクロが定義されている場合、個体群プール（Pool）の平均適応度を算出する avg_pool などのデバッグ用ヘルパー関数がコンパイル対象となる。

シグネチャまたは形状

GEQO_DEBUG が有効な場合に定義される内部関数のシグネチャ：

static double avg_pool(Pool *pool);

入力と出力

GEQO_DEBUG 有効時にコンパイルされる avg_pool 関数の入力と出力は以下の通りである：

  • **入力**: Pool *pool — 評価対象となる個体群プール構造体へのポインタ。
  • **出力**: double 型の戻り値 — プール内の全個体が持つ適応度（worth）の平均値。

前提条件と不変条件

  • avg_pool の呼び出し時、引数として渡される pool ポインタは有効でなければならず、そのプールサイズ（pool->size）は 0 より大きくなければならない。

アルゴリズムまたは振る舞い

GEQO_DEBUG 有効時にコンパイルされる avg_pool は、以下の手順で平均値を算出する： 1. プールサイズ（pool->size）が 0 以下であるか検証する。 2. プール内の個体群が持つ適応度（pool->data[i].worth）の平均値を算出する。この際、プール内に DBL_MAX が複数含まれている場合を考慮し、累積時の浮動小数点オーバーフローを回避するため、各個体の適応度をあらかじめ pool->size で除算してから累積変数 cumulative に加算する。 3. 最終的に累積された平均値を戻り値として返す。

関連データ構造

  • Pool: 個体群プールを表す構造体。プールサイズを示す size や、個体データの配列である data（各要素は適応度 worth を保持する）をメンバとして持つ。

失敗モードと境界条件

  • **プールサイズが 0 以下の場合**: pool->size <= 0 の場合、elog(ERROR, "pool_size is zero") を呼び出してエラーを発生させ、処理を中断する。
