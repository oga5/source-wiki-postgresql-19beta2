~~~c static indexed_tlist * build_tlist_index(List *tlist) { indexed_tlist *itlist; tlist_vinfo *vinfo; ListCell *l;

/* Create data structure with enough slots for all tlist entries */ itlist = (indexed_tlist *) palloc(offsetof(indexed_tlist, vars) + list_length(tlist) * sizeof(tlist_vinfo));

itlist->tlist = tlist; itlist->has_ph_vars = false; itlist->has_non_vars = false;

/* Find the Vars and fill in the index array */ vinfo = itlist->vars; foreach(l, tlist) { TargetEntry *tle = (TargetEntry *) lfirst(l);

if (tle->expr && IsA(tle->expr, Var)) { Var *var = (Var *) tle->expr;

vinfo->varno = var->varno; vinfo->varattno = var->varattno; vinfo->resno = tle->resno; vinfo->varnullingrels = var->varnullingrels; vinfo++; } else if (tle->expr && IsA(tle->expr, PlaceHolderVar)) itlist->has_ph_vars = true; else itlist->has_non_vars = true; }

itlist->num_vars = (vinfo - itlist->vars);

return itlist; } ~~~

目的

子プランのターゲットリスト（tlist）を高速に検索・参照するための indexed_tlist インデックスデータ構造を構築する。

シグネチャまたは形状

  • シグネチャ: static indexed_tlist * build_tlist_index(List *tlist)

入力と出力

  • 引数: List *tlist - 検索インデックスの構築対象となるターゲットリスト（TargetEntry ノードのリスト）
  • 戻り値: indexed_tlist * - 割り当ておよび初期化された indexed_tlist 構造体へのポインタ

前提条件と不変条件

  • 入力の tlist に含まれる各要素は TargetEntry であること。
  • 戻り値の indexed_tlist は、指定された tlist の長さに応じたメモリ領域が割り当てられ、有効な変数情報配列とフラグ群を保持する。

アルゴリズムまたは振る舞い

1. メモリ割り当て: 入力された tlist の項目数に基づき、indexed_tlist 本体と可変長配列 vars（tlist_vinfo の配列）を格納するのに十分なメモリ領域を palloc で確保する。 2. 初期化: 確保した indexed_tlist の tlist フィールドに入力をセットし、プレースホルダー変数有無フラグ（has_ph_vars）と非変数式有無フラグ（has_non_vars）を共に false に初期化する。 3. ターゲットリストの走査: tlist 内の各 TargetEntry (tle) を順にループ処理する。

  • tle->expr が存在し、かつ Var ノードである場合: 対応する tlist_vinfo スロットに varno、varattno、resno、varnullingrels を書き込み、インデックスポインタを進める。
  • tle->expr が PlaceHolderVar である場合: has_ph_vars を true に設定する。
  • それ以外の場合: has_non_vars を true に設定する。

    • 4. 変数の総数設定: 書き込まれた vinfo のポインタ差分から num_vars を計算して格納し、構築した indexed_tlist を返す。

失敗モードと境界条件

  • tlist が空である場合、num_vars は 0 となり、変数スロットを持たない indexed_tlist が正常に構築される。
