ソース抜粋

~~~c bool join_clause_is_movable_to(RestrictInfo *rinfo, RelOptInfo *baserel) { /* Clause must physically reference target rel */ if (!bms_is_member(baserel->relid, rinfo->clause_relids)) return false;

/* Cannot move an outer-join clause into the join's outer side */ if (bms_is_member(baserel->relid, rinfo->outer_relids)) return false;

/*

  • Target rel's Vars must not be nulled by any outer join. We can check
  • this without groveling through the individual Vars by seeing whether
  • clause_relids (which includes all such Vars' varnullingrels) includes
  • any outer join that can null the target rel. You might object that
  • this could reject the clause on the basis of an OJ relid that came from
  • some other rel's Var. However, that would still mean that the clause
  • came from above that outer join and shouldn't be pushed down; so there
  • should be no false positives.

    • */ if (bms_overlap(rinfo->clause_relids, baserel->nulling_relids)) return false;

/* Clause must not use any rels with LATERAL references to this rel */ if (bms_overlap(baserel->lateral_referencers, rinfo->clause_relids)) return false;

/* Ignore clones, too */ if (rinfo->is_clone) return false;

return true; } ~~~

目的

結合条件（RestrictInfo）が指定されたベース関係（RelOptInfo）の走査に移動可能（パラメータ化に利用可能）か検証する。

入力と出力

  • 引数:
  • RestrictInfo *rinfo: 検証対象の結合条件ノード
  • RelOptInfo *baserel: 移動先となるターゲットのベース関係
  • 戻り値: bool: 条件が移動可能な場合は true、それ以外の場合は false

前提条件と不変条件

  • 条件は物理的にターゲット関係を参照していなければならない。
  • 外部結合の条件をその結合の外側へ移動することはできない。
  • ターゲット関係の変数はいかなる外部結合によってもヌル化されてはならない。
  • 条件は、この関係への LATERAL 参照を持ついかなる関係も使用してはならない。
  • クローンである条件は無視され移動不可となる。

アルゴリズムまたは振る舞い

1. baserel->relid が rinfo->clause_relids に含まれているか（物理的に参照しているか）を bms_is_member で検証し、含まれていなければ false を返す。 2. baserel->relid が rinfo->outer_relids に含まれているかを bms_is_member で検証し、含まれていれば外部結合の外側へ移動することになるため false を返す。 3. rinfo->clause_relids と baserel->nulling_relids がオーバーラップしているかを bms_overlap で検証し、重複がある場合はターゲット関係の変数が外部結合でヌル化されるため false を返す。 4. baserel->lateral_referencers と rinfo->clause_relids がオーバーラップしているかを bms_overlap で検証し、重複がある場合は LATERAL 参照を持つ関係を使用しているため false を返す。 5. rinfo->is_clone が真であるかを検証し、クローンである場合は false を返す。 6. すべてのチェックを通過した場合は true を返す。

失敗モードと境界条件

  • ターゲット関係を物理的に参照していない場合、直ちに false を返す。
  • 外部結合の関係識別子が競合する場合や、LATERAL 参照関係との重なりがある場合は安全側に倒して移動不可（false）とする。
