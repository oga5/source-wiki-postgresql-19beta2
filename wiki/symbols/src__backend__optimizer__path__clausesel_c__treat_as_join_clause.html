目的

与えられた演算子句を結合句（join clause）として扱うべきか、制限句（restriction clause）として扱うべきかを判定する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Node *clause: 判定対象の句の式ノード
  • RestrictInfo *rinfo: 句に対応する RestrictInfo 構造体（NULL の場合がある）
  • int varRelid: 制限モードを強制するためのリレーション ID（0 以外の場合は強制）
  • SpecialJoinInfo *sjinfo: 特殊結合（アウタージョイン等）の情報（NULL の場合がある）
  • 戻り値:
  • bool: 結合句として扱う場合は true、制限句として扱う場合は false

前提条件と不変条件

  • varRelid が 0 以外の場合は、インナーインデックススキャンの条件検査などの理由により制限モードが強制されるため、常に false を返す。
  • sjinfo が NULL の場合、スキャンノードで評価される条件であることを意味するため、常に false を返す。

アルゴリズムまたは振る舞い

  • 引数 varRelid が 0 以外であれば、強制的に制限モードとして false を返す。
  • sjinfo が NULL である場合は、スキャンノードでの評価となるため制限句として false を返す。
  • 上記以外の場合で、rinfo が渡されているときは rinfo->num_base_rels > 1 であるかを判定し、渡されていないときは NumRelids(root, clause) > 1 であるかを判定して結合句かどうかを決定する（ベースリレーションの数が複数であれば結合句とみなす）。

失敗モードと境界条件

  • 外部結合によって遅延された単一リレーションの条件であっても、ベースリレーションの数のみをカウントし、アウタージョインで注入された可能性のあるリレーションは除外して制限句側の見積もりに誘導する設計になっている。
