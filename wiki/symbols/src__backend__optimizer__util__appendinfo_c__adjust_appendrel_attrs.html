目的

指定された式またはノード内の親リレーションの属性や識別子を、対応するアペンドリレーション（子リレーション）向けにコピーおよび変換するためのエントリーポイントを提供する。

シグネチャまたは形状

  • シグネチャ: Node * adjust_appendrel_attrs(PlannerInfo *root, Node *node, int nappinfos, AppendRelInfo **appinfos)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を保持する構造体へのポインタ。
  • Node *node: 変換対象の式またはノードツリー。
  • int nappinfos: 渡されたアペンドリレーション情報配列の要素数。
  • AppendRelInfo **appinfos: 変換に用いるアペンドリレーション情報の配列。
  • 戻り値:
  • Node *: 属性や識別子が子リレーション向けに調整された新しい式またはノードツリー。

前提条件と不変条件

  • 調整対象の appinfos が存在している必要があり、要素数 nappinfos は 1 以上で、かつ appinfos は NULL であってはならない。
  • 翻訳対象のノードが Query ツリーであってはならない。

アルゴリズムまたは振る舞い

  • ローカルの adjust_appendrel_attrs_context 構造体を初期化し、引数で渡された root、nappinfos、appinfos をセットする。
  • アサートによる前提条件の検証（nappinfos >= 1 && appinfos != NULL および node == NULL || !IsA(node, Query)）を実行する。
  • adjust_appendrel_attrs_mutator を呼び出して、ノードツリーの変換処理を実行し、その結果を返す。

失敗モードと境界条件

  • nappinfos < 1 または appinfos == NULL の場合、アサートによって処理が中断される。
  • 変換対象の node が Query 型である場合、アサート違反により処理が中断される。
