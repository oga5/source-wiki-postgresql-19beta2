目的

不要な左結合（Left Join）の削除または自己結合排除（Self-Join Elimination）の際に、プランナのクエリ情報や関連データ構造（ベースリレーション集合、特殊結合情報、プレースホルダ、等価クラス、変数参照など）に含まれる削除対象リレーションのIDや結合関係を更新・削除する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を保持する構造体。
  • int relid: 削除または置換対象のベースリレーションID。
  • int subst: 自己結合排除時の置換先リレーションID（左結合削除時は負の値）。
  • SpecialJoinInfo *sjinfo: 外部結合削除の場合は対象の特殊結合情報、自己結合排除の場合は NULL。
  • Relids joinrelids: 外部結合の結合関係を表すリレーションID集合、自己結合排除の場合は NULL。
  • 戻り値: なし（void）。

前提条件と不変条件

  • is_outer_join（外部結合削除）または is_self_join（自己結合排除）のいずれか一方が成立していること。
  • 外部結合削除の場合、ojrelid（sjinfo->ojrelid）が 0 より大きく、かつ joinrelids が NULL でないこと。

アルゴリズムまたは振る舞い

1. **基本リレーション集合の更新**:

  • root->all_baserels および root->all_query_rels 内の relid を subst に調整する。
  • 外部結合削除の場合は、root->outer_join_rels および root->all_query_rels から ojrelid を削除する。

    • 2. **SpecialJoinInfo の走査と更新**:

  • root->join_info_list の各要素について、元データを保護するために min_lefthand、min_righthand、syn_lefthand、syn_righthand を複製する。
  • 各リレーションID集合を adjust_relid_set で更新する。
  • 外部結合の場合は、ojrelid のメンバー削除および commute_above_l や commute_below_r などの通勤集合から ojrelid を除外する。
  • 自己結合排除の場合は、semi_rhs_exprs 内の変数ノードを ChangeVarNodesExtended と replace_relid_callback を用いて置換する。

    • 3. **PlaceHolderVar (PHV) 情報の処理**:

  • root->placeholder_list を走査し、外部結合削除かつ条件（ph_needed が joinrelids のサブセット、かつ ph_eval_at に relid が含まれ ojrelid が含まれない）を満たす場合は、該当するプレースホルダ情報をリストと配列から完全に削除する。
  • 削除されないプレースホルダについては、ph_eval_at や phrels のリレーションID集合を調整し、ph_needed を「relation 0」または NULL に縮小する。
  • 自己結合排除の場合は、式内の変数ノードを置換し、ph_lateral の調整と差分計算を行う。

    • 4. **EquivalenceClass の更新**:

  • 外部結合削除の場合のみ、各等価クラスに対して remove_rel_from_eclass を呼び出して対象リレーションの参照を除去する。
  • 自己結合排除では、呼び出し元ですでに更新済みのためこのステップをスキップする。

    • 5. **各リレーションの attr_needed および制限条件の再構築準備**:

  • root->simple_rel_array 内の有効な他リレーションを走査し、各属性の attr_needed を「relation 0」ビットのみ保持するか NULL にリセットする。
  • 自己結合排除の場合は、lateral_vars リスト内の変数参照を置換する。
  • 外部結合削除の場合は、生存するリレーションの baserestrictinfo に埋め込まれた PHV から対象リレーションと結合を除去する。

失敗モードと境界条件

  • 削除対象のリレーションが他のプレースホルダのラテラル依存関係（ph_lateral）に残っている場合、外部結合削除の条件分岐によりアサート違反を引き起こす可能性がある（Assert(!is_outer_join || !bms_is_member(relid, phinfo->ph_lateral))）。
  • プレースホルダの評価位置（ph_eval_at）やリレーション集合が空になってはならないという不変条件を満たさない場合、アサートで失敗する。
