ソース抜粋

~~~c typedef struct inline_cte_walker_context { const char *ctename; /* name and relative level of target CTE */ int levelsup; Query *ctequery; /* query to substitute */ } inline_cte_walker_context; ~~~

目的

inline_cte_walker_context は、指定された共通テーブル式（CTE）の名前と相対的なネスティングレベルに基づき、クエリ内の RTE_CTE 範囲変数ノードを RTE_SUBQUERY にインライン化するための走査コンテキスト構造体である。

フィールドと表現

  • const char *ctename: 対象となる CTE の名前を表す文字列ポインタであり、相対的なレベル情報とともにターゲットを特定するために使用される。
  • int levelsup: 対象 CTE に対する相対的なネスティングレベルの深さを表す整数値。
  • Query *ctequery: インライン化の置き換え先として適用される置換用のクエリ構造体ポインタ。
