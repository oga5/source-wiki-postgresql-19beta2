目的

メモ化パス（Memoize）のキャッシュキーとして使用するパラメータ式と対応する等価演算子、およびバイナリ比較モードのフラグを収集・検証する。

シグネチャまたは形状

  • シグネチャ: static bool paraminfo_get_equal_hashops(PlannerInfo *root, ParamPathInfo *param_info, RelOptInfo *outerrel, RelOptInfo *innerrel, List *ph_lateral_vars, List **param_exprs, List **operators, bool *binary_mode)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • ParamPathInfo *param_info: パラメータ化パス情報
  • RelOptInfo *outerrel: 外部リレーション
  • RelOptInfo *innerrel: 内部リレーション
  • List *ph_lateral_vars: プレースホルダー由来のラテラル変数リスト
  • List **param_exprs: 抽出されたパラメータ式の格納先ポインタ
  • List **operators: 抽出された演算子 OID の格納先ポインタ
  • bool *binary_mode: バイナリ比較モードフラグの格納先ポインタ
  • 戻り値:
  • bool: 処理が成功しメモ化が適用可能な場合は true、不適合な条件により中断した場合は false を返す。

前提条件と不変条件

  • 出力先のポインタ群 (*param_exprs, *operators, *binary_mode) は関数開始時にそれぞれ NIL, NIL, false に初期化される。

アルゴリズムまたは振る舞い

1. **初期化**: *param_exprs を NIL、*operators を NIL、*binary_mode を false に設定する。 2. **param_info の走査（結合条項の処理）**:

  • param_info が存在する場合、その ppi_clauses 内の各 RestrictInfo を順に検査する。
  • 抽出した OpExpr が 2 少ない引数を持つこと、および結合側が outerrel と innerrel に合致することを確認する。不適合な場合は構築中の *operators と *param_exprs を解放し false を返す。
  • rinfo->outer_is_left の値に応じて左側または右側の式とハッシュ等価演算子（hasheqoperator）を取得する。
  • hasheqoperator が無効（OidIsValid が偽）である場合はメモ化を行えないため、リストを解放し false を返す。
  • *param_exprs に未登録の式であれば、*operators に演算子 OID を追加し、*param_exprs に式を追加する。
  • 該当する結合演算子にハッシュ結合演算子（rinfo->hashjoinoperator）が存在しない場合は、バイナリ比較モードへの切り替えフラグ *binary_mode を true に設定する。

    • 3. **ラテラル変数の走査**:

  • ph_lateral_vars と innerrel->lateral_vars を結合したラテラル変数リストを順に検査する。
  • 変数式に揮発性関数（contain_volatile_functions）が含まれる場合は、リストを解放し false を返す。
  • lookup_type_cache を用いて式の型キャッシュからハッシュプロシージャと等価演算子を取得する。
  • ハッシュプロシージャまたは等価演算子のいずれかが無効な場合は、リストを解放し false を返す。
  • 未登録の式であれば、等価演算子を *operators に、式を多様なパラメータ式リストに追加する。
  • ラテラル変数の利用形態が不明確であるため、*binary_mode を true に設定する。

    • 4. **終了**: すべての検証と収集が完了した場合は true を返す。

失敗モードと境界条件

  • param_info 内の条項が 2 引数の OpExpr でない場合や、結合側が一致しない場合、リストを解放して false を返す。
  • 外部型のハッシュ等価演算子（hasheqoperator）が無効な場合、処理を中断し false を返す。
  • ラテラル変数に揮発性関数が含まれている場合、処理を中断し false を返す。
  • ラテラル変数の型キャッシュから有効なハッシュプロシージャまたは等価演算子が取得できない場合、処理を中断し false を返す。
