目的

reduce_outer_joins_partial_state は、かつてフル外側結合（FULL join）であった結合のうち、片側だけが内部結合へ縮小されたものの状態を保持するための構造体である。

フィールドと表現

  • int full_join_rti: かつてFULL結合であったものの範囲テーブルインデックス（RT index）を表す。
  • Relids unreduced_side: その未だにnullableな側にあるリレーションIDの集合（relids）を表す。

ライフサイクルと所有権

  • オプティマイザの処理中において、外側結合削減処理の中で動的に割り当てられて状態リストに格納される。
