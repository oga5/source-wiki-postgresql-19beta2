~~~c RelOptInfo * find_base_rel(PlannerInfo *root, int relid) { RelOptInfo *rel;

/* use an unsigned comparison to prevent negative array element access */ if ((uint32) relid < (uint32) root->simple_rel_array_size) { rel = root->simple_rel_array[relid]; if (rel) return rel; }

elog(ERROR, "no relation entry for relid %d", relid);

目的

指定されたリレーション識別子（relid）に対応するベースまたはその他のリレーションエントリ（RelOptInfo）をプランナー情報構造体から検索して返します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーの全体情報を保持する構造体へのポインタ。
  • int relid: 検索対象のリレーション識別子（範囲変数インデックス）。
  • 戻り値:
  • RelOptInfo *: 該当するリレーションノードへのポインタ。

前提条件と不変条件

  • 負の配列要素へのアクセスを防ぐため、relid と配列サイズは符号なし比較（uint32 キャスト）によって検証されます。

アルゴリズムまたは振る舞い

  • 入力された relid を uint32 にキャストし、root->simple_rel_array_size 未満であるかを符号なしで比較します。
  • 条件を満たしている場合、root->simple_rel_array[relid] から対応する RelOptInfo エントリを取得します。
  • 取得したエントリが非 NULL であれば、そのままそのリレーションポインタを返します。

失敗モードと境界条件

  • relid が配列サイズを超過している場合、または対応する配列エントリが NULL である場合は、ERROR レベルの elog を発行して処理を中断します。
