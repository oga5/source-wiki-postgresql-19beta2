~~~c RelOptInfo * gimme_tree(PlannerInfo *root, Gene *tour, int num_gene) { GeqoPrivateData *private = GetGeqoPrivateData(root); List *clumps; int rel_count;

/*

  • Sometimes, a relation can't yet be joined to others due to heuristics
  • or actual semantic restrictions. We maintain a list of "clumps" of
  • successfully joined relations, with larger clumps at the front. Each
  • new relation from the tour is added to the first clump it can be joined
  • to; if there is none then it becomes a new clump of its own. When we
  • enlarge an existing clump we check to see if it can now be merged with
  • any other clumps. After the tour is all scanned, we forget about the
  • heuristics and try to forcibly join any remaining clumps. If we are
  • unable to merge all the clumps into one, fail.

    • */ clumps = NIL;

for (rel_count = 0; rel_count < num_gene; rel_count++) { int cur_rel_index; RelOptInfo *cur_rel; Clump *cur_clump;

/* Get the next input relation */ cur_rel_index = (int) tour[rel_count]; cur_rel = (RelOptInfo *) list_nth(private->initial_rels, cur_rel_index - 1);

/* Make it into a single-rel clump */ cur_clump = palloc_object(Clump); cur_clump->joinrel = cur_rel; cur_clump->size = 1;

/* Merge it into the clumps list, using only desirable joins */ clumps = merge_clump(root, clumps, cur_clump, num_gene, false); }

if (list_length(clumps) > 1) { /* Force-join the remaining clumps in some legal order */ List *fclumps; ListCell *lc;

fclumps = NIL; foreach(lc, clumps) { Clump *clump = (Clump *) lfirst(lc);

fclumps = merge_clump(root, fclumps, clump, num_gene, true); } clumps = fclumps; }

/* Did we succeed in forming a single join relation? */ if (list_length(clumps) != 1) return NULL;

~~~

目的

ツアー（遺伝子の配列）として与えられた結合順序を元に、ヒューリスティックやセマンティックな制約を考慮しながら結合済みリレーションの「クランプ（clump）」リストを維持し、最終的な結合ツリーの構築を試みる。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報を格納する構造体ポインタ。
  • Gene *tour: 遺伝子の配列（リレーションインデックスの並び）。
  • int num_gene: ツアー内の遺伝子数。
  • 戻り値: 正常に単一の結合リレーション（RelOptInfo *）の形成に成功した場合はそのポインタを返し、失敗した場合は NULL を返す。

前提条件と不変条件

  • 成功した結合の「クランプ」は、より大きなクランプがリストの前方に位置するように維持される。
  • ツアーの走査中は、望ましい結合（desirable joins）のみを使用してクランプがマージされる。

アルゴリズムまたは振る舞い

1. clumps リストを空（NIL）に初期化する。 2. ツアー内の各遺伝子を順番に走査する（rel_count からインデックスを取得し、private->initial_rels から対応する RelOptInfo を取得する）。 3. 取得したリレーションからサイズ 1 の単一リレーションクランプ（Clump）を割り当てて作成する。 4. merge_clump を呼び出し、ヒューリスティックに基づいて望ましい結合のみを使用して、新しく作成したクランプを既存の clumps リストにマージする（force = false）。 5. ツアー全体の走査が完了した時点で clumps リストの長さが 1 より大きい場合、ヒューリスティックを忘れ、残りのクランプを強制的に法的な順序で結合する（force = true で merge_clump を再適用する）。 6. 最終的な clumps リストの長さが 1 であるか検証し、1 でなければ NULL を返し、1であればその結合リレーション（joinrel）を返す。

失敗モードと境界条件

  • ツアーをすべて走査し強制結合を行った後でも、すべてのクランプを 1 つに統合できず clumps リストの長さが 1 でない場合は NULL を返す。
