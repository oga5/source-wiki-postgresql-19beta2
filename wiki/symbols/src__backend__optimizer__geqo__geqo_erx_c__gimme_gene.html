目的

GEQO（遺伝的クエリ最適化）のエッジ組換え交叉（ERX）アルゴリズムにおいて、現在のエッジリストから次に探索すべき遺伝子（都市）を選択して返す。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナーのグローバル情報
  • Edge edge: 候補の遺伝子リスト（edge_list）と未使用エッジ数（unused_edges）を持つエッジ構造体
  • Edge *edge_table: 全遺伝子のエッジ状態を管理するエッジテーブル配列
  • 戻り値:
  • Gene: 選択された次の遺伝子ID

前提条件と不変条件

  • エッジリスト内の負の値は共有エッジ（両親で共通するエッジ）を表す
  • 1点から他の点へ向かうエッジ数は最大4個を超えないため、最小エッジ数の初期値は 5 に設定される

アルゴリズムまたは振る舞い

1. **初期設定**: 最小エッジ数保持用の変数 minimum_edges を 5 に、最小候補カウント minimum_count を -1 に初期化する。 2. **候補走査フェーズ**: edge.unused_edges の回数だけループをまわし、各候補遺伝子（friend）を順に評価する。

  • 候補が負の値（共有エッジ）である場合は、直ちに絶対値に変換してその遺伝子を返す。
  • 候補の残り未使用エッジ数が現在の minimum_edges より小さい場合は、minimum_edges を更新し、minimum_count を 1 にリセットする。
  • minimum_count が -1 のまま更新されない場合はエラー（minimum_count not set）とする。
  • 残り未使用エッジ数が minimum_edges と等しい場合は minimum_count をインクリメントする。

    • 3. **ランダム選択フェーズ**: 最小の未使用エッジ数を持つ候補が複数存在する場合、geqo_randint(root, minimum_count - 1, 0) を呼び出してランダムな決定値（rand_decision）を算出する。 4. **候補確定フェーズ**: 再度エッジリストを走査し、未使用エッジ数が minimum_edges と一致する候補をカウントダウンしながら探索し、カウントが rand_decision と一致した時点でその遺伝子を返す。 5. **異常終了**: 共有エッジ、最小エッジ、ランダム選択のいずれの条件も満たさずにループを抜けた場合は、エラー（neither shared nor minimum number nor random edge found）をスローする。

失敗モードと境界条件

  • minimum_count が適切に初期化されない状態で最小エッジ数の比較条件分岐に入ると、elog(ERROR) によりエラー終了する。
  • 予期せぬ状態により有効な候補が見つからずに関数の終端に到達した場合、elog(ERROR) によりエラー終了する。
