~~~c static void minmax_qp_callback(PlannerInfo *root, void *extra) { root->group_pathkeys = NIL; root->window_pathkeys = NIL; root->distinct_pathkeys = NIL;

root->sort_pathkeys = make_pathkeys_for_sortclauses(root, root->parse->sortClause, root->parse->targetList);

root->query_pathkeys = root->sort_pathkeys; } ~~~

目的

query_planner 用のコールバックとして機能し、MIN/MAX最適化用のサブクエリにおけるパスキーを設定する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーの情報構造体
  • void *extra: 追加のパラメータ（未使用）
  • 戻り値: なし（void）

前提条件と不変条件

  • root は有効な PlannerInfo 構造体を指していること。

アルゴリズムまたは振る舞い

  • グループ化、ウィンドウ関数、およびディスティンクトのパスキー（group_pathkeys, window_pathkeys, distinct_pathkeys）をすべて NIL に初期化する。
  • パースツリーのソート句（sortClause）とターゲットリスト（targetList）を基に、make_pathkeys_for_sortclauses を呼び出してソート用のパスキーを生成し、root->sort_pathkeys に設定する。
  • クエリ全体のパスキー（query_pathkeys）に生成した sort_pathkeys を割り当てる。

失敗モードと境界条件

  • 特殊なエラーパスや分岐は持たない。
