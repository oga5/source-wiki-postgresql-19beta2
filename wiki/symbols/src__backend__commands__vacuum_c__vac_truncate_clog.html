/* init oldest datoids to sync with my frozenXID/minMulti values */ oldestxid_datoid = MyDatabaseId; minmulti_datoid = MyDatabaseId;

/*

  • Scan pg_database to compute the minimum datfrozenxid/datminmxid

    • *

  • Since vac_update_datfrozenxid updates datfrozenxid/datminmxid in-place,
  • the values could change while we look at them. Fetch each one just
  • once to ensure sane behavior of the comparison logic. (Here, as in
  • many other places, we assume that fetching or updating an XID in shared
  • storage is atomic.)

    • *

  • Note: we need not worry about a race condition with new entries being
  • inserted by CREATE DATABASE. Any such entry will have a copy of some
  • existing DB's datfrozenxid, and that source DB cannot be ours because
  • of the interlock against copying a DB containing an active backend.
  • Hence the new entry will not reduce the minimum. Also, if two VACUUMs
  • concurrently modify the datfrozenxid's of different databases, the
  • worst possible outcome is that pg_xact is not truncated as aggressively
  • as it could be.

    • */ relation = table_open(DatabaseRelationId, AccessShareLock);

scan = table_beginscan_catalog(relation, 0, NULL);

Assert(TransactionIdIsNormal(datfrozenxid)); Assert(MultiXactIdIsValid(datminmxid));
