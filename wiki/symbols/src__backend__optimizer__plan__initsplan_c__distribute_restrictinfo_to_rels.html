~~~c void distribute_restrictinfo_to_rels(PlannerInfo *root, RestrictInfo *restrictinfo) { Relids relids = restrictinfo->required_relids;

if (!bms_is_empty(relids)) { int relid;

if (bms_get_singleton_member(relids, &relid)) { /*

  • There is only one relation participating in the clause, so it
  • is a restriction clause for that relation.

    • */ add_base_clause_to_rel(root, relid, restrictinfo); } else { /*

  • The clause is a join clause, since there is more than one rel
  • in its relid set.

    • */

/*

  • Check for hashjoinable operators. (We don't bother setting the
  • hashjoin info except in true join clauses.)

    • */ check_hashjoinable(restrictinfo);

/*

  • Likewise, check if the clause is suitable to be used with a
  • Memoize node to cache inner tuples during a parameterized
  • nested loop.

    • */ check_memoizable(restrictinfo);

/*

  • Add clause to the join lists of all the relevant relations.

    • */ add_join_clause_to_rels(root, restrictinfo, relids); } } else { /*

  • clause references no rels, and therefore we have no place to attach
  • it. Shouldn't get here if callers are working properly.

    • */ elog(ERROR, "cannot cope with variable-free clause"); } } ~~~

目的

RestrictInfo ノードが参照するリレーションの数（required_relids）に基づき、その制限条件や結合条件を適切なベースリレーションまたは結合リストへ分散・割り当てます。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体のグローバル情報を保持する構造体ポインタ。
  • RestrictInfo *restrictinfo: 分散対象となる制限／結合条件の構造体ポインタ。
  • 戻り値: なし（void）。

前提条件と不変条件

  • 引数で渡された restrictinfo の required_relids は空であってはならず、空の場合はエラーとして扱われます。

アルゴリズムまたは振る舞い

1. restrictinfo->required_relids を取得し、空かどうかを判定します。 2. 参照するリレーションが空である場合は、変数を含まない条件とみなして elog(ERROR, ...) によりエラーを送出します。 3. 参照するリレーションが単一である場合は、参加するリレーションが 1 つのみの制限条件（restriction clause）であると判断し、add_base_clause_to_rel を呼び出して対象ベースリレーションに条件を追加します。 4. 参照するリレーションが複数存在する場合は、結合条件（join clause）として扱います。

  • check_hashjoinable を呼び出してハッシュ結合可能かどうかの情報を設定します。
  • check_memoizable を呼び出して、パラメータ化されたネストループ内でインナータプルをキャッシュする Memoize ノードに適しているかをチェックします。
  • add_join_clause_to_rels を呼び出して、関連するすべてのリレーションの結合リストに条件を追加します。

失敗モードと境界条件

  • 変数を含まない条件（required_relids が空）が渡された場合、elog(ERROR, "cannot cope with variable-free clause") が発生します。
