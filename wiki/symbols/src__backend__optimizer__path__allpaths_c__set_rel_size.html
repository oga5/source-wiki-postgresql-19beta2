目的

リレーションの種類、制約除外、および継承の有無に基づいてリレーションのサイズ見積もりおよびパス構築へのディスパッチを行う。

入力と出力

  • 引数: PlannerInfo *root, RelOptInfo *rel, Index rti, RangeTblEntry *rte
  • 戻り値: なし (void)

前提条件と不変条件

  • すべての非ダミーリレーションは 0 より大きい行数見積もりを持つ必要がある。

アルゴリズムまたは振る舞い

1. **制約除外の評価**: リレーションが通常のベースリレーションであり、かつ制約除外 (relation_excluded_by_constraints) によってスキャンが除外できる場合、ダミーパスを即座に割り当てて終了する。 2. **継承リレーションの処理**: rte->inh が真であるアペンドリレーションの場合、set_append_rel_size を呼び出して処理する。 3. **範囲テーブルエントリ種別 (rtekind) による分岐**:

  • RTE_RELATION:
  • 外部テーブル (RELKIND_FOREIGN_TABLE) の場合、set_foreign_size を呼び出す。
  • ONLY 付きで指定されたパーティションテーブル (RELKIND_PARTITIONED_TABLE) の場合、どのパーティションもスキャンしないためダミーパスを割り当てる。
  • テーブルサンプル (tablesample != NULL) がある場合、set_tablesample_rel_size を呼び出す。
  • それ以外の場合、プレーンリレーションとして set_plain_rel_size を呼び出す。
  • RTE_SUBQUERY: サブクエリのパスを即座に構築するため set_subquery_pathlist を呼び出す。
  • RTE_FUNCTION: set_function_size_estimates を呼び出す。
  • RTE_TABLEFUNC: set_tablefunc_size_estimates を呼び出す。
  • RTE_VALUES: set_values_size_estimates を呼び出す。
  • RTE_CTE: 自己参照 (self_reference) の有無に応じて set_worktable_pathlist または set_cte_pathlist を呼び出す。
  • RTE_NAMEDTUPLESTORE: set_namedtuplestore_pathlist を呼び出す。
  • RTE_RESULT: set_result_pathlist を呼び出す。
  • デフォルト: 予期しない rtekind の場合、エラー (elog(ERROR, ...)) を発生させる。

    • 4. **検証アサーション**: 処理終了時に rel->rows > 0 またはダミーリレーションであること (IS_DUMMY_REL(rel)) をアサートする。

失敗モードと境界条件

  • サポートされていない予期しない rtekind が渡された場合、エラーがスローされる。
  • 計算された行数見積もりが 0 以下であり、かつダミーリレーションではない場合、アサーション違反により異常終了する。
