~~~c double clamp_row_est(double nrows) { /*

  • Avoid infinite and NaN row estimates. Costs derived from such values
  • are going to be useless. Also force the estimate to be at least one
  • row, to make explain output look better and to avoid possible
  • divide-by-zero when interpolating costs. Make it an integer, too.

    • */ if (nrows > MAXIMUM_ROWCOUNT || isnan(nrows)) nrows = MAXIMUM_ROWCOUNT; else if (nrows <= 1.0) nrows = 1.0; else nrows = rint(nrows);

return nrows; } ~~~

目的

行数の推定値に対してクランプ処理と整数化を行い、無限大や NaN、1行未満の値に起因するコスト計算での除算ゼロや無効な値を防止する。

入力と出力

  • 引数: double nrows（処理対象の行数推定値）
  • 戻り値: double（クランプおよび丸め処理後の行数）

前提条件と不変条件

  • 入力された行数が MAXIMUM_ROWCOUNT を超える場合や NaN である場合は MAXIMUM_ROWCOUNT に制限される。
  • 行数が 1.0 以下である場合は 1.0 に切り上げられる。
  • それ以外の通常の数値範囲では、rint() によって整数値に丸められる。

アルゴリズムまたは振る舞い

  • まず nrows > MAXIMUM_ROWCOUNT || isnan(nrows) の条件を評価し、真であれば nrows を MAXIMUM_ROWCOUNT に置き換える。
  • 次に nrows <= 1.0 の条件を評価し、真であれば nrows を 1.0 に置き換える。
  • どちらの条件にも該当しない場合は、rint(nrows) を適用して整数型に丸めた値を設定する。
  • 最終的に調整済みの nrows を返す。

失敗モードと境界条件

  • NaN や無限大の入力値は MAXIMUM_ROWCOUNT に安全にクランプされる。
  • 1行未満またはゼロ以下の見積もり行数は強制的に 1.0 に引き上げられ、コスト補間時のゼロ除算を防ぐ。
