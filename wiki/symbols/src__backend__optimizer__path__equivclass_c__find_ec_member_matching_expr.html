~~~c EquivalenceMember * find_ec_member_matching_expr(EquivalenceClass *ec, Expr *expr, Relids relids) { EquivalenceMemberIterator it; EquivalenceMember *em;

/* We ignore binary-compatible relabeling on both ends */ while (expr && IsA(expr, RelabelType)) expr = ((RelabelType *) expr)->arg;

setup_eclass_member_iterator(&it, ec, relids); while ((em = eclass_member_iterator_next(&it)) != NULL) { Expr *emexpr;

/*

  • We shouldn't be trying to sort by an equivalence class that
  • contains a constant, so no need to consider such cases any further.

    • */ if (em->em_is_const) continue;

/*

  • Ignore child members unless they belong to the requested rel.

    • */ if (em->em_is_child && !bms_is_subset(em->em_relids, relids)) continue;

/*

  • Match if same expression (after stripping relabel).

    • */ emexpr = em->em_expr; while (emexpr && IsA(emexpr, RelabelType)) emexpr = ((RelabelType *) emexpr)->arg;

if (equal(emexpr, expr)) return em; }

return NULL; } ~~~

目的

指定された同値クラス（EquivalenceClass）の中から、指定された式およびリレーションIDに一致する同値メンバー（EquivalenceMember）を探索して返す。

入力と出力

  • 入力:
  • EquivalenceClass *ec: 探索対象の同値クラス
  • Expr *expr: 照合する式
  • Relids relids: 対象のリレーション集合
  • 戻り値:
  • 条件に一致した EquivalenceMember *。一致するものがない場合は NULL。

前提条件と不変条件

  • 両端のバイナリ互換なリレーベリング（RelabelType）は無視される。
  • 定数を含むメンバー（em_is_const が真のもの）はソート対象等として扱わないため無視される。
  • 子メンバー（em_is_child が真のもの）は、要求されたリレーション集合に属さない場合（em_relids が relids のサブセットでない場合）に無視される。

アルゴリズムまたは振る舞い

1. **式の正規化（入力側）**: 渡された expr の両端にある RelabelType を剥がして内部式を取り出す。 2. **イテレータの設定**: setup_eclass_member_iterator を使用して、指定された同値クラスとリレーション集合に基づくメンバーイテレータを初期化する。 3. **メンバーの走査と検証**: イテレータから順次 EquivalenceMember を取得し、以下の条件を順に評価する。

  • メンバーが定数（em_is_const）である場合はスキップする。
  • 子メンバーかつ要求されたリレーション集合（relids）の部分集合でない場合はスキップする。
  • メンバーの持つ式（em_expr）からも同様に RelabelType を剥がした上で、入力式と equal() 関数により一致するか比較する。

    • 4. **一致判定**: 式が一致した場合はその EquivalenceMember を返す。イテレータが終端に達した場合は NULL を返す。

失敗モードと境界条件

  • 一致するメンバーが存在しない場合は NULL を返す。
  • 定数を含む同値クラスや、指定リレーションに合致しない子メンバーは正しく除外される。
