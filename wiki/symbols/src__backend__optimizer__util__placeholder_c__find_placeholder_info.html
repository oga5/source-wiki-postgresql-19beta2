目的

指定された PlaceHolderVar (phv) に対応する PlaceHolderInfo 構造体を高速に検索するか、未登録であれば新規作成してプランナ情報へ登録します。

シグネチャまたは形状

  • シグネチャ: PlaceHolderInfo * find_placeholder_info(PlannerInfo *root, PlaceHolderVar *phv)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報コンテキスト
  • PlaceHolderVar *phv: 情報を取得または作成する対象のプレースホルダ変数ノード
  • 戻り値:
  • PlaceHolderInfo *: 対応するプレースホルダ情報構造体へのポインタ

前提条件と不変条件

  • phv->phlevelsup は常に 0 であること（親クエリレベルの参照を含まないこと）。
  • 既存の PlaceHolderInfo がヒットした場合、その phid は phv->phid と一致すること。
  • 新規作成された phinfo->ph_var->phnullingrels は常に空（NULL）に初期化されること。

アルゴリズムまたは振る舞い

1. **レベルの検証**: phv->phlevelsup == 0 であることをアサートで確認する。 2. **キャッシュからの高速検索**: root->placeholder_array から phv->phid をインデックスとして既存の PlaceHolderInfo を引き、存在すればそのまま返す。 3. **凍結状態のチェック**: キャッシュに存在せず root->placeholdersFrozen が真の場合は、新規作成が遅すぎるためエラーを送出する。 4. **新規 PlaceHolderInfo の割り当てと初期化**:

  • PlaceHolderInfo ノードを確保し、phid およびコピーした ph_var を設定する。
  • ph_var->phnullingrels を NULL に設定する。

    • 5. **評価位置とラテラル参照の算出**:

  • 式 phv->phexpr が参照する変数リストから使用リレーション集合 (rels_used) を引く。
  • 構文上のスコープ (phv->phrels) の外側を参照するリレーションをラテラル参照 ph_lateral (rels_used と phv->phrels の差分) として算出する。
  • 構文上のスコープ内にあるリレーションを評価位置 ph_eval_at (rels_used と phv->phrels の共通集合) として算出する。
  • 含有変数が空の場合は、評価位置を構文上の位置 phv->phrels に強制する。

    • 6. **幅の見積もりとリスト・配列への登録**:

  • データ型の平均幅関数を用いて ph_width を初期見積もりする。
  • root->placeholder_list に phinfo を追加する。
  • 必要に応じて root->placeholder_array を再割当て・拡大し、phinfo を登録する。

    • 7. **ネストしたプレースホルダの処理**: 内部式に含まれる低レベルのプレースホルダを検出するため、find_placeholders_in_expr を呼び出す。

失敗モードと境界条件

  • **エラー終了 (ERROR)**: プレースホルダ集合が既に凍結されている状態 (root->placeholdersFrozen が真) で新しい PlaceHolderInfo を作成しようとした場合、エラーが発生する。
  • **配列拡張の境界**: phinfo->phid が現在の root->placeholder_array_size を超える場合、サイズを 2 倍に拡大しながら十分な大きさになるまでループして placeholder_array を再割り当てする。
