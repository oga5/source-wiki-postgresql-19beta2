~~~c typedef struct { int relid; Oid reloid; } SelfJoinCandidate; ~~~

目的

自己結合の排除（Self-Join Elimination: SJE）の候補となるベースリレルの識別子と物理リレーションのOIDを保持し、Oidによるソートによって二乗オーダーの計算量を回避するためのユーティリティ構造体です。

フィールドと表現

  • int relid: 自己結合排除の候補となるベースリレルの識別子を保持します。
  • Oid reloid: 該当するベースリレルが参照する物理リレーションのOIDを保持します。
