~~~c double geqo_rand(PlannerInfo *root) { GeqoPrivateData *private = GetGeqoPrivateData(root);

return pg_prng_double(&private->random_state); } ~~~

目的

PlannerInfo に紐づく GEQO プライベートデータの乱数状態から、[0.0, 1.0) の範囲の倍精度浮動小数点乱数を生成して返す。

アルゴリズムまたは振る舞い

引数として渡された PlannerInfo *root から GetGeqoPrivateData(root) を用いてプライベートデータを取得し、そこに含まれる random_state を pg_prng_double 関数に渡して乱数値を得る。
