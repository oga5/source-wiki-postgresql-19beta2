~~~c static Oid having_var_grouping_eqop(Var *var, void *context) { having_grouping_ctx *ctx = (having_grouping_ctx *) context;

if (var->varno != ctx->group_rtindex || var->varlevelsup != 0) return InvalidOid;

return group_var_eqop(ctx->parse, var); } ~~~

目的

HAVING 句内の式走査時に、指定された Var がグループ化変数に一致するかどうかを判定し、対応する等価演算子（Oid）を取得するコールバック関数として機能します。

アルゴリズムまたは振る舞い

  • 引数のコンテキストポインタを having_grouping_ctx * 型にキャストして参照します。
  • Var ノードの範囲変数インデックス（varno）がコンテキストの group_rtindex と一致し、かつ変数レベル（varlevelsup）が 0 であるかを検証します。
  • 条件を満たさない場合は InvalidOid を返します。
  • 条件を満たす場合は group_var_eqop を呼び出してグループ化の等価演算子 Oid を返します。
