目的

トップレベルの AND/OR 構造を再帰的に走査して冗長な重複式の共通因数を括り出し、定数畳み込みとツリーの平坦化を行う。

シグネチャまたは形状

static Expr *find_duplicate_ors(Expr *qual, bool is_check)

入力と出力

  • 入力:
  • Expr *qual: 処理対象の式ツリー
  • bool is_check: CHECK 制約であるかどうかを示すフラグ
  • 出力:
  • Expr *: 最適化および簡約化された式ツリー

前提条件と不変条件

  • 入力される修飾式はすでに eval_const_expressions を経由しており、AND/OR のフラットネスが保持されているという前提のもとで動作する。

アルゴリズムまたは振る舞い

1. qual が OR 節（is_orclause(qual)）の場合:

  • 各引数に対して再帰的に find_duplicate_ors を実行する。
  • 引数が Const ノードである場合、is_check フラグの値に応じて定数（TRUE、FALSE、NULL）の枝刈りや縮退を行う（例: CHECK 内の定数 FALSE はドロップされ、一般 WHERE 内の定数 FALSE または NULL もドロップされる）。
  • 残った引数リストを lappend で集約したあと、pull_ors で平坦化する。
  • 最後に process_duplicate_ors を呼び出して重複 OR の共通因数を抽出し、その結果を返す。

    • 2. qual が AND 節（is_andclause(qual)）の場合:

  • 各引数に対して再帰的に find_duplicate_ors を実行する。
  • 引数が Const ノードである場合、is_check フラグに応じて定数の枝刈りや縮退を行う。
  • 残った引数リストを lappend で集約したあと、pull_ands で平坦化する。
  • リストが空になった場合は定数 TRUE を返し、要素数が 1 つの場合はその単一式をそのまま返し、複数の場合は make_andclause で AND 節ノードを構築して返す。

    • 3. 上記のいずれでもない場合:

  • qual をそのまま返す。

失敗モードと境界条件

  • OR 節または AND 節の引数が定数に還元され、式全体が TRUE や FALSE に縮退する場合がある。
  • AND 節の引数リストが空になった場合は TRUE のブール定数ノードを返す。
  • AND 節の引数リストの要素数が 1 つだけ残った場合は、リスト構造を剥がしてその単一式を直接返す。
