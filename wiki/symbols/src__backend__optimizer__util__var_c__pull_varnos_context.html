ソース抜粋

~~~c typedef struct { Relids varnos; PlannerInfo *root; int sublevels_up; } pull_varnos_context; ~~~

目的

pull_varnos_context は、式ツリーやクエリツリーからリレーションID（varnos）を抽出する処理（pull_varnos および pull_varnos_of_level）の実行中に走査状態を保持するためのコンテキスト構造体です。

フィールドと表現

  • Relids varnos: 収集されたリレーションIDの集合をビットマップとして保持します。
  • PlannerInfo *root: プランナ情報へのポインタを保持します。
  • int sublevels_up: 現在処理している対象のクエリ階層の深さ（サブクエリのレベル差）を追跡します。
