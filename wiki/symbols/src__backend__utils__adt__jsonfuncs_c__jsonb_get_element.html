目的

jsonb_get_element 関数は、JSONBコンテナから指定された一連のパス（オブジェクトのキーまたは配列のインデックスの配列）に沿って要素を抽出し、要求された型（テキスト表現またはJSONBバイナリ）で返す。

入力と出力

  • 引数:
  • Jsonb *jb: 対象となるJSONBコンテナへのポインタ。
  • const Datum *path: 抽出パスを表す Datum 配列。
  • int npath: パスの深さ（要素数）。
  • bool *isnull: 結果がNULLまたは見つからなかった場合に真が設定される出力引数。
  • bool as_text: 結果をテキスト形式で返す場合は true、JSONB形式で返す場合は false。
  • 戻り値: Datum （抽出された要素のDatum表現）。

前提条件と不変条件

  • 処理の開始時に *isnull は false に初期化される。

アルゴリズムまたは振る舞い

1. **初期状態の判定**:

  • jb のルートがオブジェクトであるか、配列であるか、またはスカラーであるかを判定し、それぞれ対応するフラグ（have_object または have_array）を設定する。
  • ルートがスカラーであり npath <= 0 の場合、先頭の値を初期の jbvp として取得する。

2. **空パスの処理**:

  • npath <= 0 かつ jbvp == NULL の場合、抽出を行わずにコンテナ全体を返す。as_text が真の場合はテキストに変換して返し、偽の場合は元の jsonb をそのまま返す。

3. **パスの走査ループ**:

  • 0 から npath - 1 までパスの各要素を順に辿る。
  • have_object が真の場合、現在のパス要素をテキストに変換し、オブジェクトコンテナからキーに対応する値（jbvp）を取得する。
  • have_array が真の場合、パス要素を文字列に変換した上で strtoint を用いて整数インデックスに変換する。変換に失敗した場合は *isnull = true として終了する。
  • 負のインデックスの場合、配列の要素数を算出して逆方向のインデックスに変換する。インデックスが範囲外である場合は *isnull = true とする。
  • その後、インデックスに対応する要素をコンテナから取得する。
  • スカラー型の場合、要素の抽出はできないため *isnull = true として終了する。
  • 現在のステップが最終パス（i == npath - 1）であればループを抜ける。
  • 取得した値がバイナリ型（jbvBinary）の場合、内部コンテナを更新し、次段のコンテナがオブジェクトか配列かに応じてフラグを再設定する。スカラー型の場合は両方のフラグを不活性にする。

4. **結果の返却**:

  • as_text が真の場合、値がSQLのNULL（jbvNull）であれば *isnull = true とし、それ以外は JsonbValueAsText を用いてテキスト表現に変換して返す。
  • as_text が偽の場合、JsonbValueToJsonb を用いて Jsonb 構造体に変換し、マクロを介して返す。

失敗モードと境界条件

  • パスの数値インデックス変換時に不正な文字列やオーバーフローが発生した場合、*isnull = true が設定され、空のDatumが返される。
  • 配列インデックスが範囲外（負の過大値や要素数超え）である場合、*isnull = true が設定される。
  • テキストモードにおいて抽出された値がJSONの null 値である場合、*isnull = true が設定される。
  • 配列またはオブジェクトではないコンテナに対して予期せぬ不整合がある場合、アサーション失敗やエラーログが出力される場合がある。
