目的

結合条件（結合句）が存在しない状態で、既存のリレーションと他のリレーション候補のリストを走査し、条件なしの結合（デカルト積など）に相当する結合リレーションを構築します。

入力と出力

  • 入力: PlannerInfo *root（プランナのグローバル情報）, RelOptInfo *old_rel（ベースとなる既存リレーション）, List *other_rels（結合対象となる他のリレーションのリスト）
  • 出力: なし (void)

前提条件と不変条件

  • other_rels 内の各リレーションと old_rel との間で、リレーションID集合 (relids) が重複していないこと。

アルゴリズムまたは振る舞い

  • other_rels リストを foreach マクロにより順に走査し、各要素を RelOptInfo *other_rel として取り出します。
  • 各 other_rel のリレーションID集合と old_rel のリレーションID集合が重複しているか (bms_overlap) を判定します。
  • 重複していない場合のみ、make_join_rel を呼び出して old_rel と other_rel の結合関係を構築・登録します。

失敗モードと境界条件

  • other_rel->relids と old_rel->relids がオーバーラップしている場合、bms_overlap の条件により make_join_rel はスキップされます。
