目的

指定された同値クラス（EquivalenceClass）に対して、非子要素（non-child）の同値メンバー（EquivalenceMember）を新しく構築して追加し、クラス全体の関係リレーション集合（ec_relids）を更新する。

シグネチャまたは形状

  • シグネチャ: static EquivalenceMember * add_eq_member(EquivalenceClass *ec, Expr *expr, Relids relids, JoinDomain *jdomain, Oid datatype)

入力と出力

  • 引数:
  • EquivalenceClass *ec: 新規メンバーを追加する対象の同値クラス
  • Expr *expr: 追加する式
  • Relids relids: 式が依存する関係ID集合
  • JoinDomain *jdomain: 結合ドメイン
  • Oid datatype: 式のデータ型 OID
  • 戻り値:
  • EquivalenceMember *: 作成および登録された新しい同値メンバーへのポインタ

前提条件と不変条件

  • 追加されるメンバーは非子要素として構築される。

アルゴリズムまたは振る舞い

  • make_eq_member を呼び出して、指定されたパラメータを持つ新しい EquivalenceMember を生成する。
  • 生成したメンバーを ec->ec_members リストの末尾に結合する。
  • 親メンバーの識別関係として、ec->ec_relids に対して引数 relids をビットマップ結合（bms_add_members）で追加する。
  • 登録完了後、作成した EquivalenceMember ポインタを返す。

呼び出し元と呼び出し先

  • 呼び出し元: process_equivalence, get_eclass_for_sort_expr
  • 呼び出し先: make_eq_member, lappend, bms_add_members

関連データ構造

  • EquivalenceClass: 同値関係を保持するクラス構造体。
  • EquivalenceMember: クラス内の個別の式や項を表す構造体。
  • Expr: 式ノード。
  • Relids: 関係IDの集合を表すビットマップ。
  • JoinDomain: 結合ドメイン。

失敗モードと境界条件

  • 渡された expr や relids が無効である場合や、メモリ不足時には下位のメモリ割り当てやリスト操作、ビットマップ操作に依存した失敗・異常終了が発生しうる。
