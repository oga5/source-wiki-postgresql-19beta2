目的

指定されたノードまたは式ツリーの中に、特定のクエリレベル (levelsup) に属する変数や式要素が含まれているかを判定する。

シグネチャまたは形状

  • シグネチャ: bool contain_vars_of_level(Node *node, int levelsup)

入力と出力

  • 引数:
  • Node *node: 走査対象の構文木または式ツリーのルートノード。
  • int levelsup: 検出対象とするクエリ階層の深さ（サブレベル数）。
  • 戻り値: bool - 指定レベルの変数が含まれている場合は真、それ以外の場合は偽を返す。

アルゴリズムまたは振る舞い

  • sublevels_up 変数に引数 levelsup を設定し、query_or_expression_tree_walker を介して contain_vars_of_level_walker によるツリー走査を実行する。
