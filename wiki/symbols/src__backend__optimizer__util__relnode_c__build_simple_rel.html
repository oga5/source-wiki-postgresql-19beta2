定義

目的

ベースリレーションまたは子（other）リレーションのための RelOptInfo 構造体を構築し、初期化して、対応するクエリのシンプルリレーション配列に登録する。

シグネチャまたは形状

  • シグネチャ: RelOptInfo * build_simple_rel(PlannerInfo *root, int relid, RelOptInfo *parent)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報を保持する構造体ポインタ。
  • int relid: 対象となるレンジテーブルエントリのインデックス（範囲ID）。
  • RelOptInfo *parent: 継承関係やサブクエリにおける親リレーション（存在しない場合は NULL）。
  • 戻り値:
  • RelOptInfo *: 生成・初期化されたリレーション情報構造体ポインタ。

前提条件と不変条件

  • relid は 0 より大きく、root->simple_rel_array_size 未満でなければならない。
  • 指定された relid に対するリレーションがすでに root->simple_rel_array に存在していてはならない。
  • root->simple_rte_array[relid] が指すレンジテーブルエントリ（RTE）が存在していなければならない。

アルゴリズムまたは振る舞い

1. **初期存在チェック**: relid の有効性を Assert で確認し、すでに root->simple_rel_array[relid] が存在している場合はエラーを出力する。 2. **基本構造体の割り当てと初期化**:

  • root->simple_rte_array[relid] から RTE を取得する。
  • RelOptInfo ノードを新規作成し、parent の有無に応じて reloptkind を RELOPT_OTHER_MEMBER_REL または RELOPT_BASEREL に設定する。
  • relids に単一要素のビットマップを設定し、コスト計算フラグ、空のパターゲッティング、各種リストやコスト・統計フィールドを初期化する。

    • 3. **ユーザーID（権限チェック用）の設定**:

  • rtekind が RTE_RELATION の場合、ベースリレーションまたはサブクエリ配下の OTHER_MEMBER_REL であればパーミッション情報から checkAsUser を取得し、それ以外の場合は親の userid を引き継ぐ。
  • RTE_RELATION 以外の場合は InvalidOid を設定する。

    • 4. **階層・継承プロパティの伝播**:

  • parent が存在するペレント階層では、親へのバックリンク（parent、top_parent、top_parent_relids）および nulling_relids や lateral 関連の参照情報を親から引き継ぐ。
  • parent が NULL の場合はこれらをすべて NULL に初期化する。

    • 5. **RTE種別ごとの属性・統計情報取得**:

  • RTE_RELATION: get_relation_info を呼び出してシステムカタログから統計情報等を取得する。
  • サブクエリ、関数、テーブル関数、VALUES、CTE、名前付きタプルストアなどの各種エントリ: 属性範囲や attr_needed、attr_widths のメモリ領域を割り当てて初期化する。
  • RTE_RESULT: 属性を持たないため関連フィールドをクリアする。
  • その他未知の RTE 種別ではエラーとする。

    • 6. **プラグインフックの呼び出し**: build_simple_rel_hook が設定されている場合はこれを実行し、リレーション情報やカタログ情報を拡張・編集できるようにする。 7. **子リレーションへのベース制約の適用**:

  • parent が存在する場合、対応する AppendRelInfo を取得し、apply_child_basequals で親の制約条件を子に適用する。
  • 条件が定数 FALSE または NULL に縮約されて行を返さないと判定された場合は、mark_dummy_rel を呼び出してダミーリレーションとしてマークする。

    • 8. **登録と返却**: 構築した rel を root->simple_rel_array[relid] に格納し、ポインタを返す。

失敗モードと境界条件

  • 指定した relid のリレーションがすでに存在している場合、elog(ERROR, ...) によりエラーが発生する。
  • 該当する relid に対する RangeTblEntry が存在しない場合（rte == NULL）、Assert により異常終了する。
  • サポートされていない予期せぬ rtekind に直面した場合、elog(ERROR, "unrecognized RTE kind: %d", ...) が呼び出される。
