~~~c static double avg_pool(Pool *pool) { int i; double cumulative = 0.0;

if (pool->size <= 0) elog(ERROR, "pool_size is zero");

/*

  • Since the pool may contain multiple occurrences of DBL_MAX, divide by
  • pool->size before summing, not after, to avoid overflow. This loses a
  • little in speed and accuracy, but this routine is only used for debug
  • printouts, so we don't care that much.

    • */ for (i = 0; i < pool->size; i++) cumulative += pool->data[i].worth / pool->size;

return cumulative; } ~~~

目的

プール全体の平均コストを算出するデバッグ用関数です。

入力と出力

  • 入力: Pool *pool （評価対象の個体群プール）
  • 戻り値: double （算出した平均コスト）

前提条件と不変条件

  • プールのサイズ pool->size は 0 より大きい必要があります。

アルゴリズムまたは振る舞い

  • 浮動小数点のオーバーフローを防ぐため、DBL_MAX が複数含まれる可能性のある各個体のコスト総和を後から割るのではなく、事前に pool->size で除算してから累積します。
  • 0 から pool->size - 1 までループを回し、各個体の worth をプールサイズで割った値を cumulative に加算していき、最終的な累積値を返します。

失敗モードと境界条件

  • pool->size が 0 以下の場合、elog(ERROR, "pool_size is zero") を呼び出しエラーが発生します。
