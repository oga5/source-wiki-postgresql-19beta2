目的

式ツリーを再帰的に走査し、ノードが Aggref である場合に前処理を実行するヘルパー関数である。

入力と出力

  • 引数:
  • Node *node: 走査対象の式ツリーノード。
  • PlannerInfo *root: プランナのグローバル情報構造体。
  • 戻り値: bool （expression_tree_walker の規約に従う）

前提条件と不変条件

  • 入力ノードが SubLink である場合はアサーション違反により失敗する。
  • パーサにより、集約された引数、直接引数、フィルタ句に同一階層の集約が含まれないことが確認されていると仮定する。

アルゴリズムまたは振る舞い

1. node が NULL の場合は false を返す。 2. node が Aggref 型の場合は、該当ノードを Aggref * にキャストして preprocess_aggref を呼び出して前処理を行い、集約内部の引数やフィルタ句へは再帰せず false を返す。 3. node が SubLink でないことをアサーションで確認する。 4. それ以外の場合は、expression_tree_walker を用いて子ノードを再帰的に走査する。

失敗モードと境界条件

  • 対象ノードが SubLink である場合、アサーション（Assert(!IsA(node, SubLink))）により処理が中断される。
