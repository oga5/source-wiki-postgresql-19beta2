~~~c void mark_dummy_rel(RelOptInfo *rel) { MemoryContext oldcontext; AppendPathInput in = {0};

/* Already marked? */ if (is_dummy_rel(rel)) return;

/* No, so choose correct context to make the dummy path in */ oldcontext = MemoryContextSwitchTo(GetMemoryChunkContext(rel));

/* Set dummy size estimate */ rel->rows = 0;

/* Evict any previously chosen paths */ rel->pathlist = NIL; rel->partial_pathlist = NIL;

/* Set up the dummy path */ add_path(rel, (Path *) create_append_path(NULL, rel, in, NIL, rel->lateral_relids, 0, false, -1));

/* Set or update cheapest_total_path and related fields */ set_cheapest(rel);

MemoryContextSwitchTo(oldcontext); } ~~~

目的

指定されたリレーション (RelOptInfo) が空の結果を返す（ダミーである）ことをマークし、関連する行数見積もり、パスリスト、最安パス情報をその状態に合わせて再構築する。

入力と出力

  • 引数:
  • RelOptInfo *rel: ダミーリレーションとしてマークおよび初期化する対象のリレーション構造体
  • 戻り値:
  • なし (void)

前提条件と不変条件

  • すでにダミーリレーションとしてマークされている場合は、重複処理を行わずに即座に復帰する。

アルゴリズムまたは振る舞い

1. 重複マークの確認: is_dummy_rel(rel) を呼び出し、既にダミーリレーションであれば何もせず終了する。 2. メモリコンテキストの切り替え: 対象リレーション rel が属するメモリチャンクのコンテキストへ一時的に切り替える。 3. サイズ見積もりと既存パスの破棄:

  • 推定行数 rel->rows を 0 に設定する。
  • 既存の通常パスリスト (rel->pathlist) および部分パスリスト (rel->partial_pathlist) を NIL にクリアして破棄する。

    • 4. ダミーパスの追加: create_append_path を用いて新規のダミーパスを作成し、add_path を経由してリレーションのパスリストへ登録する。 5. 最安パスの更新: set_cheapest を呼び出し、cheapest_total_path などの関連フィールドを更新する。 6. コンテキストの復元: 処理開始前のメモリコンテキストに戻す。

失敗モードと境界条件

  • 対象のリレーションがすでにダミーリレーションである場合、処理は早期リターンするため安全に無視される。
