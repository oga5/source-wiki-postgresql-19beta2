~~~c static EquivalenceMember * add_child_eq_member(PlannerInfo *root, EquivalenceClass *ec, int ec_index, Expr *expr, Relids relids, JoinDomain *jdomain, EquivalenceMember *parent_em, Oid datatype, Index child_relid) { EquivalenceMember *em;

Assert(parent_em != NULL);

/*

  • Allocate the array to store child members; an array of Lists indexed by
  • relid, or expand the existing one, if necessary.

    • */ if (unlikely(ec->ec_childmembers_size < root->simple_rel_array_size)) { if (ec->ec_childmembers == NULL) ec->ec_childmembers = palloc0_array(List *, root->simple_rel_array_size); else ec->ec_childmembers = repalloc0_array(ec->ec_childmembers, List *, ec->ec_childmembers_size, root->simple_rel_array_size);

ec->ec_childmembers_size = root->simple_rel_array_size; }

em = make_eq_member(ec, expr, relids, jdomain, parent_em, datatype);

/* add member to the ec_childmembers List for the given child_relid */ ec->ec_childmembers[child_relid] = lappend(ec->ec_childmembers[child_relid], em);

/* Record this EC index for the child rel */ if (ec_index >= 0) { RelOptInfo *child_rel = root->simple_rel_array[child_relid];

child_rel->eclass_indexes = bms_add_member(child_rel->eclass_indexes, ec_index); }

return em; } ~~~

目的

子リレーション向けの同値メンバー（EquivalenceMember）を生成し、指定された同値クラス（EquivalenceClass, EC）および子リレーションのインデックス構造に登録する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体のグローバル情報
  • EquivalenceClass *ec: メンバーを追加する対象の同値クラス
  • int ec_index: 子リレーションのビットマップに記録する同値クラスのインデックス（無効な場合は負の値）
  • Expr *expr: 追加するメンバーの式
  • Relids relids: 式が参照するリレーション集合
  • JoinDomain *jdomain: 結合ドメイン情報
  • EquivalenceMember *parent_em: 継承元となる親同値メンバー
  • Oid datatype: 式のデータ型 Oid
  • Index child_relid: 対象となる子リレーションの識別子（インデックス）
  • 戻り値: 新規作成・登録された EquivalenceMember * へのポインタ

前提条件と不変条件

  • parent_em は NULL であってはならない（Assert(parent_em != NULL) が課されている）。

アルゴリズムまたは振る舞い

1. 前提条件の検証: parent_em が NULL でないことをアサーションで確認する。 2. 子メンバー配列の容量確保: 同値クラス ec の子メンバー管理配列 (ec_childmembers) のサイズが root->simple_rel_array_size 未満である場合、配列を新規割り当て（palloc0_array）または再割り当て（repalloc0_array）によって拡張し、サイズを更新する。 3. 同値メンバーの作成: make_eq_member を呼び出して、指定された引数から新しい同値メンバー em を構築する。 4. 子メンバーリストへの登録: 作成した em を、対応する child_relid をインデックスとする ec->ec_childmembers のリスト末尾に lappend を用いて追加する。 5. リレーションへのインデックス記録: ec_index が 0 以上である場合、root->simple_rel_array から該当する子リレーション（child_relid）を取得し、その eclass_indexes ビットマップに ec_index を追加する。 6. 結果の返却: 作成した同値メンバー em を返す。

失敗モードと境界条件

  • parent_em に NULL が渡された場合はアサーション違反により失敗する。
  • ec_childmembers_size が不足している状態での自動拡張処理においてメモリ割り当てに失敗した場合は、基盤のメモリ管理機構によりエラー処理される。
