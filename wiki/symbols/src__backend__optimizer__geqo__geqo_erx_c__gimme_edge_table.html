ソース抜粋

~~~c float gimme_edge_table(PlannerInfo *root, Gene *tour1, Gene *tour2, int num_gene, Edge *edge_table) { int i, index1, index2; int edge_total; /* total number of unique edges in two genes */

/* at first clear the edge table's old data */ for (i = 1; i <= num_gene; i++) { edge_table[i].total_edges = 0; edge_table[i].unused_edges = 0; }

/* fill edge table with new data */

edge_total = 0;

for (index1 = 0; index1 < num_gene; index1++) { /*

  • presume the tour is circular, i.e. 1->2, 2->3, 3->1 this operation
  • maps n back to 1

    • */

index2 = (index1 + 1) % num_gene;

/*

  • edges are bidirectional, i.e. 1->2 is same as 2->1 call gimme_edge
  • twice per edge

    • */

edge_total += gimme_edge(root, tour1[index1], tour1[index2], edge_table); gimme_edge(root, tour1[index2], tour1[index1], edge_table);

edge_total += gimme_edge(root, tour2[index1], tour2[index2], edge_table); gimme_edge(root, tour2[index2], tour2[index1], edge_table); }

/* return average number of edges per index */ return ((float) (edge_total * 2) / (float) num_gene); } ~~~

目的

2つの親ツアー (tour1, tour2) の循環エッジ情報からエッジテーブルを初期化および充填し、平均エッジ数を返します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Gene *tour1: 1つ目の親ツアー
  • Gene *tour2: 2つ目の親ツアー
  • int num_gene: 遺伝子（都市）の総数
  • Edge *edge_table: 構築対象のエッジテーブル
  • 戻り値: float 型のインデックスあたりの平均エッジ数

前提条件と不変条件

  • ツアーは循環構造（例: 1->2, 2->3, 3->1）として扱われます。
  • エッジは双方向（例: 1->2 は 2->1 と同一）であるため、各エッジにつき gimme_edge が双方向に呼び出されます。

アルゴリズムまたは振る舞い

1. 1 から num_gene までの範囲で edge_table の各エントリの total_edges と unused_edges を 0 にクリアします。 2. edge_total を 0 に初期化します。 3. 0 から num_gene - 1 まで index1 をインクリメントしながらループし、循環位置 index2 = (index1 + 1) % num_gene を計算します。 4. tour1 および tour2 の各隣接ペアについて、順方向および逆方向のエッジを gimme_edge に渡して登録し、新規追加されたエッジ数を edge_total に加算します。 5. (edge_total * 2) を num_gene で割った浮動小数点値を平均エッジ数として返します。

呼び出し元と呼び出し先

  • 呼び出し先: gimme_edge

失敗モードと境界条件

  • エラー検出や境界チェックの分岐はこの関数内には含まれておらず、渡された num_gene と edge_table のサイズが整合していることを前提にループ処理を行います。
