ソース抜粋

~~~c List * extract_actual_clauses(List *restrictinfo_list, bool pseudoconstant) { List *result = NIL; ListCell *l;

foreach(l, restrictinfo_list) { RestrictInfo *rinfo = lfirst_node(RestrictInfo, l);

if (rinfo->pseudoconstant == pseudoconstant && !rinfo_is_constant_true(rinfo)) result = lappend(result, rinfo->clause); } return result; } ~~~

目的

RestrictInfo ノードのリストから、指定された疑似定数フラグの条件を満たし、かつ定数 TRUE でない実際の式（Expr）のリストを抽出します。

シグネチャまたは形状

  • シグネチャ: List * extract_actual_clauses(List *restrictinfo_list, bool pseudoconstant)

入力と出力

  • 引数:
  • List *restrictinfo_list: 抽出元の RestrictInfo ノードのリスト。
  • bool pseudoconstant: 抽出対象とする RestrictInfo の pseudoconstant フィールドの値（真または偽）。
  • 戻り値:
  • List *: 抽出された生の式（Expr）のリスト。

前提条件と不変条件

  • 入力される restrictinfo_list 内の各要素は RestrictInfo ノードである必要があります。

アルゴリズムまたは振る舞い

  • NIL で初期化された結果リストを準備します。
  • restrictinfo_list の各要素を順に走査し、各ノードを RestrictInfo として取得します。
  • 各 RestrictInfo ノードについて、以下の条件を判定します:
  • ノードの pseudoconstant プロパティが引数 pseudoconstant と一致すること。
  • rinfo_is_constant_true(rinfo) が偽を返すこと（すなわち、定数 TRUE そのものではないこと）。
  • 両方の条件を満たす場合、その RestrictInfo が保持する生の式（rinfo->clause）を lappend を用いて結果リストに追加します。
  • 走査完了後、構築された式リストを返します。

関連データ構造

  • RestrictInfo
  • List
  • ListCell

失敗モードと境界条件

  • restrictinfo_list が空（NIL）の場合、ループは実行されず空のリストが返されます。
  • リスト内のすべての要素が条件に一致しない場合、戻り値は NIL となります。
