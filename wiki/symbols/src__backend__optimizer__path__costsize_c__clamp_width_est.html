ソース抜粋

~~~c int32 clamp_width_est(int64 tuple_width) { /*

  • Anything more than MaxAllocSize is clearly bogus, since we could not
  • create a tuple that large.

    • */ if (tuple_width > MaxAllocSize) return (int32) MaxAllocSize;

/*

  • Unlike clamp_row_est, we just Assert that the value isn't negative,
  • rather than masking such errors.

    • */ Assert(tuple_width >= 0);

return (int32) tuple_width; } ~~~

目的

タプル幅の推定値（tuple_width）を受け取り、許容される上限値（MaxAllocSize）および下限値の制約を適用した上で、安全な int32 型の幅へクランプして返します。

シグネチャまたは形状

  • int32 clamp_width_est(int64 tuple_width)

入力と出力

  • 入力: int64 tuple_width（評価対象となるタプル幅）
  • 出力: int32（クランプ処理後の安全なタプル幅）

前提条件と不変条件

  • tuple_width は負の値であってはならず、関数内の Assert(tuple_width >= 0) によって検証されます。

アルゴリズムまたは振る舞い

  • 引数 tuple_width が MaxAllocSize を超える場合は、大きすぎるため不正とみなし、明示的に (int32) MaxAllocSize に切り詰めて返します。
  • 負の値でないことをアサーションで確認した上で、値を int32 にキャストして返します。

失敗モードと境界条件

  • tuple_width が負の数の場合、デバッグビルドでは Assert により停止します。
