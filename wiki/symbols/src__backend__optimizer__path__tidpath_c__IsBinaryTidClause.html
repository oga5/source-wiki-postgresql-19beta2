~~~c static bool IsBinaryTidClause(RestrictInfo *rinfo, RelOptInfo *rel) { OpExpr *node; Node *arg1, *arg2, *other; Relids other_relids;

/* Must be an OpExpr */ if (!is_opclause(rinfo->clause)) return false; node = (OpExpr *) rinfo->clause;

/* OpExpr must have two arguments */ if (list_length(node->args) != 2) return false; arg1 = linitial(node->args); arg2 = lsecond(node->args);

/* Look for CTID as either argument */ other = NULL; other_relids = NULL; if (arg1 && IsA(arg1, Var) && IsCTIDVar((Var *) arg1, rel)) { other = arg2; other_relids = rinfo->right_relids; } if (!other && arg2 && IsA(arg2, Var) && IsCTIDVar((Var *) arg2, rel)) { other = arg1; other_relids = rinfo->left_relids; } if (!other) return false;

/* The other argument must be a pseudoconstant */ if (bms_is_member(rel->relid, other_relids) || contain_volatile_functions(other)) return false;

return true; /* success */ } ~~~

目的

RestrictInfo が保持する式が、対象リレーションのタプルID（CTID）と非揮発性の他辺引数による二項演算子式であるかを検査します。

入力と出力

  • 引数:
  • RestrictInfo *rinfo: 検査対象の制限情報
  • RelOptInfo *rel: 対象のリレーション情報
  • 戻り値:
  • bool: 条件を満たす場合は true、そうでない場合は false

前提条件と不変条件

  • rinfo->clause は演算子式（OpExpr）である必要があります。
  • 演算子式は正確に2つの引数を持つ必要があります。
  • 引数のいずれか一方が対象リレーションの CTID 変数であり、もう一方の引数（他辺引数）が対象リレーション自身を含まず、かつ揮発性関数を含まない疑似定数である必要があります。

アルゴリズムまたは振る舞い

1. **演算子式の確認**: rinfo->clause が OpExpr であるかを確認し、そうでない場合は false を返します。 2. **引数の数と取得**: 演算子式の引数リストの長さが2つであることを確認し、arg1 と arg2 を取得します。 3. **CTID 変数の探索**:

  • arg1 が Var かつ対象リレーションの CTID 変数である場合、他辺引数を arg2 に、関連する右側リレーション ID を設定します。
  • arg1 が一致せず、arg2 が Var かつ対象リレーションの CTID 変である場合、他辺引数を arg1 に、関連する左側リレーション ID を設定します。
  • どちらの引数も CTID 変数でない場合は false を返します。

    • 4. **他辺引数の検証**: 他辺引数が対象リレーションに属している（bms_is_member(rel->relid, other_relids)）か、あるいは揮発性関数を含んでいる場合は false を返します。 5. **成功時**: すべての条件を満たした場合に true を返します。

失敗モードと境界条件

  • rinfo->clause が OpExpr でない場合は失敗し false を返します。
  • 引数の数が2つ以外の場合は失敗し false を返します。
  • どちらの引数も CTID 変数でない場合は失敗し false を返します。
  • 他辺引数が対象リレーションを含む場合、または揮発性関数が含まれている場合は失敗し false を返します。
