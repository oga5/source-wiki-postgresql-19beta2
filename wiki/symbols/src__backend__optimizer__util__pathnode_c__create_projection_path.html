  • conclusion; see comments therein.

    • */ oldtarget = subpath->pathtarget; if (is_projection_capable_path(subpath) || equal(oldtarget->exprs, target->exprs)) { /* No separate Result node needed */ pathnode->dummypp = true;

  • Set cost of plan as subpath's cost, adjusted for tlist replacement.

    • */ pathnode->path.rows = subpath->rows; pathnode->path.disabled_nodes = subpath->disabled_nodes; ~~~
