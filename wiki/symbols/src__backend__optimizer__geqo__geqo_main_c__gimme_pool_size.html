ソース抜粋

~~~c static int gimme_pool_size(int nr_rel) { double size; int minsize; int maxsize;

/* Legal pool size *must* be at least 2, so ignore attempt to select 1 */ if (Geqo_pool_size >= 2) return Geqo_pool_size;

size = pow(2.0, nr_rel + 1.0);

maxsize = 50 * Geqo_effort; /* 50 to 500 individuals */ if (size > maxsize) return maxsize;

minsize = 10 * Geqo_effort; /* 10 to 100 individuals */ if (size < minsize) return minsize;

return (int) ceil(size); } ~~~

目的

遺伝的クエリ最適化（GEQO）で使用する個体プールサイズを決定します。

入力と出力

  • 入力: クエリ内のリレーション数を表す int nr_rel。
  • 出力: 計算されたプールサイズを表す int。

前提条件と不変条件

  • 有効なプールサイズは必ず 2 以上でなければならないため、1 以下の選択は無視されます。

アルゴリズムまたは振る舞い

  • グローバル変数 Geqo_pool_size が 2 以上に設定されている場合は、その設定値をそのまま返します。
  • そうでない場合、2.0 の nr_rel + 1.0 乗を計算して基礎サイズを算出します。
  • グローバル変数 Geqo_effort に基づいて許容される最大サイズ（50 * Geqo_effort）および最小サイズ（10 * Geqo_effort）の制限を適用し、計算値が上限を超えた場合は最大サイズを、下限を下回った場合は最小サイズを返します。
  • 上記のいずれの境界にも該当しない場合は、算出されたサイズを ceil で切り上げて整数に変換した値を返します。

失敗モードと境界条件

  • 1 以下の不正なプールサイズ指定は Geqo_pool_size のチェックにより無視されます。
