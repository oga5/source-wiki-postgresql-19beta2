目的

指定されたレンジテーブルインデックス（rtindex）に対応する PlanRowMark を rowmarks リストから検索して返す。

入力と出力

  • 引数:
  • List *rowmarks: 検索対象となる PlanRowMark のリスト。
  • Index rtindex: 検索するレンジテーブルインデックス（rti）。
  • 戻り値: 一致する PlanRowMark *。見つからない場合は NULL を返す。

前提条件と不変条件

  • rowmarks リスト内の各要素は PlanRowMark 構造体へのポインタであると仮定する。

アルゴリズムまたは振る舞い

  • rowmarks リストを foreach マクロで先頭から順に走査する。
  • 各リスト要素から PlanRowMark 構造体を取り出し、その rti フィールドが指定された rtindex と一致するか比較する。
  • 一致した場合は該当する PlanRowMark ポインタを即座に返す。
  • リスト全体を走査しても一致するものが見つからない場合は NULL を返す。

失敗モードと境界条件

  • 一致する rtindex がリスト内に存在しない場合、エラーを起こさずに NULL を返す。
