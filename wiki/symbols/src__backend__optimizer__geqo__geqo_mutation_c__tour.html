目的

TSP遺伝的アルゴリズムにおける個体（ツアー）の遺伝子列に対して突然変異操作を適用し、探索空間の多様性を維持します。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナ情報へのポインタ。
  • Gene *tour: 変異対象となる遺伝子配列（ツアー）へのポインタ。
  • int num_gene: 遺伝子の総数。
  • 出力: なし（インプレースで tour の配列要素を変更します）。

前提条件と不変条件

  • #if defined(CX) が有効な環境（CXモード）においてのみコンパイルおよび利用されます。

アルゴリズムまたは振る舞い

1. 変異回数 num_swaps を geqo_randint(root, num_gene / 3, 0) により決定します。 2. num_swaps > 0 の間、以下の処理を繰り返します：

  • 範囲 [0, num_gene - 1] 内の異なる2つのインデックス swap1 と swap2 をランダムに選択します（swap1 == swap2 の場合は再選択します）。
  • tour[swap1] と tour[swap2] の値を一時変数 temp を介してスワップします。
  • num_swaps を 1 デクリメントします。

失敗モードと境界条件

  • swap1 と swap2 が同一のインデックスにならないよう、ループ内で再選択される保証があります。
