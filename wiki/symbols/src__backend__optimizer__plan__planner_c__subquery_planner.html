目的

サブクエリやクエリブロックに対する PlannerInfo データ構造の初期化、CTE処理、MERGE変換、範囲テーブル（RTE）の検証、サブリンクおよびサブクエリの引き上げ（プルアップ）、式および条件の前処理を実行する。

入力と出力

  • 引数:
  • PlannerGlobal *glob: 大域的なオプティマイザ状態
  • Query *parse: 処理対象のパースツリー（クエリ）
  • char *plan_name: プラン名
  • PlannerInfo *parent_root: 親クエリレベルの PlannerInfo（トップレベルの場合はNULL）
  • PlannerInfo *alternative_root: 代替ルート
  • bool hasRecursion: 再帰クエリを持つかどうかを示すフラグ
  • double tuple_fraction: タプル取得割合のヒューリスティック値
  • SetOperationStmt *setops: 集合演算ステートメント
  • 戻り値: 構築および前処理が適用された PlannerInfo *

前提条件と不変条件

  • parent_root が存在する場合、新規作成される root->query_level は parent_root->query_level + 1 となり、存在しない場合は 1 に設定される。
  • 再帰クエリ (hasRecursion が真) の場合、特殊な実行パラメータ ID が assign_special_exec_param により割り当てられる。

アルゴリズムまたは振る舞い

1. **PlannerInfo 構造体の初期化**: makeNode(PlannerInfo) を用いて新しい構造体を割り当て、パースツリー、クエリレベル、メモリコンテキスト、各種リスト（初期プラン、CTE、ジョイン領域など）を初期化する。 2. **CTE の処理**: parse->cteList が存在する場合、SS_process_ctes を呼び出して各共通表式（WITHリスト）を評価・変換する。 3. **MERGE 変換**: MERGE コマンドの場合、transform_MERGE_to_join を呼び出してジョインリストを適切に変換する。 4. **生成カラムの制約チェック**: parse->forPortionOf が指定されている場合、対象リレーションが仮想生成カラムを参照していないか検証し、違反している場合はエラーを送出する。 5. **RTE およびジョイントリーの前処理**:

  • preprocess_relation_rtes を呼び出して範囲テーブルの関係情報を取得・整理する。
  • 空のFROM句をダミーの RTE_RESULT RTE で置換する (replace_empty_jointree)。
  • サブリンクやサブクエリの引き上げ（pull_up_sublinks, pull_up_subqueries）、関数 RTE の前処理（preprocess_function_rtes）、および UNION ALL クエリの単純化（flatten_simple_union_all）を実行する。

    • 6. **範囲テーブルの走査と権限検査**:

  • レンジテーブルをスキャンし、JOIN や RESULT、LATERAL、セキュリティ修飾子などの特徴フラグやセキュリティレベルを設定する。
  • ビュー関係に対するパーミッション情報が存在する場合、アクセス権限をチェックし、拒否された場合は aclcheck_error を呼び出す。

    • 7. **式と条件の前処理**:

  • RowMark 情報を前処理し（preprocess_rowmarks）、ターゲットリスト、WITH CHECK OPTIONS、返り値リスト、JOIN/WHERE の条件（preprocess_qual_conditions）、および HAVING 句に対して preprocess_expression を適用する。

失敗モードと境界条件

  • FOR PORTION OF 句の対象リレーションが仮想生成カラム (get_attgenerated が真) を指している場合、機能未サポートのエラー (ERRCODE_FEATURE_NOT_SUPPORTED) が発生する。
  • クエリ内のビュー関係に対するパーミッションチェック（ExecCheckOneRelPerms）が失敗した場合、ACLCHECK_NO_PRIV エラーが発生する。
