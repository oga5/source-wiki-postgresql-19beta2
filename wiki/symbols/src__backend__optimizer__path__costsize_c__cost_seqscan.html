目的

ベースリレーションに対するシーケンシャルスキャン（Path）の起動コスト、総コスト、および行数を算出する。

シグネチャまたは形状

void cost_seqscan(Path *path, PlannerInfo *root, RelOptInfo *baserel, ParamPathInfo *param_info)

入力と出力

  • 引数:
  • Path *path: コストと行数を設定する対象のパス構造体
  • PlannerInfo *root: プランナーのグローバル情報
  • RelOptInfo *baserel: 対象のベースリレーション情報
  • ParamPathInfo *param_info: パラメータ化されたパスの情報（存在する場合は行数推定に使用）
  • 戻り値: なし（引数の path フィールドを直接更新する）

前提条件と不変条件

  • 対象リレーションはベースリレーション（baserel->relid > 0 かつ baserel->rtekind == RTE_RELATION）でなければならない。

アルゴリズムまたは振る舞い

1. **行数の決定**: 引数 param_info が存在する場合は param_info->ppi_rows を、そうでない場合は baserel->rows を path->rows に設定する。 2. **ディスクI/Oコストの計算**: テーブルスペースから取得したシーケンシャルページコスト（spc_seq_page_cost）にリレーションのページ数（baserel->pages）を乗算して disk_run_cost を算出する。 3. **CPUコストの計算**: 制限条件の評価コスト（qpqual_cost）を取得し、起動コストに qpqual_cost.startup を加算する。タプルごとのCPUコスト（cpu_tuple_cost + qpqual_cost.per_tuple）にリレーションのタプル数（baserel->tuples）を乗じて実行CPUコストを算出し、ターゲットリスト評価コスト（起動時およびタプルごと）を加算する。 4. **並列実行の調整**: path->parallel_workers > 0 の場合、並列除数（parallel_divisor）でCPU実行コストを割って按分し、ワーカーごとの処理行数を clamp_row_est(path->rows / parallel_divisor) で更新する。そうでない場合は非並列考慮マスクを有効にする。 5. **最終コストとステータスの設定**: マスク条件に基づき path->disabled_nodes を設定し、算出した startup_cost と total_cost（startup_cost + cpu_run_cost + disk_run_cost）を path に書き込む。

失敗モードと境界条件

  • baserel->relid <= 0 または baserel->rtekind != RTE_RELATION の場合、アサート違反により異常終了する。
