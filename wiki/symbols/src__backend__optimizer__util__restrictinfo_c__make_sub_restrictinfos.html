目的

OR 構造や AND 構造を持つ条件式（Expr）を再帰的に走査し、各サブ節やルートに対して適切な RestrictInfo ノードや論理構造（make_orclause や make_andclause）を付与した式ツリーを構築・返却する。

シグネチャまたは形状

  • シグネチャ: static Expr * make_sub_restrictinfos(PlannerInfo *root, Expr *clause, bool is_pushed_down, bool has_clone, bool is_clone, bool pseudoconstant, Index security_level, Relids required_relids, Relids incompatible_relids, Relids outer_relids)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Expr *clause: 処理対象の式または条件節
  • bool is_pushed_down: プッシュダウンされた条件かどうかのフラグ
  • bool has_clone: クローンが存在するかどうかのフラグ
  • bool is_clone: クローン自身かどうかのフラグ
  • bool pseudoconstant: 疑似定数かどうかのフラグ
  • Index security_level: セキュリティレベル
  • Relids required_relids: 要求される関係の識別子セット
  • Relids incompatible_relids: 互換性のない関係の識別子セット
  • Relids outer_relids: 外側の関係の識別子セット
  • 戻り値: Expr * （構築された RestrictInfo が埋め込まれた式または BoolExpr）

前提条件と不変条件

  • 引数 clause が OR 節 (is_orclause) である場合、再帰呼び出し時の required_relids には NULL が渡される。

アルゴリズムまたは振る舞い

1. **OR 節の処理**:

  • is_orclause(clause) が真の場合、clause の各引数（args）を foreach で走査する。
  • 各サブ引数に対して make_sub_restrictinfos を再帰呼び出しし（この際 required_relids には NULL を渡す）、結果のリストを orlist に蓄積する。
  • 蓄積した orlist から make_orclause(orlist) を作成し、それと元の clause を用いて make_plain_restrictinfo を呼び出し、結果をキャストして返却する。

    • 2. **AND 節の処理**:

  • is_andclause(clause) が真の場合、clause の各引数（args）を foreach で走査する。
  • 各サブ引数に対して make_sub_restrictinfos を再帰呼び出しし、結果のリストを andlist に蓄積する。
  • 蓄積した andlist から make_andclause(andlist) を作成して返却する。

    • 3. **その他の節の処理**:

  • 上記のいずれでもない場合、プレーンな式として make_plain_restrictinfo を呼び出し、結果をキャストして返却する。

失敗モードと境界条件

  • 渡された clause が OR 節、AND 節、あるいは通常の式のいずれであるかに応じて分岐するため、不正なノード構造が渡された場合の挙動は下位の is_orclause / is_andclause および make_plain_restrictinfo の実装に依存する。

保守担当者向けメモ

  • 本関数は make_restrictinfo から内部的に呼び出される再帰ヘルパーであり、OR や AND の入れ子構造を分解・再構築しながら各要素に RestrictInfo を付与する役割を持つ。
