~~~c RestrictInfo * commute_restrictinfo(RestrictInfo *rinfo, Oid comm_op) { RestrictInfo *result; OpExpr *newclause; OpExpr *clause = castNode(OpExpr, rinfo->clause);

Assert(list_length(clause->args) == 2);

/* flat-copy all the fields of clause ... */ newclause = makeNode(OpExpr); memcpy(newclause, clause, sizeof(OpExpr));

/* ... and adjust those we need to change to commute it */ newclause->opno = comm_op; newclause->opfuncid = InvalidOid; newclause->args = list_make2(lsecond(clause->args), linitial(clause->args));

/* likewise, flat-copy all the fields of rinfo ... */ result = makeNode(RestrictInfo); memcpy(result, rinfo, sizeof(RestrictInfo));

/*

  • ... and adjust those we need to change. Note in particular that we can
  • preserve any cached selectivity or cost estimates, since those ought to
  • be the same for the new clause. Likewise we can keep the source's
  • parent_ec. It's also important that we keep the same rinfo_serial.

    • */ result->clause = (Expr *) newclause; result->left_relids = rinfo->right_relids; result->right_relids = rinfo->left_relids; Assert(result->orclause == NULL); result->left_ec = rinfo->right_ec; result->right_ec = rinfo->left_ec; result->left_em = rinfo->right_em; result->right_em = rinfo->left_em; result->scansel_cache = NIL; /* not worth updating this */ if (rinfo->hashjoinoperator == clause->opno) result->hashjoinoperator = comm_op; else result->hashjoinoperator = InvalidOid; result->left_bucketsize = rinfo->right_bucketsize; result->right_bucketsize = rinfo->left_bucketsize; result->left_mcvfreq = rinfo->right_mcvfreq; result->right_mcvfreq = rinfo->left_mcvfreq; result->left_hasheqoperator = InvalidOid; result->right_hasheqoperator = InvalidOid;

return result; } ~~~

目的

commute_restrictinfo は、指定された可換演算子（comm_op）に基づき、元の RestrictInfo および内包する OpExpr の左右のオペランド、関連関係、および等価クラスを入れ替えた新しい RestrictInfo ノードを複製・生成する関数です。

入力と出力

  • 入力:
  • RestrictInfo *rinfo: 変換対象となる元の RestrictInfo 構造体へのポインタ
  • Oid comm_op: 新しい可換演算子の OID
  • 出力:
  • RestrictInfo *: 演算子が可換され、関係やオペランドが反転された新規割り当ての RestrictInfo 構造体へのポインタ

前提条件と不変条件

  • 対象となる RestrictInfo が保持する式（clause）は、2つの引数を持つ OpExpr ノードでなければならない。
  • 変換対象の RestrictInfo は orclause を保持していない（NULL である）こと。

アルゴリズムまたは振る舞い

1. OpExprの取得と検証: 引数 rinfo->clause を OpExpr にキャストし、その引数の数が正確に 2 つであることをアサートで検証する。 2. OpExprの複製と調整: 新しい OpExpr ノードを割り当てて元の内容をフラットコピーした後、演算子 ID (opno) を comm_op に更新し、演算関数 ID (opfuncid) を InvalidOid にクリアする。さらに、args リストの左右の引数を入れ替える。 3. RestrictInfoの複製と調整: 新しい RestrictInfo ノードを割り当てて元の内容をフラットコピーし、新しい OpExpr を設定する。 4. 関係・等価クラス・バケット情報の反転:

  • 左右のリレーション ID（left_relids と right_relids）を入れ替える。
  • 左右の等価クラス（left_ec と right_ec）および等価メンバ（left_em と right_em）を入れ替える。
  • キャッシュされた選択率（scansel_cache）を NIL にリセットする。
  • ハッシュ結合演算子（hashjoinoperator）が元の演算子と一致する場合は comm_op に更新し、それ以外の場合は InvalidOid に設定する。
  • バケットサイズ（left_bucketsize と right_bucketsize）および MCV 頻度（left_mcvfreq と right_mcvfreq）を入れ替える。
  • ハッシュ等価演算子（left_hasheqoperator と right_hasheqoperator）を InvalidOid にクリアする。

    • 5. 返却: 構築された新しい RestrictInfo ポインタを返す。

関連データ構造

  • RestrictInfo
  • OpExpr
  • Expr
  • Oid

失敗モードと境界条件

  • clause->args の要素数が 2 でない場合、Assert により実行時エラー（アサート違反）が発生する。
  • 変換対象の rinfo->orclause が NULL でない場合、Assert によりアサート違反が発生する。
