ソース抜粋

~~~c typedef struct { RelOptInfo *joinrel; /* joinrel for the set of relations */ int size; /* number of input relations in clump */ } Clump; ~~~

目的

Clump は、遺伝的クエリ最適化（GEQO）において結合木の構築過程で関係のセット（塊）とそのサイズを保持する内部構造体です。

フィールドと表現

  • joinrel: RelOptInfo * 型。関係のセットに対するジョインリレーションを保持します。
  • size: int 型。クランプに含まれる入力関係の数を保持します。
