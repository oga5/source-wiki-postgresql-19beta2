目的

EXISTS サブリンク (SubLink) をセミ結合 (JOIN_SEMI) またはアンチ結合 (JOIN_ANTI) の JoinExpr ノードへ変換（フラット化）する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報構造体
  • SubLink *sublink: 変換対象の EXISTS サブリンク
  • bool under_not: NOT 演算子の配下にあるかどうか（true の場合は JOIN_ANTI、false の場合は JOIN_SEMI を生成）
  • Relids available_rels: 参照が許可されている上位クエリの有効なリレーション集合
  • 戻り値:
  • JoinExpr *: 結合表現ノード。条件を満たさない場合は NULL を返す

前提条件と不変条件

  • 引数として渡される sublink の種別は EXISTS_SUBLINK でなければならない。
  • サブクエリが WITH 句（cteList）を含んでいる場合はフラット化できないため NULL が返される。
  • サブクエリのターゲットリストを除去できない場合、評価場所が失われるため処理に失敗する。
  • サブクエリの WHERE 句以外の部分（結合構造や残りの本体）は、上位クエリの変数（レベル 1 の Var）を一切参照してはならない。
  • 逆に、分離された WHERE 句は何らかの上位クエリの変数を含んでいる必要がある（結合条件となるため）。
  • WHERE 句に含まれる関数は非揮発性（volatile でないこと）でなければならない。
  • 結合条件で使用される上位クエリの変数に対応するリレーションは、available_rels のサブセットに含まれなければならない。

アルゴリズムまたは振る舞い

1. 前提検証とコピー: sublink->subLinkType == EXISTS_SUBLINK であることをアサートで確認し、サブクエリに WITH 句がある場合は NULL を返す。安全に修正するためサブクエリを copyObject で複製する。 2. クエリ単純化: simplify_EXISTS_query を呼び出し、EXISTS クエリとして不要なターゲットリストの削除など簡易化を試みる。失敗した場合は NULL を返す。 3. WHERE 句の分離: サブクエリの jointree->quals（WHERE 句）を一時的に切り離し、サブクエリ本体に親クエリのレベル 1 変数が残っていないこと、および切り離した WHERE 句には親クエリの変数が含まれておりかつ揮発的関数が含まれていないことを検証する。 4. リレーション RTE 前処理: ダミーの PlannerInfo (subroot) を構築し、仮想生成列の展開や不要な継承フラグのクリアなどを行う preprocess_relation_rtes を適用する。その後、再び WHERE 句を一時的に切り離す。 5. ジョイントリー調整: 空のジョイントリーを置換 (replace_empty_jointree) し、親クエリの範囲テーブル (rtable) の長さに基づいてサブクエリ内のすべてのレベル 0 変数ノードをオフセット（OffsetVarNodes）する。 6. 変数レベルのインクリメント: サブクエリおよび WHERE 句内の上位レベル変数のレベルを 1 つ上げる（レベル 1 をレベル 0 にする等）。 7. 参照範囲の検証: WHERE 句が参照するリレーション番号（varnos）を抽出し、それらが許容された available_rels の範囲内にあるかを検証する。 8. 範囲テーブルの結合と JoinExpr 生成: サブクエリの rtable および rteperminfos を親クエリに結合し (CombineRangeTables)、under_not の値に応じて JOIN_ANTI または JOIN_SEMI を設定した JoinExpr ノードを生成して返す。

失敗モードと境界条件

  • サブクエリが cteList（WITH 句）を持つ場合は変換不可として NULL を返す。
  • simplify_EXISTS_query による単純化に失敗した場合は NULL を返す。
  • サブクエリ本体が親クエリの変数（レベル 1）を参照している場合は結合変換を行えず NULL を返す。
  • 分離した WHERE 句が親クエリの変数を全く含まない場合（相関がない場合）は結合にならないため NULL を返す。
  • WHERE 句に揮発性（volatile）関数が含まれている場合、最適化リスクを避けるため NULL を返す。
  • WHERE 句が参照する上位クエリのリレーションが available_rels に含まれない場合は NULL を返す。
