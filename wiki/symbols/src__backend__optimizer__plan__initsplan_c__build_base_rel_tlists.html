目的

最終ターゲットリスト（final_tlist）および HAVING 句で使用される変数やプレースホルダーを抽出し、それらをベース関係のターゲットリストに追加する。

シグネチャまたは形状

  • シグネチャ: void build_base_rel_tlists(PlannerInfo *root, List *final_tlist)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を保持する構造体へのポインタ
  • List *final_tlist: クエリの最終ターゲットリスト
  • 戻り値: なし（void）

前提条件と不変条件

  • HAVING 句には集約関数（Aggrefs）を含めることができるが、ウィンドウ関数を含めることはできない。

アルゴリズムまたは振る舞い

1. final_tlist から pull_var_clause を用いて、集約、ウィンドウ関数、およびプレースホルダーを含む変数を再帰的に抽出する。 2. 抽出された変数リスト（tlist_vars）が空でない場合、add_vars_to_targetlist を呼び出してベース関係のターゲットリストに追加し、その後 list_free でメモリを解放する。 3. root->parse->havingQual（HAVING 句）が存在する場合、同様に pull_var_clause を用いて集約およびプレースホルダーを含む変数を抽出する。 4. HAVING 句の変数リスト（having_vars）が空でない場合、add_vars_to_targetlist を呼び出してベース関係のターゲットリストに追加し、その後 list_free でメモリを解放する。

失敗モードと境界条件

  • final_tlist や havingQual から抽出された変数リストが NIL である場合、追加処理はスキップされる。
