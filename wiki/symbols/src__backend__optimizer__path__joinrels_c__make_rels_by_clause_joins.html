目的

指定された既存のリレーション（old_rel）と、他のリレーションのリスト（other_rels）の各要素との間で結合句または結合順序の制約が成立する場合に、それらの間に新しい結合関係を生成します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報へのポインタ。
  • RelOptInfo *old_rel: 結合元となる既存のリレーション。
  • List *other_rels: 比較対象となる他のリレーションのリスト。
  • int first_rel_idx: other_rels の中で処理を開始するインデックス位置。
  • 戻り値: void。

前提条件と不変条件

  • 結合対象の 2 つのリレーション間でリレーション ID 集合（relids）が重複していない（交差しない）必要があります。

アルゴリズムまたは振る舞い

  • other_rels リストに対して first_rel_idx で指定された開始位置から順に走査を行います。
  • リストの各要素である other_rel と old_rel の間で以下の条件を評価します。
  • old_rel->relids と other_rel->relids がオーバーラップしないこと。
  • 両者の間に適切な結合句が存在するか（have_relevant_joinclause）、あるいは結合順序の制約が存在するか（have_join_order_restriction）のいずれかを満たすこと。
  • 条件をすべて満たした場合、make_join_rel を呼び出して old_rel と other_rel の結合関係を構築します。

失敗モードと境界条件

  • 結合条件を満たさない場合や relids が重複している場合は、make_join_rel は呼び出されずスキップされます。
