~~~c PathKeysComparison compare_pathkeys(List *keys1, List *keys2) { ListCell *key1, *key2;

/*

  • Fall out quickly if we are passed two identical lists. This mostly
  • catches the case where both are NIL, but that's common enough to
  • warrant the test.

    • */ if (keys1 == keys2) return PATHKEYS_EQUAL;

forboth(key1, keys1, key2, keys2) { PathKey *pathkey1 = (PathKey *) lfirst(key1); PathKey *pathkey2 = (PathKey *) lfirst(key2);

if (pathkey1 != pathkey2) return PATHKEYS_DIFFERENT; /* no need to keep looking */ }

/*

  • If we reached the end of only one list, the other is longer and
  • therefore not a subset.

    • */ if (key1 != NULL) return PATHKEYS_BETTER1; /* key1 is longer */ if (key2 != NULL) return PATHKEYS_BETTER2; /* key2 is longer */ return PATHKEYS_EQUAL; } ~~~

目的

2つのパスキーリスト（keys1 および keys2）を受け取り、それらの順序と等価性を比較して関係性を判定する。

入力と出力

  • 入力:
  • List *keys1: 比較元のパスキーリスト
  • List *keys2: 比較先のパスキーリスト
  • 出力:
  • PathKeysComparison: 2つのリストの関係性を表す比較結果（一致、異なる、一方が長いなど）

前提条件と不変条件

  • 入力されるパスキーリスト内の各要素は PathKey 型のポインタである。
  • パスキーは正規化されているため、要素同士の同一性はポインタ比較 (pathkey1 == pathkey2) によって正確に判定できる。

アルゴリズムまたは振る舞い

1. **同一リストの早期リターン**:

  • keys1 と keys2 のリストポインタ自体が等しい場合（主に両方とも NIL の場合を含む）、即座に PATHKEYS_EQUAL を返す。

    • 2. **要素ごとの順次比較**:

  • forboth マクロを使用して、keys1 と keys2 の要素を先頭から順にペアで走査する。
  • 各セルから取り出した pathkey1 と pathkey2 のポインタを比較し、一致しない場合はそれ以上走査を続けずに即座に PATHKEYS_DIFFERENT を返す。

    • 3. **リスト長の比較（終端チェック）**:

  • 共通のプレフィックス部分の比較が一致してループを抜けた後、一方のリストの終端に達したかどうかを判定する。
  • keys1 の走査ポインタ (key1) が終端に達していない場合（keys1 の方が長い場合）は PATHKEYS_BETTER1 を返す。
  • keys2 の走査ポインタ (key2) が終端に達していない場合（keys2 の方が長い場合）は PATHKEYS_BETTER2 を返す。
  • 両方のリストが同時に終端に達した場合は PATHKEYS_EQUAL を返す。

失敗モードと境界条件

  • どちらか一方あるいは両方のリストが空（NIL）の場合、ポインタが同一であれば PATHKEYS_EQUAL となり、片方のみ空の場合は長さの差に応じた PATHKEYS_BETTER1 または PATHKEYS_BETTER2 が返される。
