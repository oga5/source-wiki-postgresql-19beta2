目的

gimme_tree 内ですでに結合された関係のセット（クランプ）を表現するための、Clump 構造体の一部として利用されます。

アルゴリズムまたは振る舞い

Clump 構造体のフィールドとして保持され、一連の関係集合に対する結合リレーション（joinrel）を指し示します。

関連データ構造

  • Clump: すでに結合された関係の塊を保持し、RelOptInfo *joinrel と int size を内包します。
