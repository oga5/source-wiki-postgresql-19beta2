目的

ジョイン関係に対して部分集約（Eager Aggregation）の適用が可能かを評価し、グループ化されたジョイン関係（grouped join relation）の構築やパスの追加を管理する。

シグネチャまたは形状

  • シグネチャ: static void make_grouped_join_rel(PlannerInfo *root, RelOptInfo *rel1, RelOptInfo *rel2, RelOptInfo *joinrel, SpecialJoinInfo *sjinfo, List *restrictlist)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体のグローバル情報
  • RelOptInfo *rel1: 結合の左側入力リレーション
  • RelOptInfo *rel2: 結合の右側入力リレーション
  • RelOptInfo *joinrel: 対象となる結合リレーション
  • SpecialJoinInfo *sjinfo: 特殊結合（外結合など）の情報
  • List *restrictlist: 結合制限リスト
  • 戻り値: なし (void)

前提条件と不変条件

  • クエリに集約式（agg_clause_list）またはグループ化式（group_expr_list）のいずれかが欠けている場合、本関数は早期にリターンする。
  • 構築された grouped_rel は、常に IS_GROUPED_REL(grouped_rel) を満たす必要がある。
  • 2つの入力リレーション双方が grouped rel である場合（すなわち双方が空ではない、あるいは双方空である場合）、本関数ではグループ化されたリレーション同士の結合はサポートされないため早期リターンする。

アルゴリズムまたは振る舞い

1. **早期リターンチェック**: root->agg_clause_list または root->group_expr_list が NIL の場合は処理を終了する。 2. **入力リレーションのグループ状態判定**: rel1 と rel2 のそれぞれの grouped_rel を取得し、それぞれが空（NULL またはダミーリレーション）であるかを rel1_empty と rel2_empty として評価する。 3. **グループ化結合リレーションの取得または新規構築**:

  • joinrel->grouped_rel が存在しない場合、create_rel_agg_info を呼んで集約情報を準備する。
  • agg_info が取得できない場合や、集約が有用ではなくかつ両入力リレーションの空/非空の状態が一致する場合は構築をスキップしてリターンする。
  • build_grouped_rel で新規 grouped_rel を構築し、ターゲットを設定する。
  • rel1_empty と rel2_empty が異なる場合、片方の grouped 入力リレーションと他方の生リレーションを結合する前提でサイズ見積もり（set_joinrel_size_estimates）を行い、apply_agg_at を更新する。
  • 異なる状態ではない場合、既存の非グループ化ジョインパスの上に部分集約を適用するものとして行数を見積もり、apply_agg_at に joinrel->relids のコピーを設定する。

    • 4. **ダミーおよび単一入力の検証**:

  • grouped_rel がダミーリレーションと判定されている場合はリターンする。
  • rel1_empty == rel2_empty の場合は処理を終了する。

    • 5. **部分集約適用位置（apply_agg_at）のチェック**:

  • 入力側の apply_agg_at を取得し、既存の grouped_rel->agg_info->apply_agg_at と比較する。
  • 一致しないがサブセットである場合は、サイズ見積もりを再計算して apply_agg_at を更新する。
  • サブセットでもない場合はリターンする。

    • 6. **パスの移譲**: 最終的に populate_joinrel_with_paths を呼び出し、グループ化されたジョイン関係に対して物理パスを生成・追加する。

失敗モードと境界条件

  • root->agg_clause_list または root->group_expr_list が空の場合、何もせず即座に制御を戻す。
  • create_rel_agg_info が NULL を返した場合や、集約が有用でなく入力リレーションの空状態が同等の場合は処理を中断する。
  • 算出した apply_agg_at が既存の grouped_rel->agg_info->apply_agg_at のサブセットでない場合、グループ化パスの構築をスキップして終了する。
