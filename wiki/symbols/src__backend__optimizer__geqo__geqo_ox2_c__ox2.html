目的

Syswerda の順序交叉（OX2）アルゴリズムに基づき、2つの親ツアー（tour1, tour2）から遺伝子を結合して新しい子ツアー（offspring）を生成します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Gene *tour1: 第1親ツアーの遺伝子配列
  • Gene *tour2: 第2親ツアーの遺伝子配列
  • Gene *offspring: 生成される子ツアーを格納する出力バッファ
  • int num_gene: 遺伝子（都市）の総数
  • City *city_table: 都市の状態管理および選択リスト保持用の作業用配列
  • 戻り値: なし（void）

前提条件と不変条件

  • city_table は、少なくとも num_gene + 1 の要素を持つ十分なサイズが確保されている必要があります。

アルゴリズムまたは振る舞い

1. 都市テーブルの初期化

  • 1 から num_gene までの範囲で city_table[k].used を 0 にクリアし、city_table[k - 1].select_list を -1 に初期化します。

2. 第1親からの遺伝子位置選択

  • geqo_randint(root, 2 * num_gene / 3, num_gene / 3) を呼び出して、tour1 から継承する位置の数 num_positions を決定します。
  • num_positions 回ループし、geqo_randint(root, num_gene - 1, 0) でランダムな位置 pos を選択し、tour1[pos] の値を city_table[pos].select_list に設定するとともに、対応する city_table[(int) tour1[pos]].used を 1 にマークします。

3. 選択リストの隣接位置への統合

  • count と k を 0 に初期化し、count < num_positions の間ループします。
  • city_table[k].select_list が -1 の場合、後ろの有効なエントリを探して値詰めを行い、リストを連続した位置に統合します。

4. 子個体の生成

  • select = 0 から始め、tour2 を先頭から走査します。
  • city_table[(int) tour2[k]].used が真である場合は、city_table[select].select_list の値を offspring[k] に割り当てて select をインクリメントします。
  • そうでない場合は、tour2[k] の値をそのまま offspring[k] に継承させます。

  • PlannerInfo: プランナーのコンテキスト情報

  • 引数で渡される tour1, tour2, offspring, city_table の配列境界およびインデックス範囲が不正である場合、未定義動作やメモリ不正アクセスを引き起こす可能性があります。
