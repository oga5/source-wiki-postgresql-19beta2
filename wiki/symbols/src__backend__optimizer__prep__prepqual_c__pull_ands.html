~~~c static List * pull_ands(List *andlist) { List *out_list = NIL; ListCell *arg;

foreach(arg, andlist) { Node *subexpr = (Node *) lfirst(arg);

if (is_andclause(subexpr)) out_list = list_concat(out_list, pull_ands(((BoolExpr *) subexpr)->args)); else out_list = lappend(out_list, subexpr); } return out_list; } ~~~

目的

ネストした AND リストを再帰的にフラット化し、一貫したフラットな AND 構造を維持する。

入力と出力

  • 入力: List *andlist （AND 構成要素のリスト）
  • 戻り値: List * （フラット化された AND 要素のリスト）

前提条件と不変条件

  • 入力されたリスト内の各要素を走査し、AND 節である場合はその内部引数リストに対して再帰的に pull_ands を適用する。

アルゴリズムまたは振る舞い

  • 初期状態で空の out_list = NIL を作成する。
  • foreach マクロを用いて andlist の各要素 (arg) を順に走査する。
  • 各要素を Node *subexpr として取り出し、is_andclause(subexpr) を用いてサブ式が AND 節であるか判定する。
  • AND 節である場合、該当サブ式の引数リスト（((BoolExpr *) subexpr)->args）に対して pull_ands を再帰呼び出しし、その結果を list_concat で out_list に連結する。
  • AND 節ではない場合、lappend を用いてサブ式をそのまま out_list の末尾に追加する。
  • 走査完了後、構築された out_list を返す。

失敗モードと境界条件

  • 特殊なエラーパスは持たない。入力リストが空の場合は空のリストをそのまま返す。
