目的

与えられた修飾句のリストを、セキュリティレベルおよび評価コストの昇順に並べ替えて返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ情報へのポインタ
  • List *clauses: 並べ替える対象の修飾句ノードのリスト
  • 戻り値:
  • List *: コストとセキュリティレベルに基づいて整列された修飾句のリスト

前提条件と不変条件

  • 0個または1個の修飾句が渡された場合、入力リストがそのまま返される。
  • 順序付けの安定性を維持するため、クイックソートではなく挿入ソートが使用される。

アルゴリズムまたは振る舞い

1. 早期リターン評価: リスト内の項目数が 1 以下であるかをチェックし、該当する場合はそのまま clauses を返す。 2. 項目とコストの収集: 項目数分の QualItem 配列を割り当て、各修飾句に対して cost_qual_eval_node を呼び出してタプルあたりのコストを取得する。 3. セキュリティレベルの決定: 各句が RestrictInfo である場合、leakproof かつコストが 10 * cpu_operator_cost 未満であればセキュリティレベルを 0 とみなし、それ以外の場合はノミナルなセキュリティレベルを設定する。非 RestrictInfo の場合はセキュリティレベルを 0 とする。 4. 安定ソートの実行: 挿入ソートを用いて、security_level の昇順、および同一セキュリティレベルの場合は cost の昇順に並べ替える。 5. リストへの変換と返却: 整列された配列から lappend を用いて再びリストを構築し、結果を返す。
