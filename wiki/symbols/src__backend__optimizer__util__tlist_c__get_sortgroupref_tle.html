~~~c TargetEntry * get_sortgroupref_tle(Index sortref, List *targetList) { ListCell *l;

foreach(l, targetList) { TargetEntry *tle = (TargetEntry *) lfirst(l);

if (tle->ressortgroupref == sortref) return tle; }

elog(ERROR, "ORDER/GROUP BY expression not found in targetlist"); return NULL; /* keep compiler quiet */ } ~~~

目的

指定されたソート・グループ化参照番号（sortref）に一致する TargetEntry をターゲットリスト（targetList）から検索して返します。

入力と出力

  • 入力:
  • Index sortref: 検索対象のソート・グループ化参照識別子
  • List *targetList: 検索対象となる TargetEntry のリスト
  • 戻り値:
  • TargetEntry *: 一致する TargetEntry へのポインタ。見つからない場合はエラーとなります。

前提条件と不変条件

  • targetList 内の各要素は TargetEntry * 型である必要があります。

アルゴリズムまたは振る舞い

  • targetList を先頭から順に走査し、各 TargetEntry の ressortgroupref フィールドと引数の sortref を比較します。
  • 一致する ressortgroupref を持つエントリが見つかった場合、その TargetEntry を直ちに返します。

失敗モードと境界条件

  • 一致する sortref を持つ TargetEntry がリスト内に存在しない場合、elog(ERROR, ...) を呼び出してエラーを送出します。
