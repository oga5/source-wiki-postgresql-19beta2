目的

システムキャッシュの無効化通知を受け取り、演算子証明キャッシュ（OprProofCacheHash）内の全エントリが持つ含意および反駁の証明状態をリセットする。

  • uint32 hashvalue: 無効化対象のハッシュ値（個別指定がない場合は 0）
  • 戻り値:
  • なし（void）

前提条件と不変条件

  • コールバックが実行される時点で、グローバルな演算子証明キャッシュ OprProofCacheHash が初期化されており NULL でないこと。

アルゴリズムまたは振る舞い

1. OprProofCacheHash が非 NULL であることをアサートで検証する。 2. ハッシュ表をスキャンするため、hash_seq_init を用いて HASH_SEQ_STATUS 構造体を初期化する。 3. hash_seq_search をループで呼び出し、キャッシュ内の全エントリ（OprProofCacheEntry *）を順に取得する。 4. 取得した各エントリの have_implic および have_refute フラグを false に設定し、証明状態をクリアする。

失敗モードと境界条件

  • OprProofCacheHash が NULL の状態でコールバックが呼び出された場合、Assert により異常終了する。
