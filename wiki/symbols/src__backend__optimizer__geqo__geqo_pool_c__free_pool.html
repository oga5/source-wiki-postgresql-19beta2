目的

遺伝的アルゴリズム（GEQO）の個体群プール (Pool) が保持するすべての遺伝子文字列、染色体配列、およびプール構造体自身のメモリを解放する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報（未使用）
  • Pool *pool: 解放対象のプール構造体ポインタ
  • 戻り値: なし（void）

前提条件と不変条件

  • 引数 pool および pool->data が有効なメモリ領域を指していること。

アルゴリズムまたは振る舞い

1. pool->data を染色体の配列（Chromosome *）としてキャストする。 2. ループを用いて、プール内の各染色体が保持する遺伝子文字列（chromo[i].string）を順次 pfree で解放する。 3. すべての染色体データを格納していた配列領域（pool->data）を pfree で解放する。 4. 最後に Pool 構造体自身を pfree で解放する。

失敗モードと境界条件

  • 解放順序を誤ると、配下のメモリ（遺伝子文字列や染色体配列）にアクセスできなくなるため、内側から外側へ順に解放する。
