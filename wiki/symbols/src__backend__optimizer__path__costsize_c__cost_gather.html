ソース抜粋

~~~c void cost_gather(GatherPath *path, PlannerInfo *root, RelOptInfo *rel, ParamPathInfo *param_info, double *rows) { Cost startup_cost = 0; Cost run_cost = 0;

/* Mark the path with the correct row estimate */ if (rows) path->path.rows = *rows; else if (param_info) path->path.rows = param_info->ppi_rows; else path->path.rows = rel->rows;

startup_cost = path->subpath->startup_cost;

run_cost = path->subpath->total_cost - path->subpath->startup_cost;

/* Parallel setup and communication cost. */ startup_cost += parallel_setup_cost; run_cost += parallel_tuple_cost * path->path.rows;

path->path.disabled_nodes = path->subpath->disabled_nodes + ((rel->pgs_mask & PGS_GATHER) != 0 ? 0 : 1); path->path.startup_cost = startup_cost; path->path.total_cost = (startup_cost + run_cost); } ~~~

目的

GatherPath のコスト（起動コスト、総コスト）および出力行数、無効化ノード数を算出・設定します。

入力と出力

  • 引数:
  • GatherPath *path: コストと行数を設定する対象のパス
  • PlannerInfo *root: プランナーのグローバル情報（本関数内では直接参照されず）
  • RelOptInfo *rel: 対象リレーションの情報
  • ParamPathInfo *param_info: パラメータ化パスの情報（オプショナル）
  • double *rows: 明示的に指定する出力行数のポインタ（オプショナル）
  • 戻り値: なし（void）

前提条件と不変条件

  • path->subpath が有効なサブパスとして設定されていることが前提となります。

アルゴリズムまたは振る舞い

  • 出力行数（path->path.rows）を決定します。rows 引数が指定されていればその値を優先し、未指定かつ param_info が存在する場合は param_info->ppi_rows を使用し、どちらもなければ rel->rows を適用します。
  • サブパスの起動コスト（startup_cost）をそのままベースの起動コストとし、サブパスの総コストから起動コストを引いた差分を実行コスト（run_cost）とします。
  • パラレルセットアップのオーバーヘッドコスト（parallel_setup_cost）を起動コストに加算し、タプル転送コスト（parallel_tuple_cost * path->path.rows）を実行コストに加算します。
  • サブパスの disabled_nodes の値に、リレーションの pgs_mask に PGS_GATHER フラグが含まれているかに応じたペナルティ（含まれていなければ 1、含まれていれば 0）を加算して path->path.disabled_nodes に設定します。
  • 最終的な起動コストおよび（起動コストと実行コストを合算した）総コストを path->path.startup_cost と path->path.total_cost に書き込みます。

失敗モードと境界条件

  • エラー送出や例外処理パスは含まれません。
