ソース抜粋

~~~c void geqo_selection(PlannerInfo *root, Chromosome *momma, Chromosome *daddy, Pool *pool, double bias) { int first, second;

first = linear_rand(root, pool->size, bias); second = linear_rand(root, pool->size, bias);

/*

  • Ensure we have selected different genes, except if pool size is only
  • one, when we can't.

    • */ if (pool->size > 1) { while (first == second) second = linear_rand(root, pool->size, bias); }

geqo_copy(root, momma, &pool->data[first], pool->string_length); geqo_copy(root, daddy, &pool->data[second], pool->string_length); } ~~~

目的

GEQOモジュールにおいて遺伝子プールから2つの異なる親個体（momma と daddy）を選択し、指定された出力用構造体にデータをコピーします。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナーのグローバル情報。
  • Pool *pool: 選択元の遺伝子プール。
  • double bias: 線形選択スキームで使用されるバイアス値。
  • 出力・副作用:
  • Chromosome *momma: 1つ目に選択された親個体のデータがコピーされる出力先。
  • Chromosome *daddy: 2つ目に選択された親個体のデータがコピーされる出力先。

前提条件と不変条件

  • プールサイズが 1 より大きい場合、父親と母親に同じ個体が選ばれないように異なる遺伝子が選択される不変条件を満たします。

アルゴリズムまたは振る舞い

1. linear_rand 関数を呼び出して、プールサイズとバイアスに基づいて1つ目のインデックス first を取得します。 2. 同様に linear_rand を呼び出して2つ目のインデックス second を取得します。 3. プールサイズが 1 より大きい場合、first と second が等しい間 linear_rand を繰り返し呼び出して異なるインデックスを確保します。 4. 決定されたインデックス位置のプールデータから、geqo_copy を用いて momma および daddy へ染色体データをコピーします。

失敗モードと境界条件

  • プールサイズが 1 の場合は同じ遺伝子が選択されることを防げないため、重複チェックの分岐はスキップされます。
