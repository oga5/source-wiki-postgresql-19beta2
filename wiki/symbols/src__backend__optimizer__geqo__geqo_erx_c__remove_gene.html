/*

  • do for every gene known to have an edge to input gene (i.e. in
  • edge_list for input edge)

    • */

for (i = 0; i < edge.unused_edges; i++) { possess_edge = abs(edge.edge_list[i]); genes_remaining = edge_table[possess_edge].unused_edges;

/* find the input gene in all edge_lists and delete it */ for (j = 0; j < genes_remaining; j++) {

目的

指定された遺伝子へのエッジを持つすべての遺伝子のエッジリストから、該当する遺伝子を探索して削除し、エッジテーブルの状態を更新します。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナのグローバル情報
  • Gene gene: 削除対象の遺伝子
  • Edge edge: 入力遺伝子に対応するエッジ情報（接続先のエッジリストと未使用エッジ数を含む）
  • Edge *edge_table: 全遺伝子のエッジテーブルへのポインタ
  • 戻り値: なし（void）

前提条件と不変条件

  • edge.unused_edges は入力遺伝子に接続していると判明している遺伝子の数を表す。
  • 各接続先エッジリストの要素を探索する際は、符号付きの値から絶対値をとることで遺伝子番号（Gene）を特定する。

アルゴリズムまたは振る舞い

  • 入力エッジの edge_list に含まれるすべての接続先遺伝子（possess_edge）を順に走査する。
  • 各 possess_edge のエッジリスト（edge_table[possess_edge].edge_list）を走査し、対象の gene と一致するエッジを探索する。
  • 一致するエッジが見つかった場合、以下の処理を行ってループを抜ける:
  • edge_table[possess_edge].unused_edges をデクリメントする。
  • リスト内の順序を維持するため、削除位置の要素に末尾の要素（genes_remaining - 1）を上書きして詰める。

失敗モードと境界条件

  • 一致する遺伝子がエッジリスト内に存在しない場合は何も削除を行わず、リストの走査を終了する。
