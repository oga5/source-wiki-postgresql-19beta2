ソース抜粋

~~~c RestrictInfo * make_restrictinfo(PlannerInfo *root, Expr *clause, bool is_pushed_down, bool has_clone, bool is_clone, bool pseudoconstant, Index security_level, Relids required_relids, Relids incompatible_relids, Relids outer_relids) { /*

  • If it's an OR clause, build a modified copy with RestrictInfos inserted
  • above each subclause of the top-level AND/OR structure.

    • */ if (is_orclause(clause)) return (RestrictInfo *) make_sub_restrictinfos(root, clause, is_pushed_down, has_clone, is_clone, pseudoconstant, security_level, required_relids, incompatible_relids, outer_relids);

/* Shouldn't be an AND clause, else AND/OR flattening messed up */ Assert(!is_andclause(clause));

return make_plain_restrictinfo(root, clause, NULL, is_pushed_down, has_clone, is_clone, pseudoconstant, security_level, required_relids, incompatible_relids, outer_relids); } ~~~

目的

与えられた式（Expr）をラップしてオプティマイザが必要とするメタデータを付与した RestrictInfo ノードを構築し返す。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報コンテキスト
  • Expr *clause: ラップ対象の条件式
  • bool is_pushed_down: プッシュダウンされた条件かどうか
  • bool has_clone: クローンが存在するかどうか
  • bool is_clone: クローン自身かどうか
  • bool pseudoconstant: 疑似定数かどうか
  • Index security_level: セキュリティレベル
  • Relids required_relids: 必須のリレーション集合
  • Relids incompatible_relids: 非互換のリレーション集合
  • Relids outer_relids: 外側のリレーション集合
  • 戻り値: RestrictInfo *（構築された RestrictInfo ノード、または OR 節の場合は変換されたサブノード群）

前提条件と不変条件

  • 入力された clause が AND 節である場合、AND/OR の平坦化処理が失敗しているとみなされ、アサート違反になる。

アルゴリズムまたは振る舞い

  • 引数の clause が OR 節であるかを判定する。
  • OR 節である場合は、make_sub_restrictinfos を呼び出して、トップレベルの AND/OR 構造の各サブ節の上に RestrictInfo が挿入された変更済みのコピーを構築して返す。
  • OR 節ではない場合は、AND 節ではないことを Assert(!is_andclause(clause)) で検証した上で、make_plain_restrictinfo を呼び出して通常の RestrictInfo を生成して返す。

失敗モードと境界条件

  • clause が AND 節であった場合、アサート（Assert(!is_andclause(clause))）により異常終了する。
