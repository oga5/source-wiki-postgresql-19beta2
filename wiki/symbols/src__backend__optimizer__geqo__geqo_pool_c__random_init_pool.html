~~~c void random_init_pool(PlannerInfo *root, Pool *pool) { Chromosome *chromo = (Chromosome *) pool->data; int i; int bad = 0;

/*

  • We immediately discard any invalid individuals (those that geqo_eval
  • returns DBL_MAX for), thereby not wasting pool space on them.

    • *

  • If we fail to make any valid individuals after 10000 tries, give up;
  • this probably means something is broken, and we shouldn't just let
  • ourselves get stuck in an infinite loop.

    • */ i = 0; while (i < pool->size) { init_tour(root, chromo[i].string, pool->string_length); pool->data[i].worth = geqo_eval(root, chromo[i].string, pool->string_length); if (pool->data[i].worth < DBL_MAX) i++; else { bad++; if (i == 0 && bad >= 10000) elog(ERROR, "geqo failed to make a valid plan"); } }

#ifdef GEQO_DEBUG if (bad > 0) elog(DEBUG1, "%d invalid tours found while selecting %d pool entries", bad, pool->size); #endif } ~~~

目的

遺伝的クエリ最適化（GEQO）の個体群プールを指定サイズまでランダムに初期化する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Pool *pool: 初期化対象のプール構造体
  • 戻り値: なし（void）

前提条件と不変条件

  • pool->data が Chromosome 配列として割り当てられており、各染色体が文字列バッファを持つ。
  • 評価値（worth）が DBL_MAX である個体は無効とみなされ、プールに保持されずに破棄される。

アルゴリズムまたは振る舞い

1. プール内の有効な個体数が pool->size に達するまで while ループで反復する。 2. 各反復において、init_tour を呼び出してランダムなツアー文字列を生成する。 3. geqo_eval を呼び出して生成したツアーのコスト（worth）を評価する。 4. 評価値が DBL_MAX 未満（有効）であれば個体を採用し、インデックスを進める。 5. 評価値が DBL_MAX（無効）である場合は不合格カウンター bad をインクリメントする。 6. デバッグビルド時（GEQO_DEBUG 定義時）に、無効なツアーが検出された場合は DEBUG1 レベルのログを出力する。

失敗モードと境界条件

  • 最初のエントリ（i == 0）の生成において無効な個体が連続して 10,000 回発生した場合、無限ループを防ぐために elog(ERROR) によりエラー終了する。
