目的

指定された式とオプションのソート・グループ化参照を、既存の PathTarget 構造体に追加する。

シグネチャまたは形状

void add_column_to_pathtarget(PathTarget *target, Expr *expr, Index sortgroupref)

入力と出力

  • 引数:
  • PathTarget *target: 式およびソートグループ参照を追加する対象の PathTarget 構造体ポインタ
  • Expr *expr: 追加する評価式のポインタ
  • Index sortgroupref: 該当する式に関連付けられたソート・グループ化参照のインデックス（ラベルなしの場合は 0）
  • 戻り値: なし (void)

前提条件と不変条件

  • target 引数には有効な PathTarget 構造体が渡される必要がある。

アルゴリズムまたは振る舞い

1. 式の追加: target->exprs リストの末尾に expr を lappend によって追加する。 2. ソート・グループ化参照の更新:

  • target->sortgrouprefs 配列がすでに存在する場合、新しい式の数に合わせて repalloc で領域を拡張し、新しく追加された末尾の位置に sortgroupref を格納する。
  • target->sortgrouprefs が存在せず、かつ引数 sortgroupref が非ゼロである場合、これまでの無札状態から新規に palloc0 で配列を割り当て、末尾の位置に sortgroupref を格納する。

    • 3. 揮発性式の状態リセット:

  • target->has_volatile_expr が VOLATILITY_NOVOLATILE（非揮発性）に設定されている場合、新しい式の追加に伴い、状態を VOLATILITY_UNKNOWN にリセットする。

失敗モードと境界条件

  • メモリ割り当てや再割り当て (repalloc, palloc0) が失敗した場合は、PostgreSQL のバックエンドメモリ管理機構を通じてエラーが処理される。

保守担当者向けメモ

  • has_volatile_expr の再評価処理は局所的に行わず、contain_volatile_functions による遅延評価へ委譲するため、ここでは単純に VOLATILITY_UNKNOWN へのリセットに留めている。
