  • will only include the ones we want.

/* Keep searching if join order is not valid */ if (joinrel) { bool is_top_rel = bms_equal(joinrel->relids, root->all_query_rels);

/* Create paths for partitionwise joins. */ generate_partitionwise_join_paths(root, joinrel);

  • Except for the topmost scan/join rel, consider gathering
  • partial paths. We'll do the same for the topmost scan/join

目的

新しいクランプ（new_clump）を既存のクランプリスト（clumps）にマージし、必要に応じて結合リレーションの生成や再帰的な結合、サイズ順の並び替えを行う。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • List *clumps: 既存の Clump リスト
  • Clump *new_clump: マージまたは挿入対象の新しいクランプ
  • int num_gene: 遺伝子の総数
  • bool force: 結合条件を満たさない場合でも強制的にマージを行うかどうかを示すフラグ
  • 戻り値:
  • List *: 更新されたクランプリスト

前提条件と不変条件

  • 返却されるクランプリスト内のクランプはサイズ順（大きいものが先頭側）に維持される。
  • サイズが 1 のクランプや空リストに追加する場合は、末尾への追加で高速に処理される。

アルゴリズムまたは振る舞い

1. **既存クランプとの結合探索**:

  • clumps 内の各 old_clump を順番に走査する。
  • force が真であるか、または desirable_join が真を返す場合に結合を試みる。

    • 2. **結合リレーションの構築とパス生成**:

  • make_join_rel を使って old_clump->joinrel と new_clump->joinrel の結合リレーションを構築する。
  • joinrel が有効な場合、パーティションワイズ結合のパス生成、必要に応じたギャザーパスの生成、最安パスの保存（set_cheapest）を行う。
  • グループ化されたリレーションが存在する場合は、グループ化されたパスの生成と最安パスの保存を実行する。

    • 3. **マージの完了と再帰**:

  • 古いクランプの結合リレーションを更新し、サイズを合算した上で、古い new_clump を解放する。
  • リストから該当する old_clump を削除し、拡大したクランプを対象として merge_clump を再帰的に呼び出して返す。

    • 4. **独立したクランプとしての追加**:

  • マージが行われない場合、clumps が空であるか new_clump->size == 1 ならば lappend により末尾に追加する。
  • それ以外の場合はサイズを比較して適切な挿入位置を探索し、list_insert_nth を用いて挿入する。

失敗モードと境界条件

  • make_join_rel が無効な結合順序などの理由で NULL を返した場合、その old_clump とのマージは見送られ、リスト内の次の候補の探索が継続される。
  • どの既存クランプともマージできなかった場合は、新たな独立クランプとして適切なサイズ順の位置に挿入される。
