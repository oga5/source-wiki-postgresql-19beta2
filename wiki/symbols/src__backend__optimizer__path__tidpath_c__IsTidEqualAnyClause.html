目的

RestrictInfo が表す条件式が、対象リレーションの CTID と配列値を比較する CTID = ANY(...) 形式の条件（ScalarArrayOpExpr）であるかを判定します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • RestrictInfo *rinfo: 検査対象の制限条件情報
  • RelOptInfo *rel: 対象リレーションの最適化情報
  • 戻り値:
  • 条件が指定された CTID = ANY(...) の条件に一致する場合は true、それ以外の場合は false

前提条件と不変条件

  • 引数 rinfo の clause が存在し、それが ScalarArrayOpExpr ノードである必要があります。
  • 演算子は TIDEqualOperator であり、かつ useOr が真である必要があります。
  • 演算子の引数は正確に 2 つ存在する必要があります。
  • 第 1 引数は対象リレーションの CTID 属性を指す Var である必要があります。
  • 第 2 引数（配列側の式）は、対象リレーションの変数を含まない疑似定数であり、かつ揮発性関数を含まない必要があります。

アルゴリズムまたは振る舞い

1. rinfo->clause が有効であり、かつノード型が ScalarArrayOpExpr であるかを検証します。不一致の場合は false を返します。 2. 演算子 ID (node->opno) が TIDEqualOperator と一致し、かつ node->useOr が真であることを確認します。不一致の場合は false を返します。 3. node->args の引数リストの長さが 2 であることをアサートし、第 1 引数を arg1、第 2 引数を arg2 として取得します。 4. arg1 が Var ノードであり、かつ IsCTIDVar を通じて対象リレーション rel の CTID を指しているかを検証します。満たさない場合は false を返します。 5. arg2 がリレーション rel の変数（pull_varnos と bms_is_member で判定）を含んでいるか、または contain_volatile_functions により揮発性関数を含んでいるかを検査します。これらに該当する場合は false を返します。 6. すべての検証を通過した場合は true を返します。

失敗モードと境界条件

  • rinfo->clause が NULL である場合や、ScalarArrayOpExpr 以外のノードである場合は即座に false を返します。
  • 演算子が TID の等価演算子ではない場合や、useOr が偽である場合は false を返します。
  • 第 1 引数が CTID 以外の変数や式である場合、あるいは第 2 引数が対象リレーションの変数に依存している場合や揮発性関数を含む場合は不適合とみなされ false を返します。
