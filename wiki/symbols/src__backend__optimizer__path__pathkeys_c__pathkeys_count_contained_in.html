目的

2つのパスキーリスト（keys1 および keys2）の先頭からの共通一致を判定し、共通するプレフィックスの長さを算出する。

シグネチャまたは形状

  • シグネチャ: bool pathkeys_count_contained_in(List *keys1, List *keys2, int *n_common)

入力と出力

  • 引数:
  • List *keys1: 比較元のパスキーリスト
  • List *keys2: 比較先のパスキーリスト
  • int *n_common: 共通プレフィックスの長さを格納する出力用ポインタ
  • 戻り値:

前提条件と不変条件

  • 引数として渡される keys1 と keys2 の各要素は、正規化された PathKey ポインタである。
  • 出力先ポインタ n_common は有効な整数変数を指している必要がある。

アルゴリズムまたは振る舞い

1. **ポインタ等価性のチェック**: keys1 と keys2 が同一のリストポインタを指している場合、両リストは完全に一致するため、n_common に keys1 の長さを格納し true を返す。 2. **空リストのチェック**:

  • keys1 が空 (NIL) の場合、共通長は 0 であり、包含関係を満たすため n_common に 0 を設定し true を返す。
  • keys2 が空 (NIL) の場合、keys1 が空でない限り包含されないため、n_common に 0 を設定し false を返す。

    • 3. **要素ごとの走査**: 両リストが非空の場合、forboth マクロを用いて keys1 と keys2 の要素を先頭から順に比較する。 4. **不一致の検出**: 対応する PathKey ポインタ同士（pathkey1 と pathkey2）が一致しない場合、それまでにカウントした一致数 n を *n_common に代入し、false を返す。 5. **正常終了**: ループが最後まで完了した場合、処理した要素数を *n_common に格納し、keys1 が完全に走査され尽くしたか（key1 == NULL）どうかの判定結果を返す。
