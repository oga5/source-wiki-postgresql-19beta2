~~~c RelOptInfo * make_join_rel(PlannerInfo *root, RelOptInfo *rel1, RelOptInfo *rel2) { Relids joinrelids; SpecialJoinInfo *sjinfo; bool reversed; List *pushed_down_joins = NIL; SpecialJoinInfo sjinfo_data; RelOptInfo *joinrel; List *restrictlist;

/* We should never try to join two overlapping sets of rels. */ Assert(!bms_overlap(rel1->relids, rel2->relids));

/* Construct Relids set that identifies the joinrel (without OJ as yet). */ joinrelids = bms_union(rel1->relids, rel2->relids);

/* Check validity and determine join type. */ if (!join_is_legal(root, rel1, rel2, joinrelids, &sjinfo, &reversed)) { /* invalid join path */ bms_free(joinrelids); return NULL; }

/*

  • Add outer join relid(s) to form the canonical relids. Any added outer
  • joins besides sjinfo itself are appended to pushed_down_joins.

    • */ joinrelids = add_outer_joins_to_relids(root, joinrelids, sjinfo, &pushed_down_joins);

/* Swap rels if needed to match the join info. */ if (reversed) { RelOptInfo *trel = rel1;

rel1 = rel2; rel2 = trel; }

/*

  • If it's a plain inner join, then we won't have found anything in
  • join_info_list. Make up a SpecialJoinInfo so that selectivity
  • estimation functions will know what's being joined.

    • */ if (sjinfo == NULL) { sjinfo = &sjinfo_data; init_dummy_sjinfo(sjinfo, rel1->relids, rel2->relids); }

/*

  • Find or build the join RelOptInfo, and compute the restrictlist that
  • goes with this particular joining.

    • */ joinrel = build_join_rel(root, joinrelids, rel1, rel2, sjinfo, pushed_down_joins, &restrictlist); ~~~

目的

2つのリレーション（rel1 と rel2）間の結合関係（RelOptInfo）を検索または新規構築し、パスの追加やグルーピングを統括する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報
  • RelOptInfo *rel1: 結合対象の1つ目のリレーション
  • RelOptInfo *rel2: 結合対象の2つ目のリレーション
  • 戻り値:
  • RelOptInfo *: 構築または見つかった結合リレーション。結合が無効な場合は NULL

前提条件と不変条件

  • 結合対象の2つのリレーション集合は、互いにオーバーラップしていてはならない。

アルゴリズムまたは振る舞い

1. **オーバーラップ検証**: rel1->relids と rel2->relids が重なっていないことをアサートで確認する。 2. **基本リレーションID集合の作成**: 2つのリレーションの relids を統合して joinrelids を作成する。 3. **結合の合法性チェック**: join_is_legal を呼び出して結合の有効性を判定し、結合タイプや sjinfo、順序反転フラグ reversed を取得する。無効な場合は joinrelids を解放して NULL を返す。 4. **外結合リレーションIDの追加**: add_outer_joins_to_relids により外結合の relid(s) を追加して正規化された joinrelids を形成し、追加の外結合情報を pushed_down_joins に格納する。 5. **リレーションの順序調整**: reversed フラグが真である場合、結合情報に一致させるために rel1 と rel2 を入れ替える。 6. **ダミー SpecialJoinInfo の初期化**: プレインな内結合などで sjinfo が見つからない場合、選択度推定用に関数 init_dummy_sjinfo を用いてダミーの SpecialJoinInfo を作成する。 7. **結合リレーションの取得・構築**: build_join_rel を呼び出して結合 RelOptInfo を検索または構築し、対応する制限リスト (restrictlist) を取得する。 8. **空リレーションの早期リターン**: 構築した joinrelrel がダミー（空）リレーションであると判明している場合、それ以上のパス探索を行わず joinrelids を解放して joinrel を返す。 9. **グルーピングとパスの追加**: 可能であれば make_grouped_join_rel でグループ化された結合リレーションを構築し、populate_joinrel_with_paths でパスを追加する。 10. **クリーンアップ**: 作業用の joinrelids をメモリ解放した上で joinrel を返す。

失敗モードと境界条件

  • rel1 と rel2 のリレーションID集合が重複している場合、アサート違反により処理が中断される。
  • 結合の合法性チェック（join_is_legal）に失敗した場合、構築処理は中断され NULL が返される。
  • 結合リレーションが空（is_dummy_rel が真）であると判明した場合、パスの追加処理はスキップされ早期にリターンされる。
