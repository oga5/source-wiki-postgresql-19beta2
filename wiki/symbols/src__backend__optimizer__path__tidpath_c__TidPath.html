目的

指定された Var ノードが、対象リレーションの ctid 列（SelfItemPointerAttributeNumber、型 TIDOID）を正確に指しているかを検証します。

入力と出力

  • 入力:
  • Var *var: 検証対象の変数ノード。
  • RelOptInfo *rel: 対象となるリレーション情報。
  • 出力: 条件を満たす場合は true、そうでない場合は false を返します。

前提条件と不変条件

  • var->varattno は SelfItemPointerAttributeNumber でなければなりません。
  • var->vartype は TIDOID でなければなりません。
  • var->varno は rel->relid と一致しなければなりません。
  • var->varnullingrels は NULL でなければなりません。
  • var->varlevelsup は 0 でなければなりません。

アルゴリズムまたは振る舞い

1. var->varattno が SelfItemPointerAttributeNumber と一致するかをチェックします。 2. var->vartype が TIDOID であるかを確認します（厳密な整合性確認）。 3. var->varno が rel->relid と一致するかを確認します。 4. var->varnullingrels が NULL であるかを確認します。 5. var->varlevelsup が 0 であるかを確認します。 6. すべての条件を満たす場合に true を返し、それ以外の場合は false を返します。

失敗モードと境界条件

  • いずれかの属性（属性番号、型、リレーション ID、ヌリングリレーション、サブクエリレベル）が一致しない場合、あるいは安全性の要件に外れる場合は false を返します。

保守担当者向けメモ

  • 型チェック（vartype == TIDOID）は厳密な安全確認（パラノイア的な検証）として意図的に行われています。
