ソース抜粋

~~~c typedef struct { ParamListInfo boundParams; PlannerInfo *root; List *active_fns; Node *case_val; bool estimate; } eval_const_expressions_context; ~~~

目的

eval_const_expressions_context は、オプティマイザの定数畳み込みおよび式値見積もり処理（eval_const_expressions や estimate_expression_value）の実行中に、状態や走査コンテキストを保持するために使用される構造体です。

フィールドと表現

  • ParamListInfo boundParams: 式内で参照されるパラメータ（Param）の値をバインドするための情報です。
  • PlannerInfo *root: プランナ全体の情報を保持する PlannerInfo へのポインタであり、依存関係の記録などに使用されます。
  • List *active_fns: 現在評価中あるいはインライン展開中のアクティブな関数群を管理するリストです。
  • Node *case_val: CASE 式の評価時にテスト対象となる値を保持するノードです。
  • bool estimate: 安全な変換のみを行うか、見積もり用の積極的な式評価や変換を行うかを示すフラグです。
