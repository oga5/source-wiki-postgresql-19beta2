目的

通常の内結合（JOIN_INNER）用として、ダミーの SpecialJoinInfo 構造体を初期化する。

シグネチャまたは形状

  • シグネチャ: void init_dummy_sjinfo(SpecialJoinInfo *sjinfo, Relids left_relids, Relids right_relids)

入力と出力

  • 引数:
  • SpecialJoinInfo *sjinfo: 初期化対象となる SpecialJoinInfo 構造体へのポインタ
  • Relids left_relids: 左側リレーションの識別子集合（最小および構文的左側ハンドに設定される）
  • Relids right_relids: 右側リレーションの識別子集合（最小および構文的右側ハンドに設定される）
  • 戻り値: なし（void）

前提条件と不変条件

  • 引数 sjinfo には有効なメモリ領域が割り当てられていること。

アルゴリズムまたは振る舞い

1. sjinfo->type に T_SpecialJoinInfo を設定する。 2. min_lefthand および syn_lefthand に left_relids を設定する。 3. min_righthand および syn_righthand に right_relids を設定する。 4. jointype に JOIN_INNER を設定し、ojrelid を 0 に設定する。 5. すべての可換方向ポインタ（commute_above_l, commute_above_r, commute_below_l, commute_below_r）を NULL に設定する。 6. 残りの特殊フィールド（lhs_strict, semi_can_btree, semi_can_hash, semi_operators, semi_rhs_exprs）に対して、内結合用の既定値（不使用または偽・空の表現）を設定する。

関連データ構造

  • SpecialJoinInfo
  • Relids

失敗モードと境界条件

  • ダミー初期化であるため、残りのフィールドの有効化は試みられず、半結合や外結合特有の追加プロパティは検証されない。
