~~~c List * extract_update_targetlist_colnos(List *tlist) { List *update_colnos = NIL; AttrNumber nextresno = 1; ListCell *lc;

foreach(lc, tlist) { TargetEntry *tle = (TargetEntry *) lfirst(lc);

if (!tle->resjunk) update_colnos = lappend_int(update_colnos, tle->resno); tle->resno = nextresno++; } return update_colnos; } ~~~

目的

UPDATE処理等で使用するターゲットリストから更新対象の列番号（colnos）の整数リストを抽出し、ターゲットエントリのレスノ（resno）を 1 から始まる連番に再割り当てします。

入力と出力

  • 入力: List *tlist （ターゲットエントリ TargetEntry のリスト）
  • 戻り値: List * （更新対象の列番号を表す整数のリスト update_colnos）

前提条件と不変条件

  • 引数として渡されるターゲットリスト内の各要素は TargetEntry 型のポインタである必要があります。

アルゴリズムまたは振る舞い

  • update_colnos を NIL で初期化し、nextresno を 1 に設定します。
  • 渡されたターゲットリスト tlist の各要素を走査します。
  • 各 TargetEntry の resjunk が偽である場合、そのエントリの resno を update_colnos に整数として追加します。
  • 各エントリの resno を 1 からインクリメントしながら再割り当てします。
  • 構築した update_colnos リストを返します。

失敗モードと境界条件

  • エラーパスや特別な境界条件の処理は持っていません。
