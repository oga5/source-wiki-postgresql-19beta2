目的

2つの親ツアー（tour1 および tour2）の間でサイクル交叉（Cycle Crossover: CX）を実行し、子孫ツアー（offspring）を組み立てる。

シグネチャまたは形状

  • シグネチャ: int cx(PlannerInfo *root, Gene *tour1, Gene *tour2, Gene *offspring, int num_gene, City * city_table)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Gene *tour1: 親ツアー1
  • Gene *tour2: 親ツアー2
  • Gene *offspring: 構築される子孫ツアー出力先
  • int num_gene: 遺伝子の総数（都市数）
  • City * city_table: 都市の状態や位置情報を管理するための作業用テーブル
  • 戻り値: int - 親ツアー1（tour1）と生成された子孫ツアー（offspring）の間の差異の数（完全なツアーが構築された場合は 0）

前提条件と不変条件

  • num_gene は有効な都市数であり、city_table は 1 から num_gene までのインデックスに対して十分な領域を持つこと。

アルゴリズムまたは振る舞い

1. 都市テーブルの初期化:

  • 1 から num_gene までの各都市について、city_table[i].used を 0 にクリアする。
  • tour2 および tour1 における各都市のインデックス位置を city_table[tour2[i - 1]].tour2_position および city_table[tour1[i - 1]].tour1_position に記録する。

2. サイクル開始位置の選択:

  • geqo_randint を用いて、0 から num_gene - 1 の範囲からランダムにサイクルの開始位置（start_pos）を選択する。

3. ステップ 1（サイクル構築）:

  • 子孫の start_pos 位置に tour1[start_pos] の遺伝子を継承させ、該当都市の used フラグを立て、カウントをインクリメントする。
  • tour2[curr_pos] が tour1[start_pos] に一致するまでループし、tour2 の都市の位置に対応する tour1 の位置を辿りながら、順次 tour1 の遺伝子を子孫にコピーしていく。

4. ステップ 2（未訪問都市の補完）:

  • サイクル構築によって完全なツアーが生成されなかった場合（count < num_gene）、city_table を走査して used が立っていない未訪問の都市を検出する。
  • 未訪問都市について、tour2 での位置に対応する遺伝子を offspring の同じ位置に補完する。

5. ステップ 3（差異の評価と返却）:

  • それでも完全なツアーになっていない場合、tour1 と offspring を比較して差異の数を数え、その数を返す。

呼び出し元と呼び出し先

  • 呼び出し先: geqo_randint

関連データ構造

  • City: 都市の訪問状態（used）や各親ツアーでの位置（道具立てとして tour1_position, tour2_position）を保持する構造体
  • Gene: ツアーを構成する遺伝子（都市ID）型
  • PlannerInfo: プランナーのグローバルコンテキスト

失敗モードと境界条件

  • 特殊なエラー送出パスは持たないが、count < num_gene の条件分岐によって不完全な巡回路を検出した場合、ステップ 2 およびステップ 3 の補完・カウント処理にフォールバックする。
