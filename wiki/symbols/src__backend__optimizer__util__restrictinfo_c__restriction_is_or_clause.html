ソース抜粋

~~~c bool restriction_is_or_clause(RestrictInfo *restrictinfo) { if (restrictinfo->orclause != NULL) return true; else return false; } ~~~

目的

RestrictInfo ノードが OR 節を持つかどうかを判定する。

シグネチャまたは形状

bool restriction_is_or_clause(RestrictInfo *restrictinfo)

入力と出力

  • 入力: RestrictInfo *restrictinfo （判定対象の RestrictInfo 構造体へのポインタ）
  • 出力: bool （restrictinfo->orclause が NULL でない場合は true、そうでない場合は false）

アルゴリズムまたは振る舞い

引数として渡された RestrictInfo の orclause フィールドを確認し、その値が NULL でなければ true を返し、NULL であれば false を返す。
