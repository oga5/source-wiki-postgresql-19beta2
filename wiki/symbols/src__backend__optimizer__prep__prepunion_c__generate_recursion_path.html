~~~c static RelOptInfo * generate_recursion_path(SetOperationStmt *setOp, PlannerInfo *root, List *refnames_tlist, List **pTargetList) { RelOptInfo *result_rel; Path *path; RelOptInfo *lrel, *rrel; Path *lpath; Path *rpath; List *lpath_tlist; bool lpath_trivial_tlist; List *rpath_tlist; bool rpath_trivial_tlist; List *tlist; List *groupList; double dNumGroups;

/* Parser should have rejected other cases */ if (setOp->op != SETOP_UNION) elog(ERROR, "only UNION queries can be recursive"); /* Worktable ID should be assigned */ Assert(root->wt_param_id >= 0);

/*

  • Unlike a regular UNION node, process the left and right inputs
  • separately without any intention of combining them into one Append.

    • */ lrel = recurse_set_operations(setOp->larg, root, NULL, /* no value in sorted results */ setOp->colTypes, setOp->colCollations, refnames_tlist, &lpath_tlist, &lpath_trivial_tlist); if (lrel->rtekind == RTE_SUBQUERY) build_setop_child_paths(root, lrel, lpath_trivial_tlist, lpath_tlist, NIL, NULL); lpath = lrel->cheapest_total_path; /* The right path will want to look at the left one ... */ root->non_recursive_path = lpath; rrel = recurse_set_operations(setOp->rarg, root, NULL, /* no value in sorted results */ setOp->colTypes, setOp->colCollations, refnames_tlist, &rpath_tlist, &rpath_trivial_tlist); if (rrel->rtekind == RTE_SUBQUERY) build_setop_child_paths(root, rrel, rpath_trivial_tlist, rpath_tlist, NIL, NULL); rpath = rrel->cheapest_total_path; root->non_recursive_path = NULL;

/*

  • Generate tlist for RecursiveUnion path node --- same as in Append cases

    • */ tlist = generate_append_tlist(setOp->colTypes, setOp->colCollations, list_make2(lpath_tlist, rpath_tlist), refnames_tlist);

目的

再帰的 UNION クエリに対して RecursiveUnion パスノードを生成し、上位の RelOptInfo に登録する。

入力と出力

  • 引数:
  • SetOperationStmt *setOp: 対象の集合演算ステートメント
  • PlannerInfo *root: プランナーのグローバル情報
  • List *refnames_tlist: 参照名付きターゲットリスト
  • List **pTargetList: 構築されたターゲットリストの格納先ポインタ
  • 戻り値:
  • RelOptInfo *: 構築された結果リレーション

前提条件と不変条件

  • setOp->op は SETOP_UNION でなければならない（パーサー側で他は排除されている前提）。
  • ワークテーブルパラメータ ID (root->wt_param_id) が割り当てられていること（0 以上）。

アルゴリズムまたは振る舞い

1. **前提チェック**: 入力された setOp->op が SETOP_UNION であることを確認し、異なる場合は ERROR を送出する。また、root->wt_param_id が負でないことを検証する。 2. **左側（非再帰）項の処理**: recurse_set_operations を呼び出して左側ツリーを再帰的に処理する。サブクエリの場合は build_setop_child_paths を実行する。取得した最安パスを root->non_recursive_path に設定する。 3. **右側（再帰）項の処理**: recurse_set_operations を呼び出して右側ツリーを処理する。サブクエリの場合は build_setop_child_paths を実行する。処理後に root->non_recursive_path をクリアする。 4. **ターゲットリストの生成**: generate_append_tlist を使用して RecursiveUnion パスノード用のターゲットリストを生成し、*pTargetList に出力する。 5. **リレーションの構築**: 左右のリレーション ID を統合し、fetch_upper_rel を介して UPPERREL_SETOP の RelOptInfo を取得・設定する。 6. **重複排除とグループ化の判定**:

  • setOp->all が真の場合はグループリストを空とし、グループ数を 0 とする。
  • 偽の場合は generate_setop_grouplist でグループリストを生成し、grouping_is_hashable でハッシュ可能か検証する。ハッシュ不可能な場合はエラーを送出する。グループ数は最悪ケースとして見積もる。

    • 7. **パスの作成と登録**: create_recursiveunion_path でパスノードを構築し、add_path で result_rel に追加後、postprocess_setop_rel を呼び出して結果のリレーションを返す。

失敗モードと境界条件

  • setOp->op が SETOP_UNION 以外の場合、ERROR レベルのログが送出される。
  • ワークテーブルパラメータ ID が未割当（root->wt_param_id < 0）の場合、アサーション失敗となる。
  • UNION (非 ALL) クエリにおいて、カラムのデータ型がハッシュ可能でない場合、機能未サポートのエラー（ERRCODE_FEATURE_NOT_SUPPORTED）が報告される。
