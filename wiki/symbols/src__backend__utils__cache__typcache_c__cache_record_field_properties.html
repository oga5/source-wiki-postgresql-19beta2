  • equality and comparison will (we may get a failure at runtime). We

  • option between a comparison-based (sort-based) and a hash-based plan
  • chooses hashing, stuff could fail that would otherwise work if it chose
  • a comparison-based plan. In practice more types support comparison
  • than hashing.

/* Have each property if all non-dropped fields have the property */ newflags = (TCFLAGS_HAVE_FIELD_EQUALITY | TCFLAGS_HAVE_FIELD_COMPARE | TCFLAGS_HAVE_FIELD_HASHING | TCFLAGS_HAVE_FIELD_EXTENDED_HASHING); for (i = 0; i < tupdesc->natts; i++) { TypeCacheEntry *fieldentry; Form_pg_attribute attr = TupleDescAttr(tupdesc, i);
