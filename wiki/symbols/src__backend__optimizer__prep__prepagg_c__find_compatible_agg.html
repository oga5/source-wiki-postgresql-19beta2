目的

既存の集約情報リストを走査し、新しい集約呼び出しと完全に一致する集約、または入力パラメータが同一である集約の遷移状態候補を検索する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報へのポインタ
  • Aggref *newagg: 検索対象となる新しい集約参照ノード
  • List **same_input_transnos: 入力が一致する共有可能な遷移状態番号のリストを受け取る出力ポインタ
  • 戻り値:
  • int: 完全一致する既存の集約が存在する場合はその集約番号 (aggno)、存在しない場合は -1 を返す。

前提条件と不変条件

  • newagg に揮発性関数呼び出しが含まれている場合は再利用不可とみなし、即座に -1 を返す。

アルゴリズムまたは振る舞い

1. same_input_transnos を NIL に初期化する。 2. newagg に揮発性の関数呼び出しが含まれているかを contain_volatile_functions で検査し、含まれていれば -1 を返す。 3. root->agginfos 内の既存の集約情報を順に走査する。 4. 各 AggInfo の最初の Aggref (existingRef) と比較し、入力照合順序 (inputcollid)、遷移型 (aggtranstype)、集約の性質 (aggstar, aggvariadic, aggkind)、および引数 (args)、順序 (aggorder)、 DISTINCT 節 (aggdistinct)、フィルタ (aggfilter) がすべて一致するかを検査する。一致しない場合は次のエントリへ進む。 5. 上記の基本入力が一致した上で、集約関数 OID (aggfnoid)、結果型 (aggtype)、戻り値照合順序 (aggcollid)、直接引数 (aggdirectargs) もすべて一致する場合は完全一致とみなし、蓄積していた same_input_transnos リストを解放した上でその集約番号 (aggno) を返す。 6. 関数定義等は完全一致しないものの入力が一致する場合において、該当する agginfo->shareable が真であれば、その agginfo->transno を same_input_transnos リストに追加する。 7. ループが終了しても完全一致が見つからない場合は -1 を返す。

失敗モードと境界条件

  • 一致する集約が見つからなかった場合や、揮発性関数が含まれている場合は -1 を返す。
  • 完全一致が見つかった場合、それまでに収集されていた same_input_transnos のリストは list_free により解放され、ポインタは NIL にリセットされる。
