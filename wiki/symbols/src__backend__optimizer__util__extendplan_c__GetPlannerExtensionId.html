目的

指定された拡張機能名に対応する一意の整数 ID を取得します。すでに登録されている場合は既存の ID を返し、未登録の場合は新規に割り当てて返します。

入力と出力

  • 引数: const char *extension_name （対象となる拡張機能の名前）
  • 戻り値: int （割り当てられた拡張機能 ID）

前提条件と不変条件

  • 割り当てられる拡張機能 ID は、バックエンドのライフタイム内でのみ有効であり、永続的ではありません。

アルゴリズムまたは振る舞い

1. 既存の拡張機能検索:

  • PlannerExtensionNamesAssigned の数までループし、PlannerExtensionNameArray 内の既存のエントリと extension_name を strcmp で比較します。
  • 一致する名前が見つかった場合は、そのインデックス i を直ちに返します。

    • 2. 配列の初期化:

  • 登録済みの名前がなく PlannerExtensionNameArray が NULL の場合、初期割り当てサイズ 16 で TopMemoryContext から MemoryContextAlloc を用いてポインタ配列領域を確保します。

    • 3. 配列の拡張:

  • 配列がすでに存在するものの、割り当て済みサイズ (PlannerExtensionNamesAllocated) に対して割り当て済みカウント (PlannerExtensionNamesAssigned) が達しているか超過している場合、pg_nextpower2_32 を用いて新しい容量を計算し、repalloc で配列領域を拡張します。

    • 4. 新規 ID の割り当てと登録:

  • PlannerExtensionNameArray の現在のアサイン位置に extension_name を格納し、PlannerExtensionNamesAssigned をインクリメントした上で新しい ID を返します。

失敗モードと境界条件

  • メモリ割り当て時や拡張時に、基盤のメモリ管理機構 (MemoryContextAlloc, repalloc) が失敗した場合はエラー処理フローへ移行します。
