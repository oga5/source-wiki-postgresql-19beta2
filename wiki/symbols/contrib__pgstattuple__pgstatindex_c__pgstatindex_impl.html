/*

  • Reject attempts to read non-local temporary relations; we would be
  • likely to get wrong data since we have no visibility into the owning
  • session's local buffers.

  • A !indisready index could lead to ERRCODE_DATA_CORRUPTED later, so exit
  • early. We're capable of assessing an indisready&&!indisvalid index,

  • could be too low for a valid index of the table.

    • */ if (!rel->rd_index->indisvalid) ereport(ERROR, (errcode(ERRCODE_OBJECT_NOT_IN_PREREQUISITE_STATE), errmsg("index \"%s\" is not valid", RelationGetRelationName(rel))));

/*

  • Read metapage

indexStat.version = metad->btm_version; indexStat.level = metad->btm_level; indexStat.root_blkno = metad->btm_root;
