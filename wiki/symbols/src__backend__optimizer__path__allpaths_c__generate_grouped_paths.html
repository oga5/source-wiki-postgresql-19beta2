目的

結合ツリー内の可能な最低レベルで部分集約（partial aggregation）をプッシュし、グループ化されたリレーション（grouped_rel）に対してソートベースおよびハッシュベースの初期集約パスを生成する。

シグネチャまたは形状

  • void generate_grouped_paths(PlannerInfo *root, RelOptInfo *grouped_rel, RelOptInfo *rel)

入力と出力

  • 入力:
  • PlannerInfo *root: プランナーのグローバル情報
  • RelOptInfo *grouped_rel: グループ化された目標リレーション
  • RelOptInfo *rel: 元となる（グループ化されていない）リレーション
  • 出力: なし (void)

前提条件と不変条件

  • 対象リレーションがダミーリレーションである場合、grouped_rel もダミーリレーションとしてマークされる。
  • 部分集約の適用先が一致しており、かつ集約が有効である場合にのみパス生成が続行される。
  • ハッシュベースの集約を検討する際、root->numOrderedAggs == 0 であることがアサートされる。

アルゴリズムまたは振る舞い

1. 初期チェック: 渡された rel がダミーリレーションであるか判定し、該当する場合は grouped_rel をダミーとしてマークして終了する。 2. 適用可能性の検証: agg_info->apply_agg_at と rel->relids の一致性、および agg_info->agg_useful の真偽を確認し、条件を満たさない場合は終了する。 3. 集約コストとグループ化要件の計算: 初期シリアル集約のコスト構造体を初期化・取得し、グループ化がソート可能またはハッシュ可能であるかを判定する。 4. グループ数とパスの特定: 元リレーションの pathlist や partial_pathlist から、最安のトータルパスおよび最安の部分パスを抽出し、それぞれのグループ数を推計する。 5. ソートベースパスの生成: ソート可能な場合、非パラメータ化パスまたは最安パスに対して射影、必要に応じたソート（またはインクリメンタルソート）、および初期集約パス (create_agg_path) を適用し、grouped_rel に追加する。 6. ハッシュベースパスの生成: ハッシュ可能な場合、最安トータルパスおよび最安部分パスに対して射影およびハッシュ集約パスを構築し、grouped_rel に追加する。

失敗モードと境界条件

  • rel がダミーリレーションの場合は即座に処理が打ち切られ、grouped_rel がダミー化される。
  • 部分集約の適用位置が一致しない、または集約が有用でない場合はパスが生成されない。
  • 最安パスや部分パスが存在しない場合、対応するグループ数の推計やパス生成ループがバイパスされる。
