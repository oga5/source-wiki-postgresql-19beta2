目的

サブクエリや値リストの引き上げ時に、上位クエリの変数参照をサブクエリの内部実体に置換するためのコンテキスト情報を提供する構造体である。

フィールドと表現

  • PlannerInfo *root: プランナ全体の情報を保持するルート構造体へのポインタ。
  • List *targetlist: 引き上げ対象となるサブクエリのターゲットリスト（tlist）。
  • RangeTblEntry *target_rte: 引き上げ対象サブクエリの範囲テーブルエントリ（RTE）。
  • int result_relation: 書き換えられたクエリ内における結果リレーションのインデックス。
  • Relids relids: 引き上げ後の番号付けに対応する、サブクエリ内のrelid集合（target_rte->lateral が真の場合のみ設定される）。
  • nullingrel_info *nullinfo: RTEごとのnullingrel情報（target_rte->lateral が真の場合のみ設定される）。
  • bool *outer_hasSubLinks: 上位クエリの hasSubLinks フラグへのポインタ。
  • int varno: サブクエリの varno。
  • ReplaceWrapOption wrap_option: 特定の出力をPlaceHolderVar（PHV）でラップする必要性等を規定するオプション。
  • Node **rv_cache: PHV付きの結果をキャッシュするための配列ポインタ。
