目的

クエリ内の各ベースリレーションに対してサイズ見積もりや並列実行適格性の判定を適用する。

入力と出力

  • 引数: PlannerInfo *root
  • 戻り値: なし (void)

前提条件と不変条件

  • rel が NULL でない場合、rel->relid == rti であること。

アルゴリズムまたは振る舞い

1. root->simple_rel_array_size に基づき、インデックス 1 から順に simple_rel_array を走査する。 2. スロットが空 (rel == NULL) の場合や、リレーションのオプション種別が RELOPT_BASEREL でない場合はスキップする。 3. クエリ全体で並列モードが許可されている場合 (root->glob->parallelModeOK) は、対象リレーションに対する並列実行の許容性を判定するため set_rel_consider_parallel を呼び出す。 4. set_rel_size を呼び出してリレーションのサイズ見積もりを実行する。

失敗モードと境界条件

  • root->simple_rel_array 内の非ベースリレーションに対応する空のスロット (rel == NULL) は処理対象外となる。
  • RELOPT_BASEREL 以外のリレーションオプション種別を持つ「その他のリレーション」はスキップされる。
