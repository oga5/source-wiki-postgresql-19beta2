ソース抜粋

~~~c List * append_pathkeys(List *target, List *source) { ListCell *lc;

Assert(target != NIL);

foreach(lc, source) { PathKey *pk = lfirst_node(PathKey, lc);

if (!pathkey_is_redundant(pk, target)) target = lappend(target, pk); } return target; } ~~~

目的

append_pathkeys は、既存のターゲットパスキーのリストに対し、ソースとなるパスキーのリストから冗長でないものを順次追加して結合したリストを構築するユーティリティ関数です。

シグネチャまたは形状

  • シグネチャ: List * append_pathkeys(List *target, List *source)

入力と出力

  • 引数:
  • target (List *): 追加先の対象となる PathKey ノードのリスト。
  • source (List *): 結合元となる PathKey ノードのリスト。
  • 戻り値:
  • List *: source 内の非冗長なパスキーが追加された後の target リスト。

前提条件と不変条件

  • target 引数は NIL であってはならない（Assert(target != NIL) により検証される）。

アルゴリズムまたは振る舞い

  • target が NIL でないことをアサートで確認する。
  • source リスト内の各要素を foreach ループで走査する。
  • 各 ListCell から PathKey ノードを取り出す。
  • pathkey_is_redundant を用いて、当該 PathKey が既存の target リストに対して冗長であるかを判定する。
  • 冗長でない場合のみ、lappend を使用して target リストの末尾にその PathKey を追加し、リストを更新する。
  • 最終的に構築された target リストを返す。

失敗モードと境界条件

  • target に NIL が渡された場合、アサート違反により実行時エラーとなる。
