目的

指定された式や擬似変数（exprs）から計算可能な、同値クラス（ec）内の適切な同値メンバー（EquivalenceMember）を探索して返します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報コンテキスト。
  • EquivalenceClass *ec: 探索対象の同値クラス。
  • List *exprs: 利用可能な式またはターゲットエントリのリスト。
  • Relids relids: 対象とするリレーションIDのビットマップセット。
  • bool require_parallel_safe: パラレル安全性の検証を要求するかどうか。
  • 戻り値:
  • EquivalenceMember *: 条件を満たす同値メンバー、または見つからない場合は NULL。

前提条件と不変条件

  • 定数を含む同値メンバーはソート等で扱わないため、スキップ対象となります。
  • 子メンバーである場合、そのメンバーのリレーション群が指定された relids のサブセットでなければ無視されます。

アルゴリズムまたは振る舞い

1. **式の変数抽出**: 入力された exprs から pull_var_clause を用いて、集約関数、ウィンドウ関数、プレースホルダーを含む変数および擬似変数のリスト（exprvars）を抽出します。 2. **イテレータのセットアップ**: 指定された同値クラス ec と relids を基に、同値メンバーイテレータを初期化します。 3. **メンバーの順次走査とフィルタリング**:

  • eclass_member_iterator_next により各メンバー em を順に取得します。
  • em_is_const が真である場合は定数を含むためスキップします。
  • em_is_child が真かつ em_relids が relids のサブセットでない場合はスキップします。

    • 4. **利用可能性の検証**:

  • 各メンバーの式 em_expr から変数および擬似変数を抽出し（emvars）、それらのすべての変数が exprvars に含まれているかを走査して確認します。
  • 利用できない変数が含まれている場合は当該メンバーをスキップします。
  • emvars の一時リストを解放します。

    • 5. **パラレル安全性の確認**:

  • require_parallel_safe が真である場合、is_parallel_safe を用いて式がパラレル安全であるかを検証し、安全でない場合はスキップします。

    • 6. **返却**: 条件をすべて満たした有効な em が見つかった場合はそれを返し、ループが尽きた場合は NULL を返します。

失敗モードと境界条件

  • 一致する計算可能なメンバーが存在しない場合は NULL を返します。
  • メンバーが定数である場合や、要求されたリレーションに属さない子メンバーである場合は除外されます。
