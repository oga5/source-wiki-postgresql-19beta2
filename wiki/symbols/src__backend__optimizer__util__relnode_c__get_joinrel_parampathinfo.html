目的

指定されたパラメータ化要件 (required_outer) を満たす結合関係（RelOptInfo）の ParamPathInfo を取得または構築し、その結合関係へ移動可能な制限句や等価クラス由来の結合句を識別して呼び出し元の制限句リストに結合する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • RelOptInfo *joinrel: 対象の結合関係
  • Path *outer_path: 外側の入力パス
  • Path *inner_path: 内側の入力パス
  • SpecialJoinInfo *sjinfo: 特殊結合（外結合など）の情報
  • Relids required_outer: このパラメータ化に必要な外部リレーションの集合
  • List **restrict_clauses: 制限句リストへのポインタ（出力時に移動された句が追加される）
  • 戻り値:
  • ParamPathInfo *: 構築または既存の ParamPathInfo（required_outer が空の場合は NULL）

前提条件と不変条件

  • 結合関係が LATERAL 参照を持つ場合、そのすべての参照が required_outer に含まれていなければならない。
  • required_outer が空である場合、パラメータ化されたパスや追加の結合句は存在しないため NULL が返される。
  • 結合関係のリレーションID集合と required_outer は重複してはならない。

アルゴリズムまたは振る舞い

1. 初期チェック:

  • joinrel->lateral_relids が required_outer のサブセットであるか検証する。
  • required_outer が空（無パラメータ）の場合は早期に NULL を返す。
  • joinrel->relids と required_outer が重複していないことをアサートで確認する。

2. 結合句の移動可能性の判定:

  • joinrel->joininfo 内の各制限句（RestrictInfo）を走査し、現在の結合関係へ移動可能であり、かつ左右の入力パスのどちらにも単独で移動できないものを pclauses に収集する。
  • 同様に、等価クラス（EquivalenceClasses）から generate_join_implied_equalities を用いて導出された結合句を検査し、左側または右側の入力パスに移動できるものを除外、あるいは右側パスに移動できる場合は対応する等価クラスを dropped_ecs に記録した上で pclauses に追加する。

3. 破棄された等価クラス（dropped_ecs）の処理:

  • dropped_ecs が存在する場合、外側パスの親リレーションと required_outer を用いて、外側リレーションと結合の左側を結ぶ暗黙の等価句を再生成する。生成された句のうち、外側パス自体には移動できないものを pclauses に追加する。

4. 制限句リストの結合と ParamPathInfo の解決:

  • 識別された pclauses を呼び出し元の restrict_clauses リストの先頭側に破壊せずに結合する。
  • 既存の ParamPathInfo が find_param_path_info で見つかる場合はそれをそのまま返す。
  • 見つからない場合、get_parameterized_joinrel_size を用いてパラメータ化結合の行数を推定し、新しい ParamPathInfo ノードを生成して joinrel->ppilist に追加して返す。

失敗モードと境界条件

  • required_outer が空集合（bms_is_empty が真）の場合、追加の処理を行わずに即座に NULL を返す。
  • outer_path または inner_path が param_info を持たない場合、対応する outer_and_req や inner_and_req は NULL として扱われる。

保守担当者向けメモ

  • GEQO モードでは一時的なメモリコンテキスト内で呼び出されるが、joinrel 構造体も同コンテキスト内にあるためメモリ上の問題は発生しない。
