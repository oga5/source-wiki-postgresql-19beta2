~~~c void find_placeholders_in_jointree(PlannerInfo *root) { /* This must be done before freezing the set of PHIs */ Assert(!root->placeholdersFrozen);

/* We need do nothing if the query contains no PlaceHolderVars */ if (root->glob->lastPHId != 0) { /* Start recursion at top of jointree */ Assert(root->parse->jointree != NULL && IsA(root->parse->jointree, FromExpr)); find_placeholders_recurse(root, (Node *) root->parse->jointree); } } ~~~

目的

クエリのジョイントリーからプレースホルダ（PlaceHolderVar）の探索を開始するエントリーポイントとして機能する。

入力と出力

  • 入力: PlannerInfo *root
  • 戻り値: なし (void)

前提条件と不変条件

  • プレースホルダのセットが凍結されている状態 (root->placeholdersFrozen が真) では実行できない。
  • クエリのジョイントリーが存在する場合、ルートのジョイントリーノードは FromExpr 型でなければならない。

アルゴリズムまたは振る舞い

  • プレースホルダセットが未凍結であることをアサートで検証する。
  • クエリにプレースホルダ変数 (PlaceHolderVar) が含まれていない場合（root->glob->lastPHId == 0）、何も処理を行わずに終了する。
  • プレースホルダが存在する場合、ジョイントリーが FromExpr であることを検証した上で、ジョイントリーの最上位から再帰的探索関数 find_placeholders_recurse を呼び出す。

失敗モードと境界条件

  • root->placeholdersFrozen が真である状態で呼び出された場合、アサート違反により異常終了する。
  • root->glob->lastPHId != 0 かつジョイントリーが FromExpr ではない場合、アサート違反により異常終了する。
