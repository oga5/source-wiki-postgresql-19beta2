定義

  • 種別: function
  • 定義箇所: src/backend/optimizer/path/clausesel.c:116

目的

複数の述語句（clauses）からなる条件リスト全体の選択度を算出します。拡張統計情報の適用制御や、同一変数に対する範囲クエリ（下限・上限の組み合わせ）のペアリングによる精密な選択度補正を行います。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • List *clauses: 評価対象の述語句のリスト
  • int varRelid: 対象リレーションの識別子
  • JoinType jointype: 結合種別
  • SpecialJoinInfo *sjinfo: 特殊結合情報
  • bool use_extended_stats: 拡張統計情報を使用するかどうかのフラグ
  • 戻り値: Selectivity （計算された選択度）

前提条件と不変条件

  • 引数 clauses の要素数がちょうど 1 の場合は、拡張統計の適用などをスキップし clause_selectivity_ext を直接呼び出します。

アルゴリズムまたは振る舞い

1. **単一要素の早期リターン**: clauses の長さが 1 であるかを判定し、該当する場合は clause_selectivity_ext の結果をそのまま返します。 2. **拡張統計の適用試行**: use_extended_stats が真であり、条件群が単一のリレーションを参照し、かつそのリレーションに拡張統計（statlist）が存在する場合、statext_clauselist_selectivity を呼び出して複数条件を一括見積もりし、初期選択度 s1 と除外すべきインデックスリスト estimatedclauses を得ます。 3. **残余条件のループ処理**: clauses を走査し、estimatedclauses に含まれるものはスキップし、それ以外の各句について個別選択度 s2 を clause_selectivity_ext で算出します。

  • RestrictInfo のうち pseudoconstant が真のものは、単純に s1 = s1 * s2 として累積します。
  • 2引数の演算子句であり、かつ片側に疑似定数を持つ比較演算子（<, <=, >, >=）である場合、get_oprrest の結果に応じて addRangeClause を呼び出し、rqlist に登録して範囲クエリペアの候補とします。
  • それ以外の条件は一般の独立条件として s1 = s1 * s2 により累積します。

    • 4. **範囲クエリペアリストの走査と補正**: rqlist を順次走査し、下限（lobound）と上限（hibound）の両方が揃っているペアに対しては、s2 = hibound + lobound - 1.0 をベースに nulltestsel による NULL の二重除外調整を加えます。

  • 計算された s2 が 0 以下の場合、丸め誤差程度であれば 1.0e-10 に調整し、極端な負数であればデフォルトの範囲不等式選択度（DEFAULT_RANGE_INEQ_SEL）にフォールバックします。
  • ペアの片方しか見つからない場合は、存在する方の選択度をそのまま適用します。
  • 処理済みの rqlist 要素は pfree で順次解放します。

    • 5. **結果の返却**: 最終的に累積された選択度 s1 を返却します。

失敗モードと境界条件

  • 範囲クエリの計算結果 s2 がゼロ以下になった際、-0.01 未満の過度に負の値である場合は推定値の欠落とみなされ、DEFAULT_RANGE_INEQ_SEL に置き換えられます。
  • 範囲クエリの境界値がデフォルトの不等式選択度（DEFAULT_INEQ_SEL）そのままである場合、統計情報が不足していると判断され、選択度は DEFAULT_RANGE_INEQ_SEL に置き換えられます。
