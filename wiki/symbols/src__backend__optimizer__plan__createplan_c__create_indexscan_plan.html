目的

インデックスパス（IndexPath）から、実際の実行エンジンが処理可能なインデックススキャンまたはインデックスオンリースキャンのプランノード（Scan *）を構築します。

シグネチャまたは形状

  • シグネチャ: static Scan * create_indexscan_plan(PlannerInfo *root, IndexPath *best_path, List *tlist, List *scan_clauses, bool indexonly)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報を保持する構造体ポインタ。
  • IndexPath *best_path: 最適と判定されたインデックスパス。
  • List *tlist: ターゲットリスト。
  • List *scan_clauses: スキャン対象の制限条件リスト。
  • bool indexonly: インデックスオンリースキャンを行うかどうかのフラグ。
  • 戻り値:
  • Scan *: 構築されたインデックススキャンまたはインデックスオンリースキャンのプランノードを返します。

前提条件と不変条件

  • ベースリレーション（baserelid > 0）であり、範囲変数種別が RTE_RELATION である必要があります。
  • スキャン方向（best_path->indexscandir）は ForwardScanDirection または BackwardScanDirection のいずれかである必要があります。

アルゴリズムまたは振る舞い

1. 参照の検証: baserelid の正当性や rtekind、インデックススキャン方向の妥当性をアサートで確認します。 2. インデックス修飾句の修正: fix_indexqual_references を用いてインデックス条件式を抽出・複製し、テーブル変数からインデックス変数への置換やネストループパラメータの置き換えを行います。また、fix_indexorderby_references を用いてORDER BY式内のインデックス属性参照も修正します。 3. qpqual（残余修飾条件）の構築: scan_clauses を走査し、以下の条件に該当するものを除外しながら qpqual リストを構築します。

  • 擬似定数（pseudoconstant）である場合
  • is_redundant_with_indexclauses により、インデックス句と重複または同一同値クラスから生成された冗長な句である場合
  • 条件式が不変関数のみで構成され、かつ stripped_indexquals によって論理的に含意（predicate_implied_by）される場合

    • 4. qpqual の順序化と抽出: 残った qpqual 条件を order_qual_clauses で最適実行順序に並び替え、extract_actual_clauses で RestrictInfo リストから実際の式へ落とし込みます。 5. ネストループパラメータの置換: パラメータ化されたパスの場合、replace_nestloop_params を使用して stripped_indexquals、qpqual、indexorderbys 内の外部リレーション変数をネストループパラメータに置換します。 6. ソート演算子のルックアップ: indexorderbys が存在する場合、パスキーと式からデータ型を求め、オペレータファミリから対応するソート演算子（indexorderbyops）を取得します。該当する演算子が見つからない場合はエラーログを出力します。 7. インデックスオンリースキャン時のターゲットリスト処理: indexonly が真の場合、インデックスアクセス方式が返せない列を持つ indextlist エントリの resjunk を真に設定します。 8. プランノードの生成: indexonly の値に応じて make_indexonlyscan または make_indexscan を呼び出してスキャン計画ノードを作成し、最後に copy_generic_path_info でパスの共通情報をコピーして返します。

失敗モードと境界条件

  • best_path->indexscandir が前方向（ForwardScanDirection）または後方向（BackwardScanDirection）以外である場合はアサート違反となります。
  • indexorderbys が指定されているにもかかわらず、対応するソート演算子がオぺレータファミリ内に見つからない場合、ERROR レベルのログ（elog）が送出されます。
