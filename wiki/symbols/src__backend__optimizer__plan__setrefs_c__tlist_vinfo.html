ソース抜粋

~~~c typedef struct { int varno; /* RT index of Var */ AttrNumber varattno; /* attr number of Var */ AttrNumber resno; /* TLE position of Var */ Bitmapset *varnullingrels; /* Var's varnullingrels */ } tlist_vinfo; ~~~

目的

ターゲットリスト中の個々の単純変数（Var）に関する位置情報（範囲テーブルインデックス、属性番号、ターゲットリスト位置、ヌリング関係）を保持する軽量構造体です。

フィールドと表現

  • int varno: 変数（Var）が属する範囲テーブル（RT）のインデックスを保持します。
  • AttrNumber varattno: 変数（Var）の属性番号を保持します。
  • AttrNumber resno: 変数（Var）に対応するターゲットリストエントリー（TLE）の位置を保持します。
  • Bitmapset *varnullingrels: 変数（Var）の varnullingrels ビットマップセットを保持します。
