目的

与えられた式ツリーまたは句（clause）が参照しているベースリレーションのうち、外部結合リレーションを除外した実質的なリレーションの数を計算します。

シグネチャまたは形状

  • シグネチャ: int NumRelids(PlannerInfo *root, Node *clause)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報。外部結合リレーションの集合（outer_join_rels）を参照するために使用します。
  • Node *clause: 評価対象の式または句のツリー。
  • 戻り値:
  • int: 外部結合リレーションを除外した後に残った、句が参照するリレーションの数。

前提条件と不変条件

  • pull_varnos によって動的に割り当てられた Relids（Bitmapset）は、関数を抜ける前に必ず bms_free を呼び出して解放されなければなりません。

アルゴリズムまたは振る舞い

1. pull_varnos(root, clause) を呼び出し、対象の句に含まれる変数から参照されている全リレーションのビットマップ（Relids）を取得します。 2. bms_del_members を使用して、取得した varnos から root->outer_join_rels に含まれる外部結合リレーションのビットを削除します。 3. bms_num_members を用いて、残ったリレーションの数をカウントし、結果を result に格納します。 4. bms_free を呼び出して、一時的に確保した varnos ビットマップを解放します。 5. 計算された result を返します。

失敗モードと境界条件

  • **参照リレーションが存在しない場合**: 句（clause）にリレーションを参照する変数が含まれていない場合、pull_varnos は空のセット（NULL）を返します。この場合、bms_del_members や bms_num_members、bms_free は NULL を安全に処理し、最終的な戻り値は 0 になります。
  • **すべてのリレーションが外部結合リレーションである場合**: 句が参照するすべてのリレーションが root->outer_join_rels に含まれている場合、bms_del_members によってすべてのビットが削除され、結果として 0 が返されます。
  • **外部結合リレーションが定義されていない場合**: root->outer_join_rels が NULL（空）である場合、bms_del_members は元の varnos をそのまま返すため、外部結合の除外は行われず、句が参照する全リレーションの数がそのまま返されます。
