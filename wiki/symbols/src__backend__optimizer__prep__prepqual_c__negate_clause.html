目的

与えられたブール式を論理的に否定した、等価な式を構築して返却する。

シグネチャまたは形状

Node *negate_clause(Node *node)

入力と出力

  • 入力: Node *node — 否定対象となるブール式ノード。
  • 出力: Node * — 否定変換が適用された新しい式ノード、または単純化できない場合に NOT 節でラップされたノード。

前提条件と不変条件

  • 入力ノード node は NULL であってはならない。
  • 入力される NOT 節は、すでに単純化されている（二重否定などが解消されている）ことを前提とする。

アルゴリズムまたは振る舞い

入力ノードのタグ（nodeTag）に応じて、以下の分岐処理を行う。

1. 定数 (T_Const):

  • 定数が NULL の場合は、FALSE かつ null の定数を返す。
  • それ以外の場合は、ブール値を反転した定数を作成して返す。

    • 2. 演算子式 (T_OpExpr):

  • 演算子に対応する否定演算子（negator）が存在する場合、演算子 ID を置換した新しい OpExpr を構築して返す。

    • 3. 配列に対するスカラー演算子式 (T_ScalarArrayOpExpr):

  • 演算子に対応する否定演算子が存在する場合、演算子 ID を置換し、useOr フラグを反転させた新しい ScalarArrayOpExpr を構築して返す（例: x = ANY (list) を x <> ALL (list) に変換）。

    • 4. ブール演算子式 (T_BoolExpr):

  • AND_EXPR: 各引数に対して再帰的に negate_clause を適用し、その結果を引数とする OR 節（make_orclause）を構築して返す（ド・モルガンの法則）。
  • OR_EXPR: 各引数に対して再帰的に negate_clause を適用し、その結果を引数とする AND 節（make_andclause）を構築して返す（ド・モルガンの法則）。
  • NOT_EXPR: 二重否定を相殺し、内側の最初の引数をそのまま返す。

    • 5. NULLテスト (T_NullTest):

  • 行型（rowtype）でないスカラーデータ型の場合に限り、IS_NULL と IS_NOT_NULL を反転させた新しい NullTest ノードを構築して返す。

    • 6. ブールテスト (T_BooleanTest):

  • IS_TRUE ⇔ IS_NOT_TRUE、IS_FALSE ⇔ IS_NOT_FALSE、IS_UNKNOWN ⇔ IS_NOT_UNKNOWN の相互変換を行った新しい BooleanTest ノードを構築して返す。

    • 7. その他（デフォルト）:

  • 上記のいずれにも該当しない、または単純化できない場合は、明示的な NOT 節（make_notclause）でラップしたノードを構築して返す。

失敗モードと境界条件

  • 入力 node が NULL の場合、can't negate an empty subexpression というエラーを発生させる。
  • 未知の boolop や booltesttype に遭遇した場合、それぞれ ERROR を発生させる。
  • 行型（rowtype）に対する NullTest の場合、IS_NULL と IS_NOT_NULL は論理的逆元にならないため、単純化を行わずに明示的な NOT 節の付与にフォールバックする。
