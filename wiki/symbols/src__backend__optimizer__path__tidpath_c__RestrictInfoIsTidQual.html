~~~c static bool RestrictInfoIsTidQual(PlannerInfo *root, RestrictInfo *rinfo, RelOptInfo *rel) { /*

  • We may ignore pseudoconstant clauses (they can't contain Vars, so could
  • not match anyway).

    • */ if (rinfo->pseudoconstant) return false;

/*

  • If clause must wait till after some lower-security-level restriction
  • clause, reject it.

    • */ if (!restriction_is_securely_promotable(rinfo, rel)) return false;

  • Check all base cases.

    • */ if (IsTidEqualClause(rinfo, rel) || IsTidEqualAnyClause(root, rinfo, rel) || IsCurrentOfClause(rinfo, rel)) return true;

return false; } ~~~

目的

与えられた制限情報（RestrictInfo）が、擬似定数ではなく、かつセキュリティ昇格要件を満たした上で、有効なTID条件（TID等価条件、配列のTID等価条件、または CURRENT OF 条件）のいずれかに該当するかを判定します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報
  • RestrictInfo *rinfo: 検査対象の制限情報
  • RelOptInfo *rel: 対象リレーションの情報
  • 戻り値:
  • bool: 条件が有効なTID条件として使用可能な場合は true、それ以外の場合は false

前提条件と不変条件

  • 擬似定数（pseudoconstant が真であるもの）は、変数を含まないためTID条件として一致し得ず、常に拒否されます。
  • より低いセキュリティレベルの制限条件より後まで待たなければならない条件は、安全に昇格できないため拒否されます。

アルゴリズムまたは振る舞い

1. 引数 rinfo の pseudoconstant フラグが設定されている場合は、直ちに false を返します。 2. restriction_is_securely_promotable(rinfo, rel) を呼び出し、セキュリティ昇格が可能であるか検証します。不可能な場合は直ちに false を返します。 3. 以下のいずれかのベースケースに該当するかを順に評価します。

  • IsTidEqualClause(rinfo, rel) （TIDと値の等価比較）
  • IsTidEqualAnyClause(root, rinfo, rel) （TIDの配列等価比較）
  • IsCurrentOfClause(rinfo, rel) （CURRENT OF カーソル参照条件）

    • 4. いずれかの条件を満たす場合は true を返し、どれにも一致しない場合は false を返します。

失敗モードと境界条件

  • 該当するベースケースが存在しない場合や前提条件（擬似定数・セキュリティ制約）を満たさない場合は、エラーを起こさず安全に false を返します。
