目的

指定された RestrictInfo が対象リレーションに対する二項 TID 等価条件であるかどうかを検査する。

入力と出力

  • 引数: RestrictInfo *rinfo, RelOptInfo *rel
  • 戻り値: 条件が二項 TID 等価条件に一致する場合は true、そうでない場合は false を返す。

前提条件と不変条件

  • rinfo は RestrictInfo 構造体を指し示す有効なポインタであること。
  • rel は対象のリレーション情報を表す RelOptInfo であること。

アルゴリズムまたは振る舞い

1. IsBinaryTidClause(rinfo, rel) を呼び出し、条件が二項 TID 演算子式であるかを検査する。 2. 二項 TID 演算子式でない場合は直ちに false を返す。 3. rinfo->clause を OpExpr * にキャストし、その演算子番号 (opno) が TIDEqualOperator と一致するかを評価する。 4. 一致する場合は true を返し、一致しない場合は false を返す。

失敗モードと境界条件

  • rinfo->clause が OpExpr 以外のノード型である場合や、演算子が TIDEqualOperator でない場合は安全に false を返す。
