  • Randomly generates a legal "traveling salesman" tour
  • (i.e. where each point is visited only once.)

    • */ void init_tour(PlannerInfo *root, Gene *tour, int num_gene) { int i, j;

/*

  • We must fill the tour[] array with a random permutation of the numbers
  • 1 .. num_gene. We can do that in one pass using the "inside-out"
  • variant of the Fisher-Yates shuffle algorithm. Notionally, we append
  • each new value to the array and then swap it with a randomly-chosen
  • array element (possibly including itself, else we fail to generate
  • permutations with the last city last). The swap step can be optimized
  • by combining it with the insertion.

    • */ if (num_gene > 0) tour[0] = (Gene) 1;

for (i = 1; i < num_gene; i++) { j = geqo_randint(root, i, 0); /* i != j check avoids fetching uninitialized array element */ if (i != j) tour[i] = tour[j]; tour[j] = (Gene) (i + 1); } } ~~~

目的

GEQO（遺伝的クエリ最適化）の巡回セールスマン問題のツアー初期化において、ツアーに含まれる遺伝子（都市）の総数を表します。

入力と出力

  • 入力: 遺伝子の総数を表す整数値 num_gene。
  • 出力: なし（パラメータおよび値の範囲指定として機能する）。

前提条件と不変条件

  • num_gene は init_tour 関数においてツアー配列のサイズおよび順列の範囲（1 から num_gene まで）を決定します。
  • num_gene > 0 の場合、tour[0] には初期値 1 が設定されます。

アルゴリズムまたは振る舞い

  • init_tour 内のループ制御において、i が 1 から num_gene - 1 までインクリメントされながら Fisher-Yates シャッフル（インサイドアウトバリアント）の範囲指定に利用されます。
  • 各イテレーションでは geqo_randint(root, i, 0) を呼び出す際の上限境界として num_gene に依存する i が渡されます。

失敗モードと境界条件

  • num_gene が 0 以下の場合、init_tour 内の tour[0] = (Gene) 1; 代入およびシャッフルループは実行されません。
