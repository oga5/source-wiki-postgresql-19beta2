ソース抜粋

~~~c typedef struct NotnullHashEntry { Oid relid; /* OID of the relation */ Bitmapset *notnullattnums; /* attnums of NOT NULL columns */ } NotnullHashEntry; ~~~

目的

NotnullHashEntry は、リレーションの OID と、そのリレーションにおける NOT NULL カラムの属性番号（attnum）を表すビットマップを紐付けてハッシュテーブル内で管理するための構造体である。プランナの処理中において、リレーションごとの NOT NULL 制約情報をキャッシュするために使用される。

フィールドと表現

  • relid: 対象リレーションの OID を保持する Oid 型のフィールド。
  • notnullattnums: NOT NULL 制約が設定されているカラムの属性番号（attnum）を保持する Bitmapset へのポインタ。
