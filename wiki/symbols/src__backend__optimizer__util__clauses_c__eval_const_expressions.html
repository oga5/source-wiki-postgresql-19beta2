ソース抜粋

~~~c Node * eval_const_expressions(PlannerInfo *root, Node *node) { eval_const_expressions_context context;

if (root) context.boundParams = root->glob->boundParams; /* bound Params */ else context.boundParams = NULL; context.root = root; /* for inlined-function dependencies */ context.active_fns = NIL; /* nothing being recursively simplified */ context.case_val = NULL; /* no CASE being examined */ context.estimate = false; /* safe transformations only */ return eval_const_expressions_mutator(node, &context); } ~~~

目的

eval_const_expressions は、式ツリー内の定数式やバインドされたパラメータを評価・単純化し、安全な変換のみを行うためのエントリポイント関数です。

シグネチャまたは形状

  • Node * eval_const_expressions(PlannerInfo *root, Node *node)

入力と出力

  • 入力:
  • PlannerInfo *root: プランナー情報構造体（インライン化された関数の依存関係等の取得に使用され、NULL の場合もある）
  • Node *node: 対象となる式ツリーのノード
  • 出力:
  • Node *: 定数畳み込みおよび単純化が適用された新しい式ツリーのノードを返します。

前提条件と不変条件

  • root が有効な場合、その glob->glob->boundParams（または root->glob->boundParams）からバインドされたパラメータを取得します。
  • estimate フラグは false に初期化され、安全な変換のみが実行されます。

アルゴリズムまたは振る舞い

1. ローカルの eval_const_expressions_context 構造体を宣言し、初期化します。 2. root が非 NULL の場合は root->glob->boundParams をコンテキストの boundParams に設定し、NULL の場合は NULL を設定します。 3. コンテキストの root フィールドに引数の root を格納し、再帰的に単純化中のアクティブ関数リスト active_fns を NIL に、検査中の CASE 式 case_val を NULL に、estimate を false にそれぞれ設定します。 4. 構築したコンテキストと入力ノードを引数として eval_const_expressions_mutator を呼び出し、その結果を返します。

失敗モードと境界条件

  • root 引数が NULL の場合、バインドされたパラメータの参照先は NULL にフォールバックします。
