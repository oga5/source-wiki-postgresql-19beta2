ソース抜粋

~~~c typedef struct { PlannerInfo *root; indexed_tlist *subplan_itlist; int newvarno; } fix_windowagg_cond_context; ~~~

目的

WindowAggノードの実行条件（runCondition）内で WindowFunc を対応する Var に置き換えるための式変換コンテキストとして機能します。

フィールドと表現

  • PlannerInfo *root: クエリ全体の計画情報を保持するグローバルなコンテキストへのポインタ。
  • indexed_tlist *subplan_itlist: 子プランのターゲットリストをインデックス化した構造体へのポインタ。
  • int newvarno: 変換処理において変数（Var）の varno として割り当てる新しい識別番号。
