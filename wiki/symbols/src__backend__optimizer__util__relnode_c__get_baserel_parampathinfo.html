~~~c ParamPathInfo * get_baserel_parampathinfo(PlannerInfo *root, RelOptInfo *baserel, Relids required_outer) { ParamPathInfo *ppi; Relids joinrelids; List *pclauses; List *eqclauses; Bitmapset *pserials; double rows; ListCell *lc;

/* If rel has LATERAL refs, every path for it should account for them */ Assert(bms_is_subset(baserel->lateral_relids, required_outer));

/* Unparameterized paths have no ParamPathInfo */ if (bms_is_empty(required_outer)) return NULL;

Assert(!bms_overlap(baserel->relids, required_outer));

/* If we already have a PPI for this parameterization, just return it */ if ((ppi = find_param_path_info(baserel, required_outer))) return ppi;

/*

  • Identify all joinclauses that are movable to this base rel given this
  • parameterization.

    • */ joinrelids = bms_union(baserel->relids, required_outer); pclauses = NIL; foreach(lc, baserel->joininfo) { RestrictInfo *rinfo = (RestrictInfo *) lfirst(lc);

if (join_clause_is_movable_into(rinfo, baserel->relids, joinrelids)) pclauses = lappend(pclauses, rinfo); }

/*

  • Add in joinclauses generated by EquivalenceClasses, too. (These
  • necessarily satisfy join_clause_is_movable_into; but in assert-enabled
  • builds, let's verify that.)

    • */ eqclauses = generate_join_implied_equalities(root, joinrelids, required_outer, baserel, NULL); #ifdef USE_ASSERT_CHECKING foreach(lc, eqclauses) { RestrictInfo *rinfo = (RestrictInfo *) lfirst(lc);

Assert(join_clause_is_movable_into(rinfo, baserel->relids, joinrelids)); } ~~~

目的

ベース関係（baserel）に対して指定された外部パラメータ（required_outer）を満たすパラメータ付きパス情報（ParamPathInfo）を検索・生成する。

シグネチャまたは形状

  • シグネチャ: ParamPathInfo * get_baserel_parampathinfo(PlannerInfo *root, RelOptInfo *baserel, Relids required_outer)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報を保持する構造体へのポインタ
  • RelOptInfo *baserel: 対象となるベース関係の構造体へのポインタ
  • Relids required_outer: このパスが必要とする外部リレーションの識別子セット
  • 戻り値:
  • ParamPathInfo *: 該当するパラメータ化情報構造体へのポインタ、または無効な場合の NULL

前提条件と不変条件

  • ベース関係が LATERAL 参照を持つ場合、すべてのパスがそれらを考慮している必要があるため、baserel->lateral_relids は required_outer の部分集合でなければならない。
  • 非パラメータ化パスは ParamPathInfo を持たないため、required_outer が空である場合は NULL を返す。
  • ベース関係自身の識別子セットと外部パラメータの識別子セット（required_outer）が重複してはならない。

アルゴリズムまたは振る舞い

1. 前提条件の検証: baserel->lateral_relids が required_outer の部分集合であることをアサートで確認し、required_outer が空であれば NULL を返す。また、baserel->relids と required_outer が重複していないことを検証する。 2. キャッシュ済み情報の検索: find_param_path_info を用いて、指定されたパラメータ化に対する既存の ParamPathInfo が既に存在するか確認し、存在する場合はそれをそのまま返す。 3. 移動可能結合条件の特定: baserel->relids と required_outer の結合集合（joinrelids）を算出し、baserel->joininfo 内の各制限情報（RestrictInfo）に対して join_clause_is_movable_into を評価し、移動可能な結合条件を pclauses に収集する。 4. 同値クラス由来の等価条件の追加: generate_join_implied_equalities を呼び出して同値クラスから生成される結合条件（eqclauses）を取得し、アサート有効時であればそれらも移動可能であることを検証した上で、pclauses に結合する。 5. シリアル番号の収集とサイズ見積もり: 収集したすべての制限情報からシリアル番号のビットマップセット（pserials）を構築し、get_parameterized_baserel_size を用いてパラメータ化スキャンが返す行数を推計する。 6. ParamPathInfo の構築と登録: 新しい ParamPathInfo ノードを確保して各フィールドを設定し、それを baserel->ppilist に追加して返す。

失敗モードと境界条件

  • required_outer が空（bms_is_empty が真）の場合、有効なパラメータ化は存在しないため直ちに NULL が返される。
  • 既に同一の required_outer に対する ParamPathInfo が存在する場合は新規作成を行わず、既存のキャッシュされた構造体が返される。
