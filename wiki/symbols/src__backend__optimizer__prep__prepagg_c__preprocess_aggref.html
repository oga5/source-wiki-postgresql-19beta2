目的

preprocess_aggref は、単一の集約関数呼び出し（Aggref）ノードに対してシステムカタログ（pg_aggregate）から情報を取得し、多態的な遷移型の解決、重複集約や共有可能な遷移状態の検索、およびコスト見積もりや部分集約の実行可否判定のための構造体登録を行うインプレース前処理関数である。

シグネチャまたは形状

  • static void preprocess_aggref(Aggref *aggref, PlannerInfo *root)

入力と出力

  • 引数:
  • Aggref *aggref: 前処理対象の集約関数呼び出しノード
  • PlannerInfo *root: プランナのグローバル情報および集約リストを保持する構造体
  • 戻り値:
  • なし（void）

前提条件と不変条件

  • aggref->agglevelsup == 0 であること（サブクエリの集約ではない、カレントクエリレベルの集約であること）がアサーションで検証される。
  • 入力された Aggref ノードのフィールド（aggtranstype, aggno, aggtransno）は、本関数の実行によってインプレースで書き換えられる。

アルゴリズムまたは振る舞い

1. カタログ情報の取得:

  • aggref->aggfnoid をキーに AGGFNOID システムキャッシュを検索し、対応する pg_aggregate タプルを取得する。
  • 遷移関数、結合関数、シリアライズ/デシリアライズ関数、遷移型、遷移空間などの各属性を抽出する。

    • 2. 多態的遷移型の解決:

  • get_aggregate_argtypes により引数の型群を抽出し、resolve_aggregate_transtype を用いて多態的な集約遷移型（aggtranstype）を実際のデータ型へ解決して aggref->aggtranstype に設定する。
  • 最初の引数と遷移型が同一である場合は、その型修飾子（aggtranstypmod）を引き継ぐ。

    • 3. 共有可能性と初期値の取得:

  • 最終関数が AGGMODIFY_READ_WRITE でマークされている場合は状態共有不可（shareable = false）とする。
  • 出力値の型長および byval 属性を取得し、さらに SysCacheGetAttr と GetAggInitVal を用いて初期値（initValue）を取得する。
  • 読み込みに使用したシステムキャッシュタプルを解放する。

    • 4. 既存集約との重複チェック (find_compatible_agg):

  • 完全に同一の集約呼び出しがすでに存在するかを検索する。
  • 一致するものが見つかった場合は既存の agginfo に aggref を追加し、既存の transno を流用する。

    • 5. 新規集約情報の登録と遷移状態の共有チェック (find_compatible_trans):

  • 一致する集約がない場合は新規に AggInfo ノードを作成して root->agginfos に追加する。
  • 順序付き集約（aggorder または aggdistinct が存在する場合）である場合は、順序付き集約数および非部分集約フラグ（root->hasNonPartialAggs）をインクリメント・設定する。
  • 既存の遷移状態の中で入力を共有できるものを find_compatible_trans で検索する。
  • 互換性のある遷移状態が見つからない場合は新規に AggTransInfo を作成して root->aggtransinfos に追加し、結合関数やシリアライズ関数、INTERNAL 型に関する部分集約・シリアライズの実行可否を評価してフラグを更新する。

    • 6. インプレース更新:

  • 確定した aggno および transno を aggref->aggno と aggref->aggtransno に格納する。

失敗モードと境界条件

  • aggref->aggfnoid に対するシステムキャッシュ (AGGFNOID) の検索に失敗し、取得したヒープタプルが無効な場合は elog(ERROR) によりエラー終了する。

保守担当者向けメモ

  • 本関数は引数として渡された Aggref 構造体のフィールドを直接書き換える副作用を持つ。
