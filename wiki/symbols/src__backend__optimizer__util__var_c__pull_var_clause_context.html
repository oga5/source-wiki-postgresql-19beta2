目的

pull_var_clause_context は、式ツリーから変数を抽出する処理（pull_var_clause）において、抽出されたノードのリストと、集約関数やウィンドウ関数、プレースホルダーなどの扱いを指定するフラグを保持するための走査コンテキスト構造体です。

フィールドと表現

  • List *varlist: 抽出された変数や関連ノードを蓄積するためのリストポインターです。
  • int flags: 抽出動作や許容するノードの種類を制御するためのフラグ群を保持する整数フィールドです。
