目的

指定された制限情報（RestrictInfo）の節が、対象のリレーション（RelOptInfo）を参照する CURRENT OF 式（CurrentOfExpr）であるかどうかを判定します。

シグネチャまたは形状

  • シグネチャ: static bool IsCurrentOfClause(RestrictInfo *rinfo, RelOptInfo *rel)

入力と出力

  • **rinfo**: 検査対象の制限情報（RestrictInfo 構造体へのポインタ）。
  • **rel**: 照合対象のリレーション情報（RelOptInfo 構造体へのポインタ）。
  • **戻り値**: rinfo の節が rel を参照する CurrentOfExpr である場合は true、それ以外の場合は false を返します。

前提条件と不変条件

  • 引数 rinfo および rel は、有効な構造体を指すポインタである必要があります。
  • rinfo->clause が NULL である場合、または CurrentOfExpr 型でない場合は、安全に false を返します。

アルゴリズムまたは振る舞い

1. **ノード型の検査**: rinfo->clause が存在し、かつそのノード型が CurrentOfExpr であるかを IsA マクロを用いて判定します。この条件を満たさない場合は、即座に false を返します。 2. **リレーションIDの照合**: rinfo->clause を CurrentOfExpr * にキャストし、その式が参照する変数範囲番号（node->cvarno）が、対象リレーションのID（rel->relid）と一致するかを比較します。一致する場合は true を、一致しない場合は false を返します。

呼び出し元と呼び出し先

  • **呼び出し元**: RestrictInfoIsTidQual および TidQualFromRestrictInfoList から呼び出されます。
  • **呼び出し先**: IsA マクロを呼び出してノード型を判定します。

関連データ構造

  • RestrictInfo
  • RelOptInfo
  • CurrentOfExpr

失敗モードと境界条件

  • rinfo->clause が NULL の場合、最初の条件式における rinfo->clause の評価が偽となるため、ヌルポインタ参照を起こすことなく安全に false を返します。
