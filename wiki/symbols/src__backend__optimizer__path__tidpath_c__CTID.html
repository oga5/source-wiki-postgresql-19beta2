目的

指定された Var ノードが、対象リレーションの ctid 列（SelfItemPointerAttributeNumber、型 TIDOID）を正確に指しているかを検証する。

入力と出力

  • 入力:
  • Var *var: 検査対象の変数ノード。 ``
  • RelOptInfo *rel: 照合先のリレーション情報。 ``
  • 出力:
  • bool: 条件に一致する場合は true、そうでない場合は false を返す。 ``

前提条件と不変条件

  • 変数の属性番号が SelfItemPointerAttributeNumber であること。 ``
  • 変数の型が TIDOID であること。 ``
  • 変数のリレーション識別子 (varno) が rel->relid と一致すること。 ``
  • 変数のヌルリングリレーション (varnullingrels) が NULL であること。 ``
  • 変数のサブクエリレベルアップ (varlevelsup) が 0 であること。 ``

アルゴリズムまたは振る舞い

  • var->varattno が SelfItemPointerAttributeNumber かつ var->vartype が TIDOID であるかをチェックし、パラノイア的な厳密な型確認を行う。 ``
  • さらに、var->varno == rel->relid、var->varnullingrels == NULL、および var->varlevelsup == 0 の各条件をすべて満たすかどうかを評価する。 ``
  • すべての条件が真であれば true を返し、一つでも満たさない場合は false を返す。 ``

失敗モードと境界条件

  • 対象ノードが Var 以外のノード構造である場合や、他リレーションを指している場合、あるいは上位クエリの変数やヌルリングを伴う場合には false が返される。 ``
