目的

集合演算ノード用の子孫参照ターゲットリスト（tlist）を生成し、必要に応じて型キャストやコレーションの調整を行う。

シグネチャまたは形状

  • シグネチャ: static List * generate_setop_tlist(List *colTypes, List *colCollations, Index varno, bool hack_constants, List *input_tlist, List *refnames_tlist, bool *trivial_tlist)

入力と出力

  • 引数:
  • List *colTypes: 出力列のデータ型（Oid）のリスト
  • List *colCollations: 出力列のコレーション（Oid）のリスト
  • Index varno: 入力列を指し示す変数番号（リレーションIDまたは0）
  • bool hack_constants`: 定数をサブクエリ出力の参照にせずそのままコピーするかどうかのフラグ
  • List *input_tlist: 入力側のターゲットリスト（TargetEntry のリスト）
  • List *refnames_tlist: 参照名用のターゲットリスト（列名の取得元）
  • bool *trivial_tlist: 自明なターゲットリストであるかどうかを収める出力パラメータ
  • 戻り値: 構築された TargetEntry のリスト（List *）

前提条件と不変条件

  • 入力される input_tlist と refnames_tlist の各エントリの resno は、処理対象の列番号 resno（1から開始）と一致していなければならない。
  • 入力側の TargetEntry および参照用の TargetEntry はいずれも resjunk であってはならない。
  • 集合演算ツリーのすべての出力列において、出力列の ressortgroupref は自身の resno と等しく設定される。

アルゴリズムまたは振る舞い

1. **初期化**: 出力パラメータ *trivial_tlist を true に設定し、結果のターゲットリスト tlist を NIL、列番号 resno を 1 に初期化する。 2. **列ごとのループ**: colTypes, colCollations, input_tlist, refnames_tlist の4つのリストを同時に走査（forfour）する。 3. **入力式の抽出・ハック適用**:

  • hack_constants が真であり、かつ入力式が Const ノードである場合は、サブクエリ出力の参照ではなく定数式をそのまま使用する（主に UNKNOWN 定数の型調整のため）。
  • それ以外の場合は、指定された varno と入力列の属性番号・型・型モディファイア・コレーションを持つ Var ノードを makeVar で生成する。

    • 4. **データ型の強制（Coercion）**:

  • 式の型が目標の colType と一致しない場合、coerce_to_common_type を用いて共通型へのキャストを挿入する。このとき、型変換が行われた場合は *trivial_tlist を false に設定する。

    • 5. **コレーションの調整**:

  • 式のコレーションが目標の colColl と一致しない場合、applyRelabelType を用いてコレーションを適合させる。このとき、適用が行われた場合は *trivial_tlist を false に設定する。

    • 6. **ターゲットエントリの作成と追加**:

  • 参照名リスト（refnames_tlist）から列名（resname）を複製して取得し、調整済みの式、連番の resno、列名を持つ TargetEntry を makeTargetEntry で生成する。
  • 生成した TargetEntry の ressortgroupref に自身の resno を割り当て、lappend で tlist に追加する。

    • 7. **終了**: すべての列の処理が完了したあと、構築された tlist を返す。

失敗モードと境界条件

  • 入力リスト間の要素数が一致していない場合、forfour マクロの前提が崩れ、想定外の動作やアサーション違反を引き起こす可能性がある。
  • inputtle->resno および reftle->resno が期待される resno と一致しない場合、Assert 失敗により処理が中断される。
