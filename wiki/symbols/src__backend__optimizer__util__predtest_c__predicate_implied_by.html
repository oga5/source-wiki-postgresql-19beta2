~~~c bool predicate_implied_by(List *predicate_list, List *clause_list, bool weak) { Node *p, *c;

if (predicate_list == NIL) return true; /* no predicate: implication is vacuous */ if (clause_list == NIL) return false; /* no restriction: implication must fail */

/*

  • If either input is a single-element list, replace it with its lone
  • member; this avoids one useless level of AND-recursion. We only need
  • to worry about this at top level, since eval_const_expressions should
  • have gotten rid of any trivial ANDs or ORs below that.

    • */ if (list_length(predicate_list) == 1) p = (Node *) linitial(predicate_list); else p = (Node *) predicate_list; if (list_length(clause_list) == 1) c = (Node *) linitial(clause_list); else c = (Node *) clause_list;

/* And away we go ... */ return predicate_implied_by_recurse(c, p, weak); } ~~~

目的

制限句のリスト（clause_list）が述語のリスト（predicate_list）を論理的に含意するかどうかをトップレベルで判定する。

入力と出力

  • 引数:
  • List *predicate_list: 含意されているか検証される述語のリスト
  • List *clause_list: 含意を証明するために使用する制限句のリスト
  • bool weak: 弱い含意ルールを適用するかどうかを示すフラグ
  • 戻り値:
  • bool: 条件を満たす場合は true、そうでない場合は false

前提条件と不変条件

  • predicate_list が空（NIL）の場合は無条件で含意が成立するため true を返す。
  • clause_list が空（NIL）の場合は制限が存在しないため含意が不成立となり false を返す。

アルゴリズムまたは振る舞い

1. predicate_list または clause_list が空であるかをチェックし、空であればそれぞれ早期に true または false を返す。 2. predicate_list の要素数が 1 の場合はその単一の要素を抽出し、複数要素の場合はリストのまま扱う。 3. clause_list の要素数が 1 の場合はその単一の要素を抽出し、複数要素の場合はリストのまま扱う。単一要素のアンラップにより、無用な AND 再帰のレベルを避ける。 4. 抽出または調整されたノードを引数として predicate_implied_by_recurse を呼び出し、その結果を返す。

失敗モードと境界条件

  • 入力リストの一方が空リストである場合、再帰評価を行わずに直ちに結果が確定する。
