目的

エッジテーブル (edge_table) を使用して、GEQOの辺組換え交叉（ERX）における新しい子ツアー (new_gene) を構築します。

シグネチャまたは形状

  • シグネチャ: int gimme_tour(PlannerInfo *root, Edge *edge_table, Gene *new_gene, int num_gene)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報へのポインタ。
  • Edge *edge_table: 構築済みのエッジテーブル。
  • Gene *new_gene: 生成される新しい遺伝子（ツアー）の配列格納先。
  • int num_gene: 遺伝子の総数（ツアー長）。
  • 戻り値: int 形質構築中に発生したエッジ障害（フォールバック）の総数。

前提条件と不変条件

  • ツアーの最初の遺伝子 new_gene[0] は 1 から num_gene の間のランダムな整数として初期化されます。
  • ツアーに組み込まれたノードは、エッジテーブル上で unused_edges = -1 にマークされます。

アルゴリズムまたは振る舞い

  • ランダムに選んだ最初の遺伝子を new_gene[0] に設定します。
  • 1 から num_gene - 1 までの各ステップで以下を繰り返します:
  • remove_gene を呼び出して、直前の遺伝子をエッジテーブルから削除します。
  • 直前の遺伝子の unused_edges が 0 より大きい場合は、gimme_gene を呼び出して次の遺伝子を決定します。
  • そうでない場合はフォールバックとして edge_failures をインクリメントし、edge_failure を呼び出して代替の遺伝子を選択します。
  • 処理したノードのエッジテーブル上の unused_edges を -1 に変更して組み込み済みであることをマークします。
  • 最終的に発生したエッジ障害の総数 (edge_failures) を返します。

呼び出し元と呼び出し先

  • 呼び出し元: geqo (src/backend/optimizer/geqo/geqo_main.c)
  • 呼び出し先: geqo_randint, remove_gene, gimme_gene, edge_failure

関連データ構造

  • PlannerInfo
  • Edge
  • Gene

失敗モードと境界条件

  • エッジの有効な接続先が枯渇している（unused_edges <= 0）状態に陥った場合、edge_failure を呼び出してフォールバック処理を行い、障害カウンタ (edge_failures) を加算します。
