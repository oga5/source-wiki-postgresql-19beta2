定義

目的

指定された RestrictInfo がリレーションに対してセキュリティ上安全に早期評価（プロモート）可能かどうかを判定する。

シグネチャまたは形状

  • シグネチャ: bool restriction_is_securely_promotable(RestrictInfo *restrictinfo, RelOptInfo *rel)

入力と出力

  • 引数:
  • RestrictInfo *restrictinfo: 判定対象の制限条件ノード。
  • RelOptInfo *rel: 対象のリレーション情報。
  • 戻り値: bool: 条件が安全にプロモート可能な場合は true、それ以外の場合は false。

アルゴリズムまたは振る舞い

  • リレーションのベース制限条件のうち順序を守る必要があるものよりもセキュリティレベルが低いか等しい場合、または該当する RestrictInfo がリークプルーフ（leakproof）である場合に true を返す。
  • それ以外の場合は false を返す。
