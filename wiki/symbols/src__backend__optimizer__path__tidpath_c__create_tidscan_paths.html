目的

指定されたリレーションに対して、CTIDベースのスキャンパス（通常、範囲、並列範囲、およびパラメータ付き TidPath および TidRangePath）の生成を統括する。

シグネチャまたは形状

  • シグネチャ: bool create_tidscan_paths(PlannerInfo *root, RelOptInfo *rel)

入力と出力

  • 引数:
  • root: PlannerInfo * - プランナのグローバル情報
  • rel: RelOptInfo * - パスを生成する対象リレーション
  • 戻り値: bool - CURRENT OF 式による強制的なTidPathが追加され、他のパス追加をスキップすべき場合は true、それ以外は false を返す。

前提条件と不変条件

  • rel->pgs_mask の PGS_TIDSCAN ビットにより、TIDスキャンが全体として有効化されているかどうかが判定される。ただし CurrentOfExpr が含まれる場合は無効化設定に関わらず例外的に許可される。

アルゴリズムまたは振る舞い

1. 基本 TID 条件の解析とパス追加:

  • rel->baserestrictinfo から TidQualFromRestrictInfoList を呼び出して tidquals と isCurrentOf フラグを取得する。
  • tidquals が空でなく、かつ TID スキャンが有効（enabled）または isCurrentOf が真である場合、create_tidscan_path を用いて通常（非パラメータ付き）の TidPath を作成し、add_path でリレーションに追加する。
  • isCurrentOf が真である場合は、他のいかなるパスも実行できないため、直ちに true を返して処理を終了する。

    • 2. TID スキャン無効時の早期リターン:

  • TID スキャンが無効化されている場合（enabled が偽）、以降のパス生成処理を行わずに false を返す。

    • 3. 範囲条件に基づくパス追加:

  • rel->baserestrictinfo から TidRangeQualFromRestrictInfoList を用いて範囲条件（tidrangequals）を収集する。
  • tidrangequals が空でない場合、create_tidrangescan_path を使って TidRangePath を作成し、add_path で追加する。
  • リレーションが並列考慮可能であり、かつ required_outer が NULL である場合、compute_parallel_worker によりワーカー数を計算し、有効なワーカー数が得られれば create_tidrangescan_path と add_partial_path を通じて並列範囲スキャンパスを追加する。

    • 4. 同値クラス（EquivalenceClass）からのパラメータ付きパス追加:

  • rel->has_eclass_joins が真の場合、generate_implied_equalities_for_column を使って ec_member_matches_ctid に合致する同値クラス列の等価条件を生成し、BuildParameterizedTidPaths に渡してパラメータ付きパスを構築する。

    • 5. 緩い結合条件（joininfo）からのパラメータ付きパス追加:

  • rel->joininfo に含まれる外部結合条件等の「緩い」結合条件を用いて BuildParameterizedTidPaths を呼び出し、パラメータ付き TidPath を追加する。

    • 6. 最終的に false を返す。

失敗モードと境界条件

  • TID スキャンがマスク PGS_TIDSCAN によって無効化されている場合、限定的な CurrentOfExpr 条件が存在する場合を除いて基本 TID スキャンパスの生成はスキップされる。
  • CurrentOfExpr 条件が存在する場合は、他のあらゆる TID 条件やパスの追加がブロックされ、直ちに早期リターンが行われる。
