目的

等価クラス（EquivalenceClass）等から導出された暗黙の等値条件を構築し、簡約や変数参照の伝播処理を経たうえで対応するリレーションおよびリストへ分散させる。

シグネチャまたは形状

  • シグネチャ: RestrictInfo * process_implied_equality(PlannerInfo *root, Oid opno, Oid collation, Expr *item1, Expr *item2, Relids qualscope, Index security_level, bool both_const)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ全体の情報構造体
  • Oid opno: 演算子のOID
  • Oid collation: 照合順序のOID
  • Expr *item1: 等値比較の左辺式
  • Expr *item2: 等値比較の右辺式
  • Relids qualscope: 条件が有効なスコープ（リレーションIDの集合）
  • Index security_level: セキュリティレベル
  • bool both_const: 両辺が定数であるかを示すフラグ
  • 戻り値:
  • RestrictInfo *: 生成された制限情報構造体（定数畳み込みにより真と評価されて消滅する場合は NULL）

前提条件と不変条件

  • 抽出された変数の集合 relids は、指定された qualscope の部分集合である必要がある。

アルゴリズムまたは振る舞い

1. 演算子式の構築: make_opclause と copyObject を使用し、オリジナルとサブ構造を共有しない独立した演算子式（clause）を作成する。 2. 定数畳み込みと簡約: both_const が真の場合、eval_const_expressions を実行して式を定数評価する。結果が非NULLかつブール型の真（TRUE）の定数であれば条件自体が常に成立するため、この関数は早期に NULL を返す。 3. 変数参照の抽出とスコープ検証: pull_varnos により式中に出現するすべてのリレーションID（relids）を抽出し、qualscope の部分集合であることを検証する。 4. 変数フリー条件の処理: relids が空である場合、get_join_domain_min_rels を用いて結合ドメインの安全な最小レベルを決定し、擬似定数（gating qual）としてマークした上で root->hasPseudoConstantQuals を真に設定する。 5. RestrictInfoの生成: make_restrictinfo を呼び出して RestrictInfo ノードを生成する。 6. 結合条件のターゲットリスト伝播: 複数リレーションにまたがる結合条件（relids が複数メンバーを持つ場合）である場合、式中の変数（集約やウィンドウ関数、プレースホルダを含む）を抽出し、add_vars_to_targetlist を通じて各リレーションのターゲットリストに追加する。 7. マージ結合可能性のチェック: check_mergejoinable を呼び出してマージ結合可能か検証する。 8. 制限情報の分散: distribute_restrictinfo_to_rels を呼び出して、生成した RestrictInfo を適切なリレーションの制限情報リストに登録し、構築した RestrictInfo を返す。

失敗モードと境界条件

  • both_const が真かつ式が真の定数に簡約された場合、条件は無視され NULL が返される。

保守担当者向けメモ

  • 呼び出し側で initialize_mergeclause_eclasses() を後から実行するため、この関数内では実行しない。
