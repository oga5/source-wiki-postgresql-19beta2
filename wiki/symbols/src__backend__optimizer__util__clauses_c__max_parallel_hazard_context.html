~~~c typedef struct { char max_hazard; /* worst proparallel hazard found so far */ char max_interesting; /* worst proparallel hazard of interest */ List *safe_param_ids; /* PARAM_EXEC Param IDs to treat as safe */ } max_parallel_hazard_context; ~~~

目的

max_parallel_hazard_context は、クエリ全体の並列安全性（Parallel Hazard）を判定する walker のコンテキスト構造体です。クエリツリー内の関数や構文を走査する際に、検出された危険度や関心の閾値、安全とみなすパラメータの識別子を保持します。

フィールドと表現

  • max_hazard: これまでに発見された最悪の並列危険度（worst proparallel hazard found so far）を保持する char 型のフィールドです。
  • max_interesting: 追跡対象となる最悪の並列危険度閾値（worst proparallel hazard of interest）を保持する char 型のフィールドです。
  • safe_param_ids: 安全として扱う PARAM_EXEC の Param ID リスト（List *）です。
