~~~c static int find_compatible_trans(PlannerInfo *root, Aggref *newagg, bool shareable, Oid aggtransfn, Oid aggtranstype, int transtypeLen, bool transtypeByVal, Oid aggcombinefn, Oid aggserialfn, Oid aggdeserialfn, Datum initValue, bool initValueIsNull, List *transnos) { ListCell *lc;

/* If this aggregate can't share transition states, give up */ if (!shareable) return -1;

foreach(lc, transnos) { int transno = lfirst_int(lc); AggTransInfo *pertrans = list_nth_node(AggTransInfo, root->aggtransinfos, transno);

/*

  • if the transfns or transition state types are not the same then the
  • state can't be shared.

    • */ if (aggtransfn != pertrans->transfn_oid || aggtranstype != pertrans->aggtranstype) continue;

/*

  • The serialization and deserialization functions must match, if
  • present, as we're unable to share the trans state for aggregates
  • which will serialize or deserialize into different formats.
  • Remember that these will be InvalidOid if they're not required for
  • this agg node.

    • */ if (aggserialfn != pertrans->serialfn_oid || aggdeserialfn != pertrans->deserialfn_oid) continue;

/*

  • Combine function must also match. We only care about the combine
  • function with partial aggregates, but it's too early in the
  • planning to know if we will do partial aggregation, so be
  • conservative.

    • */ if (aggcombinefn != pertrans->combinefn_oid) continue;

/*

  • Check that the initial condition matches, too.

    • */ if (initValueIsNull && pertrans->initValueIsNull) return transno;

if (!initValueIsNull && !pertrans->initValueIsNull && datumIsEqual(initValue, pertrans->initValue, transtypeByVal, transtypeLen)) return transno; ~~~

目的

入力条件が一致する既存の集約遷移状態（Transition State）の候補リストの中から、遷移関数、シリアライズ関数、結合関数、および初期値が完全に一致するものを探索し、再利用可能な既存の遷移番号（transno）を返却する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Aggref *newagg: 新規に処理対象となっている集約関数参照ノード
  • bool shareable: 遷移状態の共有が許可されているかどうかを示すフラグ
  • Oid aggtransfn: 遷移関数の OID
  • Oid aggtranstype: 遷移状態のデータ型 OID
  • int transtypeLen: 遷移型長
  • bool transtypeByVal: 遷移型が値渡し（ByVal）かどうか
  • Oid aggcombinefn: 結合関数の OID
  • Oid aggserialfn: シリアライズ関数の OID
  • Oid aggdeserialfn: デシリアライズ関数の OID
  • Datum initValue: 初期値の Datum 表現
  • bool initValueIsNull: 初期値が NULL かどうか
  • List *transnos: 検査対象となる既存の遷移番号（transno）のリスト
  • 戻り値: int 形式。条件に一致する既存の遷移番号（transno）、あるいは一致するものが見つからない場合は -1 を返す

前提条件と不変条件

  • shareable が偽である場合、関数は即座に -1 を返し、遷移状態の共有を行わない。
  • 部分集約を行うかどうかが計画段階では早期であるため、結合関数（aggcombinefn）の比較は保守的に厳密一致が要求される。

アルゴリズムまたは振る舞い

1. shareable が偽であるかを検査し、偽であれば -1 を返して終了する。 2. transnos リスト内の各要素を foreach ループで順に走査する。 3. リスト内の各整数 transno に対応する AggTransInfo 構造体 (pertrans) を root->aggtransinfos から取得する。 4. 以下の条件を順番に評価し、一つでも不一致であれば次の候補へスキップする (continue)：

  • 遷移関数 (aggtransfn と pertrans->transfn_oid) および遷移状態型 (aggtranstype と pertrans->aggtranstype) が一致していること。
  • シリアライズ関数およびデシリアライズ関数 (aggserialfn/aggdeserialfn と pertrans->serialfn_oid/pertrans->deserialfn_oid) が一致していること。
  • 結合関数 (aggcombinefn と pertrans->combinefn_oid) が一致していること。

    • 5. 初期値の条件を評価する：

  • initValueIsNull と pertrans->initValueIsNull が共に真であれば、一致するものとみなして現在の transno を返す。
  • 双方ともに偽であり、かつ datumIsEqual(initValue, pertrans->initValue, transtypeByVal, transtypeLen) が真を返す場合は、一致するものとみなして現在の transno を返す。

    • 6. ループ内で一致する遷移状態が見つからないまま終了した場合、-1 を返す。

失敗モードと境界条件

  • 適合する遷移状態が存在しない、または shareable が不許可の場合は -1 が返される。
  • 順次比較においてシリアライズ関数やデシリアライズ関数、結合関数、遷移関数、データ型、初期値のいずれか一つでも不一致が生じた場合は、該当候補がスキップされて次の候補の検査へと進む。
