目的

RangeQueryClause は、同一の変数に対する大小比較（例: x > 34 や x < 42）のペア情報を蓄積するための連結リスト要素の構造体です。オプティマイザがクエリの選択率を計算する際に、範囲クエリの重なりを考慮した正確な見積もりを行うために利用されます。

フィールドと表現

  • struct RangeQueryClause *next: リンクリスト内における次の要素へのポインタ。
  • Node *var: 複数の範囲クエリ句が共通して参照する変数。
  • bool have_lobound: 下限側の句（var > something など）がすでに発見されているかを示すフラグ。
  • bool have_hibound: 上限側の句（var < something など）がすでに発見されているかを示すフラグ。
  • Selectivity lobound: var > something 型の句の選択率。
  • Selectivity hibound: var < something 型の句の選択率。

ライフサイクルと所有権

動的構造体として関数スコープ内のローカルなリンクリストの一部として palloc を用いて確保され、関数スコープ内で明示的に解放されます。
