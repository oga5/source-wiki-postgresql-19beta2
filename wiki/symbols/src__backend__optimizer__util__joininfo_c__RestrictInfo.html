目的

2つのリレーション間に関連する結合条件が存在するかどうかを検出します。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナーのグローバル情報
  • RelOptInfo *rel1: 比較対象の1つ目のリレーション
  • RelOptInfo *rel2: 比較対象の2つ目のリレーション
  • 出力:
  • bool: 関連する結合条件が存在する場合は true、それ以外の場合は false

前提条件と不変条件

  • 検出される結合条件は、必ずしもその2つのリレーションのみで評価可能である必要はありません（例: 3つのリレーションにまたがる条件であっても、クロスジョインやインデックススキャンの理由として考慮されるため対象となります）。

アルゴリズムまたは振る舞い

1. リスト長の比較: rel1 と rel2 のうち、joininfo リストの要素数が短い方のリレーションを選択し、もう一方のリレーションの識別子（relids）を other_relids とします。 2. 結合情報リストの走査: 選択した joininfo リスト内の各 RestrictInfo ノードについて、その required_relids と other_relids がオーバーラップするかどうかを順に確認します。 3. 一致の判定: オーバーラップする RestrictInfo が見つかった場合は結果を true に設定してループを終了します。 4. 同値クラスの確認: リスト上で該当条件が見つかっておらず、かつ両方のリレーションが has_eclass_joins を持っている場合は、have_relevant_eclass_joinclause を呼び出して同値クラスデータ構造内の関係も追加で確認します。

失敗モードと境界条件

  • 該当する joininfo リストに条件がなく、かつ同値クラス側の結合条件も存在しない場合は、最終的に false を返します。
