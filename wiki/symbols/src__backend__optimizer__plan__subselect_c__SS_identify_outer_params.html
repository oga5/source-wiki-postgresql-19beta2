~~~c void SS_identify_outer_params(PlannerInfo *root) { Bitmapset *outer_params; PlannerInfo *proot; ListCell *l;

/*

  • If no parameters have been assigned anywhere in the tree, we certainly
  • don't need to do anything here.

    • */ if (root->glob->paramExecTypes == NIL) return;

/*

  • Scan all query levels above this one to see which parameters are due to
  • be available from them, either because lower query levels have
  • requested them (via plan_params) or because they will be available from
  • initPlans of those levels.

    • */ outer_params = NULL; for (proot = root->parent_root; proot != NULL; proot = proot->parent_root) { /*

  • Include ordinary Var/PHV/Aggref/GroupingFunc/ReturningExpr params.

    • */ foreach(l, proot->plan_params) { PlannerParamItem *pitem = (PlannerParamItem *) lfirst(l);

outer_params = bms_add_member(outer_params, pitem->paramId); } /* Include any outputs of outer-level initPlans */ foreach(l, proot->init_plans) { SubPlan *initsubplan = (SubPlan *) lfirst(l); ListCell *l2;

foreach(l2, initsubplan->setParam) { outer_params = bms_add_member(outer_params, lfirst_int(l2)); } } /* Include worktable ID, if a recursive query is being planned */ if (proot->wt_param_id >= 0) outer_params = bms_add_member(outer_params, proot->wt_param_id); } root->outer_params = outer_params; } ~~~

目的

上位のクエリレベルから利用可能なパラメータを識別し、指定されたクエリ計画情報の outer_params フィールドに格納する。

入力と出力

  • 入力: PlannerInfo *root （対象のクエリレベルのプランナ情報）
  • 出力: なし（root->outer_params を設定する）

前提条件と不変条件

  • ツリー内のどこにもパラメータが割り当てられていない場合（root->glob->paramExecTypes == NIL の場合）、何も処理を行わずに即座にリターンする。

アルゴリズムまたは振る舞い

1. root->glob->paramExecTypes が NIL であるかを検証し、該当する場合は早期リターンする。 2. outer_params ビットマップを NULL で初期化する。 3. root->parent_root から開始して上位のクエリレベル（proot）を順に走査する。 4. 各上位レベルにおいて以下を収集し、outer_params ビットマップに追加する：

  • proot->plan_params に含まれる通常の Var/PHV/Aggref/GroupingFunc/ReturningExpr パラメータ（pitem->paramId）。
  • proot->init_plans 内の各 SubPlan が持つ setParam 内の出力パラメータID。
  • 再帰クエリが計画されている場合のワークテーブル ID（proot->wt_param_id >= 0 の場合の proot->wt_param_id）。

    • 5. 走査完了後、構築した outer_params を root->outer_params に設定する。

失敗モードと境界条件

  • ツリー全体に実行時パラメータが一切存在しない場合、ループに入らず早期リターンする。
  • 再帰クエリではない場合、ワークテーブルIDの追加条件（proot->wt_param_id >= 0）により追加処理はスキップされる。
