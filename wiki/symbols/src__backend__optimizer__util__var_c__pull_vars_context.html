~~~c typedef struct { List *vars; int sublevels_up; } pull_vars_context; ~~~

目的

pull_vars_context は、指定されたクエリレベルの Var および PlaceHolderVar ノードのリストを収集するための走査コンテキスト構造体です。

フィールドと表現

  • List *vars: 走査の過程で収集された Var および PlaceHolderVar ノードのリストを保持します。
  • int sublevels_up: 対象とするクエリの階層差を管理し、何階層上の変数を収集するかを指定します。
