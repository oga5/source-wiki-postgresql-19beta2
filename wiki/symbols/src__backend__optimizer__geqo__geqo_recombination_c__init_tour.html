~~~c void init_tour(PlannerInfo *root, Gene *tour, int num_gene) { int i, j;

/*

  • We must fill the tour[] array with a random permutation of the numbers
  • 1 .. num_gene. We can do that in one pass using the "inside-out"
  • variant of the Fisher-Yates shuffle algorithm. Notionally, we append
  • each new value to the array and then swap it with a randomly-chosen
  • array element (possibly including itself, else we fail to generate
  • permutations with the last city last). The swap step can be optimized
  • by combining it with the insertion.

    • */ if (num_gene > 0) tour[0] = (Gene) 1;

for (i = 1; i < num_gene; i++) { j = geqo_randint(root, i, 0); /* i != j check avoids fetching uninitialized array element */ if (i != j) tour[i] = tour[j]; tour[j] = (Gene) (i + 1); } } ~~~

目的

遺伝的クエリ最適化（GEQO）において、1 から num_gene までの数値をランダムに並べ替えた順列（ツアー）を tour 配列に生成します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報
  • Gene *tour: 順列を受け取る出力先の遺伝子配列
  • int num_gene: 配列内の要素数（遺伝子の総数）
  • 戻り値: なし（void）

前提条件と不変条件

  • tour 配列は少なくとも num_gene 要素分のメモリ領域が割り当てられている必要があります。

アルゴリズムまたは振る舞い

  • Fisher-Yates シャッフルアルゴリズムの「インサイドアウト」バリアントを1パスで実行し、1から num_gene までのランダムな順列を生成します。
  • num_gene > 0 の場合、先頭の tour[0] に (Gene) 1 を設定します。
  • i = 1 から num_gene - 1 までループを回し、geqo_randint(root, i, 0) を呼び出して 0 から i の範囲のランダムなインデックス j を取得します。
  • i != j である場合は未初期化の配列要素へのアクセスを避けるために tour[i] = tour[j] を実行し、その後 tour[j] = (Gene) (i + 1) を代入します。

失敗モードと境界条件

  • num_gene が 0 以下の場合、ループや配列への書き込みはスキップされます。
