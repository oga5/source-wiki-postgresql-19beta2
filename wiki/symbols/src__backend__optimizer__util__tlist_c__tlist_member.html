ソース抜粋

~~~c TargetEntry * tlist_member(Expr *node, List *targetlist) { ListCell *temp;

foreach(temp, targetlist) { TargetEntry *tlentry = (TargetEntry *) lfirst(temp);

if (equal(node, tlentry->expr)) return tlentry; } return NULL; } ~~~

目的

指定した式に一致する最初の TargetEntry をターゲットリストから検索して返します。

入力と出力

  • 引数: Expr *node（検索対象の式）, List *targetlist（検索元のターゲットリスト）
  • 戻り値: TargetEntry *（一致したエントリのポインタ、見つからない場合は NULL）

前提条件と不変条件

  • targetlist 内の各要素は TargetEntry 構造体へのポインタである必要があります。

アルゴリズムまたは振る舞い

  • targetlist の各要素を順次走査します。
  • 各エントリの TargetEntry->expr と引数の node を equal() 関数によって比較します。
  • 一致する式を持つエントリが見つかった時点で、その TargetEntry を直ちに返します。
  • リストの最後まで一致が見つからない場合は NULL を返します。

失敗モードと境界条件

  • targetlist が空である場合や、どのエントリの式とも一致しない場合は、単に NULL を返します。
