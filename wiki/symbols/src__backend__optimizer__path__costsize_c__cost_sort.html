目的

ソート処理を行うパスの起動コストおよび実行コストを計算し、引数として渡された Path 構造体に反映させます。

入力と出力

  • 引数:
  • Path *path: コストと行数の情報を設定する対象のパス
  • PlannerInfo *root: プランナーのグローバル情報
  • List *pathkeys: ソート順序を規定するパスキー
  • int input_disabled_nodes: 入力パスが無効化したノード数
  • Cost input_cost: 入力パスのコスト
  • double tuples: ソート対象の行数 (タプル数)
  • int width: タプルの平均幅
  • Cost comparison_cost: 比較演算子あたりのコスト
  • int sort_mem: ソートに利用可能なメモリ容量 (work_mem)
  • double limit_tuples: 制限された取得行数 (リミット)
  • 戻り値: なし (void)

前提条件と不変条件

  • PGS_CONSIDER_NONPARTIAL の考慮は、関連する場合はすでに前提となる入力パス側に反映されているため、本関数内では無視されます。

アルゴリズムまたは振る舞い

1. cost_tuplesort を呼び出して、指定されたタプル数、幅、比較コスト、ソート用メモリ、制限行数に基づき、ソート処理単体の起動コスト (startup_cost) と実行コスト (run_cost) を算出し取得します。 2. 入力パスのコスト (input_cost) をソートの起動コストに加算します。 3. パスの行数 (path->rows) にタプル数を設定します。 4. 有効な enable_sort 設定と入力側の無効化ノード数に基づき、パスの無効化ノード数 (path->disabled_nodes) を決定します (enable_sort が偽の場合は 1 が加算されます)。 5. パスの起動コスト (path->startup_cost) と総コスト (path->total_cost = 起動コスト + 実行コスト) を設定します。
