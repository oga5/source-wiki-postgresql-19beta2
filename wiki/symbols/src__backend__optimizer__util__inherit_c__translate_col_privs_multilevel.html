~~~c static Bitmapset * translate_col_privs_multilevel(PlannerInfo *root, RelOptInfo *rel, RelOptInfo *parent_rel, Bitmapset *parent_cols) { AppendRelInfo *appinfo;

/* Fast path for easy case. */ if (parent_cols == NULL) return NULL;

/* Recurse if immediate parent is not the top parent. */ if (rel->parent != parent_rel) { if (rel->parent) parent_cols = translate_col_privs_multilevel(root, rel->parent, parent_rel, parent_cols); else elog(ERROR, "rel with relid %u is not a child rel", rel->relid); }

/* Now translate for this child. */ Assert(root->append_rel_array != NULL); appinfo = root->append_rel_array[rel->relid]; Assert(appinfo != NULL);

return translate_col_privs(parent_cols, appinfo->translated_vars); } ~~~

目的

多段階の継承階層にわたって、親リレーションの列権限ビットマップを子リレーションの列番号へと再帰的に変換します。

入力と出力

  • 入力: PlannerInfo *root, RelOptInfo *rel, RelOptInfo *parent_rel, Bitmapset *parent_cols
  • 戻り値: Bitmapset *（変換後の列ビットマップ、または parent_cols が NULL の場合は NULL）

前提条件と不変条件

  • parent_cols が NULL でない場合、root->append_rel_array は非 NULL でなければなりません。
  • 処理対象のリレーションの append_rel_array[rel->relid] に対応する AppendRelInfo が存在していなければなりません。

アルゴリズムまたは振る舞い

1. **早期リターン**: 引数 parent_cols が NULL の場合は、そのまま NULL を返します。 2. **多段階再帰の判定**: 即座の親リレーション（rel->parent）がトップの親（parent_rel）と一致しない場合、さらに上位の階層へ向かって自身を再帰呼び出しし、parent_cols を上位から順次変換します。 3. **子リレーションへの変換適用**: root->append_rel_array から rel->relid に対応する AppendRelInfo を取得し、translate_col_privs を呼び出して親の列セットを子リレーションの変数にマッピングして返します。

失敗モードと境界条件

  • parent_cols == NULL の場合は変換を行わず NULL を返します。
  • rel->parent が存在しないにもかかわらず rel->parent != parent_rel である場合は、elog(ERROR, ...) によりエラーが発生します。
  • root->append_rel_array が NULL である場合や、該当する AppendRelInfo が NULL である場合は、Assert によりアボートします。
