~~~c Node * adjust_appendrel_attrs_multilevel(PlannerInfo *root, Node *node, RelOptInfo *childrel, RelOptInfo *parentrel) { AppendRelInfo **appinfos; int nappinfos;

/* Recurse if immediate parent is not the top parent. */ if (childrel->parent != parentrel) { if (childrel->parent) node = adjust_appendrel_attrs_multilevel(root, node, childrel->parent, parentrel); else elog(ERROR, "childrel is not a child of parentrel"); }

/* Now translate for this child. */ appinfos = find_appinfos_by_relids(root, childrel->relids, &nappinfos);

node = adjust_appendrel_attrs(root, node, nappinfos, appinfos);

pfree(appinfos);

return node; } ~~~

目的

複数階層（中間親を挟む）にわたるアペンドリレーション構造において、指定された式またはノード内の属性やリレーション識別子を親から子へ再帰的に翻訳する。

シグネチャまたは形状

  • Node * adjust_appendrel_attrs_multilevel(PlannerInfo *root, Node *node, RelOptInfo *childrel, RelOptInfo *parentrel)

入力と出力

  • 入力:
  • root: プランナのグローバル情報を保持する PlannerInfo *
  • node: 翻訳対象の構文木ノード (Node *)
  • childrel: 変換先の子リレーション情報 (RelOptInfo *)
  • parentrel: 変換元の親リレーション情報 (RelOptInfo *)
  • 戻り値: 翻訳済みの Node * を返す。

前提条件と不変条件

  • childrel の直接の親（childrel->parent）が parentrel ではない場合、中間階層を辿るための再帰呼び出しが実行される。

アルゴリズムまたは振る舞い

1. childrel->parent が parentrel と一致するかを判定する。 2. 一致しない場合、childrel->parent の存在を確認した上で、自身を childrel->parent に対して再帰呼び出しし、上位階層の属性変換を先に適用する。 3. find_appinfos_by_relids を呼び出し、childrel->relids に対応する AppendRelInfo 配列を取得する。 4. 取得した appinfos を用いて adjust_appendrel_attrs を呼び出し、ノード内の属性を現在のレベルに合わせて翻訳する。 5. 翻訳処理後、動的に割り当てられた appinfos 配列を pfree で解放する。

関連データ構造

  • PlannerInfo
  • Node
  • RelOptInfo
  • AppendRelInfo

失敗モードと境界条件

  • childrel->parent が存在しない（NULL である）にもかかわらず childrel->parent != parentrel である場合、elog(ERROR, "childrel is not a child of parentrel") が発生して処理が中断される。
