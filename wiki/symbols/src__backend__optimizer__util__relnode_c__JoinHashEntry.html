ソース抜粋

~~~c typedef struct JoinHashEntry { Relids join_relids; /* hash key --- MUST BE FIRST */ RelOptInfo *join_rel; } JoinHashEntry; ~~~

目的

JoinHashEntry は、結合関係（join relation）を高速にルックアップするための補助ハッシュテーブルのエントリ構造体です。

フィールドと表現

  • join_relids: ハッシュキーとして機能する Relids 型の値であり、エントリ構造体の先頭（MUST BE FIRST）に配置されます。
  • join_rel: 対応する結合関係の特性を保持する RelOptInfo 構造体へのポインタです。

不変条件

  • join_relids フィールドは必ずエントリ構造体の先頭に配置されなければなりません。
