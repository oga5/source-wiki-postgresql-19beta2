目的

指定された level の結合リレーションを網羅的に探索し、root->join_rel_level[level] リストに格納する。

シグネチャまたは形状

  • シグネチャ: void join_search_one_level(PlannerInfo *root, int level)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報および探索状態を保持する構造体ポインタ。
  • int level: 構築対象のジョインレベル。
  • 戻り値: なし (void)

前提条件と不変条件

  • 探索対象レベルの結合リレーションリストが空であること (Assert(joinrels[level] == NIL))。

アルゴリズムまたは振る舞い

1. **レベル設定**: root->join_cur_level に level を設定する。 2. **左右側プラン（Left-sided / Right-sided plans）の検討**:

  • レベル $level-1$ の各リレーション (old_rel) について、結合句、等価クラス結合、または結合制限の有無を確認する。
  • 結合句や制限がある場合、level == 2 のときは重複を避けるために foreach_current_index(r) + 1 以降の初期リレーションを対象とし、それ以外は全初期リレーションを対象として make_rels_by_clause_joins を実行する。
  • 結合句や制限がない場合、make_rels_by_clauseless_joins を用いてデカルト積の結合を生成する。

    • 3. **ブッシュプラン（Bushy plans）の検討**:

  • $2 \le k \le level-2$ を満たす $k$ について、レベル $k$ のリレーションとレベル $other\_level$ ($level - k$) のリレーションの組み合わせを走査する (k > other_level に達するまで)。
  • 双方のリレーションの relids がオーバーラップせず、かつ関連する結合句または結合順序制約が存在する場合に make_join_rel を呼び出す。

    • 4. **ラストリゾート（デカルト積の強制）**:

  • ここまでの探索で joinrels[level] が空のままである場合、レベル $level-1$ のリレーションと初期リレーション間でのデカルト積結合を make_rels_by_clauseless_joins によって再度強制的に生成する。
  • 特別結合（Special Joins）や LATERAL 参照が存在せず、かつこの追加生成後も joinrels[level] が空のままである場合は、elog(ERROR, ...) によりエラーを発生させる。

失敗モードと境界条件

  • 特殊結合が含まれるクエリにおいて、特定の $N$ 順結合を直接構築する合法なパスが存在しない場合、レベル $N$ で結合が生成されないことがあるが、これはバグではなく上位レベルのブッシュプラン探索によって解決される。
  • 特殊結合、LATERAL 参照のいずれも存在しないにもかかわらず指定レベルの結合構築に失敗した場合は、エラーとして検出される。
