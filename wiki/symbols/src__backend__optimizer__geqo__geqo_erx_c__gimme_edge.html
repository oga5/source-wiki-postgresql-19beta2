~~~c static int gimme_edge(PlannerInfo *root, Gene gene1, Gene gene2, Edge *edge_table) { int i; int edges; int city1 = (int) gene1; int city2 = (int) gene2;

/* check whether edge city1->city2 already exists */ edges = edge_table[city1].total_edges;

for (i = 0; i < edges; i++) { if ((Gene) abs(edge_table[city1].edge_list[i]) == city2) {

/* mark shared edges as negative */ edge_table[city1].edge_list[i] = 0 - city2;

return 0; } }

/* add city1->city2; */ edge_table[city1].edge_list[edges] = city2;

/* increment the number of edges from city1 */ edge_table[city1].total_edges++; edge_table[city1].unused_edges++;

return 1; } ~~~

目的

指定された2つの都市（遺伝子）間のエッジをエッジテーブルに登録または更新する。既に存在するエッジの場合は共有エッジとして負の値にマークし、存在しない場合は新規エッジとして追加する。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナー情報へのポインタ
  • Gene gene1: 接続元の遺伝子（都市）
  • Gene gene2: 接続先の遺伝子（都市）
  • Edge *edge_table: エッジテーブルの配列
  • 戻り値:
  • 新規にエッジを追加した場合は 1、既存のエッジを共有エッジに更新した場合は 0 を返す

前提条件と不変条件

  • gene1 および gene2 はそれぞれ整数型（int）の都市インデックス（city1, city2）として扱われる。

アルゴリズムまたは振る舞い

  • gene1 をインデックスとするエッジテーブルのエントリから既存のエッジリストを走査する。
  • 走査中に、絶対値が city2 と一致する既存エッジが見つかった場合、該当するエッジの値を負の値（0 - city2）に書き換えて共有エッジとしてマークし、0 を返す。
  • 既存のエッジが見つからない場合、edge_table[city1].edge_list の末尾に city2 を追加し、total_edges と unused_edges をそれぞれインクリメントした上で、1 を返す。

失敗モードと境界条件

  • エラーパスは持たない。
