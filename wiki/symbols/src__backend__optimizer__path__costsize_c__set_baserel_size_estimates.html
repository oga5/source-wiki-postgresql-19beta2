ソース抜粋

~~~c void set_baserel_size_estimates(PlannerInfo *root, RelOptInfo *rel) { double nrows;

/* Should only be applied to base relations */ Assert(rel->relid > 0);

nrows = rel->tuples * clauselist_selectivity(root, rel->baserestrictinfo, 0, JOIN_INNER, NULL);

rel->rows = clamp_row_est(nrows);

cost_qual_eval(&rel->baserestrictcost, rel->baserestrictinfo, root);

set_rel_width(root, rel); } ~~~

目的

ベースリレーション（基本関係）に対して、制限条件の選択性を適用した行数の見積もり計算、制限評価コストの算出、およびリレーションのタプル幅の設定を実行します。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報を保持する構造体ポインタ。
  • RelOptInfo *rel: サイズ見積もり対象となるベースリレーションの情報を保持する構造体ポインタ。
  • 戻り値: なし（void）。

前提条件と不変条件

  • 対象のリレーションはベースリレーション（rel->relid > 0）でなければなりません。

アルゴリズムまたは振る舞い

  • 入力された RelOptInfo がベースリレーションであることを Assert で検証します。
  • rel->tuples にベースリレーションの制限条件リスト（rel->baserestrictinfo）の選択性を乗算して、未加工の予想行数（nrows）を算出します。
  • 算出した予想行数を clamp_row_est に渡して安全な値に補正し、rel->rows に格納します。
  • cost_qual_eval を呼び出して、ベース制限条件の評価コストを rel->baserestrictcost に設定します。
  • set_rel_width を呼び出して、対象リレーションのタプル幅を算出・設定します。

失敗モードと境界条件

  • ベースリレーション以外のリレーションが渡された場合、rel->relid > 0 の前提条件違反により Assert が失敗します。
