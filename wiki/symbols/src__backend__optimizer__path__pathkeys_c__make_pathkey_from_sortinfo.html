ソース抜粋

~~~c static PathKey * make_pathkey_from_sortinfo(PlannerInfo *root, Expr *expr, Oid opfamily, Oid opcintype, Oid collation, bool reverse_sort, bool nulls_first, Index sortref, Relids rel, bool create_it) { CompareType cmptype; Oid equality_op; List *opfamilies; EquivalenceClass *eclass;

cmptype = reverse_sort ? COMPARE_GT : COMPARE_LT;

/*

  • EquivalenceClasses need to contain opfamily lists based on the family
  • membership of mergejoinable equality operators, which could belong to
  • more than one opfamily. So we have to look up the opfamily's equality
  • operator and get its membership.

    • */ equality_op = get_opfamily_member_for_cmptype(opfamily, opcintype, opcintype, COMPARE_EQ); if (!OidIsValid(equality_op)) /* shouldn't happen */ elog(ERROR, "missing operator %d(%u,%u) in opfamily %u", COMPARE_EQ, opcintype, opcintype, opfamily); opfamilies = get_mergejoin_opfamilies(equality_op); if (!opfamilies) /* certainly should find some */ elog(ERROR, "could not find opfamilies for equality operator %u", equality_op);

/* Now find or (optionally) create a matching EquivalenceClass */ eclass = get_eclass_for_sort_expr(root, expr, opfamilies, opcintype, collation, sortref, rel, create_it);

/* Fail if no EC and !create_it */ if (!eclass) return NULL;

/* And finally we can find or create a PathKey node */ return make_canonical_pathkey(root, eclass, opfamily, cmptype, nulls_first); } ~~~

目的

指定されたソート情報（式、演算子ファミリー、データ型、照合順序、ソート方向、NULL配置など）を基に、対応する EquivalenceClass を検索または作成し、最終的に正規化された PathKey ノードを構築して返す。

シグネチャまたは形状

  • シグネチャ: static PathKey * make_pathkey_from_sortinfo(PlannerInfo *root, Expr *expr, Oid opfamily, Oid opcintype, Oid collation, bool reverse_sort, bool nulls_first, Index sortref, Relids rel, bool create_it)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナのグローバル情報へのポインタ
  • Expr *expr: ソート対象の式
  • Oid opfamily: 演算子ファミリーの OID
  • Oid opcintype: 演算子クラスの入力データ型 OID
  • Oid collation: 照合順序の OID
  • bool reverse_sort: 降順ソートであるかどうか（真の場合 COMPARE_GT、偽の場合 COMPARE_LT を選択する）
  • bool nulls_first: NULLを先頭に配置するかどうか
  • Index sortref: ソート参照インデックス（get_eclass_for_sort_expr に渡される）
  • Relids rel: 関連するリレーション集合
  • bool create_it: 一致する EquivalenceClass が存在しない場合に新規作成するかどうか
  • 戻り値:
  • PathKey *: 生成または検索された正規化済み PathKey ノードへのポインタ。ただし create_it が偽で対応する EquivalenceClass が見つからない場合は NULL を返す。

前提条件と不変条件

  • 渡された opfamily から COMPARE_EQ に対応する等価演算子 (equality_op) が正常に取得できなければならない（取得できない場合はエラーとなる）。
  • 取得した等価演算子に対応するマージ結合用演算子ファミリーのリスト (opfamilies) が空であってはならない（空の場合はエラーとなる）。

アルゴリズムまたは振る舞い

1. **比較型の決定**: reverse_sort の値に基づき、比較型 cmptype を COMPARE_GT または COMPARE_LT に設定する。 2. **等価演算子の取得**: get_opfamily_member_for_cmptype を呼び出し、指定された opfamily と opcintype からマージ結合可能な等価演算子 (equality_op) をルックアップする。 3. **演算子ファミリーの検証**: 取得した equality_op が有効であるか検証し、さらに get_mergejoin_opfamilies を用いて属する演算子ファミリーのリスト (opfamilies) を取得する。 4. **等価クラスの検索または作成**: get_eclass_for_sort_expr を呼び出し、ソート式に対応する EquivalenceClass (eclass) を検索または作成する。 5. **早期リターン判定**: eclass が見つからず、かつ create_it が偽である場合は NULL を返す。 6. **パスキーの構築**: make_canonical_pathkey を呼び出して正規化された PathKey ノードを生成し、それを返す。
