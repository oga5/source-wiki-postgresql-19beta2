~~~c Relids pull_varnos_of_level(PlannerInfo *root, Node *node, int levelsup) { pull_varnos_context context;

context.varnos = NULL; context.root = root; context.sublevels_up = levelsup;

/*

  • Must be prepared to start with a Query or a bare expression tree; if
  • it's a Query, we don't want to increment sublevels_up.

    • */ query_or_expression_tree_walker(node, pull_varnos_walker, &context, 0);

return context.varnos; } ~~~

目的

式木またはクエリツリーから、指定されたクエリ階層レベル（levelsup）に一致する参照リレーションID（varnos）の集合を抽出する。

アルゴリズムまたは振る舞い

  • pull_varnos_context 構造体を初期化し、varnos を NULL、root を渡されたプランナ情報、sublevels_up を指定された levelsup に設定する。
  • query_or_expression_tree_walker を呼び出して、クエリツリーまたは単一の式木を pull_varnos_walker により走査する。この際、対象が Query である場合は内部で sublevels_up がインクリメントされずに適切に処理される。
  • 収集されたリレーションIDのビットマップである context.varnos を戻り値として返す。
