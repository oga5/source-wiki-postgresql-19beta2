ソース抜粋

~~~c static bool IsTidRangeClause(RestrictInfo *rinfo, RelOptInfo *rel) { Oid opno;

if (!IsBinaryTidClause(rinfo, rel)) return false; opno = ((OpExpr *) rinfo->clause)->opno;

if (opno == TIDLessOperator || opno == TIDLessEqOperator || opno == TIDGreaterOperator || opno == TIDGreaterEqOperator) return true;

return false; } ~~~

目的

指定された RestrictInfo が対象リレーションに対する有効な TID 範囲演算子（<、<=、>、>=）を用いた二項条件であるかどうかを判定します。

入力と出力

  • 引数:
  • RestrictInfo *rinfo: 検査対象の制限情報
  • RelOptInfo *rel: 対象のリレーション情報
  • 戻り値:
  • bool: 条件が有効な TID 範囲条件である場合は true、そうでない場合は false

前提条件と不変条件

  • rinfo は非ヌルである必要があります。
  • 内部で呼び出される IsBinaryTidClause により、該当の式が二項演算子であり、片方の辺が対象リレーションの CTID を指し、もう片方の辺が非揮発性の式であることを前提とします。

アルゴリズムまたは振る舞い

1. IsBinaryTidClause(rinfo, rel) を呼び出し、条件が CTID と非揮発性引数による二項 TID 条件であるかを検証します。偽であれば即座に false を返します。 2. rinfo->clause から演算子の Oid (opno) を取得します。 3. 取得した opno が TIDLessOperator、TIDLessEqOperator、TIDGreaterOperator、または TIDGreaterEqOperator のいずれかに一致するかを判定し、一致する場合は true、それ以外の場合は false を返します。

呼び出し元と呼び出し先

  • 呼び出し元: TidRangeQualFromRestrictInfoList
  • 呼び出し先: IsBinaryTidClause

失敗モードと境界条件

  • 演算子が等価演算子やその他の非範囲演算子である場合は false を返します。
  • 二項 TID 条件の構造を満たさない不適切な RestrictInfo が渡された場合、IsBinaryTidClause の判定により安全に false が返されます。
