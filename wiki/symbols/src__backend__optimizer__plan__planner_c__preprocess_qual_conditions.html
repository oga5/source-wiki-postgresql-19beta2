~~~c static void preprocess_qual_conditions(PlannerInfo *root, Node *jtnode) { if (jtnode == NULL) return; if (IsA(jtnode, RangeTblRef)) { /* nothing to do here */ } else if (IsA(jtnode, FromExpr)) { FromExpr *f = (FromExpr *) jtnode; ListCell *l;

目的

ジョイントリー（jtnode）の階層構造を再帰的に走査し、各結合式やフロム句に含まれる修飾条件（quals）に対して式の前処理を実行する。

シグネチャまたは形状

  • シグネチャ: static void preprocess_qual_conditions(PlannerInfo *root, Node *jtnode)

入力と出力

  • 引数:
  • PlannerInfo *root: オプティマイザの大域的情報構造体ポインタ
  • Node *jtnode: 処理対象のジョイントリーノード（RangeTblRef, FromExpr, JoinExpr のいずれか、または NULL）
  • 戻り値: なし (void)

前提条件と不変条件

  • jtnode が NULL の場合、関数は何もせずに即座にリターンする。

アルゴリズムまたは振る舞い

1. **null チェック**: jtnode が NULL であれば処理を終了する。 2. **ノード型による分岐**:

  • RangeTblRef の場合: 特段の処理を行わない。
  • FromExpr の場合:
  • fromlist 内の各要素に対して preprocess_qual_conditions を再帰的に呼び出す。
  • f->quals に対して preprocess_expression(root, f->quals, EXPRKIND_QUAL) を実行し、結果を f->quals に再設定する。
  • JoinExpr の場合:
  • 左側引数 (j->larg) と右側引数 (j->rarg) に対してそれぞれ preprocess_qual_conditions を再帰的に呼び出す。
  • j->quals に対して preprocess_expression(root, j->quals, EXPRKIND_QUAL) を実行し、結果を j->quals に再設定する。
  • その他の型の場合: elog(ERROR, ...) を呼び出してエラーを送出する。

呼び出し元と呼び出し先

  • 呼び出し元: subquery_planner, preprocess_qual_conditions（再帰）
  • 呼び出し先: preprocess_qual_conditions, preprocess_expression

関連データ構造

PlannerInfo, Node, RangeTblRef, FromExpr, JoinExpr, ListCell

失敗モードと境界条件

  • 想定外のノード型が渡された場合、認識できないノード型である旨のエラーが elog(ERROR) により発生する。
