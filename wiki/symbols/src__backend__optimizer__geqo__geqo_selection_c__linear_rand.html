目的

与えられたバイアス値とプールサイズに基づき、線形確率分布に従うランダムなインデックスを算出します。

シグネチャまたは形状

  • シグネチャ: static int linear_rand(PlannerInfo *root, int pool_size, double bias)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーの情報構造体。
  • int pool_size: 選択対象のプールサイズ。
  • double bias: 選択確率の偏りを制御するバイアス値。
  • 戻り値: int (算出されたインデックス)

前提条件と不変条件

  • 返されるインデックスは 0 <= index < max の範囲を満たします。

アルゴリズムまたは振る舞い

  • geqo_rand(root) を呼び出して乱数を取得し、バイアスパラメータを用いて二次方程式の平方根項 (sqrtval) を計算します。
  • 計算された sqrtval が 0.0 より大きい場合は sqrt() 関数を適用し、インデックス値を導出します。
  • 算出された index が有効範囲外である場合（geqo_rand() が 1.0 を返した場合の境界値や丸め誤差によるものを含む）、有効な値が得られるまでループして再試行します。
  • 最終的に index を整数にキャストして返します。

失敗モードと境界条件

  • geqo_rand() が 1.0 を返した場合や丸め誤差によって範囲外の不正な値が算出された場合、sqrt() への不適切な負の値の渡却を防ぎつつ、ループにより再試行して不正値を排除します。
