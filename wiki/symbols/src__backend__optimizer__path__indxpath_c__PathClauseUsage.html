ソース抜粋

~~~c typedef struct { Path *path; /* IndexPath, BitmapAndPath, or BitmapOrPath */ List *quals; /* the WHERE clauses it uses */ List *preds; /* predicates of its partial index(es) */ Bitmapset *clauseids; /* quals+preds represented as a bitmapset */ bool unclassifiable; /* has too many quals+preds to process? */ } PathClauseUsage; ~~~

目的

PathClauseUsage は、クエリのオプティマイザにおいて、インデックス関連のパス（IndexPath, BitmapAndPath, BitmapOrPath）が使用する WHERE 句や部分インデックスの述語情報を収集・管理するための構造体です。

フィールドと表現

  • path: 対象となるパス（IndexPath, BitmapAndPath, BitmapOrPath のいずれか）へのポインタ。
  • quals: そのパスが使用する WHERE 句のリスト。
  • preds: 部分インデックスの述語（predicates）のリスト。
  • clauseids: quals と preds をあわせて表現したビットマップセット（Bitmapset）。
  • unclassifiable: 処理すべき条件や述語が多すぎる場合に真となるフラグ。
