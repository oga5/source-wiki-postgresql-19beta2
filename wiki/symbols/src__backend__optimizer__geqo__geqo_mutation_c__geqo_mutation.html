ソース抜粋

~~~c void geqo_mutation(PlannerInfo *root, Gene *tour, int num_gene) { int swap1; int swap2; int num_swaps = geqo_randint(root, num_gene / 3, 0); Gene temp;

while (num_swaps > 0) { swap1 = geqo_randint(root, num_gene - 1, 0); swap2 = geqo_randint(root, num_gene - 1, 0);

while (swap1 == swap2) swap2 = geqo_randint(root, num_gene - 1, 0);

temp = tour[swap1]; tour[swap1] = tour[swap2]; tour[swap2] = temp;

num_swaps -= 1; } } ~~~

目的

遺伝的クエリ最適化（GEQO）において、指定された遺伝子配列（tour）の要素をランダムにスワップして変異処理を行ない、個体の多様性を維持する。

シグネチャまたは形状

  • シグネチャ: void geqo_mutation(PlannerInfo *root, Gene *tour, int num_gene)

入力と出力

  • 引数:
  • PlannerInfo *root: クエリのプランナー情報（乱数生成器に渡される）
  • Gene *tour: 変異対象の遺伝子配列ポインタ（インプレースで更新される）
  • int num_gene: 配列内の遺伝子数
  • 戻り値: なし（void）

前提条件と不変条件

  • num_gene は配列の有効な長さを表し、乱数の上限値計算の基準として利用される。

アルゴリズムまたは振る舞い

  • geqo_randint(root, num_gene / 3, 0) を呼び出し、実行するスワップの総回数（num_swaps）を決定する。
  • num_swaps > 0 の間、以下の処理をループする：
  • geqo_randint を用いて、0 から num_gene - 1 の範囲で2つの異なるインデックス swap1 と swap2 を選択する。
  • swap1 と swap2 が同じ値を指している間は、swap2 を再選択する。
  • tour 配列の swap1 番目と swap2 番目の遺伝子を一時変数 temp を介して相互に入れ替える。
  • num_swaps を 1 減算する。
