目的

指定された結合条件（RestrictInfo）を、join_relids に含まれる各ベースリレーションの joininfo リストから削除する。

入力と出力

  • 入力:
  • PlannerInfo *root: プランナのグローバル情報構造体へのポインタ
  • RestrictInfo *restrictinfo: 削除対象の結合条件情報へのポインタ
  • Relids join_relids: 結合条件が関連付けられていたリレーション識別子の集合（ビットマップ）
  • 戻り値: なし（void）

前提条件と不変条件

  • 削除対象の結合条件は、あらかじめベースリレーションの joininfo リストに追加されている必要がある。

アルゴリズムまたは振る舞い

  • join_relids に含まれるすべてのリレーション ID を bms_next_member を用いて順に走査する。
  • 各リレーション ID に対して find_base_rel_ignore_join を呼び出し、対応するベースリレーション構造体（RelOptInfo）を取得する。
  • 該当するリレーションが存在しない（NULL である）場合はスキップする。
  • リレーションが存在する場合、list_member_ptr を用いて rel->joininfo リストに restrictinfo が含まれていることをアサーションで検証する。
  • list_delete_ptr を用いて rel->joininfo リストから restrictinfo をポインタ比較により削除し、更新されたリストを再設定する。

失敗モードと境界条件

  • join_relids に対応するベースリレーションがオプティマイザのツリー内に見つからない場合（rel == NULL）、エラーとならず単にスキップされる。
  • 削除対象の restrictinfo がリレーションの joininfo リストに存在しない状態で呼び出された場合、Assert によりデバッグ時クラッシュまたはアサーション違反を引き起こす。
