ソース抜粋

~~~c Relids pull_varnos(PlannerInfo *root, Node *node) { pull_varnos_context context;

context.varnos = NULL; context.root = root; context.sublevels_up = 0;

/*

  • Must be prepared to start with a Query or a bare expression tree; if
  • it's a Query, we don't want to increment sublevels_up.

    • */ query_or_expression_tree_walker(node, pull_varnos_walker, &context, 0);

return context.varnos; } ~~~

目的

式木またはクエリツリーから、参照されているリレーションIDの集合（Relids ビットマップ）を抽出する。

シグネチャまたは形状

Relids pull_varnos(PlannerInfo *root, Node *node)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナ情報へのポインタ。
  • Node *node: 対象の式木またはクエリツリーのルートノード。
  • 戻り値:
  • Relids: 抽出されたリレーションIDのビットマップセット。

アルゴリズムまたは振る舞い

  • pull_varnos_context 構造体を初期化し、varnos を NULL、root を引数の root、sublevels_up を 0 に設定する。
  • query_or_expression_tree_walker を呼び出し、渡されたノードが Query であるか単なる式木であるかに応じて適切に走査を行う。
  • Query から開始する場合、sublevels_up をインクリメントせずにウォーカーを適用する。
  • 走査中に収集されたリレーションIDのビットマップセット context.varnos を返す。
