目的

条件を満たす場合に、ネストループ結合の内側パスに対してキャッシュ機構を持つ Memoize パスを構築・返却する。

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体のグローバル情報
  • RelOptInfo *innerrel: 内部リレーションのメタデータ
  • RelOptInfo *outerrel: 外部リレーションのメタデータ
  • Path *inner_path: 内部リレーションの実行パス
  • Path *outer_path: 外部リレーションの実行パス
  • JoinType jointype: 結合種別（JoinType）
  • JoinPathExtraData *extra: 結合パス構築用の追加データ
  • 戻り値: 条件に合致する場合は生成された Path *（Memoize パス）、条件を満たさない場合は NULL。

前提条件と不変条件

  • extra->pgs_mask に PGS_NESTLOOP_MEMOIZE が含まれていない場合はパスを構築しない。
  • 内部関係のターゲットリスト、ベース制限情報、またはパラメータ化されたパスの制限情報に揮発性（volatile）関数が含まれている場合は利用できない。

アルゴリズムまたは振る舞い

1. **無効マスクの確認**: extra->pgs_mask でネストループメモ化が無効化されている場合は NULL を返す。 2. **行数に基づく早期リターン**: 外部パスの親の行数が 2 未満かつ通常のネストループ戦略が有効な場合、最初のスキャンでキャッシュミスとなるため無駄なコストを避ける目的で NULL を返す。 3. **キャッシュキーの抽出と存在確認**:

  • innerrel->relids に基づき、プレースホルダー変数内の潜在的な変数/PHVを抽出する。
  • パラメータ化されたパス句、内部リレーションの結合変数、および抽出したプレースホルダー変数のいずれも存在しない場合は NULL を返す。

    • 4. **結合型の検証**:

  • JOIN_SEMI または JOIN_ANTI 結合であり、かつ extra->inner_unique が偽である場合は、完了マークを正しく扱えないため NULL を返す。
  • 一意な結合（extra->inner_unique が真）の場合、内部パスにパラメータ情報が存在し、かつ制限リストの全エントリがそのパラメータシリアルに含まれているかを検証し、不適合であれば NULL を返す。

    • 5. **揮発性関数のチェック**: 内部リレーションのターゲットリスト、ベース制限情報、およびパスのパラメータ化句に揮発性関数が含まれていないことを走査して確認する。 6. **ハッシュ演算子の取得とパス生成**:

  • paraminfo_get_equal_hashops を呼び出し、パラメータに対するハッシュ演算子や式、バイナリモードを取得する。
  • 取得に成功した場合は create_memoize_path を用いてメモ化パスを生成して返す。失敗した場合は NULL を返す。

失敗モードと境界条件

  • キャッシュキーやハッシュ演算子が特定できない場合、あるいは揮発性関数が含まれている場合は構築処理が中断され NULL を返す。
