~~~c Relids adjust_child_relids(Relids relids, int nappinfos, AppendRelInfo **appinfos) { Bitmapset *result = NULL; int cnt;

for (cnt = 0; cnt < nappinfos; cnt++) { AppendRelInfo *appinfo = appinfos[cnt];

/* Remove parent, add child */ if (bms_is_member(appinfo->parent_relid, relids)) { /* Make a copy if we are changing the set. */ if (!result) result = bms_copy(relids);

result = bms_del_member(result, appinfo->parent_relid); result = bms_add_member(result, appinfo->child_relid); } }

/* If we made any changes, return the modified copy. */ if (result) return result;

/* Otherwise, return the original set without modification. */ return relids; } ~~~

目的

Relids（Bitmapset）内に含まれる親リレーション識別子を、対応する子リレーション識別子に置換します。

入力と出力

  • 引数:
  • Relids relids: 変換対象のリレーション識別子の集合
  • int nappinfos: 配列 appinfos の要素数
  • AppendRelInfo **appinfos: 変換規則を保持する AppendRelInfo 構造体ポインタの配列
  • 戻り値:
  • Relids: 変更が行われた場合は新しく複製・変更された Bitmapset、変更がなかった場合は元の Relids

前提条件と不変条件

  • 引数 appinfos が指す配列には有効な AppendRelInfo ポインタが nappinfos 個格納されていること
  • 変更が発生しない限り、入力された relids はそのまま返され、新規のメモリ割り当ては行われないこと

アルゴリズムまたは振る舞い

1. 変更後の Bitmapset を保持するローカル変数 result を NULL で初期化する。 2. cnt を 0 から nappinfos - 1 までインクリメントしながら、各 AppendRelInfo（appinfo）について以下の処理を繰り返す。

  • appinfo->parent_relid が現在の relids（または result が構築されている場合は更新中の result）のメンバーに含まれているか bms_is_member で確認する。
  • メンバーに含まれている場合:
  • result がまだ NULL の場合は、元の relids のコピーを bms_copy(relids) で作成して result に代入する。
  • result から appinfo->parent_relid を bms_del_member で削除する。
  • result に appinfo->child_relid を bms_add_member で追加する。

    • 3. ループ終了後、result が NULL でなければ変更された result を返し、NULL のままであれば元の relids をそのまま返す。

失敗モードと境界条件

  • 該当する parent_relid が relids に含まれない場合、置換は行われず元の relids がそのまま返される。
