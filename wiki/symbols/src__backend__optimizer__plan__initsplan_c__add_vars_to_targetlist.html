~~~c void add_vars_to_targetlist(PlannerInfo *root, List *vars, Relids where_needed) { ListCell *temp;

Assert(!bms_is_empty(where_needed));

foreach(temp, vars) { Node *node = (Node *) lfirst(temp);

if (IsA(node, Var)) { Var *var = (Var *) node; RelOptInfo *rel = find_base_rel(root, var->varno); int attno = var->varattno;

if (bms_is_subset(where_needed, rel->relids)) continue; Assert(attno >= rel->min_attr && attno <= rel->max_attr); attno -= rel->min_attr; if (rel->attr_needed[attno] == NULL) { /*

  • Variable not yet requested, so add to rel's targetlist.

    • *

  • The value available at the rel's scan level has not been
  • nulled by any outer join, so drop its varnullingrels.
  • (We'll put those back as we climb up the join tree.)

    • */ var = copyObject(var); var->varnullingrels = NULL; rel->reltarget->exprs = lappend(rel->reltarget->exprs, var); /* reltarget cost and width will be computed later */ } rel->attr_needed[attno] = bms_add_members(rel->attr_needed[attno], where_needed); } else if (IsA(node, PlaceHolderVar)) { PlaceHolderVar *phv = (PlaceHolderVar *) node; PlaceHolderInfo *phinfo = find_placeholder_info(root, phv);

phinfo->ph_needed = bms_add_members(phinfo->ph_needed, where_needed); } else elog(ERROR, "unrecognized node type: %d", (int) nodeTag(node)); } } ~~~

目的

指定された変数やプレースホルダー変数のリスト（vars）を走査し、各要素が必要とされる関係（where_needed）に応じて、ベース関係のターゲットリストやプレースホルダー情報へ登録または必要性フラグの更新を行う。

シグネチャまたは形状

  • シグネチャ: void add_vars_to_targetlist(PlannerInfo *root, List *vars, Relids where_needed)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナー全体の情報を保持する構造体へのポインタ
  • List *vars: 処理対象の式または変数のリスト（Var または PlaceHolderVar）
  • Relids where_needed: 変数やプレースホルダーが必要とされる関係IDのセット
  • 戻り値: なし（void）

前提条件と不変条件

  • where_needed は空のビットマップであってはならない（!bms_is_empty(where_needed) が常に成立する）。

アルゴリズムまたは振る舞い

1. where_needed が空でないことをアサートで検証する。 2. vars リスト内の各要素を順番にループ処理する。 3. ノードの型が Var である場合の処理:

  • find_base_rel を使って変数が属するベース関係（RelOptInfo）を特定する。
  • where_needed がそのベース関係の relids のサブセットである場合は処理をスキップする。
  • 属性番号（attno）がベース関係の最小から最大属性の範囲内にあることを検証し、配列インデックス用に調整する。
  • 該当属性の必要性管理配列（rel->attr_needed[attno]）が NULL の場合、変数を複製し varnullingrels をクリアした上で、そのベース関係の reltarget->exprs に追加する。
  • 該当属性の attr_needed[attno] に where_needed をメンバーとして追加・結合する。

    • 4. ノードの型が PlaceHolderVar である場合の処理:

  • find_placeholder_info を用いて対応する PlaceHolderInfo を取得し、その ph_needed に where_needed を追加・結合する。

    • 5. 上記以外の未知のノード型の場合は、エラーログを出力して終了する。

失敗モードと境界条件

  • where_needed が空の集合である場合、Assert(!bms_is_empty(where_needed)) によりデバッグビルドでクラッシュする。
  • リスト内のノードが Var でも PlaceHolderVar でも無い場合、elog(ERROR, ...) を呼び出してエラーを送出する。
