~~~c typedef struct { List *tlist; /* underlying target list */ int num_vars; /* number of plain Var tlist entries */ bool has_ph_vars; /* are there PlaceHolderVar entries? */ bool has_non_vars; /* are there other entries? */ tlist_vinfo vars[FLEXIBLE_ARRAY_MEMBER]; /* has num_vars entries */ } indexed_tlist; ~~~

目的

子プランのターゲットリストを高速に検索するためにインデックス化した構造体です。

フィールドと表現

  • List *tlist: 元となるターゲットリストへのポインタ。
  • int num_vars: 単純な Var ターゲットリストエントリの数。
  • bool has_ph_vars: PlaceHolderVar エントリが存在するかどうかを示すフラグ。
  • bool has_non_vars: その他のエントリが存在するかどうかを示すフラグ。
  • tlist_vinfo vars[FLEXIBLE_ARRAY_MEMBER] (num_vars エントリを持つ): tlist_vinfo 要素を格納するフレキシブル配列。
