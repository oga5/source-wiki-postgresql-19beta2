~~~c typedef struct { PlannerInfo *root; bool is_grouping_target; /* true if processing grouping target */ /* This is a List of bare expressions: */ List *input_target_exprs; /* exprs available from input */ /* These are Lists of Lists of split_pathtarget_items: */ List *level_srfs; /* SRF exprs to evaluate at each level */ List *level_input_vars; /* input vars needed at each level */ List *level_input_srfs; /* input SRFs needed at each level */ /* These are Lists of split_pathtarget_items: */ List *current_input_vars; /* vars needed in current subexpr */ List *current_input_srfs; /* SRFs needed in current subexpr */ /* Auxiliary data for current split_pathtarget_walker traversal: */ int current_depth; /* max SRF depth in current subexpr */ Index current_sgref; /* current subexpr's sortgroupref, or 0 */ } split_pathtarget_context; ~~~

目的

split_pathtarget_context は、split_pathtarget_walker トラバーサルにおいて、セット返却関数（SRF: Set-Returning Function）を含むターゲット式の多段階分割状態やネスト深度、必要な入力変数などの状態を保持するコンテキスト構造体である。

フィールドと表現

  • PlannerInfo *root: プランナ全体の情報（PlannerInfo）へのポインタ。
  • bool is_grouping_target: グループ化ターゲットを処理中である場合に真となるフラグ。
  • List *input_target_exprs: 入力側から利用可能なプレーンな式のリスト。
  • List *level_srfs: 各階層で評価すべき SRF 式のリストのリスト。
  • List *level_input_vars: 各階層で必要となる入力変数のリストのリスト。
  • List *level_input_srfs: 各階層で必要となる入力 SRF のリストのリスト。
  • List *current_input_vars: 現在のサブ式で必要となる変数の split_pathtarget_item リスト。
  • List *current_input_srfs: 現在のサブ式で必要となる SRF の split_pathtarget_item リスト。
  • int current_depth: 現在のサブ式における最大 SRF 深度。
  • Index current_sgref: 現在のサブ式の sortgroupref、または 0。
