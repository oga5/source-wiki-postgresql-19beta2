目的

新しい染色体を遺伝的アルゴリズムのプール内の適切な位置に挿入し、最もコスト（worth）の悪い末尾の個体を置換・排除する。

シグネチャまたは形状

  • シグネチャ: void spread_chromo(PlannerInfo *root, Chromosome *chromo, Pool *pool)

入力と出力

  • 引数:
  • PlannerInfo *root: プランナーのグローバル情報。
  • Chromosome *chromo: プールに挿入する新しい染色体。
  • Pool *pool: 染色体を保持する個体群プール。
  • 戻り値: なし（void）

前提条件と不変条件

  • プール内の染色体は worth の昇順（最良が先頭、最悪が末尾）にソートされていること。

アルゴリズムまたは振る舞い

1. **早期リターン評価**:

  • 新しい染色体の worth がプールの最悪値（pool->data[pool->size - 1].worth）より大きい場合、プール内で使用価値がないため何もせずに終了する。

    • 2. **二分探索による挿入位置の特定**:

  • top（0）、mid（中央）、bot（末尾）のインデックスを使用し、index == -1 の間 while ループで探索を行う。
  • 4つの条件（chromo->worth <= pool->data[top].worth、== pool->data[mid].worth、== pool->data[bot].worth、あるいは bot - top <= 1）のいずれかに合致した位置を index として決定する。
  • いずれにも合致しない場合、chromo->worth と pool->data[mid].worth の大小関係に応じて top または bot を更新し、mid を再計算して探索を継続する。

    • 3. **末尾プールの置換と要素のシフト**:

  • geqo_copy を呼び出して、プールの最悪値の位置（pool->size - 1）に新しい chromo の内容をコピーする。
  • swap_chromo に一時退避させた末尾の遺伝子文字列と worth を用いて、特定された index からプール末尾にかけての各要素を順次後ろへスワップ（シフト）させ、順序を維持する。

  • Chromosome: 遺伝子文字列と評価値（worth）を保持する構造体。
  • Pool: 複数の染色体配列（data）、プールサイズ（size）、文字列長（string_length）を管理する構造体。

失敗モードと境界条件

  • 新しい染色体の worth がプールの最悪値より大きい場合、挿入処理を行わずに正常終了する。
