src/backend/optimizer/geqo/geqo_copy.c

概要

  • PostgreSQLの遺伝的クエリ最適化（GEQO）モジュールにおいて、個体（染色体）のデータを別の個体へ複製するためのユーティリティ関数を提供するソースファイルです。
  • D. Whitley氏の「Genitor」アルゴリズムの実装をベースにしています。

モジュール内での役割

  • GEQOサブシステム（src/backend/optimizer/geqo）において、遺伝的アルゴリズムの世代交代や選択、交叉（Recombination）処理の過程で、個体（Chromosome）のデータを退避・複製する共通ユーティリティとして機能します。
  • 複雑な最適化ロジックからデータコピーの低レベルな配列操作を分離し、モジュール全体のコードの可読性を高める役割を持っています。

責務

  • **遺伝子配列の複製**: 指定された長さ（string_length）に基づき、コピー元（chromo2）からコピー先（chromo1）へ遺伝子配列（Geneの配列）を正確にコピーします。
  • **評価値（適応度）の同期**: 遺伝子配列のコピーに伴い、その個体の評価値（worth）も同時にコピー先に同期します。

重要なシンボル

  • **geqo_copy (関数)**: 本ファイルが提供する唯一の公開関数です。PlannerInfo、コピー先およびコピー元の Chromosome 構造体へのポインタ、および遺伝子長を受け取り、インプレースでデータを複製します。

制御フローとデータフロー

1. **入力**: コピー先ポインタ（chromo1）、コピー元ポインタ（chromo2）、およびコピー対象の遺伝子長（string_length）を受け取ります。 2. **ループ処理**: 0 から string_length - 1 までのループを回し、chromo2->string[i] の値を chromo1->string[i] に代入します。 3. **評価値のコピー**: chromo2->worth の値を chromo1->worth に代入します。 4. **データフローの境界**: 本関数は呼び出し元のメモリ領域（通常はGEQOプール内の個体領域）を直接書き換えます。

直接依存

  • **postgres.h**: PostgreSQLの基本データ型やシステム定義。
  • **optimizer/geqo_copy.h**: 本関数のプロトタイプ宣言を提供するヘッダーファイル。間接的に optimizer/geqo.h（Chromosome 構造体の定義を含む）に依存しています。

関連コード

  • **src/backend/optimizer/geqo/geqo_pool.c**: 染色体プール（個体群）を管理するモジュール。個体のソートや入れ替え時に geqo_copy を頻繁に呼び出します。
  • **src/backend/optimizer/geqo/geqo_main.c**: GEQOのメインループを制御し、世代交代処理の中で本関数を利用します。

読者向けメモ

  • 本ファイルは非常にシンプルであり、メモリの新規確保（pallocなど）は行いません。呼び出し側が事前に chromo1 の string 配列に対して十分なメモリ領域を確保していることを前提としています。
  • 引数として PlannerInfo *root を受け取りますが、現在の実装では関数内部でこの変数は使用されていません。将来的な拡張や他のGEQOインターフェースとの整合性のために引数として維持されています。
