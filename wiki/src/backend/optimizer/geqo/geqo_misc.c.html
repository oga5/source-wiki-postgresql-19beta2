src/backend/optimizer/geqo/geqo_misc.c

概要

src/backend/optimizer/geqo/geqo_misc.c は、PostgreSQLの遺伝的クエリ最適化（GEQO）モジュールにおけるデバッグおよび進捗可視化用のユーティリティファイルです。遺伝的アルゴリズム（GA）の実行過程において、個体群プールやエッジテーブルの内部状態を標準出力やログファイル（FILE *）へダンプする機能を提供します。

モジュール内での役割

GEQOサブシステム（src/backend/optimizer/geqo）において、アルゴリズムの挙動分析やデバッグを支援する補助的な位置づけにあります。メインの探索ループや特定の交叉アルゴリズムから呼び出され、世代交代ごとの統計情報やデータ構造の整合性を検証するために使用されます。

責務

  • **個体群統計の算出と出力**: 現在の世代における最良・最悪・中央値・平均のコスト（worth）を算出し、フォーマット出力します。
  • **プール状態のダンプ**: 個体群プール（Pool）内の各個体が持つ遺伝子配列（ジョイン順序）とコストの対応リストを出力します。
  • **エッジテーブルの可視化**: 辺組換え交叉（ERX）で使用される、ノード間の接続関係を示すエッジテーブルの内容をダンプします。
  • **数値オーバーフローの防止**: 平均値計算において、非常に大きなコスト値（DBL_MAXなど）の累積による浮動小数点オーバーフローを回避します。

重要なシンボル

  • **デバッグ出力インターフェース（GEQO_DEBUG 有効時のみ）**:
  • print_gen: 指定された世代の最良、最悪、中央値、および平均コストを1行で出力します。
  • print_pool: プール内の指定された範囲の個体（遺伝子配列とコスト）をダンプします。入力値に対する境界値の安全チェックも行います。
  • print_edge_table: 辺組換え交叉（ERX）で用いられるエッジテーブルの隣接リストを出力します。
  • **内部計算ヘルパー**:
  • avg_pool (静的関数): プール全体の平均コストを計算します。オーバーフローを避けるため、各個体のコストをプールサイズで除算してから累積する工夫がなされています。

制御フローとデータフロー

1. **呼び出し元からの制御流入**: geqo_main.c などのメインループから、世代の節目やデバッグ要求時に print_gen や print_pool が呼び出されます。 2. **データの集計**:

  • print_gen は、ソート済みの Pool 構造体から、最良（インデックス 0）、最悪（インデックス size - 2 ※最後尾はバッファ）、中央値（インデックス size / 2）を直接取得します。
  • 平均値の算出は avg_pool に委譲され、プール内の全個体の worth を走査して集計します。

    • 3. **ストリームへの書き出し**: 集計されたデータや遺伝子配列は、指定された FILE *fp ストリームへ fprintf を用いて書き出され、fflush によって即座に出力バッファがフラッシュされます。

直接依存

  • postgres.h: PostgreSQLの基本型定義や elog マクロ。
  • optimizer/geqo_misc.h: 本ファイルの関数プロトタイプ宣言（GEQO_DEBUG 定義時のみ有効）。

関連コード

  • src/backend/optimizer/geqo/geqo_main.c: GEQOのメインエントリーポイント。世代交代のループ内で print_gen などを呼び出します。
  • src/backend/optimizer/geqo/geqo_erx.c: 辺組換え交叉の実装。エッジテーブルの構築時に print_edge_table を利用してデバッグ可能です。
  • src/backend/optimizer/geqo/geqo_pool.c: 個体群プール（Pool）の管理。本ファイルが操作するデータ構造の実体です。

読者向けメモ

  • **条件付きコンパイル**: 本ファイルの実装はすべて #ifdef GEQO_DEBUG ブロックで囲まれています。通常ビルド（製品版）ではコード領域に含まれず、パフォーマンスへの影響はありません。
  • **平均値計算の精度**: avg_pool では、オーバーフロー回避のために「各要素を割ってから足す」アプローチを採用しています。これにより、浮動小数点の丸め誤差がわずかに発生する可能性がありますが、デバッグ用途であるため許容されています。
