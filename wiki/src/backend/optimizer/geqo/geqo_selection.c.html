src/backend/optimizer/geqo/geqo_selection.c

概要

src/backend/optimizer/geqo/geqo_selection.c は、PostgreSQLの遺伝的クエリ最適化（GEQO）モジュールにおいて、遺伝子プールから親世代となる個体を選択する**線形選択スキーム（Linear Selection Scheme）**を実装しています。この実装は、D. Whitley氏の「Genitor」アルゴリズムをベースにしています。

モジュール内での役割

GEQOサブシステムにおいて、探索の収束性と多様性のバランスを保つための「親選択」フェーズを担います。

  • 評価済みの遺伝子プールから、適応度（クエリコスト）に基づくバイアスを適用して親個体（momma と daddy）を選び出します。
  • 選択された親個体は、その後の交叉（Crossover）や変異（Mutation）ステップへと引き渡されます。

責務

  • **バイアス付き確率選択**: 単なる一様ランダムではなく、適応度の高い（プール内で上位に位置する）個体が優先的に選ばれるように線形確率分布を用いてインデックスを決定します。
  • **重複選択の防止**: プールサイズが2以上の場合、同一の個体が「父親」と「母親」に重複して選ばれないように制御します。
  • **染色体データの抽出**: 選択されたインデックスに対応する染色体データを、出力用の構造体へ安全にコピーします。

重要なシンボル

  • **geqo_selection (関数)**: 外部に公開されているメインAPI。プールから異なる2つの親個体を選択し、momma および daddy にデータをコピーします。
  • **linear_rand (静的関数)**: 与えられたバイアス値（bias）に基づき、0 から pool_size - 1 の範囲で線形分布に従うランダムなインデックスを算出するヘルパー関数です。

制御フローとデータフロー

1. **親選択の開始**: geqo_main.c 等から geqo_selection が呼び出されます。 2. **インデックスの生成**:

  • linear_rand を呼び出して1つ目のインデックス（first）を決定します。
  • 続いて2つ目のインデックス（second）を決定します。

    • 3. **重複排除**: プールサイズが1より大きい場合、first == second である限り linear_rand を再実行して異なるインデックスになるまでループします。 4. **データコピー**: 決定されたインデックスを用いて、pool->data から momma および daddy へ geqo_copy を用いて染色体データをコピーします。

[geqo_selection]
       │
       ├─► [linear_rand] ──► (1つ目のインデックス決定)
       ├─► [linear_rand] ──► (2つ目のインデックス決定)
       │         │
       │         └─► (重複していれば再試行)
       │
       └─► [geqo_copy] ──► pool->data から momma/daddy へコピー

直接依存

  • postgres.h: PostgreSQLの基本システム定義。
  • <math.h>: sqrt() などの数学関数（linear_rand での確率分布計算に使用）。
  • "optimizer/geqo_copy.h": 染色体データをコピーする geqo_copy の提供。
  • "optimizer/geqo_random.h": 乱数生成器 geqo_rand の提供。
  • "optimizer/geqo_selection.h": 自身の関数プロトタイプ宣言。

関連コード

  • src/backend/optimizer/geqo/geqo_main.c: GEQOのメインアルゴリズムループを管理し、本モジュールを呼び出す起点。
  • src/backend/optimizer/geqo/geqo_pool.c: 選択元となる遺伝子プール（Pool 構造体）のソートや管理。
  • src/backend/optimizer/geqo/geqo_recombination.c: 選択された親個体（momma, daddy）を用いて交叉を行う。

読者向けメモ

  • **丸め誤差への配慮**: linear_rand 内の do-while ループは、geqo_rand() が極稀に 1.0 を返した場合や、浮動小数点の丸め誤差によって算出されたインデックスが有効範囲（0 <= index < max）を外れた場合に、安全に再試行するためのガードレールとして機能しています。
  • **バイアス値の意味**: bias は線形分布の傾きを制御するパラメータであり、優秀な個体が選択される確率の偏り具合を決定します。
