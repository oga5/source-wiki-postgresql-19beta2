src/backend/optimizer/util/paramassign.c

概要

src/backend/optimizer/util/paramassign.c は、PostgreSQLオプティマイザがクエリのプランニング過程において実行時パラメータスロット (PARAM_EXEC) を割り当て・管理するための一連の関数を提供するソースファイルです。サブクエリへの値の受け渡し (plan_params) やネストループの右側へのパラメータ供給 (curOuterParams)、および全体的な実行時パラメータ型情報の管理 (paramExecTypes) を担います。

モジュール内での役割

src/backend/optimizer/util モジュール内に位置し、式やプルの変換時に必要となる外部変数（Outer Var）やプレースホルダ変数（PHV）、集約関数（Aggref）、グルーピング関数などの参照を PARAM_EXEC 型の Param ノードへと置換する実務的な変換処理を担当します。ヘッダーファイル src/include/optimizer/paramassign.h とペアを成しています。

責務

  • **グローバルパラメータ型の管理**: root->glob->paramExecTypes を拡張し、クエリツリー全体で共有される PARAM_EXEC スロットのデータ型 OID リストを維持する。
  • **サブクエリパラメータ管理**: root->plan_params を使用して、上位クエリレベルから下位サブクエリへ供給すべき Var や PlaceHolderVar などの項目を記録・重複排除・管理する。
  • **ネストループパラメータ管理**: root->curOuterParams を使用して、ネストループの親側から右側（子プランノード）へ受け渡すべき NestLoopParam を記録・抽出する。
  • **各種式ノードのパラメータ置換**: Var、PlaceHolderVar、Aggref、GroupingFunc、MergeSupportFunc、ReturningExpr などの外向き参照を Param ノードへ変換する。
  • **特殊パラメータの割り当て**: 実行時のシグナリング（再帰共用体のワークテーブルスキャンや EvalPlanQual など）用の値を持たない PARAM_EXEC スロットを確保する。

重要なシンボル

変数・状態管理関連

  • root->glob->paramExecTypes: プラン全体の PARAM_EXEC スロットのデータ型 OID を保持するリスト（グローバル）。永続的。
  • root->plan_params: サブクエリ計画中に一時的に構築される PlannerParamItem のリスト。
  • root->curOuterParams: ネストループの構築中に子プランノードへ渡すパラメータを保持する NestLoopParam のリスト。

外部変数・式置換ファミリー

  • replace_outer_var(PlannerInfo *root, Var *var): varlevelsup > 0 の Var を PARAM_EXEC パラメータに置換し、plan_params に記録する。
  • replace_outer_placeholdervar(PlannerInfo *root, PlaceHolderVar *phv): 外部 PlaceHolderVar を PARAM_EXEC パラメータに置換する。
  • replace_outer_agg(PlannerInfo *root, Aggref *agg): 外部 Aggref を PARAM_EXEC パラメータに置換する（重複排除なしで毎回スロットを割り当て）。
  • replace_outer_grouping(PlannerInfo *root, GroupingFunc *grp): 外部 GroupingFunc を PARAM_EXEC パラメータに置換する。
  • replace_outer_merge_support(PlannerInfo *root, MergeSupportFunc *msf): 外部 MERGE クエリの RETURNING リストにある MergeSupportFunc を置換する。
  • replace_outer_returning(PlannerInfo *root, ReturningExpr *rexpr): 外部の ReturningExpr を置換する。

ネストループパラメータファミリー

  • replace_nestloop_param_var(PlannerInfo *root, Var *var): ネストループ用の外部 Var を curOuterParams に登録し、必要に応じて重複排除しながら Param を生成する。
  • replace_nestloop_param_placeholdervar(PlannerInfo *root, PlaceHolderVar *phv): ネストループ用の外部 PlaceHolderVar を処理する。
  • process_subquery_nestloop_params(PlannerInfo *root, List *subplan_params): FROM句内のサブクエリ（LATERAL参照）が要求するパラメータを curOuterParams に追加する。
  • identify_current_nestloop_params(PlannerInfo *root, Relids leftrelids, Relids outerrelids): 指定された左側リレーションで評価可能な NestLoopParam を curOuterParams から抽出して返す。

スロット生成ヘルパー

  • generate_new_exec_param(PlannerInfo *root, Oid paramtype, int32 paramtypmod, Oid paramcollation): 既存のプランパラメータ項目に追加せず、型情報のみを指定して新しい PARAM_EXEC の Param ノードを発行する。
  • assign_special_exec_param(PlannerInfo *root): 実行時シグナリング用の値を持たない PARAM_EXEC ID（型 OID は InvalidOid）を割り当てる。
  • assign_param_for_var / assign_param_for_placeholdervar (内部関数): 既存の plan_params 内を走査して合致する項目があればその ID を返し、なければ新規作成して paramExecTypes と plan_params に追加する。

制御フローとデータフロー

1. **探索とレベル解決**: replace_outer_* 系関数は、ノードの *levelsup プロパティに従って root = root->parent_root をたどり、対象のクエリレベルのコンテキストにアクセスする。 2. **重複排除とスロット割り当て**:

  • assign_param_for_var は、同一クエリレベルの plan_params 内にある既存の PlannerParamItem と比較（_equalVar 相当のフィールド一致）し、既存であれば既存の paramId を再利用する。
  • 新規の場合は、list_length(root->glob->paramExecTypes) を新しい paramId とし、そのデータ型を paramExecTypes に追加する。

    • 3. **ネストループへの伝播**:

  • プラン作成段階で replace_nestloop_param_var が呼ばれると、root->curOuterParams を確認し、未登録であれば新規 NestLoopParam を作成して追加する。
  • identify_current_nestloop_params により、特定の NestLoop ノードの左側リレーションズで評価可能になったパラメータが curOuterParams から取り外され、実行計画のその階層へバインドされる。

読者向けメモ

  • **メモリ所有権**: copyObject() を用いて元の式構造をコピーし、レベルアップのオフセット調整（IncrementVarSublevelsUp）を行った上でプラン構造体に保持させるため、Plannerのコンテキストメモリ上で所有・管理される。
  • **不変条件**: root->glob->paramExecTypes はエグゼキュータが単一の配列として参照するため、プラン全体で一意かつ不変（要素の削除は行われない）である必要がある。値を持たない特殊なシグナル用パラメータには InvalidOid が登録される。
