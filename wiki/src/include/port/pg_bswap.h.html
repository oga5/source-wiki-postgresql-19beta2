src/include/port/pg_bswap.h

概要

src/include/port/pg_bswap.h は、16ビット、32ビット、64ビットの符号なし整数および Datum 値のバイトオーダー（エンディアン）を反転・変換するためのポータブルなマクロおよびインライン関数を提供するヘッダーファイルです。

モジュール内での役割

PostgreSQL の src/include/port ディレクトリに属し、プラットフォーム依存の差異を吸収するポータビリティレイヤーの一部として機能します。コンパイラやOSが提供する組み込み関数を優先して利用し、環境に応じた最適なバイトスワップ処理を抽象化します。

責務

  • 16、32、64ビット整数に対するバイトスワップ処理（pg_bswap16, pg_bswap32, pg_bswap64）の提供。
  • 標準的なネットワーク・ホストバイトオーダー変換関数を64ビットに拡張したもの（pg_hton*, pg_ntoh*）の提供。
  • ビット比較を効率化するための Datum 値のエンディアン変換マクロ（DatumBigEndianToNative）の定義。

重要なシンボル

  • pg_bswap16 / pg_bswap32 / pg_bswap64: 指定されたサイズの符号なし整数のバイト順を反転する。
  • pg_hton16 / pg_hton32 / pg_hton64: ホストバイトオーダーからネットワークバイトオーダーへの変換（ビッグエンディアン環境では何もしない）。
  • pg_ntoh16 / pg_ntoh32 / pg_ntoh64: ネットワークバイトオーダーからホストバイトオーダーへの変換。
  • DatumBigEndianToNative: ビッグエンディアン表現の Datum をネイティブのバイトオーダーに変換し、安価な数値比較を可能にする。

制御フローとデータフロー

1. **コンパイル時最適化の選択**: コンパイラが __builtin_bswap* をサポートしている場合はそれを直接マクロ展開します。 2. **MSVC環境のフォールバック**: MSVC環境では、対応する _byteswap_* 組み込み関数（stdlib.h 経由）にルーティングされます。 3. **汎用フォールバック**: どちらも利用できない環境では、ビットシフトとマスク演算を行う static inline 関数にフォールバックします。 4. **エンディアン判定**: WORDS_BIGENDIAN の有無により、pg_hton* や DatumBigEndianToNative などの高水準マクロが何もしないか、対応する pg_bswap を呼び出すかが決定されます。

直接依存

直接的なインクルードファイルはありません。コンパイラ組み込み関数や MSVC のビルトインに依存しており、前提となる基本型（uint16, uint32, uint64 など）は上位のヘッダー（c.h 等）を通じて提供されます。

関連コード

  • src/include/port/: プラットフォーム固有の抽象化を提供する周辺の port ヘッダー群。

読者向けメモ

  • 符号付き整数に対してこれらのラッパーマクロを使用する場合は、予期せぬ挙動を防ぐために十分な注意が必要です（引数および戻り値は常に符号なし整数として扱われます）。
