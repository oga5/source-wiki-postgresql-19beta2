src/include/port/pg_bitutils.h

概要

src/include/port/pg_bitutils.h は、PostgreSQLにおけるビット操作（ビットスキャン、ポップカウント、累乗計算、ビットローテートなど）のためのインライン関数および外部関数を提供するヘッダーファイルです。コンパイラ組み込み関数（__builtin_clz、__builtin_ctz）やMSVCのイントリンシック（_BitScanForward、_BitScanReverse）を利用して高速化を図るとともに、環境非依存のポータブルな実装やルックアップテーブルを併用しています。

モジュール内での役割

src/include/port サブシステムの一部として、プラットフォーム非依存かつ高パフォーマンスな低水準ビット演算ユーティリティを提供します。対応する実装ファイル src/port/pg_bitutils.c とペアをなし、同ファイルで定義されるルックアップテーブル (pg_leftmost_one_pos, pg_rightmost_one_pos, pg_number_of_ones) やポータブル版・最適化版のポップカウント関数を外部公開します。

責務

  • ビットスキャン操作の抽象化：32ビットおよび64ビット整数における最上位ビット（MSB）および最下位ビット（LSB）の位置検出。
  • 2の冪乗（Power of 2）計算：指定された値の上下の近傍2の冪乗の算出、および ceil(log2(num)) の計算。
  • ポップカウント（Population Count）：単一ワードまたはバイト配列内における1ビットの数を、CPU固有の最適化命令や並列ビットハック、ルックアップテーブルを切り替えて計算。
  • ビットローテート操作：32ビット整数の左右方向へのビット回転。
  • プラットフォーム差異の吸収：GCC/Clangの組み込み関数、MSVCのイントリンシック、フォールバック用のルックアップテーブルやビット演算の切り替え。

重要なシンボル

ビット位置スキャン関数

  • pg_leftmost_one_pos32(uint32 word), pg_leftmost_one_pos64(uint64 word): 最上位の1ビットの位置を返す（0オリジン、word != 0 の前提）。
  • pg_rightmost_one_pos32(uint32 word), pg_rightmost_one_pos64(uint64 word): 最下位の1ビットの位置を返す（0オリジン、word != 0 の前提）。

2の冪乗・対数関連関数

  • pg_nextpower2_32(uint32 num), pg_nextpower2_64(uint64 num): num 以上の最小の2の冪乗を返す（num > 0 && num <= MAX / 2 + 1）。
  • pg_prevpower2_32(uint32 num), pg_prevpower2_64(uint64 num): num 以下の最大の2の冪乗を返す（num > 0）。
  • pg_ceil_log2_32(uint32 num), pg_ceil_log2_64(uint64 num): ceil(log2(num)) に相当する値を返す。

ポップカウント関数

  • pg_popcount32(uint32 word), pg_popcount64(uint64 word): 並列ビットハックを用いてワード内の1ビット数を数える。
  • pg_popcount(const char *buf, int bytes), pg_popcount_masked(const char *buf, int bytes, uint8 mask): バッファ全体またはマスク適用後の1ビット数を数える。8バイト未満の場合はルックアップテーブルによるインライン処理、8バイト以上の場合は関数ポインタ経由の最適化版 (pg_popcount_optimized 等) へディスパッチする。

ビットローテート関数

  • pg_rotate_right32(uint32 word, int n), pg_rotate_left32(uint32 word, int n): 32ビット整数のビットローテートを行う。

外部公開テーブルおよび関数

  • pg_leftmost_one_pos, pg_rightmost_one_pos, pg_number_of_ones: 各バイト値（0〜255）に対するビット位置や1の個数を格納した256バイトの定数配列。
  • pg_popcount_optimized, pg_popcount_masked_optimized: CPU固有命令またはポータブル実装を指す関数ポインタ。

制御フローとデータフロー

1. **ビットスキャン系**:

  • HAVE__BUILTIN_CLZ / HAVE__BUILTIN_CTZ が定義されている環境では、コンパイラ組み込み関数（__builtin_clz / __builtin_ctz 等）を直接呼び出します。
  • _MSC_VER 環境では、MSVCの _BitScanForward / _BitScanReverse 系イントリンシックを利用します。
  • それ以外の環境では、8ビットごとのシフトとルックアップテーブル (pg_leftmost_one_pos / pg_rightmost_one_pos) を用いたフォールバックループを実行します。

    • 2. **バッファベースのポップカウント (pg_popcount / pg_popcount_masked)**:

  • 入力サイズ bytes を評価します。
  • bytes < 8 の場合：関数呼び出しのオーバーヘッドを避けるため、バッファを1バイトずつ走査し、pg_number_of_ones テーブルを参照してインラインで累算します。
  • bytes >= 8 の場合：ハードウェア固有の最適化命令（SSE4.2のPOPCNTやSVE等）またはポータブル実装にディスパッチする関数ポインタ (pg_popcount_optimized) へ処理を委譲します。

直接依存

  • <intrin.h>: MSVC環境においてビットスキャンなどのイントリンシックを利用するためにインクルードされます（_MSC_VER ブロック内）。

関連コード

  • src/port/pg_bitutils.c: 配列（pg_leftmost_one_pos, pg_rightmost_one_pos, pg_number_of_ones）の実体やポータブル版のポップカウント関数の実体を定義するペアファイル。
  • src/include/port/simd.h: SIMD命令やCPU機能検出に関連するモジュール。

読者向けメモ

  • **前提条件（インバリアント）**: pg_leftmost_one_pos32/64 や pg_rightmost_one_pos32/64 に渡す word は、必ず非ゼロである必要があります（内部で Assert(word != 0) により検証されます）。
  • **メモリ・ライフタイム**: グローバル配列は読み取り専用 (const uint8) としてエクスポートされ、動的なメモリ割り当てや解放はありません。
