src/include/port/atomics/generic-msvc.h

概要

MSVC（Microsoft Visual C++）環境におけるアトミック操作の実装を提供するヘッダーファイルです。Windows プラットフォーム固有のコンパイラ組込み関数（intrin.h）を使用して、32ビットおよび64ビット整数のアトミックな比較・交換、置換、算術加算を実現しています。

モジュール内での役割

src/include/port/atomics/generic.h からインクルードされるプラットフォーム固有バックエンドの一つとして機能します。単体でのインクルードはガード（INSIDE_ATOMICS_H）により禁止されており、上位の atomics.h を経由して利用されます。

責務

  • **バリアの実装**: コンパイラバリア（pg_compiler_barrier_impl）およびメモリバリア（pg_memory_barrier_impl）の定義。
  • **データ型の定義**: 32ビットおよび64ビットのアトミック整数構造体（pg_atomic_uint32, pg_atomic_uint64）の提供（64ビット版は8バイトアライメントを保証）。
  • **U32/U64 アトミック操作の提供**: Win32 の Interlocked 系 API およびコンパイラ組込み関数を活用したアトミック関数のインライン実装。

重要なシンボル

データ構造とバリア

  • **pg_atomic_uint32**: 32ビット符号なし整数のアトミック変数を保持する構造体。volatile 修飾された uint32 value をラップします。
  • **pg_atomic_uint64**: 64ビット符号なし整数のアトミック変数を保持する構造体。alignas(8) により8バイト境界へのアライメントが強制されます。
  • **pg_compiler_barrier_impl**: コンパイラによる命令の並び替えを防止するマクロ（_ReadWriteBarrier に展開）。
  • **pg_memory_barrier_impl**: CPUのメモリオーダリングを制御するメモリバリアマクロ（MemoryBarrier に展開）。

32ビットアトミック操作

  • **pg_atomic_uint32 関連マクロ / インライン関数**:
  • PG_HAVE_ATOMIC_U32_SUPPORT, PG_HAVE_ATOMIC_COMPARE_EXCHANGE_U32, PG_HAVE_ATOMIC_EXCHANGE_U32, PG_HAVE_ATOMIC_FETCH_ADD_U32 を定義。
  • **pg_atomic_compare_exchange_u32_impl**: InterlockedCompareExchange を呼び出し、期待値 (expected) と現在値を比較。一致すれば newval に置換し、一致しなければ expected に実際の現在値を書き戻してブール値を返します。
  • **pg_atomic_exchange_u32_impl**: InterlockedExchange を用いて値を強制的に置換し、古い値を返します。
  • **pg_atomic_fetch_add_u32_impl**: InterlockedExchangeAdd を用いて指定値をアトミックに加算し、加算前の古い値を返します。

64ビットアトミック操作

  • **pg_atomic_uint64 関連マクロ / インライン関数**:
  • PG_HAVE_ATOMIC_U64_SUPPORT, PG_HAVE_ATOMIC_COMPARE_EXCHANGE_U64 を定義。
  • **pg_atomic_compare_exchange_u64_impl**: _InterlockedCompareExchange64 組込み関数を使用し、64ビット値の比較・交換を行います（32ビット版と同様に不一致時は expected を更新）。
  • **pg_atomic_exchange_u64_impl** / **pg_atomic_fetch_add_u64_impl**: _WIN64 マクロが定義されている（64ビットビルドの）場合のみ有効化され、それぞれ _InterlockedExchange64, _InterlockedExchangeAdd64 を通じて実装されます。

制御フローとデータフロー

1. **比較・交換 (compare_exchange) のフロー**:

  • 呼び出し元から渡されたポインタ（ptr->value）と expected の値を、Win32 の InterlockedCompareExchange または _InterlockedCompareExchange64 に渡してハードウェアレベルのアトミック比較を実行します。
  • 返された現在の値が expected と一致するか評価し、結果（ret）を決定します。
  • 不一致の場合は、引数として渡された expected の参照先に実際の現在値を格納して呼び出し元にフィードバックします。

    • 2. **値の置換・加算 (exchange / fetch_add) のフロー**:

  • InterlockedExchange や InterlockedExchangeAdd（64ビットは _WIN64 環境下でのみ _InterlockedExchange64 等）を直接呼び出し、操作前の古い値を即座に返します。

直接依存

  • <intrin.h>: MSVCのコンパイラ組込み関数（_ReadWriteBarrier, _InterlockedCompareExchange64 など）を利用するためにインクルードされます。

関連コード

  • src/include/port/atomics/generic.h: 本ファイルをインクルードし、アトミックAPIの共通インターフェースを構築する上位ヘッダー。

読者向けメモ

  • **ライフタイムとメモリレイアウト**: pg_atomic_uint64 は alignas(8) により適切なアライメントが保証されています。これにより、64ビットアトミック操作がアライメント違反によるペナルティやハードウェア例外を受けるのを防ぎます。
  • **プラットフォーム制限**: 64ビットの exchange および fetch_add 操作（pg_atomic_exchange_u64_impl, pg_atomic_fetch_add_u64_impl）は、ソース内の #ifdef _WIN64 により 64ビットビルドでのみコンパイルされます。
