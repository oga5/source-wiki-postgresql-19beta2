src/include/port/atomics/generic-msvc.h

概要

MSVC（Microsoft Visual C++）環境におけるアトミック操作の実装を提供するヘッダーファイルです。Windows プラットフォーム向けのコンパイラビリティ、メモリバリア、および 32ビット・64ビット整数に対する各種アトミック演算（比較交換、交換、加算）を Win32 インターロック関数（Interlocked*）を使って定義します。

モジュール内での役割

src/include/port/atomics/ モジュールの一部として、MSVC コンパイラが選択された場合に汎用アトミック API のバックエンド実装を提供します。直接インクルードすることは禁止されており、上位の atomics.h を経由してインクルードされる設計になっています。

責務

  • **コンパイラ・メモリバリアの提供**: _ReadWriteBarrier() と Windows の MemoryBarrier() を用いたバリアのマクロ定義。
  • **データ型の定義**: volatile 修飾子と適切なアライメントを持つ 32ビットおよび 64ビットの原子変数型（pg_atomic_uint32, pg_atomic_uint64）の提供。
  • **アトミック演算の実装**: MSVC のインロック関数群をラップし、PostgreSQL のアトミック API 規約に適合させるインライン関数の提供。

重要なシンボル

型定義とサポートマクロ

  • pg_atomic_uint32: volatile uint32 value を保持する 32ビットアトミック構造体。
  • pg_atomic_uint64: alignas(8) 付きの volatile uint64 value を保持する 64ビットアトミック構造体。
  • PG_HAVE_ATOMIC_U32_SUPPORT / PG_HAVE_ATOMIC_U64_SUPPORT: それぞれ 32ビットおよび 64ビットアトミック操作のサポートを示すマクロ。

32ビットアトミック操作

  • pg_atomic_compare_exchange_u32_impl: InterlockedCompareExchange を用いた比較・交換操作。期待値と現在値が一致した場合は newval に更新し、一致しない場合は expected に現在の値を書き戻して false を返します。
  • pg_atomic_exchange_u32_impl: InterlockedExchange を用いた値の置換と旧値の取得。
  • pg_atomic_fetch_add_u32_impl: InterlockedExchangeAdd を用いた加算と加算前の旧値の取得。

64ビットアトミック操作

  • pg_atomic_compare_exchange_u64_impl: _InterlockedCompareExchange64 を用いた 64ビットの比較・交換操作。
  • pg_atomic_exchange_u64_impl (_WIN64 のみ): _InterlockedExchange64 を用いた 64ビットの値の置換。
  • pg_atomic_fetch_add_u64_impl (_WIN64 のみ): _InterlockedExchangeAdd64 を用いた 64ビットの加算。

制御フローとデータフロー

1. **比較と交換のフロー**:

  • 呼び出し元からアトミック変数へのポインタ (ptr)、期待値へのポインタ (expected)、新しい値 (newval) が渡されます。
  • インロック関数（InterlockedCompareExchange または _InterlockedCompareExchange64）を実行し、変数内の現在の値を取得します。
  • 取得した現在値と *expected を比較し、一致すれば原子的に newval に置き換えます。
  • *expected には常に最新の現在値が上書きされ、比較結果（一致したかどうか）のブール値が返されます。

    • 2. **アーキテクチャ依存の分岐**:

  • 64ビット版の交換および加算関数（pg_atomic_exchange_u64_impl, pg_atomic_fetch_add_u64_impl）は、ビルド環境が 64ビット（_WIN64）の場合のみコンパイル・有効化されます。

直接依存

  • <intrin.h>: MSVC のコンパイライントリンシックおよびインタロック関数を利用するためにインクルードされます。

読者向けメモ

  • **インクルードガードの制約**: INSIDE_ATOMICS_H マクロが定義されていない状態で単体インクルードされた場合、ビルドエラーが発生する仕組みになっています。
  • **メモリのレイアウトとアライメント**: pg_atomic_uint64 には alignas(8) が指定されており、64ビット整数に対するアトミック操作のハードウェア要件を満たしています。
  • **最小サポート要件**: コードコメントによると、Windows XP 以降を最小ベースラインとして想定しているため、古い 486 向けの特例処理は省略されています。
