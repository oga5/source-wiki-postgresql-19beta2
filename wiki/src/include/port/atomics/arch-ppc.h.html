src/include/port/atomics/arch-ppc.h

概要

PowerPC アーキテクチャ固有の低レベルアトミック操作とメモリバリアの実装を提供します。GCC インラインアセンブラを用いて、PowerPC のロード予約/ストア条件付き命令（lwarx / stwcx. および ldarx / stdcx.）を直接実行します。

モジュール内での役割

src/include/port/atomics サブシステムの一部として、CPU アーキテクチャに依存する最適化されたアトミック処理を提供します。共通のラッパーヘッダである generic.h からインクルードされ、PowerPC 環境でのプリミティブを定義します。

責務

  • PowerPC 向けのメモリバリア命令（sync, lwsync）のマクロ定義。
  • 32ビットおよび 64ビット（64ビットモード時のみ）の符号なし整数アトミック構造体の定義。
  • 比較交換（Compare-and-Swap）および加算フェッチ（Fetch-and-Add）のインライン関数実装。
  • 8バイトの単一コピーアトミシティ（Single-copy atomicity）のサポート宣言。

制御フローとデータフロー

  • **メモリバリア**: pg_memory_barrier_impl() は sync を発行し、pg_read_barrier_impl() / pg_write_barrier_impl() は軽量な lwsync を発行します。
  • **アトミック演算ループ**: pg_atomic_compare_exchange_u32_impl 等では、lwarx で予約付きロードを行い、期待値と比較のうえ stwcx. でストアを試みます。条件付きストアが失敗した場合はループバックして再試行します。
  • **定数最適化**: __builtin_constant_p を用いてオペランドが 16 ビット即値に収まる場合に最適化された命令バリエーションを選択します。

関連コード

  • src/include/port/atomics/generic.h: 本ファイルで定義されたアーキテクチャ依存のマクロや関数を取り込み、上位の共通アトミック API を構築する親ヘッダ。

読者向けメモ

  • 64 ビットアトミック操作（pg_atomic_uint64 および関連関数）は、SIZEOF_VOID_P >= 8（64ビットモード）でのみ有効化されます。
  • レジスタ割り当てにおいて、汎用レジスタ r0 の割り当てを避けるための制約（"=&b" 等）が使用されています。
