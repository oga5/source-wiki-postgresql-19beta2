src/include/port/atomics/arch-ppc.h

概要

PowerPC (PPC) アーキテクチャ向けのインラインアセンブリを用いたハードウェア固有のアトミック操作およびメモリバリアの実装を提供します。

モジュール内での役割

src/include/port/atomics サブシステムの一部として、汎用アトミック API (generic.h) からバックエンドとして利用され、PPC 環境における 32 ビットおよび 64 ビットのアトミック処理を直接定義します。

責務

  • GCC インラインアセンブリを使用して、PowerPC 独自のロード・ストア予約命令 (lwarx/stwcx. および ldarx/stdcx.) によるアトミック操作を実装する。
  • sync および lwsync 命令を活用してメモリバリア (pg_memory_barrier_impl, pg_read_barrier_impl, pg_write_barrier_impl) を定義する。
  • 64 ビットアトミック操作のサポート判定 (SIZEOF_VOID_P >= 8) と、8 バイトの単一コピー原子性 (PG_HAVE_8BYTE_SINGLE_COPY_ATOMICITY) を宣言する。

重要なシンボル

  • struct pg_atomic_uint32, struct pg_atomic_uint64: 32 ビットおよび 64 ビットのアトミック整数型コンテナ。
  • pg_atomic_compare_exchange_u32_impl, pg_atomic_compare_exchange_u64_impl: 比較・交換（CAS）操作のインライン実装。
  • pg_atomic_fetch_add_u32_impl, pg_atomic_fetch_add_u64_impl: アトミックな加算と値の取得を行うインライン実装。

制御フローとデータフロー

1. 各関数は、まず sync 命令を発行して先行するメモリ操作を完了させます。 2. lwarx または ldarx 命令で対象変数をロードし、予約をかけます。 3. 比較（cmpw/cmpd）または演算（add/addi）を行い、条件付きストア命令 stwcx. / stdcx. を実行します。 4. ストアが失敗した場合（他のスレッド割り込み等）、ループ (bne) により予約とストアを再試行します。 5. 成功時は lwsync 命令で順序付けを保証し、必要に応じて条件レジスタ（mfcr）から結果を取得して呼び出し元へ返します。

直接依存

直接のローカルインヘリタンスやインクルードはありませんが、GCC のコンパイラ拡張（__GNUC__, __builtin_constant_p, インラインアセンブリ構文）に依存しています。

関連コード

  • src/include/port/atomics/generic.h: 本ファイルで定義されたインプレース実装を統括する上位の汎用アトミックヘッダー。
  • 他のアーキテクチャ固有ヘッダー（arch-x86.h, arch-arm.h 等）

読者向けメモ

  • 64 ビットアトミック操作 (pg_atomic_uint64) は、64 ビットモード（SIZEOF_VOID_P >= 8）でのみ有効化されます。
  • 定数最適化（HAVE_I_CONSTRAINT__BUILTIN_CONSTANT_P）により、即値をとれる場合は cmpwi や addi などの即値命令が選択されます。
