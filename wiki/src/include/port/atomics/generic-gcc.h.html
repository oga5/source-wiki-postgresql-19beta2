src/include/port/atomics/generic-gcc.h

概要

src/include/port/atomics/generic-gcc.h は、GCC または互換コンパイラ（Clang など）が提供するビルトイン関数を使用して、PostgreSQL のアトミック操作を実装するヘッダーファイルです。直接インクルードすることは意図されておらず、atomics.h 経由でのみインクルードされます。レガシーな __sync ビルトインと、メモリモデルを認識する新しい __atomic ビルトインの両方を抽象化します。

モジュール内での役割

src/include/port/atomics モジュール内において、プラットフォーム固有の最適化（arch-x86.h など）が適用されない環境やフォールバックが必要な環境で、GCC 互換の汎用アトミック操作を提供する役割を担います。

責務

  • **バリアの実装**: コンパイラバリアおよびメモリフェンス（Acquire/Release/SeqCst）を提供する。
  • **データ型の定義**: pg_atomic_flag、pg_atomic_uint32、pg_atomic_uint64 の定義とアライメント（64ビット型では8バイトアライメント）の確保。
  • **フラグ操作の実装**: テスト・アンド・セット（TAS）、ロッククリア、初期化などのフラグ操作をインライン関数で提供。
  • **算術・比較交換操作の実装**: 32ビットおよび64ビット整数に対する Compare-And-Swap (CAS)、Exchange、Fetch-and-Add/Sub/And/Or 操作の実装。

重要なシンボル

バリアおよびコンパイラ制御

  • pg_compiler_byter_impl(): 空の volatile アセンブリブロックによるコンパイラバリア。
  • pg_memory_barrier_impl(): __atomic_thread_fence または __sync_synchronize を用いたフルメモリバリア。
  • pg_read_barrier_impl() / pg_write_barrier_impl(): Acquire/Release セマンティクスを伴う読み取り/書き込みバリア。

データ構造

  • pg_atomic_flag: テスト・アンド・セット用のフラグ構造体（環境に応じて int または char の volatile 値）。
  • pg_atomic_uint32: 32ビット符号なし整数のアトミック wrapper。
  • pg_atomic_uint64: 8バイトアライメントが強制された64ビット符号なし整数のアトミック wrapper。

フラグ操作関数

  • pg_atomic_test_set_flag_impl(): フラグをセットし、以前の値がクリアされていたかを返す。
  • pg_atomic_unlocked_test_flag_impl(): ロックを取得せずにフラグの状態を確認する。
  • pg_atomic_clear_flag_impl(): フラグを解放する。
  • pg_atomic_init_flag_impl(): フラグを初期状態（クリア）にする。

整数アトミック操作関数 (32-bit / 64-bit)

  • pg_atomic_compare_exchange_u32_impl / u64_impl: 期待値と比較し、一致すれば新値を書き込む（__atomic_compare_exchange_n または __sync_val_compare_and_swap を使用）。
  • pg_atomic_exchange_u32_impl / u64_impl: 新値を書き込み、古い値を返す。
  • pg_atomic_fetch_add_u32_impl / u64_impl (他 sub, and, or): 算術・論理演算を行い、演算前の古い値を返す。

制御フローとデータフロー

1. **マクロによる機能検知**: コンパイル時フラグ（HAVE_GCC__ATOMIC_INT32_CAS や HAVE_GCC__SYNC_INT32_CAS など）に基づき、利用可能な最も高度なビルトイン関数（可能な場合は __atomic、フォールバックとして __sync）を選択してインライン関数を定義します。 2. **CAS操作のフロー**:

  • pg_atomic_compare_exchange_u32_impl では、*expected の値と ptr->value を比較します。
  • 一致した場合は newval がアトミックに書き込まれ、関数は true を返します。
  • 不一致の場合は、ptr->value の現在の値が *expected に書き戻され、関数は false を返します。

    • 3. **64ビット操作の制約**: PG_DISABLE_64_BIT_ATOMICS が定義されていない場合のみ有効化され、AssertPointerAlignment(expected, 8) によってポインタが8バイトアラインされていることが検証されます。

直接依存

  • 直接の #include 文はありません。コンパイラの事前定義マクロと、上位の atomics.h が提供する定義やアサーションマクロ（AssertPointerAlignment など）に依存します。

関連コード

  • src/include/port/atomics.h: このファイルを包括し、公開インターフェースを提供する上位ヘッダー。
  • src/include/port/atomics/generic.h: 汎用アトミック操作のディスパッチ元。
  • src/include/port/atomics/arch-x86.h: x86 アーキテクチャ固有の最適化実装。

読者向けメモ

  • **インガードの欠如**: 本ファイルにはインクルードガードが意図的に存在せず、INSIDE_ATOMICS_H が定義されている場合のみインクルードされる設計になっています。
  • **メモリ順序モデル**: 可能であれば __atomic ビルトインのシーケンシャル一貫性モデル（__ATOMIC_SEQ_CST）を優先し、レガシー環境では __sync ビルトインにフォールバックします。
