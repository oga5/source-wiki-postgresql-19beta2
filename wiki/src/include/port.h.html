src/include/port.h

概要

src/include/port.h は、PostgreSQL のプラットフォーム間での差異を吸収し、src/port/ および src/common/ 内の互換性関数を利用するための共通ヘッダーファイルです。ソケット型の抽象化、移植性の高いパス操作、標準ライブラリ関数の置き換え、各種システムコールのラッパー宣言を提供します。

モジュール内での役割

src/include モジュール内において、プラットフォーム固有の抽象化や移植性マクロを定義する基盤ヘッダーとして機能します。多くのバックエンドおよびフロントエンドソースからインクルードされ、OSごとのAPI（主にWindows/Win32とUnix系）の違いを隠蔽します。

責務

  • **ネットワーク抽象化**: ソケット型の定義（pgsocket、PGINVALID_SOCKET）、ソケットのブロック制御、およびネットワーク接続断エラーのマクロ定義（ALL_CONNECTION_FAILURE_ERRNOS）。
  • **パス・ファイルシステム操作**: ディレクトリ区切り文字や絶対パス判定のプラットフォーム別マクロ、パス正規化、ディレクトリ列挙（pgfnames）、再帰的削除（rmtree）などの宣言。
  • **文字列操作と安全なラッパー**: ASCII 大小文字変換、snprintf や strerror などの安全な独自置き換え版、および strlcpy / strlcat のような移植性関数の提供。
  • **プロセス・環境制御**: 実行バイナリの探索（find_my_exec 等）、シグナル処理（pqsignal）、乱数生成（pg_strong_random）、およびプロセス終了ステータスの解析。

重要なシンボル

ネットワーク関連

  • pgsocket: プラットフォームに応じたソケットディスクリプタ型（非Windowsでは int、Windowsでは SOCKET）。
  • PGINVALID_SOCKET: 無効なソケットを表すマクロ。
  • ALL_CONNECTION_FAILURE_ERRNOS: ネットワーク接続のハードエラー（EPIPE, ECONNRESET, ETIMEDOUT 等）をまとめた switch 用マクロ。

パス・ファイル操作

  • IS_DIR_SEP(ch) / is_absolute_path(filename): OSに応じて非Windows用またはWindows用の判定に切り替わるマクロ。
  • canonicalize_path(char *path): パス文字列を正規化する関数。
  • make_absolute_path(const char *path): 相対パスから絶対パスを生成する関数。
  • pgfnames(const char *path) / pgfnames_cleanup(char **filenames): ディレクトリ内のファイル名一覧を取得・解放する関数群。

移植性・文字列・フォーマット

  • pg_ascii_toupper / pg_ascii_tolower: C/POSIX ロケール規則に基づくインラインの文字大小文字変換関数。
  • snprintf / sprintf / vfprintf 等: すべて pg_ プレフィックス付きの安全な独自実装へマクロ置換。
  • strerror / strerror_r: 堅牢な独自ラッパーへ置換。

ソート・ユーティリティ

  • qsort: 内部で pg_qsort に置き換えられるマクロ。
  • qsort_arg / bsearch_arg: 追加の引数を取るソートおよび二分探索関数。

制御フローとデータフロー

  • **パス解決フロー**: find_my_exec や find_other_exec を通じて自身の実行ファイルのパスを特定し、get_share_path や get_lib_path などのヘルパー関数へ渡すことで、設定ファイルやリソースの絶対パスを動的に構築します。
  • **入出力の安全化**: snprintf や strerror などの標準関数呼び出しは、マクロによって PostgreSQL 独自の安全な実装（pg_snprintf, pg_strerror 等）へリダイレクトされ、バッファオーバーランやロケールの問題を回避します。
  • **プラットフォーム分岐**: #ifndef WIN32 などのプリプロセッサ分岐により、ファイルオープンやソケットクローズ（closesocket）などの挙動をプラットフォーム固有のラッパー関数へと振り分けます。

直接依存

  • <ctype.h>
  • port/win32_port.h （Windows 環境のみ）
  • <io.h> （MSVC 環境の Windows のみ）
  • <unistd.h> （MinGW 環境の Windows のみ）
  • <netinet/in.h> （HAVE_INET_ATON 未定義時）
  • <arpa/inet.h> （HAVE_INET_ATON 未定義時）
  • <math.h> （Clang 使用時の isinf 組み込み関数対策）

関連コード

  • src/port/: 本ヘッダーで宣言されている各種互換性関数（パス処理、シグナル、文字列操作等）の実装元。
  • src/common/: pgfnames.c や wait_error.c などの共通実装。
  • src/include/postgres.h: PostgreSQL の全体的な基本型やマクロを定義するヘッダー。

読者向けメモ

  • **printf系のマクロ置換**: printf を除く多くのフォーマット出力関数は __VA_ARGS__ を用いたマクロで置き換えられています。そのため、これらの関数への関数ポインタを取得する際は、マクロの影響を避けるために pg_printf などを直接指定する必要があります。
  • **Windows固有の動作**: Windows 環境では rename、unlink、open、fopen、system、popen などが pg プレフィックス付きの関数や _lseeki64、_chsize_s を利用するマクロに置き換えられており、排他制御や64ビット対応のエミュレーションが行われています。
