src/include/port.h

概要

src/include/port.h は、PostgreSQL の src/port/ 互換関数群およびプラットフォーム間の差異を隠蔽するためのヘッダーファイルです。Windows (Win32) と POSIX (Unix) 系の差異を吸収し、標準ライブラリの関数を独自実装に置き換えたり、プラットフォーム固有の機能をラップするためのマクロや関数宣言を提供します。

モジュール内での役割

src/include モジュール内において、プラットフォーム非依存なインターフェースとOS固有の差異をつなぐ基盤ヘッダーとして機能します。多くのコアソースファイルやフロントエンド（libpq等）が依存する基本的な型、パス処理、ネットワークエラー定義、文字列操作などを定義しています。

責務

  • プラットフォーム差異の吸収: Windows と Unix 間のソケット型、パス区切り文字、ファイルI/O、シグナル処理の差異を吸収する。
  • ポータブルなパス処理: パスの正規化、絶対パス・相対パスの判定、ディレクトリ名・ファイル名の操作に関する関数を提供する。
  • ネットワーク・エラーとソケットの抽象化: ソケット型（pgsocket）や接続断を判定するエラーコードマクロ（ALL_CONNECTION_FAILURE_ERRNOS）を定義する。
  • 標準関数の置換と拡張: snprintf、strerror、qsort などを安全な PostgreSQL 独自実装にリダイレクトする。
  • ユーティリティ関数の宣言: ディレクトリ走査（pgfnames）、暗号論的に強力な乱数生成、プロセス実行（find_my_exec 等）のインターフェースを提供する。

重要なシンボル

プラットフォーム・ネットワーク関連

  • pgsocket: ソケット記述子の型。非 Windows 環境では int、Windows 環境では SOCKET に定義されます。
  • socklen_t: プラットフォームが socklen_t を提供しない場合に unsigned int として定義されます。
  • SOCKET / ECONNRESET / EPIPE / ETIMEDOUT: ネットワーク通信のエラーやソケット関連のシンボル。特に ALL_CONNECTION_FAILURE_ERRNOS マクロは、ネットワーク接続のハードエラー（EPIPE, ECONNRESET 等）を switch 文でまとめて処理するために使用されます。

ソート・探索関数

  • pg_qsort: 標準の qsort のラッパーであり、通常は qsort マクロによって置き換えられます。
  • bsearch_arg: ユーザー引数（arg）を受け取ることができる拡張版の二分探索関数です。

ユーティリティ・システム・シグナル関連

  • pg_: pg_strcasecmp、pg_usleep、pg_snprintf、pg_strerror など、プレフィックスに pg_ を持つ一連の移植性向上関数の総称です。
  • pgoff_t: fseeko/ftello で使用されるファイルオフセット型（非 Windows 環境では off_t）。
  • qsort_arg_comparator: 追加のコンテキスト引数を受け取るソート用コンパレータ関数の型定義。
  • SIGNAL_ARGS: シグナルハンドラーの引数型定義（pqsigfunc で使用）。

制御フローとデータフロー

  • パスの正規化と解決: canonicalize_path や make_absolute_path などの関数を通じて、異なるOSのパス区切り文字（/ と \）を適切に扱い、バッファ上でのパス文字列を安全に変換・構築するフローを支えます。
  • エラーハンドリングと文字列置換: strerror や strerror_r が pg_strerror にマクロ置換されているため、システムエラー番号からエラーメッセージを取得する際は常に堅牢なラッパー経由で処理が行われます。
  • ソート処理: コード中の qsort(...) 呼び出しはマクロにより自動的に pg_qsort(...) へルーティングされ、プラットフォーム依存を排除した安定したソート処理を実現します。

直接依存

  • <ctype.h>
  • "port/win32_port.h"（WIN32 かつ !__CYGWIN__ の場合）
  • <io.h>（MSVC 環境の場合）
  • <math.h>（Clang で isinf 組み込み関数を利用する場合）
  • <netinet/in.h> / <arpa/inet.h>（HAVE_INET_ATON が未定義の場合）

関連コード

  • src/port/: 本ヘッダーで宣言されている多くの関数（パス操作、pg_qsort、pg_usleep など）の実体が存在するディレクトリ。
  • src/include/c.h: PostgreSQL の基本型やマクロが定義されている、本ファイルの前提となるヘッダー。

読者向けメモ

  • マクロによる置換: snprintf や strerror などの標準関数は、安全性と一貫性を担保するため pg_ プレフィックス付きの独自実装にマクロですり替えられています。関数ポインタを取得する際には注意が必要です。
  • Windows 特有の挙動: Windows 環境では open、fopen、rename、unlink、lseek などのシステムコールが pgwin32_ 系関数や64位対応版（_lseeki64 等）に置き換えられます。
