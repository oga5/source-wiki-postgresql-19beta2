src/include/portability/instr_time.h

概要

ポータブルな高精度インターバル計測のための抽象化レイヤーを提供するヘッダーファイルです。Unix 系システムでは clock_gettime()、Windows では QueryPerformanceCounter()、x86-64 アーキテクチャでは RDTSC/RDTSCP 命令を直接利用して時間を計測します。計測値は不透明な型 instr_time として隠蔽され、マクロを通じてゼロ初期化、加算、減算、比較、単位変換などの操作を行います。

モジュール内での役割

src/include/portability サブシステムの一部として、プラットフォーム固有のタイマー API の差異を吸収し、バックエンドおよびフロントエンドプログラム共通の高精度計測基盤を提供します。

責務

  • **データ型定義**: 計測値を格納する不透明な instr_time 構造体の提供。
  • **プラットフォーム非依存のマクロ API**: 計測の開始・停止・加算・差分計算・単位変換を行う INSTR_TIME_* マクロ群の定義。
  • **クロックソース管理**: システムクロックとハードウェア TSC（Time Stamp Counter）の切り替え管理、およびナノ秒単位へのスケーリング制御。
  • **低レベル計測関数**: ターゲットアーキテクチャに応じた最適な命令（clock_gettime, QueryPerformanceCounter, RDTSC, RDTSCP）のインラインラッパー提供。

重要なシンボル

型・データ構造

  • instr_time: 内部にプラットフォーム固有の ticks（int64）を保持する不透明な計測値構造体。
  • TimingClockSourceType: クロックソースの種類を表す列挙型（TIMING_CLOCK_SOURCE_AUTO, TIMING_CLOCK_SOURCE_SYSTEM, TIMING_CLOCK_SOURCE_TSC）。
  • TscClockSourceInfo: TSC クロスの周波数やソース情報を保持する構造体（PG_INSTR_TSC_CLOCK 有効時のみ）。

初期化・制御関数

  • pg_initialize_timing(void): タイミングインフラストラクチャを初期化する。
  • pg_set_timing_clock_source(TimingClockSourceType source): 使用するクロックソースを設定する。
  • pg_current_timing_clock_source(void): 現在有効なクロックソースを返すインライン関数。

変換・取得ヘルパー

  • pg_get_ticks(void) / pg_get_ticks_fast(void): 現在時刻を instr_time として取得する（必要に応じて OOO ウィンドウの完了を待機）。
  • pg_ticks_to_ns(int64 ticks): プラットフォーム固有の ticks をナノ秒に変換する。
  • pg_ns_to_ticks(int64 ns): ナノ秒をプラットフォーム固有の ticks に変換する。
  • pg_rdtsc(void) / pg_rdtscp(void): x86 の rdtsc/rdtscp 命令のインラインラッパー。

制御フローとデータフロー

1. **初期化**: ユーザーコードやシステム起動時に pg_initialize_timing() が呼ばれ、プラットフォームに応じたシステムクロックの初期設定が行われます。 2. **計測 (INSTR_TIME_SET_CURRENT)**:

  • pg_get_ticks() が呼び出され、timing_tsc_enabled が真であれば pg_rdtscp()（または高速版の pg_rdtsc()）により CPU の TSC を直接読み込みます。
  • 偽であれば pg_get_ticks_system() を経由して clock_gettime() または QueryPerformanceCounter() の値を読み込みます。

    • 3. **変換と計算**:

  • 測定値は instr_time.ticks に格納され、累積や差分計算は整数演算（加算・減算）で高速に行われます。
  • 最終的な出力時に pg_ticks_to_ns() が呼ばれ、必要に応じて固定小数点シフト（TICKS_TO_NS_SHIFT）とスケーリング値（ticks_per_ns_scaled）を用いたオーバーフロー防止付きのスケーリング演算を経てナノ秒に変換されます。

直接依存

  • <time.h>: ポータブルなシステムクロック（clock_gettime）を利用する場合の定義。
  • <intrin.h>: MSVC 環境で x86 組み込み関数（__rdtsc 等）を利用する場合の定義。

関連コード

  • src/common/instr_time.c: 非インラインのタイミング初期化およびスケーリング因子の計算を実装するペアファイル。

読者向けメモ

  • **メモリ安全性とライフサイクル**: instr_time は値型として扱われ、スタックや構造体のメンバーとして直接保持されます。明示的な解放処理は不要です。
  • **インライン最適化**: 頻繁に呼び出される pg_get_ticks および pg_get_ticks_fast は、コンパイラの最適化ヒューリスティックの制限を回避するため pg_always_inline が付与されています。
  • **GUC 変更時の注意**: タイミング計測中にグローバルなクロックソースやスケーリング係数を変更すると不正な計測結果を生むため、計測中の変更は想定されていません。
