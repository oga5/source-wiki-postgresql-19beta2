src/include/nodes/nodeFuncs.h

概要

src/include/nodes/nodeFuncs.h は、PostgreSQLの構文木や実行計画木などの Node ツリーを汎用的に操作・検査するための関数群、マクロ、コールバック型定義を提供するヘッダーファイルです。式ツリーの型推定、ウォーカー／ミューテーターの共通マクロ群、および述語や論理演算子（AND/OR/NOT など）の判定・分解を行うインライン関数を定義しています。

モジュール内での役割

src/backend/nodes/nodeFuncs.c と対をなすヘッダーであり、src/include/nodes モジュール配下において、パーサーやオプティマイザ、エグゼキューターが共通して必要とする構文木ノードのユーティリティを提供します。特に、不必要な execnodes.h のインクルードを避けるための前方宣言（PlanState）や、型安全性を高めつつコールバックを渡すためのマクロラッパー群を集約しています。

責務

  • 式ノードの属性取得と操作: 式の結果型（exprType）、型修飾子、照合順序（Collation）、位置情報の取得。
  • 式構造の判定と分解: 関数呼び出し、演算子、AND/OR/NOT などの論理演算子の判定および引数の抽出（インライン関数による高速な実装）。
  • ツリー走査・変形フレームワーク: expression_tree_walker / mutator や query_tree_walker / mutator などのマクロ定義を通じた、抽象構文木（AST）およびクエリ木のトラバーサル機構の提供。
  • 制御フラグの定義: クエリツリー走査時の挙動を制御する QTW_* フラグ群（サブクエリやレンジテーブルの無視・検査など）の定義。

重要なシンボル

基本データ型と前方宣言

  • PlanState (struct): 実行計画ノードの状態を表す構造体の前方宣言。ヘッダー内での循環インクルードや不要な依存を避けるために定義されています。
  • Oid: PostgreSQLのオブジェクト識別子（OID）。式の結果型やOID操作の基本型として利用されます。
  • Node: すべての構文木ノードの基底構造体。

句および論理演算子の判定・分解（インライン関数）

  • is_funcclause: 指定された句が FuncExpr ノードであるかを判定します（NULL安全）。
  • is_opclause: 指定された句が OpExpr ノードであるかを判定します。
  • get_leftop: 二項演算子句の左引数、または単項演算子句の唯一の引数を抽出します（引数がなければ NULL）。
  • get_rightop: 二項演算子句の右引数を抽出します（単項の場合は NULL）。
  • is_andclause: BoolExpr が AND_EXPR であるかを判定します。
  • is_orclause: BoolExpr が OR_EXPR であるかを判定します。
  • is_notclause: BoolExpr が NOT_EXPR であるかを判定します。
  • get_notclausearg: NOT 句からその内部引数（Expr）を抽出します。

制御フローとデータフロー

  • ツリー走査（Walker / Mutator）:

    • 使用者側は expression_tree_walker(node, walker_func, context) などのマクロを呼び出します。マクロ層で関数ポインタのキャスト（tree_walker_callback への変換）を行い、コンパイラの型警告を抑制しつつ、実体関数（_impl サフィックスを持つ関数）へ処理を委譲します。

  • 演算子・句の検査:

    • オプティマイザやプランナーが WHERE 句やターゲットリストを走査する際、is_andclause や is_opclause などの軽量なインライン関数でノードの種類を高速に判別し、get_leftop / get_rightop を通じて子式へのアクセスを行います。

直接依存

  • nodes/parsenodes.h: パーサーのノード定義（Query, RangeTblEntry など）

関連コード

  • src/backend/nodes/nodeFuncs.c: 本ヘッダーで宣言された非インライン関数（exprType や各種 walker/mutator の実装）の本体。
  • src/include/nodes/nodes.h: Node タグや IsA マクロなどの基礎定義。

読者向けメモ

  • メモリ管理とライフタイム: このファイルで定義される関数群はツリーの構造を変更・検査するものであり、メモリーコンテキスト自体の割り当てや解放は行いません。変更後のツリーは通常、呼び出し元のメモリーコンテキスト上で構築されます。
  • 型キャストのマクロ: expression_tree_walker などのマクロでは、C標準の void * に対する構造体ポインタの互換性警告を回避するため、明示的な関数ポインタキャストが挿入されています。
