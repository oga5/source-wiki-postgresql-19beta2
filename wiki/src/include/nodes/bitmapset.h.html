src/include/nodes/bitmapset.h

概要

非負整数の集合を効率的に表現・操作するための汎用ビットマップセット（Bitmapset）パッケージのインターフェースを定義するヘッダーファイルです。

モジュール内での役割

  • src/include/nodes サブシステムの一部として、プランナやオプティマイザなどで頻繁に使用される集合演算のデータ構造を提供します。
  • 実体処理を行うペアファイル src/backend/nodes/bitmapset.c に対する公開 API を定義しています。

責務

  • 64ビットまたは32ビットのワードを用いた動的なビットマップ構造体 Bitmapset の定義。
  • 集合の比較結果（BMS_Comparison）や所属状態（BMS_Membership）を表す列挙型の提供。
  • 和集合、積集合、差集合、メンバー判定、イテレーション、ハッシュ化などの関数プロトタイプの宣言。

重要なシンボル

  • Bitmapset: ノードタグ、ワード数、可変長ワード配列を持つメインの構造体。
  • bitmapword / signedbitmapword: プラットフォームのポインタサイズに応じたビット演算用の符号なし／符号付き整数型。
  • BMS_Comparison / BMS_Membership: 集合間の関係や要素数を判定するための列挙型。
  • bms_is_empty: 空集合（NULL ポインタ）を効率的に判定するマクロ。

制御フローとデータフロー

  • 空集合は NULL ポインタとして表現され、有効な Bitmapset は常に1つ以上のワードを持ちます。末尾のゼロワードは許可されません。
  • 呼び出し側は、集合を変更する関数（例: bms_add_member）の戻り値を元のポインタに再代入する必要があります。
  • プラットフォームのワード長に応じて、bmw_leftmost_one_pos、bmw_rightmost_one_pos、bmw_popcount などのビット操作マクロが適切にルーティングされます。

直接依存

  • nodes/nodes.h: NodeTag および関連するノード属性マクロの定義のため。

関連コード

  • src/backend/nodes/bitmapset.c: ビットマップセットの実際のロジックとメモリ管理を実装するペアファイル。
  • port/pg_bitutils.h: ポップカウントやビット位置検索などの低水準ビット操作関数を提供。

読者向けメモ

  • 集合を変更する関数はインプレースで更新する保証がないため、返り値の取り扱いに注意が必要です。
  • 最大値が比較的小さい（数百程度までの）非負整数の集合を対象に最適化されています。
