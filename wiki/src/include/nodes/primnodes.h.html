src/include/nodes/primnodes.h

概要

src/include/nodes/primnodes.h は、PostgreSQLのクエリパイプライン（解析・計画・実行）の複数のステージで共通して使用される「プリミティブ」なノード型の定義を提供するヘッダーファイルである。主に実行可能式（executable expressions）および結合ツリー（join trees）を構成するノード構造体、列挙型、およびマクロが定義されている。

モジュール内での役割

src/include/nodes サブシステム内において、本ファイルはクエリのパース段階で生成された構文木が最適化や実行に向けてどのように表現・変形されるかの基本データ構造を定めている。parsenodes.h が主にパース段階の表現を扱い、plannodes.h や execnodes.h が計画・実行段階を扱うのに対し、primnodes.h はそれらのステージ間で横断的に利用される式や演算子の基盤を提供する。

責務

  • 式ノードの定義: 変数、定数、関数呼び出し、演算子、キャスト、制御構造（CASE、COALESCEなど）といった実行可能式のノード構造体を定義する。
  • 結合ツリーノードの定義: FROM句やJOIN構造を表現するための RangeTblRef、JoinExpr、FromExpr などの構造体を定義する。
  • 特殊クエリ構築ノードの定義: ターゲットリストエントリ (TargetEntry)、サブ計画 (SubPlan)、JSON/XML処理用ノード、ウィンドウ関数や集約関数用のノードを定義する。

重要なシンボル

識別子・基本情報・範囲変数

  • Alias: 範囲変数やテーブル名に付与される別名、および列のリネーム情報を保持する。
  • RangeVar: FROM句やユーティリティ文におけるテーブル名、カタログ名、スキーマ名、継承フラグ、別名を指定する。
  • TableFunc: XMLTABLE や JSON_TABLE などのテーブル関数の入力ドキュメント、行フィルタ、列定義、計画を保持する。
  • IntoClause: SELECT INTO、CREATE TABLE AS、CREATE MATERIALIZED VIEW のターゲット情報を保持する。
  • TargetEntry: クエリのターゲットリスト（targetList）のエントリ。式、列番号 (resno)、列名、ソート・グループ参照インデックスなどを保持する。

実行式（Expr）と基本項

  • Expr: すべての実行可能式ノードの抽象的なスーパー親クラス（先頭フィールドとして NodeTag type を持つ）。
  • Var: テーブル列などの変数を表す式ノード。varno、varattno、型情報、外側参照を示す varlevelsup などを保持する。
  • Const: 定数値を表す式ノード。バッファ内の値 (constvalue)、型、NULLフラグを保持する。
  • Param: パラメータを表す式ノード。PARAM_EXTERN、PARAM_EXEC、PARAM_SUBLINK、PARAM_MULTIEXPR などの種類とIDを持つ。

集約・ウィンドウ関数・グループ化

  • Aggref: 集約関数呼び出しを表すノード。関数Oid、引数リスト、ORDER BY/DISTINCT 句、フィルタなどを保持する。
  • GroupingFunc: GROUPING(...) 式を表し、GROUP BY句のどの列に対応するかを示す。
  • WindowFunc: ウィンドウ関数呼び出しを表すノード。
  • WindowFuncRunCondition: WindowAgg の実行をショートサーキットするための中間演算子式を表す。
  • MergeSupportFunc: MERGE コマンドの RETURNING リストで実行されたアクション（INSERT/UPDATE/DELETE）を返す関数式。

コンテナ・演算・関数呼び出し

  • SubscriptingRef: 配列やコンテナに対する添字付け（単一要素の取得・更新、スライスの取得・更新）を記述する。
  • FuncExpr: 関数呼び出しを表す式ノード。
  • NamedArgExpr: 関数呼び出しにおける名前付き引数を表す。
  • OpExpr: 演算子呼び出しを表す式ノード。
  • ScalarArrayOpExpr: scalar op ANY/ALL (array) 形式の比較式を表す。
  • BoolExpr: 基本的なブール演算子（AND、OR、NOT）の式ノード。

サブクエリ・副計画

  • SubLink: 式の中に現れるサブセレクト（EXISTS、IN、スカラーサブクエリなど）を表す。
  • SubPlan: プランナーが SubLink を置き換える、実行可能なサブ計画ノード。
  • AlternativeSubPlan: 高速スタートプラン等の代替サブ計画から選択するためのトランジスタノード。

型キャスト・値変換・制御構造

  • FieldSelect: タプル値から1つのフィールドを抽出する操作を表す。
  • FieldStore: タプル値の1つのフィールドを変更し、新しいタプル値を生成する操作を表す。
  • RelabelType: バイナリ互換な型の間での「ダミー」の型キャストを表す。
  • CoerceViaIO: 入出力関数を介した型キャストを表す。
  • ArrayCoerceExpr: 配列型から別の配列型への、要素ごとのキャストを表す。
  • ConvertRowtypeExpr: 複合型（行型）から別の複合型への名前ベースの変換を表す。
  • CollateExpr: 照合順序（Collation）を指定する式ノード（前処理で RelabelType に置換される）。
  • CaseExpr: CASE 式を表す。
  • CaseWhen: CASE 式の1つの WHEN 条件アームを表す。
  • CaseTestExpr: CASE 式、ArrayCoerceExpr、ネストされた代入式などで評価値を一時保持するプレースホルダーノード。
  • ArrayExpr: ARRAY[...] リスト式を表す。
  • RowExpr: ROW(...) 行構築式を表す。
  • RowCompareExpr: (a, b) <= (1, 2) のような行単位の比較式を表す。
  • CoalesceExpr: COALESCE 式を表す。
  • MinMaxExpr: GREATEST または LEAST 関数を表す。
  • SQLValueFunction: CURRENT_DATE や CURRENT_USER などのパラメータレス特殊関数を表す。

XML/JSON および 特殊式

  • XmlExpr: 各種SQL/XML関数を表す。
  • JsonFormat: JSON形式句を表す。
  • JsonReturning: JSONの RETURNING 句の変換表現。
  • JsonValueExpr: JSON値式を表す。
  • JsonConstructorExpr: SQL/JSONコンストラクターを表す。
  • JsonIsPredicate: IS JSON 述語を表す。
  • JsonBehavior: SQL/JSONの ON ERROR / ON EMPTY の振る舞いを指定する。
  • JsonExpr: JSON_VALUE()、JSON_QUERY()、JSON_EXISTS() の変換済み表現。
  • JsonTablePath: JSON_TABLE プランノード用のJSONパス式。
  • JsonTablePlan: JSON_TABLE の実行計画を表す抽象クラス。
  • JsonTablePathScan: JSONパス式を評価する JSON_TABLE プラン。
  • JsonTableSiblingJoin: 兄弟 NESTED COLUMNS 句の行を結合するプラン。
  • NullTest: IS NULL / IS NOT NULL テストを表す。
  • BooleanTest: IS TRUE / IS FALSE / IS UNKNOWN テストを表す。
  • MergeAction: MERGE 文の WHEN 句の変換済み表現。
  • CoerceToDomain: ドメイン型への型強制と制約チェックを表す。
  • CoerceToDomainValue: ドメインチェック制約用のプレースホルダー値。
  • SetToDefault: INSERT または UPDATE における DEFAULT マーカー。
  • CurrentOfExpr: [WHERE] CURRENT_OT cursor_name を表す。
  • NextValueExpr: シーケンスからの次値取得（権限チェックなし）を表す。
  • InferenceElem: 一意インデックス推論仕様の要素。
  • ReturningExpr: 更新可能なビュー等の RETURNING リストで OLD/NEW 式を展開するラッパー。
  • GraphLabelRef: GRAPH_TABLE 句内のラベル参照。
  • GraphPropertyRef: GRAPH_TABLE 句内のプロパティ参照。

結合ツリーノード

  • RangeTblRef: クエリのレンジテーブル（RTE）のエントリへの参照。
  • JoinExpr: SQLの JOIN 式を表す。
  • FromExpr: FROM ... WHERE ... 構造を表す（複数の結合サブ subtree を保持可能）。
  • OnConflictExpr: ON CONFLICT DO ... 式を表す。
  • ForPortionOfExpr: FOR PORTION OF （期間指定更新）式を表す。

制御フローとデータフロー

本ファイルは純粋なヘッダーファイル（データ構造の定義）であり、関数本体の実装を含まないため直接的な制御フローは持たない。

  • データフロー: パーサー（gram.y および parse_expr.c 等）がクエリ文字列を解析してこれら Expr 派生ノードを構築する。その後、クエリリライターおよびオプティマイザー（プランナー）がそれらをトラバース・変形し、最終的に PlannedStmt や実行ステージ（execnodes.h の ExprState 等）へと引き渡される。

直接依存

  • access/attnum.h: 属性番号 (AttrNumber) の定義
  • access/cmptype.h: 比較型 (CompareType) の定義
  • nodes/bitmapset.h: ビットマップセット (Bitmapset) の定義
  • nodes/lockoptions.h: ロックオプション (LockClauseStrength 等) の定義
  • nodes/pg_list.h: リスト構造 (List) の定義

関連コード

  • src/include/nodes/parsenodes.h: 解析段階の構文木ノード定義
  • src/include/nodes/plannodes.h: 計画段階のプランノード定義
  • src/include/nodes/execnodes.h: 実行段階のノードおよび ExprState の定義
  • src/include/nodes/nodeFuncs.h: ノードツリーを操作・走査する共通関数群

読者向けメモ

  • メモリ所有権: 定義されているノードは通常、PostgreSQLのメモリコンテキスト（MemoryContext）上に割り当てられ、明示的な個別解放ではなくコンテキストのリセットによって一括管理される。
  • query_jumble_ignore 等の属性: 各構造体フィールドに付与されている pg_node_attr(...) マクロ（例: query_jumble_ignore, equal_ignore）は、pg_stat_statements のクエリ正規化（jumbling）や等価性比較において、どのフィールドを無視すべきかを指定している。ソースコードを読む際はこれらのアトリビュートに注意すること。
