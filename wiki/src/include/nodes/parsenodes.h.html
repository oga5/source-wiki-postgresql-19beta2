src/include/nodes/parsenodes.h

概要

PostgreSQLのパーサや文法解析器（gram.y）が生成する、構文木（Parse Tree）、クエリツリー（Query）、および各種DDL/DMLユーティリティ文のノード構造体を定義する中心的なヘッダーファイルである。数千行におよび多様なノード構造が含まれるため、PostgreSQLコンパイラやプランナの前段階におけるデータ表現の基盤をなす。

モジュール内での役割

src/include/nodes サブシステムの一部であり、抽象構文木（AST）の共通定義である nodes.h や、式ノードを定義する primnodes.h と深く結合している。パーサが生成した生（raw）のツリー構造を型安全に保持し、パーサ解析（parser/analyze.c）やリライタを経て、最終的にプランナへ渡る Query 構造体へ変換するためのデータモデルを提供する。

責務

  • **生構文木の定義**: SQL文法（gram.y）直後の表現となる SelectStmt, InsertStmt, UpdateStmt, DeleteStmt, MergeStmt などのステートメント単位ノードの定義。
  • **クエリツリーの定義**: 解析済みの最適化可能クエリを表現する Query 構造体および RangeTblEntry（RTE）の定義。
  • **式および節の表現**: TypeName, ColumnRef, A_Expr, FuncCall, SortGroupClause などの、クエリ内の細かな式や節を表現する補助ノード群の提供。
  • **DDL・ユーティリティ文の定義**: CreateStmt, AlterTableStmt, DropStmt など、非最適化または特殊処理を要するコマンド用構造体の網羅。

重要なシンボル

コア・クエリと範囲テーブル構造

  • **Query**: パーサ解析によってすべてのSQL文（最適化可能なもの）が変換されるルートツリー構造。リライタおよびプランナの入力となる。
  • **RangeTblEntry (RTE)**: Query->rtable を構成する要素。リレーション、サブクエリ、結合（JOIN）、関数、CTEなどのソースを統一的に識別する。
  • **RTEPermissionInfo**: 各RTEに対する実行時権限チェックや列レベルのアクセス権（selectedCols, insertedCols, updatedCols）を保持する。
  • **RangeTblFunction**: 関数形式のRTE（RTE_FUNCTION）における個々の関数式や列定義メタデータを保持する。
  • **TableSampleClause**: 変換済みのFROM句等に現れる TABLESAMPLE 句のハンドラOIDと引数を保持する。
  • **WithCheckOption**: 自動更新可能なビューや行セキュリティポリシー（RLS）における WITH CHECK OPTION 制約の条件式。

式・定数および名前解決ノード

  • **TypeName**: 型定義やキャストにおいてデータ型を特定するための一時的またはOIDベースの構造。
  • **ColumnRef**: 列名や修飾子、アスタリスク（*）の参照を保持する。
  • **ParamRef**: $n 形式のパラメータ参照。
  • **A_Expr**: 未解析のインフィックス、プレフィックス、ポストフィックス式（演算子、IN, LIKE, BETWEEN など）。
  • **A_Const**: リテラル定数。インライン化された ValUnion を用いて効率的に数値を保持する。
  • **TypeCast**: 明示的なキャスト式（CAST(... AS ...)）。
  • **CollateClause**: 照合順序（Collation）を指定する式。
  • **RoleSpec**: ロール名や CURRENT_USER などの特殊なロール指定。
  • **FuncCall**: 関数や集約関数の呼び出し（ORDER BY, FILTER, OVER などを内包）。
  • **A_Star**: * による全列展開のマーカー。
  • **A_Indices**: 配列の添字やスライス境界（[idx] または [lidx:uidx]）。
  • **A_Indirection**: 複合型のフィールド選択や配列添字アクセスを連鎖的に保持する（例: (foo).field1[42]）。
  • **A_ArrayExpr**: ARRAY[...] 構成要素のリスト。
  • **ResTarget**: SELECTのターゲットリストにおける列ラベル、またはINSERT/UPDATEの代入先列。
  • **MultiAssignRef**: SET (a, b) = (...) 形式の更新におけるマルチ代入ソースの参照。
  • **SortBy**: ORDER BY 句における式、ソート方向、NULL順序指定。
  • **WindowDef**: WINDOW や OVER 句の生表現（パーティションやフレームオプションを保持）。

範囲（Range）およびテーブル構造

  • **RangeSubselect**: FROM句内のサブクエリ。
  • **RangeFunction**: FROM句内の関数呼び出し（ROWS FROM(...) を含む）。
  • **RangeTableFunc**: XMLTABLEなどのテーブル関数の生表現。
  • **RangeTableFuncCol**: テーブル関数内の個々の生成列。
  • **RangeGraphTable**: GRAPH_TABLE 句の生表現。
  • **RangeTableSample**: 生のFROM句における TABLESAMPLE のラップ構造。
  • **ColumnDef**: カラム定義（制約、デフォルト値、データ型など）。
  • **TableLikeClause**: CREATE TABLE (... LIKE ...) のオプション。
  • **IndexElem**: インデックス定義やON CONFLICT句におけるインデックス要素。
  • **DefElem**: 汎用的な name = value オプション定義。
  • **LockingClause**: FOR UPDATE / FOR SHARE などのロッキング句。
  • **XmlSerialize**: XMLSERIALIZE 式の生表現。

パーティショニング構造

  • **PartitionElem**: パーティションキーの単一要素（式または列）。
  • **PartitionSpec**: パーティショニング戦略とキーの仕様。
  • **PartitionBoundSpec**: 個々のパーティションに割り当てられた値の境界仕様（Hash, List, Range）。
  • **PartitionRangeDatum**: 範囲パーティション境界の構成要素（MINVALUE, MAXVALUE, 特定値）。
  • **SinglePartitionSpec**: 分割（SPLIT）等の対象となる単一パーティションの仕様。
  • **PartitionCmd**: ALTER TABLE等でのパーティションアタッチ/デタッチ/分割/結合コマンドの仕様。

グラフパターン（Property Graph）構造

  • **GraphPattern**: パスパターンリストとWHERE句を保持するグラフクエリの構造。
  • **GraphElementPattern**: 頂点やエッジのパターン（VERTEX_PATTERN, 各種 EDGE_PATTERN）。

節・修飾句・CTE構造

  • **SortGroupClause**: ORDER BY, GROUP BY, DISTINCT で使用されるソート・グループ化・等価比較演算子の表現。
  • **GroupingSet**: CUBE, ROLLUP, GROUPING SETS 句のツリー構造。
  • **WindowClause**: 解析済みのウィンドウ関数用句（WINDOW / OVER）。
  • **RowMarkClause**: クエリツリー内の行ロック要求の表現。
  • **ForPortionOfClause**: FOR PORTION OF 句（期間/マルチレンジ更新用）。
  • **WithClause**: WITH 句（CTEリストを保持）。
  • **InferClause**: ON CONFLICT における一意インデックス推論句。
  • **OnConflictClause**: ON CONFLICT 句のアクション定義。
  • **CTESearchClause**: CTEの探索句（Breadth-First等）。
  • **CTECycleClause**: CTEの循環検出句（CYCLE）。
  • **CommonTableExpr**: 各CTEの定義（マテリアライゼーションやサブクエリを保持）。
  • **MergeWhenClause**: MERGE 文における WHEN 句の生パーサ表現。
  • **ReturningClause**: RETURNING 句（式とRETURNING WITHオプション）。
  • **TriggerTransition**: トリガーの遷移ロー/テーブル命名句。

SQL/JSONサポート構造

  • **JsonOutput**: JSON関数の出力句（RETURNING type）。
  • **JsonArgument**: PASSING 句の引数。
  • **JsonFuncExpr**: JSONクエリ関数の未解析表現。
  • **JsonTablePathSpec**: JSONパス式の仕様。
  • **JsonTable**: JSON_TABLE の未解析表現。
  • **JsonTableColumn**: JSON_TABLE のカラム定義。
  • **JsonKeyValue**: JSONオブジェクトのキー・バリューペア。
  • **JsonParseExpr**, **JsonScalarExpr**, **JsonSerializeExpr**: 各種JSON式。
  • **JsonObjectConstructor**, **JsonArrayConstructor**, **JsonArrayQueryConstructor**: JSON構築式。
  • **JsonAggConstructor**, **JsonObjectAgg**, **JsonArrayAgg**: JSON集約関数。

ステートメント（DML・DDL・ユーティリティ）構造

  • **RawStmt**: 単一の生パーサツリー（stmt）を保持するコンテナ。
  • **InsertStmt**, **DeleteStmt**, **UpdateStmt**, **MergeStmt**: 各種DML文の生パーサ構造。
  • **SelectStmt**: SELECT 文や集合演算（UNION/INTERSECT/EXCEPT）のツリー構造。
  • **SetOperationStmt**: 解析済みの集合演算ノード。
  • **ReturnStmt**: SQL関数内部の RETURN 文。
  • **PLAssignStmt**: PL/pgSQLの代入文。
  • **CreateSchemaStmt**, **AlterTableStmt**, **AlterTableCmd**, **ATAlterConstraint**, **ReplicaIdentityStmt**, **AlterDomainStmt**, **GrantStmt**, **ObjectWithArgs**, **AccessPriv**, **GrantRoleStmt**, **AlterDefaultPrivilegesStmt**, **CopyStmt**, **VariableSetStmt**, **VariableShowStmt**, **CreateStmt**, **Constraint**, **AlterTableMoveAllStmt**, **AlterExtensionContentsStmt**, **CreateForeignTableStmt**, **ImportForeignSchemaStmt**, **CreatePolicyStmt**, **AlterPolicyStmt**, **CreateTrigStmt**, **CreateSeqStmt**, **AlterSeqStmt**, **DefineStmt**, **CreateDomainStmt**, **CreateOpClassStmt**, **CreateOpClassItem**, **CreateOpFamilyStmt**, **AlterOpFamilyStmt**, **DropStmt**, **CommentStmt**, **SecLabelStmt**, **DeclareCursorStmt**, **ClosePortalStmt**, **FetchStmt**, **IndexStmt**, **CreateStatsStmt**, **StatsElem**, **CreateFunctionStmt**, **FunctionParameter**, **AlterFunctionStmt**, **DoStmt**, **InlineCodeBlock**, **CallStmt**, **CallContext**, **RenameStmt**, **AlterObjectDependsStmt**, **AlterObjectSchemaStmt**, **AlterOwnerStmt**, **RuleStmt**, **NotifyStmt**, **TransactionStmt**, **CompositeTypeStmt**, **CreateEnumStmt**, **CreateRangeStmt**, **ViewStmt**, **CreatedbStmt**, **VacuumStmt**, **VacuumRelation**, **RepackStmt**, **ExplainStmt**, **CreateTableAsStmt**, **CheckPointStmt**, **DiscardStmt**, **LockStmt**, **ConstraintsSetStmt**, **ReindexStmt**, **CreatePropGraphStmt**, **PropGraphVertex**, **PropGraphEdge**, **PropGraphLabelAndProperties**, **PropGraphProperties**, **PrepareStmt**, **ExecuteStmt**, **DeallocateStmt**, **AlterTSConfigurationStmt**, **PublicationTable**, **AlterPublicationStmt**, **AlterSubscriptionStmt**, **WaitStmt**: 各種DDL、ユーティリティ、トランザクション、レプリケーション制御用ステートメントの定義。

制御フローとデータフロー

1. **パース段階**: バイト単位のSQL文字列がBisonによる文法定義（gram.y）を通じ、RawStmt にラップされた各種 SelectStmt, InsertStmt などの生構文木として生成される。 2. **パーサ解析段階**: parser/analyze.c が生構文木を入力として受け取り、名前解決、型チェック、権限確認を行いながら、最適化可能な文を Query ツリーへ変換する。この過程で RangeTblEntry（RTE）や SortGroupClause が構築される。非最適化のユーティリティ文は、Query->utilityStmt に生パーサツリーがそのまま格納される。 3. **リライト・プランニング段階**: Query ツリーはルールシステム（リライタ）によって書き換えられ、最終的にプランナによって実行プラン（PlannedStmt）へと変換される。

読者向けメモ

  • **メモリ管理**: 本ファイルで定義されるすべてのノードはPostgreSQLのメモリコンテキスト（MemoryContext）上で割り当てられ、明示的な個別の解放処理を必要としないことが多い。
  • **位置情報 (location)**: 多くのノードには、元テキスト上のバイトオフセットを示す ParseLoc location フィールドが含まれており、エラーカーソルの位置特定に使用される。
  • **拡張属性 (pg_node_attr)**: 一部の構造体フィールドには pg_node_attr(...) アノテーションが付与されており、クエリジャンブル（query jumbling）やノードの等価性比較、シリアライズ処理において特定フィールドを無視・カスタム処理させる制御を行っている。
