src/include/nodes/value.h

概要

src/include/nodes/value.h は、PostgreSQLのパーサーやレキサーで使用される基本的なリテラル表現（整数、浮動小数点数、真偽値、文字列、ビット文字列）のデータ構造とアクセサマクロを定義するヘッダーファイルです。

モジュール内での役割

  • src/include/nodes サブシステムの一部として、構文解析やプリミティブノード群で扱う基本定数型の定義を提供します。
  • バックエンド側の実装ファイルである src/backend/nodes/value.c とペアで機能し、ノード生成関数群の実装インターフェースを規定します。

責務

  • プリミティブなリテラル値をリスト構造に格納可能な PostgreSQL ノード (Integer, Float, Boolean, String, BitString) として定義する。
  • ノードから実際の値を取り出すためのキャスト・アクセサマクロ (intVal, floatVal, boolVal, strVal) を提供する。
  • リテラルノードを動的に割り当てて初期化するコンストラクタ関数のシグネチャを宣言する。

重要なシンボル

  • Integer, Float, Boolean, String, BitString: 各種リテラルを表すノード構造体。
  • intVal, floatVal, boolVal, strVal: 汎用ノードから具体的な値やC型へ安全に変換・抽出するマクロ。
  • makeInteger, makeFloat, makeBoolean, makeString, makeBitString: 各種リテラルノードのインスタンスを生成する関数。

制御フローとデータフロー

  • レキサーやパーサーが読み込んだリテラル値は、対応する make* 関数（例: makeInteger や makeString）を介してヒープ上にノードとして構築されます。
  • 構築されたノードは List 構造などに格納され、パーサー全体で共有・伝播されます。
  • 値を利用する際は、intVal() などのアクセサマクロを通じて元のCの型（int や char * など）として安全に取り出されます。

直接依存

  • nodes/nodes.h: PostgreSQL のノード基盤と NodeTag などの定義。

関連コード

  • src/backend/nodes/value.c: value.h で宣言された make* 関数の実際の割り当てロジックを実装するペアファイル。
  • src/include/nodes/pg_list.h: 値ノードが格納されるリスト構造を提供するモジュール。

読者向けメモ

  • Float 型は精度保持のため、Cの double ではなく文字列（char *）として内部保持されます。そのため、数値として利用する際には floatVal() マクロ経由で atof() による変換が行われます。
