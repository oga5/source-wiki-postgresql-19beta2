src/include/nodes/value.h

概要

src/include/nodes/value.h は、PostgreSQL のパーサーやレキサーで使用される各種プリミティブなリテラル値（整数、浮動小数点数、真偽値、文字列、ビット列）を表現するためのデータ構造と、それらを生成・抽出するためのコンストラクタおよびアクセサマクロを定義するヘッダーファイルです。対応する実装は src/backend/nodes/value.c に存在します。

モジュール内での役割

PostgreSQL のノードシステム (src/include/nodes) の一部として位置づけられています。通常の C 言語のプリミティブ型ではなく PostgreSQL の List 構造等に格納できるようにラップするための軽量なノード群を提供し、構文解析プロセスの初期段階や定数の保持において重要な役割を果たします。

責務

  • リテラル値ノード構造体の定義: Integer、Float、Boolean、String、BitString の各ノード構造体を定義し、それぞれが NodeTag を持つ PostgreSQL ノードであることを規定する。
  • 値のコンストラクタ提供: 各値ノードをメモリ上に割り当てて初期化する makeInteger、変形・文字列を保持する makeFloat、makeBoolean、makeString、makeBitString を宣言する。
  • 値の抽出アクセサ提供: 汎用的なノードポインタから元のプリミティブ値を取り出すためのキャスト・アクセサマクロ (intVal, floatVal, boolVal, strVal) を提供する。

重要なシンボル

データ構造 (構造体)

  • Integer: NodeTag type と int ival を保持し、整数リテラルを表します。
  • Float: NodeTag type と char *fval を保持します。精度落ちを防ぐため内部表現として C の double ではなく文字列を採用しており、大きすぎる整数もここにフォールバックします。
  • Boolean: NodeTag type と bool boolval を保持し、真偽値リテラルを表します。
  • String: NodeTag type と char *sval を保持し、文字列リテラルを表します。
  • BitString: NodeTag type と char *bsval を保持し、ビット列リテラルを表します。

コンストラクタ関数

  • makeInteger: 指定された C の int 値を持つ Integer ノードを割り当てて返します。
  • makeFloat: 呼び出し元が palloc した数値文字列を受け取り、それを保持する Float ノードを返します。
  • makeBoolean: 指定された bool 値を持つ Boolean ノードを返します。
  • makeString: 呼び出し元が palloc した文字列を受け取り、それを保持する String ノードを返します。
  • makeBitString: 呼び出し元が palloc したビット列文字列を受け取り、それを保持する BitString ノードを返します。

アクセサマクロ

  • intVal(v): 汎用ノード v を Integer にキャストして内部の ival を返します。
  • floatVal(v): 汎用ノード v を Float にキャストし、保持する文字列 fval を atof() で double に変換して返します。
  • boolVal(v): 汎用ノード v を Boolean にキャストして内部の boolval を返します。
  • strVal(v): 汎用ノード v を String にキャストして内部の sval ポインタを返します。

制御フローとデータフロー

1. レキサーまたはパーサーがソースコードからリテラルを読み取ると、対応するコンストラクタ（例: makeInteger, makeString）を呼び出します。 2. コンストラクタ内部では makeNode() マクロ（内部で palloc0 等を使用）を用いて該当する構造体のメモリ領域を確保し、各フィールドに値を設定して返します。 3. 生成されたノードは List に追加されたり、構文木の一部として保持されます。 4. 値を取り出す際は、intVal や strVal などのマクロを介して安全に castNode による型チェックとフィールドへのアクセスが行われます。

直接依存

  • nodes/nodes.h: NodeTag および makeNode や castNode などのノード基盤マクロ定義。

関連コード

  • src/backend/nodes/value.c: 本ヘッダーで宣言されているコンストラクタ関数の実体を定義するソースファイル。
