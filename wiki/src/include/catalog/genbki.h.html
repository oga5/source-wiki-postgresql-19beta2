src/include/catalog/genbki.h

概要

PostgreSQL のシステムカタログヘッダーファイルを C コンパイラが読み込めるようにしつつ、同時にビルドツール genbki.pl が BKI ブートストラップファイル、インデックス定義、TOAST テーブル定義、シスキャッシュ定義などを生成するためのマクロ定義を提供するメタプログラミング用のヘッダーファイルである。

モジュール内での役割

src/include/catalog サブシステムにおいて、全てのシステムカタログ定義（pg_class.h, pg_proc.h など）の基礎となる。C コンパイラに対しては通常の C 構造体定義として解釈させ、genbki.pl スクリプトに対してはメタデータ（Oid、ブートストラップ属性、外部キー関係など）を抽出させる二重の役割を持つ。

責務

  • カタログ構造体の定義開始・終了時にプラットフォーム依存の構造体パディング（AIX における 864 ビット整数アライメントの調整など）を制御する。
  • CATALOG、BKI_BOOTSTRAP、BKI_SHARED_RELATION などの属性修飾子マクロを定義し、C コンパイラ上では無効化しつつビルドスクリプトにメタ情報を伝達する。
  • DECLARE_TOAST、DECLARE_INDEX、MAKE_SYSCACHE などのメタコマンド用ダミーマクロを提供し、C コンパイラのパースエラーを防ぐ。
  • クライアントコードに公開すべきコードセクションの境界を指定する EXPOSE_TO_CLIENT_CODE や可変長フィールド制御のためのシンボルを提供する。

重要なシンボル

アライメントおよび構造体定義制御

  • BEGIN_CATALOG_STRUCT / END_CATALOG_STRUCT: プラットフォーム（AIX など ALIGNOF_DOUBLE < ALIGNOF_INT64_T の環境）で int64 フィールドのパディングを強制し、タプル形成・分解ルールと構造体レイアウトを一致させる。
  • CATALOG(name,oid,oidmacro): カタログ構造体の定義を開始し、FormData_{name} 型を宣言する。

カタログおよび属性修飾子

  • BKI_BOOTSTRAP, BKI_SHARED_RELATION, BKI_ROWTYPE_OID, BKI_SCHEMA_MACRO: カタログ自体の特性を指定する（Cコンパイラ上では空に展開される）。
  • BKI_FORCE_NULL, BKI_FORCE_NOT_NULL, BKI_DEFAULT, BKI_ARRAY_DEFAULT: 属性ごとのデフォルト値や NULL 制約を指定する。
  • BKI_LOOKUP(catalog) / BKI_LOOKUP_OPT(catalog): OID 参照先カタログを指定し、初期データ内の名前解決や回帰テストの検証に利用される。

構築・インデックス・外部キー宣言用マクロ

  • DECLARE_TOAST / DECLARE_TOAST_WITH_MACRO: システムカタログに対する TOAST テーブルおよびインデックスの OID 割り当てを指定する。
  • DECLARE_INDEX, DECLARE_UNIQUE_INDEX, DECLARE_UNIQUE_INDEX_PKEY: ブートストラップパーサ用の DefineIndex コマンド生成元となるインデックス宣言。
  • DECLARE_FOREIGN_KEY 系マクロ: カタログ間の参照整合性関係を機械可読な形で記録する。
  • MAKE_SYSCACHE: 指定されたインデックスとバケットサイズでシスキャッシュを作成する定義。

その他言語要素

  • int64: ソース内のインデックス付きシンボル（Cの標準型/拡張型定義に基づく）。

制御フローとデータフロー

本ファイルは純粋なマクロ定義の集まりであり、実行時の制御フローやデータフローの本体は持たない。

  • ビルド時フロー: PostgreSQL のビルドプロセスにおいて、genbki.pl が本ファイルがインクルードされたカタログヘッダー群をパースする。マクロ（CATALOG, DECLARE_INDEX など）を解釈して .bki ファイルや生成ヘッダー（*_d.h）を出力する。
  • コンパイル時フロー: バックエンドおよびクライアントの C コードがカタログヘッダーをインクルードする際、これらのマクロは空（またはプラットフォーム固有の _Pragma("pack(...)")）に展開され、メモリ上のタプルレイアウトと整合する C 構造体が構築される。

直接依存

なし（純粋なプリプロセッサマクロ定義のため、他ファイルへのインクルード依存を持たない）。

関連コード

  • src/backend/catalog/genbki.pl: 本ファイルで定義されたマクロを解析して BKI ファイルを生成する Perl スクリプト。
  • 各種カタログヘッダー（src/include/catalog/pg_class.h など）: 本ファイルを必須インクルードとして使用するファイル群。
  • src/backend/bootstrap/bootstrap.c: BKI ブートストラップパーサの実装。

読者向けメモ

  • メモリレイアウトとアライメント: AIX などのプラットフォーム制約により、int64 のアライメントが異なる場合のハック（_Pragma("pack(push,4)")）が含まれている。カタログ構造体を直接ディスク上のタプルフォーマットやキャッシュ構造として扱う際の重要なインーブリゲーションである。
  • 浅い領域: C コンパイラ側では実効的なコードを持たないスタブマクロ（extern int no_such_variable など）が多数定義されているため、実際の処理はすべて genbki.pl 側の処理系に依存している。
