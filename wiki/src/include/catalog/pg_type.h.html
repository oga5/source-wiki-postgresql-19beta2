src/include/catalog/pg_type.h

概要

PostgreSQLのデータ型カタログ（pg_type）のスキーマ定義、列挙マクロ、および関連関数宣言を提供するヘッダーファイルです。Catalog.pm モジュールによってパースされ、ブートストラップやシステムカタログのメタデータ構築に利用されます。

モジュール内での役割

src/include/catalog モジュール群の一部として、データベース内のすべてのデータ型（基本型、複合型、ドメイン、列挙型、疑似型、範囲型など）の静的構造およびインデックス定義を定義します。また、src/backend/catalog/pg_type.c とペアになり、型の作成やシェル型の挿入などの操作インターフェースを提供します。

責務

  • **カタログ構造の定義**: FormData_pg_type および Form_pg_type による pg_type リレーションのタプル構造の定義。
  • **型分類マクロの提供**: typtype、typcategory、typalign、typstorage などの属性値に対する定数マクロの提供。
  • **多態性・配列判定マクロの提供**: IsPolymorphicType や IsTrueArrayType などの判定マクロの提供。
  • **型操作関数の宣言**: TypeShellMake、TypeCreate、GenerateTypeDependencies、名前変更や配列型名生成を行う関数の外部インターフェース宣言。

重要なシンボル

型定義・フォーム

  • FormData_pg_type: pg_type カタログの1行分の物理レイアウト構造体。
  • Form_pg_type: FormData_pg_type * 型へのポインタ。

型分類・属性マクロ (EXPOSE_TO_CLIENT_CODE)

  • TYPTYPE_*: 型の種類を表すマクロ（基底型、複合型、ドメイン、列挙、疑似型、範囲等）。
  • TYPCATEGORY_*: 型のカテゴリを表すマクロ（配列、ブール、数値、文字列等）。
  • TYPALIGN_*: アライメント要件を表すマクロ（char, short, int, double）。
  • TYPSTORAGE_*: TOAST ストレージ戦略を表すマクロ（plain, external, extended, main）。

多態性・配列判定マクロ

  • IsPolymorphicType(typid): 指定された OID が多態的な疑似型ファミリーに属するか判定。
  • IsTrueArrayType(typeForm): typelem と typsubscript が有効な真の配列型であるか判定。

操作・依存関係関数宣言

  • TypeShellMake: 未定義のプレースホルダー（シェル型）タプルを挿入。
  • TypeCreate: 完全なデータ型定義を作成してカタログに登録。
  • GenerateTypeDependencies: 型に関連する依存関係（拡張、要素型など）を生成。
  • makeArrayTypeName / moveArrayTypeName / makeMultirangeTypeName: 配列型名やマルチレンジ型名の生成・移動。

制御フローとデータフロー

  • 型定義の作成フローでは、まず TypeShellMake がダミーの値を持つシェル型タプルを pg_type に挿入し、I/O関数などがリンクできるようにします。
  • その後、TypeCreate が呼び出されて実際の属性値（アライメント、ストレージ、I/O関数など）で上書きされ、typisdefined が true に更新されます。
  • GenerateTypeDependencies により、要素型やデフォルト式、所有者、名前空間に対する依存関係が pg_depend 等に登録されます。

直接依存

  • catalog/genbki.h: BKI 生成マクロ定義。
  • catalog/objectaddress.h: ObjectAddress 構造体の定義。
  • catalog/pg_type_d.h: 定数およびOID定義（IWYU export）。
  • nodes/nodes.h: ノードツリー定義（pg_node_tree 用）。

関連コード

  • src/backend/catalog/pg_type.c: ペアとなる実装ファイル。型作成やシェル型構築の実ロジックを含む。
  • src/include/catalog/pg_type_d.h: pg_type に関連する OID マクロの定義。

読者向けメモ

  • システムテーブルのサイズとアライメントは、コンパイラが構造体をレイアウトする方法と一致している必要があるため、変更時は注意が必要です。
  • #ifdef CATALOG_VARLEN 以降のフィールド（typdefaultbin、typdefault、typacl）は可変長属性として扱われます。
