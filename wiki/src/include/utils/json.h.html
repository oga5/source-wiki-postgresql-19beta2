src/include/utils/json.h

概要

src/include/utils/json.h は、PostgreSQL における標準 JSON データ型のサポートおよび関連処理のための公開関数宣言を提供するヘッダーファイルです。

モジュール内での役割

src/include/utils ユーティリティモジュールの一部であり、JSON / JSONB サブカテゴリに属します。ペアとなる実装ファイル src/backend/utils/adt/json.c の宣言インターフェースとして機能します。

責務

  • PostgreSQL の内部データ構造（Datum や composite 型など）から JSON への変換処理関数の宣言を提供する。
  • JSON 文字列のエスケープ処理関数の公開。
  • JSON の構築、検証、日時エンコードに関するワーカー関数のプロトタイプ定義。

重要なシンボル

  • escape_json: C 文字列を JSON 形式にエスケープしてバッファに追加する。
  • composite_to_json: 複合型（コンポジット）データを JSON 表現に変換する。
  • json_build_object_worker / json_build_array_worker: JSON オブジェクトおよび配列を構築する内部ワーカー関数。
  • json_validate: テキストとしての JSON の妥当性（および一意キー）を検証する。

制御フローとデータフロー

  • ヘッダーファイル単体には実行ロジックはありません。
  • 呼び出し側（SQL関数やビルトイン関数）が本ファイルの宣言を参照し、実際のデータ変換やエスケープ処理はペアファイル src/backend/utils/adt/json.c 内の関数へディスパッチされます。

直接依存

  • lib/stringinfo.h: 可変長文字列バッファ操作型である StringInfo の定義。

関連コード

  • src/backend/utils/adt/json.c: ペアとなる実装ファイル。
  • src/include/utils/jsonb.h: JSONB バイナリ表現向けの関連宣言。
  • src/include/utils/jsonfuncs.h: JSON 操作用の追加関数の宣言。
  • src/include/utils/jsonpath.h: JSONPath サポートの宣言。

読者向けメモ

  • JSON 型の内部ストレージ構造自体は text 型と同一であり、バリデーションやシリアライズの境界定義としてこのヘッダーが利用されます。
