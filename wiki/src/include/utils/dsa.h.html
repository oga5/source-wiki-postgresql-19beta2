src/include/utils/dsa.h

概要

src/include/utils/dsa.h は、動的共有メモリ領域（Dynamic Shared Memory Areas: DSA）の公開インターフェースを定義するヘッダーファイルです。DSM（Dynamic Shared Memory）セグメントを基盤とし、小オブジェクトの動的割り当てや解放、プロセス間でのポインタ共有を可能にするヒープ機構を提供します。

モジュール内での役割

src/include/utils モジュール内において、複数バックエンド間で共有される複雑なデータ構造（ハッシュ、ツリー等）の構築に必要な共有メモリ上のアロケータを定義する中核ファイルです。実装本体である src/backend/utils/mmgr/dsa.c とペアで機能します。

責務

  • dsa_area 型および操作用関数プロトタイプの公開。
  • プロセス間で共有可能な擬似ポインタ型 dsa_pointer およびアトミック操作用マクロの定義。
  • アロケーションフラグ、セグメントサイズ制限、無効値などの定数・マクロの提供。
  • 領域の生成、破棄、アタッチ、detach、メモリ割り当て・解放、ポインタ変換APIの規定。

重要なシンボル

型・データ構造

  • **struct dsa_area / dsa_area**: DSA領域の状態を隠蔽する不透明型（opaque type）。
  • **dsa_pointer**: 共有メモリ内の相対位置を指す擬似ポインタ型（環境により32ビットまたは64ビット）。
  • **dsa_pointer_atomic**: マルチスレッド/マルチプロセスでのアトミック操作用 dsa_pointer 型。
  • **dsa_handle**: 他のプロセスが既存のDSA領域にアタッチするための識別子（内部的には dsm_handle）。

ライフサイクル・アタッチ管理API

  • **dsa_create / dsa_create_ext**: 新規DSA領域およびその初期DSMセグメントを生成する。
  • **dsa_create_in_place / dsa_create_in_place_ext**: 既存の共有メモリ空間上にDSA領域を構築する。
  • **dsa_attach / dsa_detach**: 既存のDSA領域へのアタッチおよびデタッチを行う。
  • **dsa_pin / dsa_unpin / dsa_pin_mapping**: 領域やマッピングの寿命を制御する。

メモリ管理・変換API

  • **dsa_allocate / dsa_allocate_extended / dsa_allocate0**: 領域内からメモリを割り当て、dsa_pointer を返す。
  • **dsa_free**: 割り当てられたメモリを解放する。
  • **dsa_get_address**: 共有 dsa_pointer を自プロセスのローカルメモリ上の実アドレス (void *) に変換する。
  • **DsaPointerIsValid / InvalidDsaPointer**: ポインタの有効性検証および無効値。

制御フローとデータフロー

  • **アロケーションフロー**:

    • 1. クライアントが dsa_allocate（または dsa_allocate_extended）を呼び出す。 2. 内部でサイズに応じて大容量（ページ単位のフリーページマネージャ）または小オブジェクト用プール（スパンド管理）から領域が割り当てられ、セグメント識別子とオフセットをエンコードした dsa_pointer が返される。

  • **逆参照フロー**:

    • 1. 共有される dsa_pointer を受け取ったバックエンドは dsa_get_address(area, dp) を呼び出す。 2. dsa_area の管理情報に基づき、自プロセスの仮想アドレス空間上のローカルポインタへ変換してデータにアクセスする。

直接依存

  • port/atomics.h: アトミック操作のサポート。
  • storage/dsm.h: 動的共有メモリセグメントの管理。

関連コード

  • src/backend/utils/mmgr/dsa.c: DSAの実装本体。
  • src/include/utils/freepage.h: フリーページ管理。

読者向けメモ

  • **ポインタの性質**: dsa_pointer はそのままデリファレンスできません。必ず dsa_get_address を介してローカルポインタに変換する必要があります。
  • **ポインタサイズ**: システムのポインタサイズや PG_HAVE_ATOMIC_U64_SUPPORT の有無、あるいは USE_SMALL_DSA_POINTER の定義により、32ビット（uint32）または64ビット（uint64）に切り替わります。
