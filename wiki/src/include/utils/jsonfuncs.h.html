src/include/utils/jsonfuncs.h

概要

PostgreSQL の JSON および JSONB データ型を操作・処理するための関数群、型定義、マクロを提供するヘッダーファイルです。

モジュール内での役割

src/include/utils/ ディレクトリ配下に位置し、JSON サブシステムにおいて型変換、値の走査、構文解析、およびエラーハンドリングの共通インターフェースを公開します。

責務

  • JSON の字句解析コンテキスト（JsonLexContext）の生成・管理機能の宣言。
  • JSON および JSONB 文書内の特定の要素を走査（iterate）または変換（transform）するためのコールバック型と関数の提供。
  • SQL データ型と JSON 型の間での相互変換、および型カテゴリ分類（JsonTypeCategory）の定義。
  • パースエラー時に安全なエラー通知や例外送出を行う機構の提供。

重要なシンボル

  • JsonToIndex: 走査時に対象とする JSON 要素の種類（キー、文字列、数値、真偽値、すべて）を指定する列挙型。
  • JsonIterateStringValuesAction: 各 JSON 値を走査する際に適用されるアクション関数の型。
  • JsonTransformStringValuesAction: 各 JSON 値を変換する際に適用されるアクション関数の型。
  • JsonTypeCategory: json_categorize_type が返す、SQL 型を JSON 変換用に分類する列挙型。
  • pg_parse_json_or_ereport: 内部の pg_parse_json_or_errsave をラップし、パース失敗時にエラーを報告するマクロ。

制御フローとデータフロー

  • 入力された text 型または Jsonb 型のデータに対し、makeJsonLexContext やパース関数を用いて構文解析の準備を行います。
  • iterate_json_values や transform_json_string_values などの関数は、指定されたフラグ（JsonToIndex）に基づいて文書内を巡回し、各要素に対してコールバック関数（Action）を適用します。
  • datum_to_json / datum_to_jsonb や json_populate_type は、JsonTypeCategory を参照して対応する型変換関数（outfuncoid）を呼び出し、Datum と JSON 間の相互変換データフローを実現します。

直接依存

  • common/jsonapi.h: 基本的な JSON の字句解析およびセマンティクス解析構造体。
  • nodes/nodes.h: PostgreSQL のノード基底定義（エラーコンテキスト用）。
  • utils/jsonb.h: JSONB 固有のデータ構造と操作関数。

関連コード

  • src/backend/utils/adt/jsonfuncs.c: 本ヘッダーで宣言されている関数の実装本体。
  • src/include/utils/json.h: 標準 JSON 型を扱うその他の公開関数群。
  • src/include/utils/jsonpath.h: JSONPath 式を評価するための関連モジュール。

読者向けメモ

  • 本ファイルは関数宣言とインタフェース定義が中心です。具体的なアルゴリズムや状態構造体（OkeysState, GetState など）を確認する場合は、対となる src/backend/utils/adt/jsonfuncs.c を参照してください。
