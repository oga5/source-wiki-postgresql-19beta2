src/include/utils/memutils.h

概要

PostgreSQLのメモリ管理サブシステムにおける、アロケーション関連のユーティリティ関数、マクロ、主要な標準メモリコンテキストの外部公開宣言を提供するヘッダーファイルです。utils/palloc.h よりも広範ではないものの、メモリ管理APIの核心をなす機能群を定義しています。

モジュール内での役割

src/include/utils モジュール配下において、メモリ管理の型非依存な制御関数（mcxt.c 連携）や、各種アロケータ（AllocSet、Slab、Generation、Bump）ごとのコンテキスト生成関数を束ねるインターフェースとして機能します。また、nodes/memnodes.h をインクルードし、メモリノード階層と連携します。

責務

  • **アロケーション制限の定義**: 割り当てサイズの上限（MaxAllocSize、MaxAllocHugeSize）およびバリデーションマクロの提供。
  • **標準グローバルコンテキストの宣言**: TopMemoryContext や ErrorContext などの標準トップレベルメモリコンテキスト変数の外部公開。
  • **メモリコンテキスト操作APIの宣言**: リセット、削除、統計情報取得、安全性制御など、コンテキスト型に依存しない操作関数の提供。
  • **アルゴリズム特化型コンテキスト生成関数の宣言**: AllocSet、Slab、Generation、Bump の各アロケータに対応する作成関数の提供。
  • **ゼロ埋め検証インライン関数の提供**: 指定されたメモリ領域がすべてゼロで埋められているかを効率的に判定する pg_memory_is_all_zeros の実装。

重要なシンボル

アロケーション制限とマクロ

  • MaxAllocSize: 通常のアロケーションにおける制限値（1ギガバイト - 1）。TOASTの varlena オブジェクトサイズや整数インデックスでの扱いを考慮して選択されています。
  • MaxAllocHugeSize: 巨大アロケーションにおける制限値（SIZE_MAX / 2）。
  • AllocSizeIsValid / AllocHugeSizeIsValid: 指定サイズがそれぞれの制限内であるかを検証するマクロ。

標準グローバルメモリコンテキスト

  • TopMemoryContext: バックエンド全体の最上位に位置するメモリコンテキスト。
  • ErrorContext: エラー発生時の復旧処理（PANIC時など）で安全に割り当てを行うための専用コンテキスト。
  • PostmasterContext: ポストマスタープロセスが保持する永続的なコンテキスト。
  • CacheMemoryContext: キャッシュ関連データ（シスキャッシュなど）を保持するコンテキスト。
  • MessageContext: クライアントからのコマンドメッセージ処理用のコンテキスト。
  • TopTransactionContext: 現在のトランザクション全体で維持されるコンテキスト。
  • CurTransactionContext: 現在のトランザクションのサブフェーズや短期オブジェクト用のコンテキスト。
  • PortalContext: アクティブなポータルに一時的にリンクされるメモリコンテキスト。

コンテキスト生成関数

  • AllocSetContextCreateInternal: 標準的な可変ブロックアロケータである AllocSet 方式のメモリコンテキストを作成する内部関数。
  • SlabContextCreate: 固定長チャンクを効率的に割り当てる Slab 方式のメモリコンテキストを作成する関数。
  • GenerationContextCreate: 世代ベースのガベージコレクション／一括解放を効率化する Generation 方式のメモリコンテキストを作成する関数。
  • BumpContextCreate: 単調増加（バンプ）方式で高速に領域を切り出す Bump 方式のメモリコンテキストを作成する関数。

制御フローとデータフロー

  • **メモリコンテキスト初期化とツリー構造**: バックエンド起動時に MemoryContextInit() が呼ばれ、TopMemoryContext と ErrorContext が初期化されます。以降に作成される各コンテキストは親コンテキストを指定して階層ツリーを形成します。
  • **生成とエイリアス**: AllocSetContextCreate マクロはコンテキスト名が定数文字列であるかをコンパイル時に検証した上で、実体である AllocSetContextCreateInternal を呼び出します。
  • **ゼロ埋め検証 (pg_memory_is_all_zeros)**:
  • len < sizeof(size_t) の場合はバイト単位で直接比較します。
  • len が中規模・大規模の場合、ポインタが size_t 境界に整列するまでバイト単位で比較したのち、size_t 単位（大規模時はビット単位のORを組み合わせてSIMD最適化を誘導）で高速にブロック比較を行い、不一致があれば早期に false を返します。

直接依存

  • nodes/memnodes.h: メモリコンテキストの基本データ構造および型定義 (MemoryContext 等) の提供元。

読者向けメモ

  • **文字列リテラルの制約**: AllocSetContextCreate に渡すコンテキスト名は、定数文字列であることがコンパイル時に強制されます。動的な識別子を付与したい場合は、生成後に MemoryContextSetIdentifier() または MemoryContextCopyAndSetIdentifier を使用してください。
  • **メモリ安全性**: pg_memory_is_all_zeros の呼び出し元は、渡すポインタ ptr が NULL でないことを保証する責務があります。
