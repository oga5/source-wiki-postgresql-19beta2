src/include/utils/numeric.h

概要

PostgreSQLの厳密数値データ型（NUMERIC）のためのヘッダーファイルです。型定義、制限値のマクロ、関数マネージャ（fmgr）とのインターフェースマクロ、および numeric.c で実装されるユーティリティ関数の公開宣言を提供します。

モジュール内での役割

src/include/utils モジュール内の数値演算関連ヘッダーとして位置付けられ、バックエンドの数値演算実装（src/backend/utils/adt/numeric.c）と、型システムやパーサーなどの他サブシステムを繋ぐパブリックなインターフェース定義を提供します。

責務

  • NUMERIC 型の型修飾子（typmod）における精度やスケールの制限値を定義する。
  • 内部構造体 NumericData の不透明ポインタ型（Numeric）を定義し、内部構造を隠蔽する。
  • PostgreSQLの関数マネージャ（FMGR）を通じて Datum と Numeric の相互変換を行うインライン関数およびマクロを提供する。
  • numeric.c が提供する安全な算術演算、型変換、乱数生成などの外部関数プロトタイプを宣言する。

重要なシンボル

型・データ構造

  • Node
  • 構造体の前方宣言。エラーコンテキスト（escontext）を受け渡すために使用されます。
  • Numeric
  • struct NumericData * の別名。実体は隠蔽されており、上位レイヤーからはこのポインタ経由で数値を扱います。
  • NumericData
  • numeric.c 内で定義される実際の数値データを表す不透明構造体です。

マクロ定義

  • NUMERIC
  • 本ヘッダー内では直接定義されておらず、関数マネージャ経由などで扱われる NUMERIC 型の識別や関連マクロの基盤となります（ソースファクトのインデックスに基づく）。

関数マネージャ（FMGR）インターフェース

  • Datum
  • PostgreSQLの汎用データ型。
  • DatumGetNumeric
  • 引数の Datum を必要に応じてデトースト（detoast）し、Numeric ポインタとして返します。
  • DatumGetNumericCopy
  • 引数の Datum をデトーストした上でコピーを作成し、その Numeric ポインタを返します。
  • NumericGetDatum
  • Numeric ポインタを PostgreSQL の汎用 Datum 型に変換して返します。

安全な算術演算関数

  • numeric_add_safe
  • オーバーフロー等のエラーを安全に処理しながら、2つの Numeric 値を加算します。
  • numeric_mul_safe
  • オーバーフロー等のエラーを安全に処理しながら、2つの Numeric 値を乗算します。

制御フローとデータフロー

本ファイルはインターフェース定義ヘッダーであるため、直接的な制御フローの本体は持ちません。データフローとしては、SQL実行エンジンや組み込み関数から PG_GETARG_NUMERIC(n) マクロや DatumGetNumeric() を経由して Datum から Numeric が抽出され、numeric_add_safe や numeric_mul_safe などの安全な演算関数へと渡されるパスの起点となります。エラー発生時は Node *escontext を介して呼び出し元へ伝播します。

直接依存

  • common/pg_prng.h
  • 疑似乱数生成器の状態構造体を利用するためにインクルードされています。
  • fmgr.h
  • PostgreSQLの関数マネージャ基盤および Datum 型の定義を利用するためにインクルードされています。

関連コード

  • src/backend/utils/adt/numeric.c
  • 本ヘッダーで宣言されているすべての関数、マクロ、および NumericData の実体が実装されているペアファイルです。
