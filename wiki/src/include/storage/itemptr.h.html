src/include/storage/itemptr.h

概要

ディスク上のタプルやインデックスエントリの位置を指し示す「タプルID（TID / ItemPointer）」のデータ構造と、それを操作するためのインライン関数群および外部関数群を定義するヘッダーファイルである。

モジュール内での役割

src/include/storage サブシステムのストレージ層において、ページ内の特定の位置（ブロック番号とラインポインタ配列のオフセット）を表現する基礎的なプリミティブを提供する。ヒープタプルのヘッダー（t_ctid）やインデックスから親テーブルへのクロスリンクなど、PostgreSQL 全体で広く利用される。

責務

  • **データ構造の定義**: 6バイトのコンパクトな構造体 ItemPointerData の定義とパディング防止。
  • **特殊マーカーの提供**: スペキュスラティブ挿入やパーティション間移動を示すマジック値の定義。
  • **アクセサおよびバリデーション**: ブロック番号やオフセット番号の取得・設定、および有効性検証（Assert）。
  • **比較・演算関数**: TID 同士の比較、等価性判定、ポインタのインクリメント/デクリメント。
  • **Datum 変換**: PostgreSQL の関数呼び出しインターフェース（Datum）と ItemPointer 間のキャストマクロ/インライン関数。

重要なシンボル

データ構造と型

  • ItemPointerData: ディスク上の位置（BlockIdData ip_blkid と OffsetNumber ip_posid）を保持する構造体。コンパイラ依存の属性により正確に 6 バイトに調整される。
  • ItemPointer: ItemPointerData * 型のエイリアス。

特殊値マクロ

  • SpecTokenOffsetNumber (0xfffe): スペキュスラティブ挿入トークンを表すオフセット番号。
  • MovedPartitionsOffsetNumber (0xfffd) / MovedPartitionsBlockNumber (InvalidBlockNumber): UPDATE によって他パーティションへ移動したタプルを示すマジック値。

アクセサ・バリデーション・ミューテータ (インライン関数)

  • ItemPointerIsValid(pointer): ポインタが非 NULL かつ ip_posid != 0 であるかを検証する。
  • ItemPointerGetBlockNumber(pointer) / ItemPointerGetBlockNumberNoCheck(pointer): ブロック番号を取得する。前者は有効性をアサートする。
  • ItemPointerGetOffsetNumber(pointer) / ItemPointerGetOffsetNumberNoCheck(pointer): オフセット番号を取得する。前者は有効性をアサートする。
  • ItemPointerSet(pointer, blockNumber, offNum) / ItemPointerSetBlockNumber / ItemPointerSetOffsetNumber: ブロック番号やオフセット番号を設定する。
  • ItemPointerSetInvalid(pointer): 無効な状態（InvalidBlockNumber, InvalidOffsetNumber）に設定する。
  • ItemPointerCopy(from, to): ポインタの中身をコピーする（ハッシュキーとしても利用される）。
  • ItemPointerIndicatesMovedPartitions(pointer) / ItemPointerSetMovedPartitions(pointer): パーティション間移動状態の判定および設定を行う。

比較・算術関数 (外部定義 / itemptr.c)

  • ItemPointerEquals(pointer1, pointer2): 両者が同じブロック・オフセットを指すか比較する（有効性のアサートを含む）。
  • ItemPointerCompare(arg1, arg2): B パイプラインスタイルの汎用比較関数（-1, 0, 1 を返す）。チェックなしのアクセサを使用する。
  • ItemPointerInc(pointer) / ItemPointerDec(pointer): オーバーフロー/アンダーフロー境界に配慮しつつ TID を 1 つ増減させる。

Datum 変換

  • DatumGetItemPointer(X) / ItemPointerGetDatum(X): Datum との相互変換。
  • PG_GETARG_ITEMPOINTER(n) / PG_RETURN_ITEMPOINTER(x): 関数引数/戻 сторо 用のマクロ。

制御フローとデータフロー

  • 本ファイルは主にインライン関数とマクロの定義で構成されており、単体の制御フローは持たない。
  • 値の取得や設定は pointer->ip_posid および BlockIdData（storage/block.h）を直接読み書きする。
  • ItemPointerCompare などの外部関数では、ユーザ入力などの非検証済みポインタを安全に扱うために ItemPointerGetBlockNumberNoCheck および ItemPointerGetOffsetNumberNoCheck を経由してブロック・オフセットを取り出し、大小関係を判定する。

直接依存

  • storage/block.h: BlockIdData および BlockNumber の定義。
  • storage/off.h: OffsetNumber の定義。

関連コード

  • src/backend/storage/page/itemptr.c: ItemPointerEquals, ItemPointerCompare, ItemPointerInc, ItemPointerDec の実体を保持するペアファイル。
  • src/include/storage/block.h: ブロック識別子の詳細。
  • src/include/storage/itemid.h: ページ内のラインポインタ（ItemIdData）定義。

読者向けメモ

  • **メモリレイアウトの制約**: ItemPointerData は各タプルヘッダーにインラインで含まれるため、構造体のパディングによるサイズ肥大化が厳しく制限されている（正確に 6 バイト）。ハッシュキーとしても利用されるため、メモリ上のビット列コピー（ItemPointerCopy）が前提となっている点に注意。
  • **バリデーションの使い分け**: 通常の内部処理では ItemPointerGetBlockNumber などのアサート付き関数を使い、ユーザ定義 TID や比較など不正なオフセットが入り得る文脈では NoCheck 版を使用する設計になっている。
