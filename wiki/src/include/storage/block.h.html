src/include/storage/block.h

概要

PostgreSQLのディスクブロックおよびブロック識別子（BlockId）を定義する基本ヘッダーファイルです。ファイルやインデックスのI/O単位であるディスクブロックを扱うための型と、それらを操作するインライン関数を提供します。

モジュール内での役割

src/include/storage モジュールの一部として、バッファ管理、ストレージ管理、および各種アクセスメソッド（ヒープやインデックス）が共通して依存する最下層のデータ定義を提供します。

責務

  • ディスクブロック番号を表す BlockNumber 型および、無効値 (InvalidBlockNumber) や最大値 (MaxBlockNumber) の定義。
  • ディスク上の構造体（ItemPointerData など）に格納するための、SHORTALIGN に適合したブロック識別子 BlockIdData（および BlockId）の定義。
  • BlockNumber と BlockIdData の間の相互変換、妥当性検証、および同値比較を行うインラインアクセサ関数の提供。

重要なシンボル

ブロック番号の定義と検証

  • BlockNumber (typedef): ディスクブロックの通し番号を表す uint32 型（有効範囲: 0 から 0xFFFFFFFE）。
  • InvalidBlockNumber (macro): 無効なブロック番号を表す定数 (0xFFFFFFFF)。バッファマネージャの P_NEW と同等。
  • MaxBlockNumber (macro): 許容される最大のブロック番号 (0xFFFFFFFE)。
  • BlockNumberIsValid (function): 指定された BlockNumber が InvalidBlockNumber でないかを判定するインライン関数。

ブロック識別子の構造体と操作

  • BlockIdData (struct): BlockNumber をディスク上（タプルヘッダやポインタ配列）でコンパクトに保持するための構造体。上位16ビット (bi_hi) と下位16ビット (bi_lo) の uint16 2つで構成され、SHORTALIGN を満たす。
  • BlockId (typedef): BlockIdData * 型のエイリアス。
  • BlockIdSet (function): BlockNumber を分割して BlockIdData の上位・下位フィールドに設定するインライン関数。
  • BlockIdEquals (function): 2つの BlockIdData が指すブロック番号が等しいかを比較するインライン関数。
  • BlockIdGetBlockNumber (function): BlockIdData の上位・下位フィールドを結合して元の BlockNumber を復元するインライン関数。

その他

  • SHORTALIGN (function / 宣言のみ): アライメント調整用。本ファイル内ではコメント言及のみで定義本体はないが、BlockIdData の設計根拠となっている。
  • uint32 (function / 型言及): BlockNumber の基底型としての uint32。

制御フローとデータフロー

本ファイルはデータ型とインライン関数のみで構成されており、複雑な制御フローはありません。

  • **データ表現の変換フロー**:

    • メモリ上で計算処理を行う際は BlockNumber (uint32) を使用し、ディスク上の領域節約やアライメント（SHORTALIGN）が求められる構造体に格納する際は BlockIdSet を経由して BlockIdData に分割・保存されます。

  • **復元フロー**:

    • ディスク上の構造体からブロック番号が必要になった際には、BlockIdGetBlockNumber により bi_hi と bi_lo がビット演算（シフトと論理和）で結合され、BlockNumber に復元されます。

直接依存

なし（Cの基本型や他のヘッダーへのインクルード依存はこのファイル単体では明示されていません）。

関連コード

  • src/include/storage/itemptr.h: BlockIdData を内部に含む ItemPointerData（行ポインタ等）の定義。
