src/include/storage/proclist_types.h

概要

src/include/storage/proclist_types.h は、プロセス番号 (ProcNumber) をベースにした双方向連結リストのデータ構造と型定義を提供するヘッダーファイルである。実際のリスト操作関数は proclist.h に分離されている。

モジュール内での役割

  • PostgreSQLのストレージ・プロセス管理サブシステムにおいて、プロセス間連携や待機キューなどで使用される軽量なプロセスリストの型定義を担う。
  • ポインタの代わりにプロセス番号 (ProcNumber) を利用することで、共有メモリ領域やプロセス間での効率的なリスト構造の共有を実現する。

責務

  • プロセスリストのノード、ヘッダー、およびイテレータのデータ構造を定義する。
  • リスト構造の状態（未所属時の初期値や終端状態など）を表現するための仕様を規定する。

重要なシンボル

  • struct proclist_node: リストのノード。次のプロセスと前のプロセスの ProcNumber（next, prev）を保持する。
  • struct proclist_head: リストのヘッダー。リストの先頭と末尾の ProcNumber（head, tail）を保持する。
  • struct proclist_mutable_iter: 走査中のリスト変更を安全に行うための可変イテレータ。

制御フローとデータフロー

本ファイルは型定義のみを提供するヘッダーであり、実行コードや制御フローは含まない。データの流れとしては、proclist.h の関数群がここで定義された proclist_head や proclist_node を介して、各プロセスのインデックスを操作する。

直接依存

  • storage/procnumber.h: プロセス番号の型定義 (ProcNumber) を取得するためにインクルードしている。

関連コード

  • src/include/storage/proclist.h: 本ファイルで定義された型に対する操作関数を提供する対のヘッダーファイル。
  • src/include/storage/procnumber.h: プロセス番号の定義元。

読者向けメモ

  • 未所属のノードは next == prev == 0 に初期化される規約があるため、ポインタベースのリストのNULL初期化とは異なる点に注意が必要。
  • 空のリストは head == tail == INVALID_PROC_NUMBER として表現される。
