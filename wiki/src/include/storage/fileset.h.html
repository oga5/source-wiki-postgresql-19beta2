src/include/storage/fileset.h

概要

src/include/storage/fileset.h は、PostgreSQL における名前付き一時ファイルの管理機構を提供するヘッダーファイルです。複数回にわたるオープン／クローズや、トランザクションをまたいだ生存が必要となる一時ファイルの名前空間（ディレクトリのようなもの）を定義します。

モジュール内での役割

  • ストレージサブシステム（src/include/storage/）の一部として、低水準ファイルディスクリプタ管理（storage/fd.h）の上に位置する抽象化レイヤーを提供します。
  • 一時ファイルの配置先となる一時テーブルスペース（temp_tablespaces）の割り当て情報を保持し、バックエンド間で一貫したファイルパスを構築します。
  • 対となる実体ファイル src/backend/storage/file/fileset.c と連携します。

責務

  • 名前付き一時ファイルのメタデータ構造体である FileSet 型の定義。
  • 一時ファイルセットの初期化、作成、オープン、削除、および全削除を行う公開 API 関数の宣言。
  • 複数テーブルスペースへのファイル分散配置に必要な状態管理の提供。

重要なシンボル

  • FileSet (struct): 作成プロセスの PID、識別番号、使用するテーブルスペースの数と Oid 配列を保持する構造体。
  • FileSetInit(FileSet *fileset): 指定されたファイルセット構造体を初期化し、一時テーブルスペース群をキャッシュする関数。
  • FileSetCreate(FileSet *fileset, const char *name): ファイルセット内に新しい一時ファイルを作成し、仮想ファイル識別子を返す関数。
  • FileSetOpen(FileSet *fileset, const char *name, int mode): 既存の一時ファイルをオープンする関数。
  • FileSetDelete(FileSet *fileset, const char *name, bool error_on_failure): 個別の一時ファイルを削除する関数。
  • FileSetDeleteAll(FileSet *fileset): ファイルセットに関連するすべてのファイルを削除する関数。

制御フローとデータフロー

  • 利用側コードはまず FileSet 構造体を宣言し、FileSetInit() に渡して PID やテーブルスペース群の割り当てを初期化します。
  • ファイル操作時には、FileSetCreate() または FileSetOpen() が name を受け取り、内部でパスを解決して File 型のハンドルを返します。
  • 不要になったファイルは FileSetDelete() または FileSetDeleteAll() によって明示的にクリーンアップされます。

直接依存

  • storage/fd.h: PostgreSQL のファイルディスクリプタおよび File 型の定義を利用するためインクルードしています。

関連コード

  • src/backend/storage/file/fileset.c: 本ヘッダーで宣言された API の実体を実装しているペアファイル。
  • src/include/storage/sharedfileset.h: 共有メモリ環境や複数プロセス間で FileSet を拡張して利用するための関連コンポーネント。

読者向けメモ

  • FileSet が使用するテーブルスペース配列のサイズは最大 8 まで固定されています（通常の設定では十分であるという仮定に基づきます）。
  • 自動的なガベージコレクションは行われないため、呼び出し側が責任を持って FileSetDelete または FileSetDeleteAll を呼び出す必要があります。
