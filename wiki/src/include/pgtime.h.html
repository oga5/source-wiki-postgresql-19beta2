src/include/pgtime.h

概要

src/include/pgtime.h は、PostgreSQL の内部タイムゾーンおよび時刻計算ライブラリの公開インターフェースを定義するヘッダーファイルです。標準の C ライブラリにおける時間関数群（<time.h>）に類似した API を提供しつつ、64ビット符号付き整数型を基本とすることで 2038年問題に対処しています。

モジュール内での役割

src/include モジュール内において、日時・タイムゾーン処理の基礎型や関数プロトタイプをカプセル化する役割を持ちます。実際の処理実装は src/timezone/localtime.c、src/timezone/strftime.c、src/timezone/pgtz.c などの別ファイルに委譲されています。

責務

  • **型定義の提供**: 64ビット符号付きの時刻型 pg_time_t や、分解された時刻を保持する pg_tm 構造体の定義。
  • **タイムゾーン管理インターフェースの宣言**: 内部構造体が隠蔽された pg_tz および pg_tzenum 型を介したタイムゾーン操作関数の宣言。
  • **グローバル変数とコンテキストの公開**: セッションおよびログ用のタイムゾーン変数の宣言と初期化関数の公開。

重要なシンボル

時間型とデータ構造

  • pg_time_t: 64ビット符号付き整数型 (int64)。時刻を表現するための標準型であり、プラットフォーム依存の time_t の制限を回避します。
  • struct pg_tm: 分解されたタイムスタンプを保持する構造体。IANA タイムゾーンライブラリの規約に従い、tm_mon が 0 から始まり、tm_year が 1900 年からの相対値である点について注意書きが明記されています。
  • struct pg_tz / struct pg_tzenum: タイムゾーンの内部表現および列挙状態を保持する不透明（opaque）構造体。

変換およびタイムゾーン関数

  • pg_localtime / pg_gmtime: pg_time_t と pg_tz を入力として、ローカル時刻またはグリニッジ標準時（UTC）の struct pg_tm を取得する関数。
  • session_timezone / log_timezone: それぞれセッションおよびログ出力で使用されるタイムゾーンを指すグローバル変数（PGDLLIMPORT）。

制御フローとデータフロー

本ファイルはインターフェース定義のみであり実行コードを持ちませんが、データフローの契約を規定しています。

  • クライアントコードは pg_time_t で時刻を保持し、pg_tzset や pg_tzset_offset で取得した pg_tz ポインタと組み合わせて pg_localtime に渡します。
  • 返された pg_tm 構造体は、PostgreSQL の日時関数や pg_strftime によって文字列へと変換されます。

直接依存

直接的な #include ディレクティブはこのヘッダー内には存在しません（インクルードガード _PGTIME_H のみ）。

関連コード

  • src/timezone/localtime.c: pg_localtime, pg_gmtime などの実装
  • src/timezone/strftime.c: pg_strftime の実装
  • src/timezone/pgtz.c: session_timezone, log_timezone, pg_tzset などの実装

読者向けメモ

  • **規約の違いに関する注意**: IANA タイムゾーンライブラリの tm_mon (0始まり) や tm_year (1900年相対) は、PostgreSQL の通常の datetime 関数（1始まり、1 BC相対）とは異なるため、コード間で値をやり取りする際には変換が必要です。
  • **メモリライフサイクル**: pg_tz および pg_tzenum の実体はライブラリ内部で管理され、外部からは不透明なポインタとして扱われます。
