src/include/access/tupdesc.h

概要

PostgreSQLのタプル（行）の構造を記述する TupleDesc（TupleDescData）および関連するデータ構造・マクロ・関数群を定義するヘッダーファイルである。 ストレージ上のカタログ情報や一時的な行型のレイアウトをメモリ上で効率的に表現し、タプルの変形（deformation）や制約の管理を支える。

モジュール内での役割

src/include/access モジュール内において、ヒープタプル (htup.h, htup_details.h) やテーブルアクセスメソッド (tableam.h) が扱うレコードの列構造を定義する中核的な役割を持つ。 対となるソースファイル src/backend/access/common/tupdesc.c と協調し、タプル記述子の生成、コピー、参照カウント管理、およびコンパクト属性の検証機能を提供する。

責務

  • タプル構造の定義: 列数、型ID、型モディファイア、および各属性のメタデータを保持する構造体の提供。
  • 最適化された属性表現 (CompactAttribute): 頻繁にアクセスされる属性情報をキャッシュし、タプル変形を高速化するための軽量構造体の定義。
  • 制約とデフォルト値の管理: 列のデフォルト値、チェック制約、NOT NULL制約、生成列（generated columns）の情報を保持する TupleConstr の定義。
  • ライフサイクルと参照カウント: キャッシュ内に保持されるタプル記述子の参照カウント（Pin/Release）管理の仕組みの提供。

重要なシンボル

タプル記述子とメタデータ構造

  • TupleDescData / TupleDesc: タプル構造全体を表現するメインの構造体（およびそのポインタ型）。柔軟な配列（フレキシブルアレイメンバ）として compact_attrs を持ち、その背後に FormData_pg_attribute の配列を配置するメモリレイアウトを採用している。参照カウントが >= 0 の場合はキャッシュ等で共有され、-1 の場合はエグゼキュータ等の非参照カウント用途となる。
  • CompactAttribute: FormData_pg_attribute の軽量・縮小版（8バイト）。attcacheoff、attlen、attbyval、NULL許容性などを保持し、タプル変形時のメモリアクセス効率を最大化する。
  • FormData_pg_attribute: 各列の詳細なカタログ定義データ（システムカタログ pg_attribute の行データ構造）。

制約とデフォルト値

  • TupleConstr: タプルに紐づく制約（デフォルト値、チェック制約、欠損値、NOT NULL、生成列のフラグなど）をまとめた構造体。
  • AttrDefault: 各列のデフォルト値表現（式ツリーの文字列表現 adbin を含む）。
  • ConstrCheck: チェック制約の定義（制約名、式ツリー表現、有効性など）。

アクセサとヘルパーマクロ

  • TupleDescAttr: 指定されたインデックス i の FormData_pg_attribute へのポインタを取得するインライン関数。
  • TupleDescCompactAttr: 指定されたインデックスの CompactAttribute を取得するインライン関数（アサートビルド時には verify_compact_attribute による整合性検証が行われる）。
  • TupleDescSize: TupleDescData 全体の必要メモリバイト数を計算するマクロ。

制御フローとデータフロー

1. 初期化とファイナライズ: CreateTemplateTupleDesc や CreateTupleDesc でメモリ確保を行った後、TupleDescInitEntry 等で各列を設定し、最後に TupleDescFinalize() を呼び出して firstNonCachedOffsetAttr や firstNonGuaranteedAttr などの最適化インデックスを確定させる。 2. 高速アクセスパス: エグゼキュータがタプルから値を取り出す際（タプル変形）、冗長な pg_attribute 全体を直接走査する代わりに、TupleDescCompactAttr を通じて CompactAttribute にアクセスし、アライメントや型長、NULL制約の状態を高速に判定する。 3. 参照カウント制御: キャッシュ（relcache/typcache）に格納される TupleDesc は PinTupleDesc（IncrTupleDescRefCount）と ReleaseTupleDesc（DecrTupleDescRefCount）のマクロによってライフサイクルが管理される。

直接依存

  • access/attnum.h: アトリビュート番号 (AttrNumber) の定義。
  • catalog/pg_attribute.h: FormData_pg_attribute の定義元。
  • nodes/pg_list.h: リスト構造 (List) の定義。

関連コード

  • src/backend/access/common/tupdesc.c: TupleDesc の実装本体（populate_compact_attribute、リソースオーナー連携、コピー関数など）。
  • src/include/access/htup_details.h: ヒープタプル内部構造とタプル変形処理。

読者向けメモ

  • メモリレイアウト: TupleDescData は可変長構造体であり、構造体本体の直後に CompactAttribute の配列が続き、そのさらに後ろに FormData_pg_attribute の配列が連続して配置される設計になっている。
  • CompactAttribute の更新ルール: FormData_pg_attribute を手動で変更した場合は、必ず明示的に populate_compact_attribute() を呼び出して compact_attrs 側のキャッシュを同期させる必要がある（アサートビルドでは不整合が検知される）。
