src/include/access/tupmacs.h

概要

src/include/access/tupmacs.h は、PostgreSQL のインデックス・ヒープタプル双方で共通して使用される、タプル属性へのアクセスや変形（deforming）のための低水準インライン関数およびマクロ群を提供する。タプルの NULL ビットマップ解析、値の取り出し（fetch）、アライメント調整、およびオフセット計算を効率的に行うためのロジックを集約している。

モジュール内での役割

src/include/access モジュール内において、本ファイルはタプルの物理レイアウトを直接操作するための基本プリミティブを提供する。上位のテーブルアクセス法（Heap AM）やインデックスアクセス法、あるいはタプルデスク関連のコードが、属性のオフセットや有無、長さを安全かつ効率的に計算する基盤となる。

責務

  • **NULL 状態の判定と変換**: タプルのビットマップから特定属性が NULL かどうかを判定し、あるいはビットマップ全体を論理的な真偽値配列へ高速に展開する。また、最初に見つかる NULL 属性の位置を高速に特定する。
  • **属性値の取得（Fetch/Store）**: attbyval や attlen に応じて、生データ領域から Datum への変換あるいはポインタの返却を行う。
  • **アライメントとオフセット計算**: データ型ごとのアライメント要件（TYPALIGN や CompactAttribute.attalignby）に基づき、可変長型（varlena）のショートヘッダー最適化を考慮しつつオフセットを進める。

重要なシンボル

NULL ビットマップ処理とデータ抽出

  • att_isnull: 指定された属性番号に対応するビットマップの位置を検査し、NULL であれば真を返す。
  • populate_isnull_array: タプルの NULL ビットマップを一括して bool 配列に変換する。32ビットの乗算トリック（SPREAD_BITS_MULTIPLIER_32）を活用し、8要素単位で高速に展開する。
  • first_null_attr: ビットマップのバイト単位の比較と pg_rightmost_one_pos32 を用いて、最初に出現する NULL 属性のインデックスを高速に探索する。

属性値の取得と書き込み

  • fetch_att: attbyval が真の場合は長さに応じて Datum に拡張して返し、偽の場合はデータ領域のポインタを Datum として返す。
  • fetch_att_noerr: fetch_att と同様だが、CompactAttribute 由来の安全性が保証されている場合にエラーチェックを省略して処理する。
  • align_fetch_then_add: アライメント調整、値のフェッチ、オフセットの加算を1つに統合したヘルパー。
  • ATT: マクロ名あるいは仮引数名として、属性インデックスを指すプレースホルダ。

型情報とアライメント

  • Datum: PostgreSQL の汎用データ表現型。
  • Form_pg_attribute: システムカタログ pg_attribute の行構造体へのポインタ型。
  • CompactAttribute: 最適化された属性定義のコンパクト表現。
  • ALIGNOF_DOUBLE, ALIGNOF_INT, ALIGNOF_SHORT: 各基本型のシステム固有のアライメント境界。

制御フローとデータフロー

1. **タプルデフォーム時**:

  • align_fetch_then_add や各 att_align_pointer マクロを経由して、現在のタプル内オフセット (*off) を型のアライメント要件に合わせて切り上げる。
  • 可変長型（attlen == -1）の場合、VARATT_NOT_PAD_BYTE や VARATT_IS_SHORT をチェックし、ショートヘッダーであればアライメント調整をスキップする。
  • データ領域から fetch_att または直接ポインタ経由で Datum を取得し、オフセットに attlen または可変長の実サイズ（VARSIZE_ANY）を加算する。

    • 2. **NULL 判定時**:

  • att_isnull がビット演算（ATT >> 3 と 1 << (ATT & 0x07)）によって直接ビットマップバイトをマスクし、高速に判定を行う。

直接依存

  • catalog/pg_type_d.h: TYPALIGN マクロ群を提供。
  • port/pg_bitutils.h: ビット操作ユーティリティ（例: pg_rightmost_one_pos32）。
  • port/pg_bswap.h: エンディアン変換（pg_bswap64）。
  • varatt.h: 可変長属性（varlena）の操作マクロ。

読者向けメモ

  • **メモリ安全性**: 本ファイル内のインライン関数およびマクロは、渡されたポインタやオフセットが有効なタプル領域内を指していることを前提とする。境界チェックの多くは呼び出し側の責務である。
  • **エンディアン考慮**: populate_isnull_array などでは、ビッグエンディアン環境において pg_bswap64 を用いてバイトオーダーを適切に補正している。
  • **FRONTEND ガード**: 一部の関数（fetch_att, first_null_attr, store_att_byval など）はバックエンド専用（#ifndef FRONTEND）として保護されている。
