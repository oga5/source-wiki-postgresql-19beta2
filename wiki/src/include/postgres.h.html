src/include/postgres.h

概要

PostgreSQLサーバーのバックエンドモジュールにおいて最初にインクルードされる主要なヘッダーファイルです。バックエンド全体で必要とされる広範な宣言のうち、クライアント側（フロントエンド）へは漏らさずバックエンド内部に閉じるべき表現（Datum 型やその変換関数群など）を集約しています。

モジュール内での役割

src/include モジュールおよびバックエンド全域の基盤に位置します。基本的な型定義を共有する c.h を内包しつつ、バックエンド専用のデータ表現や定数を提供することで、パーサ、プランナ、エグゼキュータ、ストレージ層といったあらゆるバックエンドサブシステムに型変換の共通基盤を提供します。

責務

  • Datum 型および関連するサポート関数・マクロの定義（値のエンコード・デコード）。
  • 値とNULL状態を効率よく保持するための構造体（NullableDatum）の提供。
  • 3値論理を表現する pg_ternary 型の定義。
  • EXEC_BACKEND ビルド構成をサポートするための NON_EXEC_STATIC マクロの提供。
  • バックエンド全体で共通して必要となるエラー処理（utils/elog.h）やメモリ割り当て（utils/palloc.h）ヘッダーのエクスポート。

重要なシンボル

Datum 型と変換関数

  • Datum: 64ビット符号なし整数（uint64_t）として定義される汎用型。値渡し型の中身または参照渡し型のポインタを保持します。
  • NullableDatum: Datum の値とそれがNULLかどうかのフラグ（isnull）を同一構造体に保持し、配列等での空間的局所性を高めるための構造体。
  • DatumGetBool / BoolGetDatum: Datum と bool 間の相互変換を行います（非ゼロ値を真とみなします）。
  • DatumGetChar / CharGetDatum: Datum と char 間の相互変換を行います。
  • DatumGetUInt8 / UInt8GetDatum: Datum と 8ビット符号なし整数間の相互変換を行います。
  • DatumGetInt16 / Int16GetDatum: Datum と 16ビット整数間の相互変換を行います。
  • DatumGetInt64 / Int64GetDatum: Datum と 64ビット整数間の相互変換を行います。コンパイラやプラットフォームに依存しない値のやり取りを支えます。

3値論理・ユーティリティ

  • pg_ternary: PG_TERNARY_FALSE（0）、PG_TERNARY_TRUE（1）、PG_TERNARY_UNSET（-1）を持つ列挙型。真・偽に加えて「未設定」を区別したい用途で使用されます。

制御フローとデータフロー

本ファイルは純粋なヘッダーファイル（型定義、インライン関数、マクロ）であるため、独自の制御フローや手続き的データフローは持ちません。 データフロー上の役割として、関数実行エンジン（fmgr）やエグゼキュータがSQLオペランドや関数引数をやり取りする際、各種 *GetDatum や DatumGet* インライン関数を介してC言語のネイティブ型と汎用 Datum 型の間をロスレスに変換するために利用されます。

直接依存

  • c.h: プリミティブ型定義やOS共通のマクロを提供します。
  • utils/elog.h: エラーログ・メッセージ出力機構を提供します。
  • utils/palloc.h: バックエンドのメモリコンテキストベースの割り当て機能を提供します。

関連コード

  • src/backend/tcop/postgres.c: 本ヘッダーをインクルードし、バックエンドのメイン処理およびトラフィックコップの制御を行うファイル。
  • src/include/postgres_fe.h: フロントエンド（クライアント側コード）向けの対応ヘッダー。

読者向けメモ

  • **メモリ所有権とライフタイム**: 参照渡しの Datum（例: CStringGetDatum や PointerGetDatum）を利用する場合、指し示されているメモリ領域が利用期間中有効であること（適切なメモリコンテキストで管理されていること）は呼び出し側の責任となります。
  • **型安全性の工夫**: PointerGetDatum マクロでは true ? (X) : NULL という条件式を用いることで、引数 X がポインタ型でない場合にコンパイルエラーを発生させる安全機構を備えています。
  • **浮動小数点数変換**: DatumGetFloat4 や Float8GetDatum 等では、ビットパターンの安全な変換を行うために union を用いた型 punning が行われています。
