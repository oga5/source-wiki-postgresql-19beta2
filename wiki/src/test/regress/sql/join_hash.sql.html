src/test/regress/sql/join_hash.sql

概要

PostgreSQLのハッシュ結合（Hash Join）コードに対する回帰テストスイート。プラン作成、メモリ管理、バッチ分割、並列ハッシュ結合（Parallel Hash）、動的バッチ増加、巨大タプル処理、HOTステータスビット再利用、およびサブプラン・パラメータを持つハッシュキーの振る舞いを検証する。

モジュール内での役割

PostgreSQLの公式リグレッションテストフレームワーク（src/test/regress/）の一部として配置され、実行時プランナーとエグゼキューターにおけるハッシュ結合の実装正確性と堅牢性を担保する。

責務

  • **ハッシュ結合プランと実行結果の検証**: 最適（Optimal）、良好（Good）、不良（Bad）、極端に偏った（Ugly）ワークメモリ配分シナリオ下でのバッチ数の増減挙動確認。
  • **並列ハッシュ結合の検証**: 並列非認識型（Parallel-oblivious）および並列認識型（Parallel-aware）ハッシュ結合、さらにリーダー不参加やフルアウター結合での動作検証。
  • **特殊ケースのエッジケース検証**: 巨大タプル（Detoasted tuple）のロード、HOTステータスビットのクリア検証、サブプランを含むハッシュキー参照、およびLateralリファレンスを伴う再スキャン防止の確認。
  • **テスト用補助関数の提供**: EXPLAIN (ANALYZE, FORMAT JSON)出力からプランツリーを走査し、ハッシュノードのバッチ数を抽出するPL/pgSQL関数を定義。

重要なシンボル

補助関数

  • find_hash(node json) returns json: JSON形式のプランツリーを再帰的に走査し、Node Type が Hash であるノードを返す。
  • hash_join_batches(query text) returns table (original int, final int): 指定されたクエリに対して EXPLAIN (ANALYZE, FORMAT JSON) を実行し、find_hash を通じて初期ハッシュバッチ数（Original Hash Batches）と最終ハッシュバッチ数（Hash Batches）を抽出する。

テスト用スキーマとテーブル

  • simple: 20,000行の正常に分散されたキーを持つ基準テーブル。
  • bigger_than_it_looks: 統計情報を過小評価（実際20,000行だが1,000行と偽装）させたテーブル。
  • extremely_skewed: 単一キーに20,000行が集中する極端な偏りを持たせたテーブル。
  • wide: 320,000バイト超の巨大タプルを持つテーブル。
  • hjtest_matchbits_t1 / hjtest_matchbits_t2: HOTタプル更新とマッチビットクリア検証用の小規模テーブル。
  • hjtest_1 / hjtest_2: サブプランを含むハッシュキー式を検証するためのテーブル。

制御フローとデータフロー

1. **設定と環境構築**: セッションまたはトランザクションスコープで work_mem, enable_parallel_hash, max_parallel_workers_per_gather などのパラメータを SET LOCAL で調整する。 2. **クエリ実行とプラン検証**: EXPLAIN（または EXPLAIN ANALYZE）により実行計画の構造を確認した後、実クエリを発行して結果セットの正しさを保証する。 3. **動的バッチ計測**: hash_join_batches() を呼び出し、実行中のメモリ不足などによってバッチ数が意図通りに増加したかをJSONプラン解析経由で検証する。 4. **ロールバック**: 各テストブロックはセーブポイント (SAVEPOINT settings, ROLLBACK TO settings) またはトランザクション全体 (BEGIN, ROLLBACK) で隔離され、状態をクリーンに保つ。

直接依存

  • PostgreSQLのPL/pgSQL言語サポート（json 型操作関数: json_array_elements, json_extract_path, ->, ->>）。
  • PostgreSQLのプランナーおよびエグゼキューター設定パラメータ（enable_hashjoin, enable_parallel_hash, work_mem, hash_mem_multiplier 等）。

関連コード

  • src/backend/executor/nodeHash.go / nodeHashjoin.c: ハッシュ結合の実行時実装。
  • src/backend/commands/explain.c: JSONフォーマットの EXPLAIN ANALYZE 出力生成。

読者向けメモ

  • 本ファイル内のテストは動的なメモリ制限（work_mem = '128kB'など）を多用するため、システム環境やデフォルトのページサイズに依存しないよう厳密なセッション変数制御が行われている。
  • ハッシュキーのマッチビット検証では、HOT更新されたタプルのフラグクリア漏れがフルアウター結合の結果に影響を与えるバグ（過去の不具合）を再現・防止している。
