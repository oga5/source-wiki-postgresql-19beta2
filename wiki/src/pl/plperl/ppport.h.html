src/pl/plperl/ppport.h

概要

src/pl/plperl/ppport.h は、CPAN の Devel::PPPort を基に自動生成された巨大な互換性ヘッダーファイルです。異なるバージョンの Perl インタープリター間で拡張モジュール（XS）をコンパイル・実行できるようにするためのマクロや、古い Perl バージョンに向けたバックポート関数を提供します。PostgreSQL の PL/Perl サブシステムにおいて、C 言語から Perl API をバージョン非依存で安全に呼び出すための基盤となります。

モジュール内での役割

本ファイルは src/pl/plperl ディレクトリに属し、plperl.c や plperl.h などの主要なソースファイルからインクルードされます。Perl のバージョンアップに伴う API の変化やスレッドコンテキスト（aTHX 等）の差異を吸収し、PostgreSQL のビルド環境でターゲットとする古い Perl から新しい Perl まで一貫したビルドを保証する役割を持ちます。

責務

  • Perl バージョン判定マクロ（PERL_VERSION_GE, PERL_BCDVERSION など）の提供
  • スレッドコンテキストマクロ（pTHX, aTHX 等）の抽象化と未定義環境へのフォールバック
  • 廃止された Perl API やバージョン依存の関数・変数（PL_parser, newCONSTSUB など）の互換レイヤー提供
  • 数値パース系ヘルパー（grok_number, grok_bin 等）や文字コード処理（UTF-8, ロケール）の互換実装

重要なシンボル

コア互換・スレッドコンテキスト

  • pTHX: スレッド有効な Perl 環境におけるインタープリター構造体ポインタ型 (PerlInterpreter *)。
  • pTHX_: pTHX にカンマを付加した型宣言用マクロ。引数リストの先頭で使用。
  • ARGSproto: プロトタイプ宣言用のスレッド引数定義マクロ。

データ型と数値処理

  • NV: Perl の浮動小数点数型 (double または long double)。
  • DPPP_: 名前空間衝突を避けるためのプリフィックス生成用マクロ。

コールスタックおよび実行制御

  • DPPP_dopoptosub_at: cxstack を走査し、指定されたブロックインデックスから最も近いサブ・評価ブロックのコンテキストインデックスを返すヘルパー関数。

制御フローとデータフロー

本ファイルは主にプリプロセッサーマクロとインライン/スタティック関数群で構成されており、独自の独立した制御フローを持ちません。代わりに、plperl.c などのコードが Perl API（例: grok_number や caller_cx）を呼び出した際、コンパイル時の Perl バージョンに応じて本ファイル内のバックポート実装（例: DPPP_(my_grok_number) や DPPP_(my_caller_cx)）へディスパッチまたはインライン展開されます。

  • **データフロー**: PostgreSQL のクエリや引数を表す Perl の SV*（Scalar Value）や HV*（Hash Value）に対し、型変換マクロ（SvIV, SvPV 等）や sv_setuv を介して安全にデータ入出力を行います。

直接依存

  • ppport.h 自体（自己完結型のスクリプトおよびヘッダー）
  • <locale.h>（ロケールおよび数値基数処理用）

読者向けメモ

  • **メモリ所有権**: 本ファイル内で提供される関数（例: newCONSTSUB, newSVpvn_share）が生成するオブジェクトのライフサイクルやメモリ管理は、Perl インタープリターのモルタルスタックやガーベッジコレクションに依存します。
  • **自動生成の注意**: ファイル冒頭に記載がある通り、本ファイルは直接編集すべきではありません（Devel::PPPort によって管理されます）。
